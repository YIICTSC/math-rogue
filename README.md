「学習ローグ」は、問題に答えながらカードやレリックを集め、デッキを育てて冒険する学習ローグライクです。小・中学校の学習指導要領に沿った単元を中心に、高校以上・大人まで楽しめる問題を収録しています。小学生編・高校編・マジック編のテーマ、カードバトル、放課後ポーカーや校庭サバイバーなどのミニゲームを楽しめます。メインゲームとミニゲームは縦画面・横画面の両方に対応しています。

PC・タブレット・スマートフォンのブラウザに対応しています。ゲーム開始操作後は、対応端末で全画面表示へ切り替わります。

## ゲームの流れ

1. 学年・学習分野・出題方法を選ぶ
2. 問題に正解して、冒険に必要な力や報酬を得る
3. カード、レリック、ポーションを組み合わせてデッキを育てる
4. 戦闘・イベント・ボスを突破し、冒険のクリアを目指す
5. 学習記録や冒険記録を振り返り、オンラインランキングにも挑戦する

## 現在の主な機能

### 学習

- 小学1年〜中学3年を中心とした算数・数学、国語・漢字、英語、生活、理科、社会
- 高校以降にもつながる数学・理科・社会・英語・情報・小論文・実用分野
- 選択式、入力式、問題読み上げ、タイピング系モード
- 日本語、ひらがな中心表示、英語表示
- 日別・単元別の正解数、正答率、苦手克服、学習進度の記録

### 冒険とカード

- 小学生・高校生・魔法世界の3テーマ
- カードバトル、マップ分岐、イベント、ショップ、ボス戦
- カード強化・合成、レリック、ポーション、キャラクター育成
- 1人用冒険に加え、合言葉で参加する協力プレイと学習レース
- 日替わり課題、教員配信課題、ランキング入賞による報酬カード

### ミニゲーム

- 放課後ポーカー
- 校庭サバイバー
- 風来の小学生 / 風来の小学生2
- 校長対決
- 紙飛行機バトル
- 帰宅ダッシュ

### オンラインランキング

ランキングは「問題・課題」「冒険・協力」「カード」「ミニゲーム」のカテゴリから詳細項目を選べます。各画面には集計方法も表示されます。

- 今日・今週・今月・シーズン・歴代の期間別集計
- 正解数、正答率、課題達成、冒険スコア、カード性能、各ミニゲームなど多様な項目
- 個人記録と、協力プレイのチーム記録
- 自動生成または自由入力で決める公開名（後から変更可能）
- いずれかの対象ランキングで3位以内に入賞した際の報酬カード
- 端末連携、記録の同期、受賞したランキング名と順位の確認

記録は端末内へ先に保存され、プレイ中の節目とランキング画面を開いた際に同期されます。一時的に通信できない場合も、送信待ち記録を保持して後から再送します。

### 保護者・教員向け連携


[学習ローグ 管理ポータル](https://learning-rogue-management.yishigeict.chatgpt.site/)を公開しています。家庭・学校の初期設定から、児童の招待、教材作成、課題配信、学習状況の確認までブラウザ上で行えます。

管理画面は次の5項目に整理されています。

| 大項目 | 主な機能 |
| --- | --- |
| ホーム | 登録人数、正答率、配信中課題、達成率の概要 |
| 学習状況 | グループ・児童別の進捗、自習内容、課題別の実施状況 |
| 課題・教材 | 課題の作成・配信、オリジナル教材、公開教材の活用 |
| グループ | 家庭・学校・学年・クラス、所属、教職員、招待URL、年度更新 |
| 管理 | 稼働状況、端末、データ削除、監査履歴 |

現在利用できる主な管理機能は以下のとおりです。

- 初回ログイン時に家庭または学校を選び、最初のグループまで作成
- 家庭、学校、年度、学年、クラス、特別支援、部活動など複数グループへの所属
- 児童・生徒と教職員を共通URLで招待し、児童側は学習ローグから参加
- 氏名・表示名、出席番号、学年、所属グループの管理者・教員による修正
- 出席番号順の児童一覧と、最大2,000人の名簿CSV一括取込
- 学習ローグ本編の全対応単元、複数単元、オリジナル教材を使った課題配信
- グループまたは個人への配信、予約配信、期限、ご褒美カードの設定
- グループ・児童ごとの学習進度、課題結果、自習内容、再挑戦、学習時間の確認
- 自分が配信した課題ごとの「未着手・取組中・達成済み」を出席番号順に確認
- 教職員の担当範囲と課題配信権限、年度更新・異動、監査履歴、削除手続き

#### 課題の強制力

| 設定 | 学習ローグ側の動作 |
| --- | --- |
| 任意課題 | 課題受信箱から児童が自由に選択 |
| 必須課題 | 通常の学習前に、期限の早い順から開始 |
| 最優先課題（起動時開始） | 起動時のオンライン確認後、問題チャレンジを自動開始 |

最優先課題は誤配信と解除不能を防ぐため、グループ配信・問題チャレンジのみ・期限設定を必須にしています。期限切れ、達成、配信者または管理者による配信停止で強制状態が解除されます。通信できない場合は端末をロックしません。

#### オリジナル教材

- 問題数の固定上限なし
- 画面上での問題作成とCSVテンプレートからの一括準備
- 数式入力、問題・選択肢への画像挿入
- 1番目の選択肢を正答として固定し、ゲーム側で選択肢をシャッフル
- 非公開、組織内公開、一般公開の公開範囲
- 教科・学年・キーワードによる公開教材の検索と再利用
- 各教科30問の公式公開教材

学習ローグと連携した児童には、複数の所属先と課題の配信元グループが表示されます。進捗同期では課題ID、単元、正誤、再挑戦、所要時間などの集計情報を扱い、問題文や児童が入力した解答本文は管理ポータルへ送りません。

詳細は[保護者・教員向けグループ管理システム導入案](./docs/guardian-educator-group-management-introduction-plan.md)を参照してください。

## データとプライバシー

- プレイデータは基本的に利用中のブラウザ内へ保存されます。
- 配信元や端末を変えると保存領域も変わるため、必要に応じてゲーム内のデータ書き出し・読み込み、または端末連携を利用してください。
- オンラインランキングには公開名と集計に必要な記録を送り、本名・学校情報・解答内容は送信しません。
- 公開名は不適切語の検査対象です。実名や個人を特定できる名前は使用しないでください。
- 保護者・教員向け機能は、招待URLまたは端末連携コードによる明示的な連携後に利用します。
- 管理ポータル、公開ランキング、ゲーム本体は用途と保存データを分離しています。

## ローカル開発

Node.js と npm が必要です。

```bash
npm install
npm run dev
```

開発サーバーは `http://localhost:5173/` で起動します。同じネットワークの別端末からは、起動時に表示される `Network` URLを利用できます。

```bash
npm run build
npm run preview
```

本番ビルドのプレビューは `http://localhost:4173/` で起動します。

### 主なコマンド

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | Vite開発サーバーを起動 |
| `npm run dev:debug` | ローカル開発限定でデバッグ機能を有効化 |
| `npm run build` | Web版を本番ビルド |
| `npm run preview` | 本番ビルドをローカル確認 |
| `npm run audit:hiragana` | ひらがな表示の監査 |
| `npm run audit:english` | 英語表示の監査 |
| `npm run test:management` | 管理システム連携を検証 |
| `npm run dist:offline` | Windows向けオフライン版を生成 |
| `npm run build:ios` | 時間制限なしのiOS有料版Web資産を生成 |
| `npm run ios:sync` | iOS向けWeb資産とネイティブ依存を同期 |
| `npm run ios:open` | XcodeでiOSプロジェクトを開く |
| `npm run ios:prepare-simulator` | Simulatorの初回共有キャッシュを生成 |
| `npm run ios:run` | iPhone Simulatorへビルド・インストール・起動 |

## 公開構成

ゲームのメイン入口はChatGPT Sites版です。GitHub Pagesを通常のゲーム配信元とし、Vercelを予備配信元として利用します。公開ランキングと認証必須の管理ポータルは、ゲーム本体および互いのデータを分離した専用Sitesとして運用しています。`main` ブランチへのpushでGitHub Pagesのデプロイが実行されます。

```text
ChatGPT Sites（メイン入口）
├─ GitHub Pages（通常配信）
├─ Vercel（予備配信）
├─ ランキングホール（公開名と集計記録）
└─ 管理ポータル（認証、所属、教材、課題、非公開進捗）
```
