# 学ロクラフト

オリジナルのアイソメトリック共有島ゲーム。画像・音声・ROMからの素材抽出は行っていない。

## 入口と学習

- タイトルの RPG・カートと同じ列に、デバッグモード時だけ入口を表示。
- `pnpm run dev:debug` で開発用フラグを有効にし、通常のタイトル操作でデバッグを有効にする。
- ホストが学習ローグ共通の問題選択で教科・単元・範囲または配信課題を指定する。4択固定。
- `?craftRoom=ABC234` の招待リンクはデバッグなしで参加可能。参加者には部屋作成・ソロの入口を表示しない。招待URLには課題やデバッグの別パラメーターを持ち込まない。
- 常設の問題ボタンから回答し、正解ごとにエネルギーを30回復（最大100）。不正解での消費はなく、エネルギー0でも回答できる。
- 選択範囲から最大36問を抽出して繰り返し出題。問題文・図・文章・音声出題に対応。回答は学習履歴にも保存し、ホストの配信課題は既存の課題記録へ連携。

## 遊び方

- WASD・矢印キー・タッチ方向パッドで移動。近くのマスをクリック／タップして、道具を選び作業ボタン。
- 木・石の採集、クラフト、木の床・石ブロックの4段建築、屋根・窓・フェンス、花壇・ランタン・ベンチ・たき火の配置。木の床で水上に橋を架けられる。採集・建築・片づけは作業ボタン長押しで連続実行。
- 種まき→90秒（水やりで45秒）→収穫。雨の日は畑が自動で水やりされる。果実は木を残して摘め、45秒で再び実る。
- 釣りは作業ボタンで投げ、浮きが沈んでから1.5秒以内に再度押して引き上げる。最初の0.5秒なら魚2匹、通常は1匹。早すぎる引き上げ、時間切れ、移動、問題への切り替えで釣りを中断。
- たき火の近くで作物2・魚1・果実1から料理を作り、食べると60秒間移動速度アップ。料理はエネルギーを回復しない。広場へ作物・魚を納品すると種2個と3コインを獲得し、お店で種（2コイン）・花壇（5コイン）を購入できる。
- 採集5、釣りは投げる2＋成功した引き上げ6、その他の作業・クラフト3エネルギー。移動は実際に進んだ距離で消費。衝突中には無駄に消費しない。
- 人間・ねこ・いぬ・うさぎ・きつね・くま・パンダ・ことり・かえるの9種類。髪型10、表情10、服装12、帽子9、小物6と肌8・髪12・服12・ズボン8・毛色10色を組み合わせる。ロビーと島の「見た目」で編集、おまかせ作成、端末保存、参加者への同期に対応。プレビューとゲーム内に同じオリジナルSVGを使い、動物の耳・しっぽ、服の形、表情を反映する。
- 足音、採集、種まき、水やり、収穫、果実摘み、釣り、クラフト、建築、片づけ、納品、購入、料理、正誤のオリジナル合成SE。最初のタップ／キー操作でWeb Audioを有効化し、SEボタンでオン・オフを保存。作業成功は粒子・波紋・腕の動きで表示。
- 他の人の建築は変更不可。作物は共同で世話・収穫可能。採集した資源は180秒後に復活する。
- ホスト端末の localStorage に5秒ごと／退出時に島とホストの持ち物を保存。「保存した島を続ける」で再開。ゲストの持ち物・エネルギー・依頼・自宅もホスト端末に保存し、同じブラウザの参加者識別子で再参加すると引き継ぐ。識別子と保存台帳は他の参加者へ送信しない。旧形式で参加者記録のない島だけ、過去の建築をホストへ引き継ぐ。

## 長期目標

- 納品・収穫・新しい場所への建築で島が5段階に発展し、資材・家具・建築資材などのお店が順に解放される。同じ場所の建築と片づけでは発展ポイントを増やせない。
- ソラ・ミドリ・ミナトの常設依頼8種類を最大3件受注し、採集・収穫・釣り・納品・家づくりで報酬を獲得する。島の1日（4分）ごとに3種類の日替わり依頼も更新される。報酬は各依頼につき一度だけ受け取れる。
- 広場から離れた空き地に木材6・石4で自宅の入口を建築。室内にベンチ・ランタン・花壇・たき火を配置でき、島の発展と材料・コインに応じて4×4→6×6→8×8へ拡張する。家具は回収して再利用できる。室内でも問題でエネルギーを回復できる。
- 発展段階、依頼、自宅、家具配置を保存し、接続し直しても継続できる。室内操作、報酬、購入、所有権、拡張条件はホストが検証する。

## 通信と運用

- PeerJS/WebRTC のホスト権威方式。ホストを含め40人、41人目は拒否。専用の永続サーバーではない。
- 20Hzシミュレーション、約6.7Hzプレイヤー同期、更新されたマスだけ差分同期。初回ワールドは64マス単位に分割。送信滞留時は状態送信を間引く。
- ホストが移動・距離・所持品・エネルギー・採点を検証。クライアントへの問題に正解番号を含めず、単発トークンで回答再送を無効化。
- ホスト画面がバックグラウンドになると全員を一時停止。ホスト退出・接続断では部屋終了（ホスト移譲なし）。ホストは画面を開いたままにする。
- 既存の `VITE_RPG_PEER_HOST / PORT / PATH / SECURE` を利用。ICEは `VITE_CRAFT_ICE_SERVERS`、未設定なら `VITE_KART_ICE_SERVERS`、それもなければPeerJS既定値。学校等で直接WebRTCが遮断される場合は運用側でTURNを設定する。
- 通信プロトコルv4。新旧クライアントは混在させず全員がページを更新する。v1形式の保存島・旧形式の外見は新しい項目の初期値を補って読み込む。
- 接続上限の検証はローカルPeerServerと実WebRTCの40接続で実施。40台の実端末・学校回線での性能や接続可否は別途実地確認が必要。

## 検証

```sh
node scripts/test-craft.mjs
node scripts/test-craft-progression.mjs
node scripts/test-craft-browser.mjs
pnpm run audit:english:gate
pnpm run build
```

ブラウザテストはPC・スマホ・タブレット・横画面の表示、問題選択ハイライト、エネルギー0からの回復、招待ルート、40接続での共有作業・回答・退出・再参加時の家と進捗の引き継ぎを検証。進行テストは報酬の重複防止、家具の保存・回収、拡張条件、島の再開を検証。画像は `tmp/craft-qa` に出力。
