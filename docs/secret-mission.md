# 学習ローグ SECRET MISSION

GAKURO VRのタイトル画面から選べる、リアルタイムの学習・推理対戦。夕暮れの学園、軌道船こもれび、星図の魔法学校、鐘灯の地下遺跡の4マップから選ぶ。

## モード

| モード | 開始条件 | 遊び方 |
| --- | --- | --- |
| 通常対戦 | 6〜15席 | 学習任務、妨害、通報、議論、投票で勝敗を決める |
| 大人数対戦 | 16〜40席 | 拡張マップを全員で遊ぶ。設定で15人以下の均等な班に分かれ、同時に開始できる |
| 授業モード | 6〜40席 | 教員はプレイヤーまたは進行役を選ぶ。進行役の席は40人の定員外。複数班を切り替えて観戦・進行できる |
| CPU練習 | 1人と5〜14体のCPU | 通信なしで通常ルールまたは鬼ごっこ。オンラインの空席にもCPUを追加できる |
| 鬼ごっこ | 6〜15席 | 会議なし。正解で加速、隠れ場所、時間短縮を順に得る。制限時間まで逃げ切るか、共同任務を達成する |

オンラインは6桁コードと招待URLで参加する。参加名にアカウント登録は不要。ホストが途中参加を許可すると、探索中はゴーストで合流して学習に加われる。切断後は35秒を目安に、同じタブからの再接続やページ更新で席を引き継げる。通常対戦は猶予経過後にホストを移し、授業モードは教員が離席した間に停止し、戻らなければ安全に終了する。

## 探索と会議

- 移動はWASD、方向キー、画面左下のスティック。Eで施設操作、Rで通報、Qで役職の行動、Mで地図。右下のボタンから同じ操作ができ、キー割り当てと描画品質は対戦中の設定で変更できる。
- 緑の端末は自分の任務。学習問題に加え、番号の並べ替え、配線、記憶、盤面パターン、タイミングの操作がある。低難度は問題だけで進められる。聞き取り問題は共通の読み上げとBGMミュートを使う。
- 停電はクルーの視界、通信障害は地図とカメラに影響する。扉は時間経過か近くの操作で開放できる。重大な設備異常は別々の2端末での復旧が必要。
- ゴーストは会議の発言・投票ができない。学習を継続でき、共同任務への加算を無効にした部屋では個人練習を選べる。終了後にも練習問題を続けられる。
- クルー側5種、裏切り者側3種、第三陣営2種の特殊役職を設定できる。トリックスターが投票で追放された場合はターン終了後に単独勝利し、サバイバーは生存したとき勝利陣営と勝利を共有する。

## 授業と記録

既存の単元選択と配信課題を利用できる。授業モードでは司会が問題を作成し、定型文、自由入力、チャット停止を選べる。教員は一時停止、時間延長、会議の招集、投票の終了、参加者の退出、班切替、集計のCSV出力ができる。

個人の正答率・問題別の集計は、本人と作成時の教員のみに表示する。部屋の授業集計はサーバーのメモリーに保持し、再戦または部屋終了で削除される。CSVは教員の端末に保存される。XP、称号、トークン、交換したエモートはプレイしたブラウザやアプリに保存される。見た目とエモートによる能力差はない。

## 確認方法

- `pnpm run test:secret-mission` は壁・視界、役職と問題の公開範囲、再回答、任務、妨害、投票、再戦を検査する。
- `pnpm run test:secret-mission:online` は実際のWebSocket接続で6・10・15・20・30・40人の開始と移動、班分割、40人時の席の復帰、教員権限を検査する。
- `pnpm run test:secret-mission:browser` はChromiumのタッチ画面でVR内の導線、CPU練習、3D描画、縦横操作、招待URL、授業用の画面を確認し、スクリーンショットを一時ディレクトリに保存する。

本番のオンライン通信は既存の専用サーバーに `/secret-mission` が反映された時点で利用できる。CPU練習には専用サーバーは不要。
