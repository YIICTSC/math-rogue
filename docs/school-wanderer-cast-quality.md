# 風来の小学生：仲間・敵・アイテムのスタイル展開

承認された約2.5頭身の主人公を保持し、丸い輪郭、黒い縦楕円の目、まとまった髪、文房具装備、適度な反射という基準を他素材へ展開した。主人公の `hero-quality.glb` を再生成・上書きせず、追加キットに分けている。

## 成果物

- `public/models/school-wanderer/cast-quality.glb`：86モデル、5,705,128 bytes。
- `assets/school-wanderer/cast-quality/cast-quality.blend`：編集可能な素材一覧。
- `assets/school-wanderer/cast-quality/manifest.json`：全モデル名・配色・アニメーション一覧。
- 確認用PNGはゲームで使用しないため削除した。再生成時の出力先はGit管理外の `tmp/school-wanderer-review/cast/`。
- `scripts/blender/build-school-cast.py`：再現可能な生成・レンダリング・GLB出力スクリプト。

## キャラクター

保健係あおいは回復ポーチ、体育係たけるは腕当て、図書係ひなたは本。髪型・配色・所持品で役割を分けた。先生は眼鏡、購買部員は帽子とエプロン、校長は口ひげと校章、忍者は覆面、魔法使いは帽子、ガキ大将は体格とスポーツ型の髪で区別する。これらの髪型・衣装の細部は既存の役割を基にした今回のデザイン案で、追加の公式設定としては扱わない。

## 敵

スライム、コウモリ、浮遊霊、トド、くさった死体、ドラゴン、植物、人体模型、ノート、跳び箱ミミック、消しゴム、おにぎり、火の玉、ほこり、時計、紙、封印シール、筆箱、居残りおばけ、長ぐつ、傘、芽ばえ、メタル系、テスト、ボールを作り分けた。牙・羽・尾・足・本のページなどを用途に応じて配置。敵の名前や行動、戦闘能力は保持する。

以前はトドを忍者モデル、校長を一般の先生、筆箱や消しゴムを汎用敵に割り当てていた箇所も、それぞれのモデルへ変更した。

## アイテム

既存アイテムはカテゴリー別のモデル群と種類ごとの配色で表現する。86モデルは86個のアイテムIDと一対一ではなく、キャラクター・敵・家具を含む基本モデルの総数。

コンパス、分度器、消火器、つるはし、刃物、時計、草、肉、爆弾、チョーク、石、紙飛行機、容器、虫めがね、ホイッスル、浮き輪、お手入れ箱を追加。従来の汎用瓶・定規・腕輪への割り当てを減らし、形から用途を判断しやすくした。元の学校家具・その他の道具も面取り、法線、Smooth Shading、PBR素材を更新してキットに含めている。

新しい鉛筆ソードと校長の盾は承認済みの主人公GLBから利用する。同じアイテムは床に落ちているときと装備したときで同じモデルを使う。未識別のアイテムは固有の形を露出させない。

## 種類別・レベル別配色

敵種ごとに基本色とアクセントを定義した。スライムは青、コウモリは紫、ドラゴンは赤、植物は緑と桃色、トドは茶色、おにぎりは白と海苔の緑。時計は金、消しゴムは桃色と青、火の玉は橙、メタル系は銀。他の敵も種類別に配色を持ち、BlenderとThree.jsは同じ `enemy-palettes.json` を使用する。

レベル差は種類の色味を保持し、明暗・彩度・アクセントで6段階を区別する。Lvラベルは青・赤・紫・金・緑・暗赤の段階色と数値を併用する。Lv7以上も実数を表示する。

通常敵の出現階層の強さを `visualTier` に保存する。1〜5F、6〜10F、11〜15F、16F以降の4段階に、進化の `schoolRank` を加える。戦闘能力や経験値は変更しない。古いセーブは種別と最大HPから推定し、現在HPは用いない。商人・校長は専用配色を保持する。

## 移動・攻撃アニメーション

主人公の7動作を保持し、仲間・先生・人型の敵・モンスター計34モデルに `Idle / Walk / Attack / Hit` の4動作を追加した。GLBのクリップ名は `モデル名_動作名`。Blenderの剛体パーツのピボットを保持し、手足の交互運動、翼の羽ばたき、尾・葉の揺れ、攻撃時の踏み込み、被弾時の反動を表現する。

移動はマスの変更、敵の攻撃は攻撃者の既存offset、仲間の攻撃は支援処理が発行する表示用時刻、被弾はHP減少に合わせて再生する。睡眠・凍結中は再生を停止する。仲間の8方向の向きにも対応。ゲームの判定・速度・ターン消費は変更しない。

編集用blendは静止状態で確認しやすいようNLAをmuteして保存する。動作を編集・再生するときは対象モデルのNLAトラックのmuteを解除する。

## 確認と制約

生成後にキャラクター・敵・アイテムのBlender画像と実際のゲーム画面を確認した。86モデルのルート名とマニフェストの一致を検査。全145種類の既存アイテムのモデル割り当て、装備7回の操作、頭巾、仲間、未探索・透視、道場移動、2D/3D切り替え、WebGL復旧をシリーズ1・2で確認。

ブラウザテストで6色の本体・表示ラベルが異なること、進化時に再描画されることを確認した。PC、390×844、844×390で表示確認。携帯実機の性能計測やLODは未実施。34モデルすべての移動／攻撃／被弾クリップのパーツ変形と、実際のターン変更による再生切り替え、仲間の移動・支援攻撃を両シリーズのブラウザで検査した。歩行と攻撃のBlenderレンダリングも確認した。

実行する確認：

```text
node scripts/test-school-3d.mjs
node scripts/test-school-enemy-ranks.mjs
node scripts/test-school-adventure.mjs
node scripts/test-school-dojo.mjs
pnpm run build
node scripts/generate-android-asset-manifest.mjs
```
