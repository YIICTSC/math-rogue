# 正解ポイント・ポイント交換・ボイスシアターの仕様案

状態: ユーザー承認を受け、背景交換・ボイスシアター・BGMジュークボックス・お気に入り・学習アルバムを実装。現行の仕様と検証方法は [point-exchange.md](point-exchange.md) を参照。以下は当初の機能選定案。

## 基本構成

- 本編・問題チャレンジ・ミニゲーム・スポーツ・オンライン学習の実際の解答を対象に、正解1問で1ポイント。不正解による減点なし。
- 既存のミニゲーム解放用正解数と財布を分離。共通の解答記録を付与入口にし、解答ごとの識別子で多重通知・再描画の重複付与を防止する。独立した解答経路の網羅確認も行う。
- 所持ポイント・累計獲得・交換履歴・所有アイテム・設定を保存。残高不足や保存失敗では交換を成立させない。データ移行の対象に含める。
- タイトルに「ポイント交換」と残高を表示。交換前にプレビューし、交換・適用を分ける。購入済み背景の再適用は無料。

## 問題背景

新規イラストを用意し、縦長・横長を別々に構図調整する。正方形・タブレットでも問題や選択肢を覆わない表示領域を確保する。

候補:

- シンプル: 主人公とノート、放課後の窓辺、小さな魔法の書斎。
- 壮大: 星海の図書館、雲上の学び舎、主人公たちが見守る世界樹。
- ファニー: 料理長の巨大プリン研究会、園芸部長の植物に占領された教室、魔法実験のふわふわ大騒動。

明るさ・背景の濃さ・ぼかし・標準背景に戻す機能は無料の基本設定とする。問題や図表の可読性を維持し、解答中には背景を変えない。

## ボイスシアター

- ポイントでモードを解禁。戦記の主人公立ち絵と通常・喜び・心配・決意の表情を利用。
- 左右の人物、表情、既存のゲーム内セリフ、背景、発言順、間を選んでオリジナル会話イベントを構成。
- 既存の収録ボイスを人物とセリフに正確に対応させる。字幕の自由入力は、収録音声を再構成する機能と区別する。自由入力文の新規音声合成を行う場合は別途仕様化が必要。
- 行の追加・複製・並べ替え・削除、1行試聴、最初から再生、停止・前後移動、オート再生。
- 複数作品の命名・保存・再編集・JSON書き出しと読み込み。読み込み時は人物・表情・文字数・行数などを検証。
- 戦記本編のセーブや既読状態を書き換えない。再生中断・画面を閉じたときの音声停止、スマホ縦横での立ち絵と字幕の収まりを確認する。

## おすすめの追加候補

1. BGMジュークボックス: 曲を交換し、タイトル・背景鑑賞・ボイスシアターで選曲。
2. 背景プレイリスト: 所有背景をお気に入り登録し、次の問題への切り替え時におまかせ表示。
3. 称号とプロフィール装飾: 正解数や好きな主人公を表す称号・額縁・学習手帳の表紙。
4. 学習アルバム: 累計正解などの節目を主人公の記念カードとして保存。節目の報酬とポイント交換は別に表示する。
5. 会話作品のお気に入り・保存・書き出し: シアターの基本機能として含めることを推奨。作品を作るたびの消費は設けない。

初期構成のおすすめは背景・ボイスシアター・ジュークボックス。保存・プレビュー・読みやすさ調整は交換後の基本機能に含める。

## 価格のたたき台

- 最初の背景: 10ポイント
- 通常背景: 30〜60ポイント
- 豪華背景: 100〜150ポイント
- BGM: 30〜80ポイント
- ボイスシアター解禁: 10,000ポイント

実際のプレイ時間と問題の出題頻度を確認して調整する。解禁後の編集・再生・保存は無料。

## 実装前に確定すること

- 初期の背景ラインナップと交換価格。
- ボイスシアターで利用できる主人公と衣装、収録セリフの範囲。
- 過去の学習記録への初回ポイント付与を行うか。既存解放カウンターは重複加算経路があるため、そのまま残高に変換しない。
