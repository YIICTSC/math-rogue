# GAKURO VR：待機室・招待URL・ホスト観戦（2026-10-14）

## 実装
- レースと共通の待機室レイアウトを使用。自分のプレビューと参加者一覧、右側に部屋コード／招待URL、キャラクター編集、ルール、単元、開始ボタン。スマホでは縦に並び、スクロールできる。
- 招待URLは `?vrRoom=S-XXXXXX` または `?vrRoom=H-XXXXXX`。公開先のベースパスを保持し、部屋コードにサーバー／ホスト通信方式を保存。招待を開くと本体からVRへ直接移動し、名前入力だけで参加。退室でURLの部屋情報を削除。
- ホストは待機室で「観戦モードにする」を選べる。協力・バトルロイヤル・爆弾バトルに対応。8秒ごとに自動切り替え、「次のプレイヤー」で手動切り替え。試合中の参加／観戦変更は不可。
- 観戦ホストをミッション配置、戦闘、衝突、補給、学習問題、勝利判定から除外。接続上限40にはホストも含む。対戦は実際に参加する2人以上、協力は1人以上で開始。
- 観戦対象の切り替えはクライアント内のカメラ／アバター更新のみ。3Dシーン全体を再生成せず、協力の出口・防衛地点も観戦対象に追従。
- 待機室のルール・単元変更はホストのみ。試合中の変更をサーバーでも拒否。学習単元変更時は出題デッキを更新。
- PeerJSの参加先IDを作成側と同じv6へ修正。

## ローカル確認
`http://localhost:5173/` でVRオンラインの待機室から観戦モードを選択。対戦の場合は別ウィンドウで参加者を2人入室させて開始。ローカルVRサーバーはポート10001。
同じPCの招待URLは他の端末では使えない。他端末でローカル確認する場合は開発サーバー／VRサーバーへ到達可能なLANホスト名が必要。公開サーバーで新しい機能を使うには更新後の手動デプロイが必要。

commit、push、Renderデプロイは実施していない。既存の無関係な変更も保持。

最終確認：`pnpm run build` 成功（既存の大きなチャンク警告あり）。英語UI監査成功、サーバービルド成功。3モードの実ブラウザ観戦と手動切り替えが成功し、協力・バトルロイヤルの確認画像も実際に確認した。型チェックは467件の既存エラーで未通過。今回追加した招待・設定・観戦モジュールに新しい型エラーは検出されなかった。
