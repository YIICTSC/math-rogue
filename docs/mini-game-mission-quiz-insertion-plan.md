# ミニゲーム常設化とミッション後3問の問題出題計画

作成日: 2026-08-21

## 目的

- 雑学カテゴリ画面からのみ起動できるミニゲームを、タイトル画面の「ミニゲーム選択」からも最初から選べるようにする。
- 選択画面のアイコンは、各ミニゲーム内で使っている専用バッジ／駒／カード系アセットを使い、汎用アイコンへのフォールバックを減らす。
- ミニゲームのミッション（クリア単位）ごとに、通常の問題選択と同じ出題ルートで3問を出す。

## 現状確認

- `src/miniGameConfig.ts` の `STONE_GLOW`、`SCHOOL_TRPG`、`LEARNING_TCG`、`SHOGI`、`GO`、`CHESS`、`MAHJONG` は `categoryOnly: true` のため、タイトル画面の一覧から除外されている。
- `src/components/MiniGameSelectScreen.tsx` は `categoryOnly` を除外し、表示中のゲームを `MINI_GAME_MODE_SELECTION` へ送ってから起動する。したがって、常設化対象は `threshold: 0` を維持すれば開始時から選択可能になる。
- カテゴリ系ゲームの専用アイコンは `public/sprites/backgrounds/mini-games/badges/*.png` に揃っている。将棋は同バッジ、TCGも同バッジを使用する。
- 問題選択の共通実装は `MiniGameProblemChallenge`。`isChallenge` を省略した通常モードでは、数学・漢字・英語・一般問題の各画面が3問を生成する。
- 長編ミニゲーム（ポーカー、サバイバー、ダンジョン、校長対決、紙飛行機、帰宅ダッシュ）は、すでにゲーム途中のレベルアップ／イベント等で問題チャレンジを持つため、外側のミッション後ゲートを追加すると二重出題になり得る。

## ミッション境界と問題の差し込み位置

| ゲーム | 1ミッションの完了イベント | 3問を差し込む位置 | クリア後の既存UI |
| --- | --- | --- | --- |
| 石ころの煌めき | `result === 'WIN'`（8点到達） | 勝利結果バナーの上にモーダル表示 | 結果バナー／再戦 |
| 放課後スクールTRPG | 最終シーンを成功して `result === 'WIN'` | エンディング表示の上にモーダル表示 | エンディング／再戦 |
| 学習ローグTCG | 各バトルで `battle.winner === 'player'` | 報酬カード選択・最終クリア画面の上に表示。回答後に元の報酬UIへ戻る | 3枚から1枚選択、または10戦クリア |
| ミニ将棋 | 1局の `game.result === 'WIN'` | 勝利結果パネルの上に表示 | 再戦／結果へ |
| 九路盤 囲碁 | 終局スコアで `result === 'WIN'` | 勝利結果バナーの上に表示 | 再戦 |
| スクールチェス | 王の捕獲・詰みで `result === 'WIN'` | 勝利結果バナーの上に表示 | 再戦 |
| まなび麻雀 | 完成手で `result === 'WIN'` | 勝利結果バナーの上に表示 | 再戦 |

### 採用理由

1. 勝敗が確定した直後なので、問題出題の発生条件が安定する。
2. 盤面や手札の操作中に割り込まず、ゲーム状態を壊さない。
3. 問題完了後は元の結果／報酬画面へ戻るため、TCGのカード獲得や将棋の結果遷移を失わない。
4. `MiniGameProblemChallenge` を再利用するので、問題モード・教科選択・英語／ひらがな・課題問題の扱いを既存ルートと揃えられる。

## 実装方針

1. `categoryOnly` の対象7ゲームを一覧へ戻し、各ゲームの専用バッジ画像を `MiniGameSpriteIcon` に登録する。
2. `MiniGameRouter` から問題モード、モードプール、解答方式、課題情報をカテゴリ系ゲームへ渡せるよう共通Propsを拡張する。
3. `TriviaMiniGameScreen` にミッション後クイズの状態を持たせ、7ゲームの勝利イベントから共通の `MiniGameProblemChallenge` を表示する。
4. 新実装の将棋・配置型TCGにも同じ3問ゲートを追加する。TCGはバトル勝利ごとにゲートを開き、報酬選択を回答後まで保持する。
5. 既存の長編ミニゲーム内の問題チャレンジは変更せず、二重出題を避ける。

## 完了条件

- タイトル画面からミニゲーム選択を開くと、上記7ゲームがロックなしで表示・起動できる。
- 各カードのアイコンが対応する `badges/*.png` を参照している。
- 7ゲームと将棋・TCGの各ミッション勝利後に、選択した問題モードでちょうど3問が出る。
- 問題3問の完了後、元の勝利・報酬・再戦UIへ戻る。
- 既存の長編ミニゲームの途中問題、課題問題、英語／ひらがな表示を壊さない。
- 英語UI監査、表示文言監査、ビルドを通過する。
