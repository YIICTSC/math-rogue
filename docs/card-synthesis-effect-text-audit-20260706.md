# カード合成時の効果文仕様表

作成日: 2026-07-06

目的: カード合成で生成される効果文を、カード面に収まる短い表記に統一する。通常カードの原文をそのまま伸ばすのではなく、効果語・カード名・数値が分かる簡潔な文へ寄せる。

## 対象コード

| 用途 | ファイル | 現在仕様 |
|---|---|---|
| 合成カード生成 | `src/utils/cardUtils.ts` | `synthesizeCards()` が素材カードの効果を合算し、短縮効果文を再生成する。 |
| 追加カード名解決 | `src/utils/cardUtils.ts` | `getDisplayCardName()` で `CARDS_LIBRARY` から表示名を引く。 |
| パワー効果文 | `src/utils/cardUtils.ts` | `describeSynthPower()` で内部IDを短い日本語効果文に変換する。 |
| 通常カード表示 | `src/components/Card.tsx` | 日本語表示では `trans(card.description, languageMode)`。合成文は生成時の `description` がほぼそのまま出る。 |
| 英語カード表示 | `src/utils/textUtils.ts` | 英語モードは `buildEnglishCardDescription()` が別生成するため、この表の主対象外。 |

## 基本方針

| 項目 | 方針 |
|---|---|
| 表記の長さ | 合成では効果が増えやすいため、短い効果ラベル + 数値を優先する。 |
| バフ・デバフ名 | `ムキムキ / カチカチ / キラキラ / スケスケ / ドクドク / へろへろ / びくびく` を使う。 |
| 内部ID | `SHIV`, `WOUND`, `DEXTERITY`, `DRAW_POWER` などをカード面に出さない。 |
| エナジー | `E` ではなく `エナジー` と書く。 |
| 生成カード | 内部IDではなく実カード名を表示する。例: `SHIV` -> `えんぴつの削りかす`, `WOUND` -> `ケガ`。 |
| 句点 | 効果ごとに `。` で区切る。1効果内は `/`, `+`, `x` を使って短くする。 |

## 未対応・注意点

| 項目 | 状態 | メモ |
|---|---|---|
| `consumedOnUse` | 対応済み | `使い切り。` として継承。 |
| `specialDescMap` 内の `E+2` | 一部残存 | `戦略家`, `空虚` など特殊名由来の短縮文には `E` 表記が残る。必要なら次に `エナジー` 表記へ統一する。 |
| 未登録 `applyPower.id` | フォールバックでID表示 | 新カード追加時に内部IDが出たら `describeSynthPower()` に追加する。 |

## 実装メモ

- 合成カードは効果が増えるため、通常カードの長い自然文ではなく短縮効果文を採用する。
- `applyPower` は `describeSynthPower()` に集約し、旧語・原語・内部IDが出ないようにする。
- 生成カード名は `getDisplayCardName()` で `CARDS_LIBRARY` から表示名へ変換する。
- 表示側で補正せず、合成カード生成時の `description` を正規化する。
