# ひらがな表示 完全翻訳修正計画

作成日: 2026-07-14

## 目的

ひらがなモードで、通常のゲーム進行、設定、確認画面、イベント、カード・アイテム説明に漢字が残らず、機械的な部分置換による誤読もない状態にする。

## 対象外

- ミニゲームの問題文、説明文、ゲーム内表示
- 固有の英数字、数式、HP、G、URL、キー名
- 画像そのものに描かれた文字

ミニゲームへ入る前後の共通UI、終了確認、報酬、エラー表示は対象に含める。

- [x] 対象画面の表示文字に未意図の漢字が残らない
- [x] 人名、カード名、敵名、専門用語の読みが文脈に合う
- [x] 数値や記号を含む動的文章が崩れない

- [x] `title`、`aria-label`、`placeholder`、`alt` の日本語直書きを監査し変換する

## 実装方針

1. UI側は文字列を直接変形せず、`trans`、`transEventText`、`transProblemSubjectName` のいずれかへ集約する。
2. 読みが一意でない文章は、短い単語の部分置換を増やさず完全一致辞書へ登録する。
3. 動的文章は固定部分だけを翻訳し、数値、カードID、保存キーを変換しない。
4. 英語問題など、内容自体を原文で出す必要がある領域には明示的な除外を設ける。
5. 修正ごとにこの文書のチェック項目と発見事項を更新する。
