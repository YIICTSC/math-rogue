# スーパー学ロカート

タイトル画面の「スーパー学ロカート」から起動する独立したオンラインミニゲーム。本編・RPGオンラインの状態やセーブデータとは分離する。

## 遊び方

- オート加速。PCは左右矢印 / A・Dで操舵、下矢印 / Space / Sでブレーキ、Eで道具を使用する。タブレット・スマホは左右ボタンとブレーキを同時押しできる。
- 走行時間90秒の距離競争。25・50・75秒で全員が停車して3問に回答。1問10秒、学習全体で最大30秒。全員が回答を終えた場合は早く再開し、再開前に3秒のカウントダウンを入れる。
- 初期最高速度105。次区間は `85 + 15 × 正解数 + 8 × Σ max(0, 1 − 正解の回答秒数 / 10)` を四捨五入する。範囲85〜154。誤答・未回答には速さボーナスを付けない。
- 学習問題は「たし算・ひき算」または「九九」。ホストが選択し、全員に同じ3問を配信する。既存の管理課題の出題・回答実績とは接続していない。
- カーブでは高速ほど外に流され、ブレーキ中は操舵が強くなる。コース外では減速。中央の道具箱は240m間隔。
- 給食ミルク：4秒間、最高速度+35。定規バリア：7秒間、コース外とチョークによる減速を防ぐ。チョークスモーク：前後180m以内の相手を3秒間減速。
- 学校・図書館・理科ラボの3コースと、既存の主人公素材3種類を用意。ひとり練習にはCPU3人が参加する。

## オンライン

6文字コードで最大8人。ホストがスタートし、開始後の途中参加は不可。ホストが20Hzで全カートと回答時間を計算し、参加者は操舵・ブレーキ・回答・道具使用の指示を送る。クライアントから速度・得点は受け取らない。ホスト退出時はレースを終了する。ホストはブラウザを前面に保つこと（バックグラウンドのタイマー抑制を受ける）。

既存RPGの `VITE_RPG_PEER_HOST / PORT / PATH / SECURE` 設定を共有する。未設定時はPeerJS既定シグナリングを使う。学校のネットワーク等でWebRTCが制限される場合の外部接続は、利用環境で確認が必要。認証・永続ランキング・ホスト移譲・再接続は現時点では実装していない。

## 素材と実装

ROMの読み込み・解析・抽出・同梱は行わない。ゲームロジック、疑似3Dコース、カート、校舎・桜などは新規コードによる描画。主人公は既存の `crane-game-protagonist-prizes-3x2-alpha-v1.webp` 上段を使用する。

## 検証

```powershell
node node_modules/typescript/bin/tsc -p tsconfig.kart.json
node scripts/test-gakuro-kart.mjs
npm install --prefix tmp/kart-peer --no-package-lock --no-audit --no-fund peer@1.0.2
node scripts/test-gakuro-kart-browser.mjs
node scripts/test-gakuro-kart-integration.mjs
pnpm run audit:english:gate
```

ブラウザテストはローカルシグナリングサーバーと実WebRTC接続で8人・満員・同期・退出を検証。PC・390pxスマホ・820pxタブレット・横向き画面の画像は `tmp/kart-qa/` に保存する。実機Safariや外部インターネットを跨ぐ接続は別途確認する。
