# TRPG：選択・代償・仲間・連携

- 判定前に直感／慎重な準備／大胆な賭け／仲間との連携を選ぶ。
- 慎重な準備は判定+2、時間+1、疲労+1。大胆な賭けは判定+1、成功の手がかり+1、失敗の追加疲労+2。
- 仲間加入後は各章1回、判定+2と疲労-1。消費はシミュレーションで検証・保存される。
- 運命点と発見物を含めたD6の成功目数と確率を、各選択肢に表示する。
- 1点差の失敗は目的の達成とは分け、疲労などの代償と引き換えに手がかり+1を得る。
- 結果画面は出目・判定の内訳・能力成長・実際の資源増減を表示する。
- 学力または友情の判定成功で共有記録を得る。その後の各イベントで、調査記録や証言を使う別解を選べる。
- 別解の成功は今章の番人との対決開始時に調査+1。同じ効果は積み上がらない。
- 防御→攻撃はダメージ+2、調査→説得は説得+1と反撃軽減1、装置操作→調査は調査+1。
- 6種類のイベントの情景・会話、6章それぞれの問い、信頼・ライバルとの同盟・疲労に応じた発言を追加。
- 追加状態は任意の結果フィールドまたは既存flagsに保存するため、既存セーブを読み込める。
