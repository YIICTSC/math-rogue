# Xboxコントローラー対応 画面別チェックリスト

関連資料: [Xboxコントローラー対応 実装方針](./xbox-controller-support-plan.md)

## この文書の使い方

この一覧は、Xboxコントローラー対応の実装状況と動作確認結果を画面単位で管理するためのもの。

- **実装**: 必要な属性、初期フォーカス、ショートカット、フォーカス表示をコードへ反映したらチェックする。
- **PC確認**: Windows + Xboxコントローラーで基本操作を確認したらチェックする。
- **回帰確認**: マウス、タッチ、キーボードの既存操作に問題がないことを確認したらチェックする。
- 1つの画面に複数の状態やモーダルがある場合は、行を追加して個別に確認する。
- 対象外画面は、ゲーム内選択肢用の初期フォーカスが発生しないことを確認する。

### 対応方式

| 記号 | 方式 | 必要な対応 |
| --- | --- | --- |
| S | ショートカット | バトル／実プレイ画面。ボタンショートカット、方向操作、決定／取消、ボタン表記を実装 |
| I | 初期位置 | ゲーム内選択画面。最も左上の有効なゲーム内選択肢へ、表示直後の1回だけ初期フォーカス |
| S+I | 両方 | 実プレイ中に独立した選択画面やモーダルを含むため、両方式を確認 |
| G | 共通操作 | 専用ショートカットを設けず、方向移動、A決定、B取消が利用できることを確認 |
| X | 対象外 | 設定・情報・管理UI。ゲーム内選択肢用の初期位置処理を適用しない |

### 現状記号

| 記号 | 意味 |
| --- | --- |
| ○ | 画面専用の対応コードあり |
| △ | 共通処理またはキー操作の一部のみあり |
| － | 専用対応は未確認／未実装 |
| 対象外 | 実装対象外。誤適用がないことだけ確認 |

## 6. 共通モーダル・オーバーレイ

`.app-modal-overlay`、`role="dialog" aria-modal="true"`、または `data-gamepad-modal` を持つモーダルは共通処理で操作をモーダル内に限定する。表示中は背面へ方向入力・決定・ショートカットを流さず、Bでは「戻る／閉じる／キャンセル」操作を優先し、該当ボタンがない場合は閉じる背景クリックを試みる。

## 7. 全画面共通の完了確認

- [ ] Xboxコントローラーの接続前後どちらでも操作を開始できる
- [ ] 左スティックと方向パッドの両方で移動できる
- [ ] Aで決定、Bで取消／戻るができる
- [ ] バトル／実プレイ画面のショートカット表示と実動作が一致する
- [ ] 無効、非表示、画面外の不正な要素へ初期フォーカスしない
- [ ] ゲーム内選択肢では最も左上の有効な候補が初期位置になる
- [ ] 初期フォーカス後、再レンダーで左上へ戻らない
- [ ] モーダル表示中に背面のボタンが実行されない
- [ ] 1回のボタン押下で処理が二重実行されない
- [ ] フォーカス中の要素が画面上で明確に分かる
- [ ] 必要に応じてフォーカス要素が表示範囲内へスクロールされる
- [ ] 設定・情報・管理UIにゲーム内選択肢用の初期位置処理が誤適用されない
- [ ] マウス、タッチ、キーボードの既存操作に回帰がない
- [ ] コントローラー切断・再接続後も操作を再開できる
