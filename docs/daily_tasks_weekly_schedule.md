# デイリー課題 週別配信スケジュール

このドキュメントは、`src/data/dailyCurriculumPlan.ts` と `src/utils/dailyAssignmentUtils.ts` に基づき、各週に実際に選ばれるデイリー課題単元をまとめたものです。

- 年度開始は4月第1週です。
- デイリー課題は「季節・週課題 30問」と「チャレンジ課題 20問」で構成されます。
- 小1〜中3の表は季節・週課題側の配信単元です。
- `総まとめ` は年度前半は前学年、年度後半は現学年のまとめが選ばれます。
- 大人はチャレンジ課題に週替わりローテーションを設定し、難読漢字や趣味雑学なども混ざるようにしています。
