# VRマルチプレイの視点改善

40人のバトルロイヤルで、自分の開始位置が固定俯瞰カメラの背後になり、キャラクターが表示されなかった。通常の俯瞰を自分／観戦対象への追従に変更し、全体マップを独立した切替にした。

## 変更内容

- 追従視点の表示範囲は人数に依存させない。外周では自分のマーカーが画面内に残る余白を確保してカメラを制限する。
- 全体表示は床と壁の包囲箱を投影し、横幅・縦幅の両方を収める。near/farもマップサイズに合わせる。爆弾バトルの縦画面で左右が切れる問題も解消する。
- 俯瞰では霧を無効化し、一人称／三人称では既存の霧を維持する。
- 自分／観戦対象に白いリング・進行方向の矢印・番号を表示。全体マップの他プレイヤーは短い番号、近距離では小さな名前を表示する。番号は参加者一覧と対応する。
- 爆弾バトルの近い12名以外に使う簡易モデルにも席ごとの色を付ける。
- 協力・バトルロイヤルのレーダーは近傍表示を基本にし、全体との切替を追加。自分の方向、目標の菱形、遠い目標への方向と距離を示す。
- 長い操作説明は閉じられる「操作とヒント」にまとめ、短い目標表示を上端へ置く。
- 三人称のカメラを肩越しにし、壁との衝突を避けて補間する。接近時は身体・武器を透過する。reduced-motionの場合は補間を使わない。
- ホスト観戦に対象固定／自動切替再開を追加。手動切替と退出者の自動除外を維持し、対象を切り替えてもcanvasを作り直さない。
- 横向きスマホでも爆弾バトルの全体マップボタンと移動・設置操作を表示する。
- 新規文言の英語・ひらがな訳を共通辞書に追加。

## 検証

- `node scripts/test-vr-camera.mjs`：協力・バトルロイヤル・爆弾、2/10/20/40人、3種類の縦横比で648の開始位置と288の外周角を確認。衝突・reduced-motionも確認。
- `node scripts/test-vr-view-browser.mjs`：36の人数／画面サイズ組合せで追従・全員の番号・全体マップ・レーダー・説明の開閉を確認。壁際の透過、観戦固定／手動切替、canvasの維持、英語HUDを確認し、40人状態のスクリーンショットを保存。
- `node scripts/test-vr-server-40.mjs`：40本の実WebSocket接続、41人目の拒否、同期、ホスト引継ぎ。
- 既存の爆弾バトルとロビー／観戦のエンジン検証、爆弾バトルの実ホスト・ゲストブラウザ検証。
- `pnpm run build`（型検査・英語監査を含む）、`pnpm run server:build`。

ブラウザの視点検証は現行エンジンで人数と配置を生成する再現用fixtureを使用する。HMDのステレオ表示・実機FPS・酔いの評価は含まない。Renderの手動デプロイ設定は変更しない。
