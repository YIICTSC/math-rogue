# エンドレスモード 導入・エンディング本文修正案

作成日: 2026-09-02
対象: 小学生編・高校編・マジック編（女性主人公／男性主人公）
用途: 実装前の日本語マスター本文。各ページの場面、本文、主人公固有のセリフ、画像に必要な要素を確定するための原稿。

実装状況: 本文・固有セリフ・画像キーを `src/data/endlessEndingCopyRevision.ts` へ反映済み。画面表示も固有セリフに対応済み。ひらがな版・英語版は日本語マスターから実行時に生成する。

## 方針

- `O1`〜`O3` は、通常編クリア後にエンドレスへ入る導入序章である。
- `T1`〜`T3` は、エンドレス50階到達後に表示する真エンディングである。
- 1主人公につき、導入3ページ＋真エンディング3ページを用意する。
- 本文は、編・主人公・役割・画像の場面に合わせて書き分ける。
- `固有セリフ` は各主人公が実際に話す短い一言として、本文とは別フィールドで管理する。
- このファイルは日本語マスターのみ。ひらがな版・英語版は日本語の内容を確定した後に作成する。
- 画像キーは既存の `opening-1`〜`opening-3`、`true-1`〜`true-3` に対応する。

実装時の想定型:

```ts
type RevisedEndlessPageCopy = {
  title: string;
  scene: string;
  text: string;
  dialogue: string;
  imageKey: `opening-${1 | 2 | 3}` | `true-${1 | 2 | 3}`;
};
```
