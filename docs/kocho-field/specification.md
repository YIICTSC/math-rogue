# 校長対決：フィールドバトル

> **お蔵入り（2026-11-17）**：ユーザー指示により開発を中止。通常タイトル・クリア後・デバッグからの入口を撤去し、公開導線から切り離した。以下は保管用の旧仕様であり、現在の提供機能ではない。既存のフィールド保存・獲得済み景品・素材は保持する。

通常の校長対決を一度クリアすると、タイトルと勝利画面に入口が開く。旧セーブの難易度解禁・クリア履歴も認識する。既存の7マスの戦闘は従来の入口から遊べる。

## マップと進行

- 全7章。現在の主人公3人と、各主人公の章開始・エンディングの既存イラスト付きフルボイスストーリーを共有する。
- 第1章は **横50マス × 3ライン**。以降は58、66、74、82、90、98マス。左端中央（0,1）から開始し、右端中央のゴールへ進む。
- 第1章は校門、第2章は階段の踊り場、第3章は購買、第4章は体育館、第5章は図書室、第6章は屋上、第7章は校長室の既存ストーリーにつながる道。章の先生は熱血教師、教頭、理科、体育、音楽、生活指導、校長の順。
- 校長は通常、激怒、真・校長の3段階。最終段階を含め、その章のボスを倒すとゴールが開く。途中の通常敵を全滅させる必要はない。
- 各章のゴール後に既存の学習問題、カードの選択、次章へ進む。問題の単元・課題・解答方式・累計正解への反映は既存の `MiniGameProblemChallenge` を通す。
- 章開始でHPを7回復。全問正解で追加HP+1。終了・敗北後は素早く再挑戦できる。
- カメラは横に追従し、斜めの接続された床・奥の建物・前後の人物サイズで3ラインの奥行きを表す。

## 操作とカード

| 操作 | 入力・処理 |
| --- | --- |
| 移動 | 上下左右／WASD／画面の十字ボタン。1入力1マス。壁や敵のいるマスには入らない |
| 向き変更 | ボタン→方向。移動せず向きだけ変更 |
| 主人公の特殊移動 | ボタンまたはX→方向。選んだ方向の隣の敵に作用。赤ジャージは交換、叛逆は回り込み、あかりは押し出す。成功後CD3 |
| カード | 3枚まで予約してA／Z／Enterで実行。予約の解除はもう一度同じカードを押す |
| 待機 | 待つボタン。予約なしのAも待機 |
| 実行中・会話・入室 | フィールド移動を止める。連打による二重実行を防ぐ |

全237枚の既存カードに、**フィールド専用の説明と4方向へ回る範囲判定**を与える。通常の7マスモードの説明・判定は変更しない。

- 回し蹴り、回転モップ、旋風などの回転技：隣接する周囲8マス。
- 通常攻撃・投げ・音波：向いている方向へ元の射程を投影。貫通は範囲内の全員、単体は最初の敵。
- 雷などの遠方攻撃：周囲6マス内の最も遠い敵。
- 移動、反動、後退、押し引きも向きに従う。3ライン外へ出ない。
- 回復・防御は自分。主人公の闘志／星光、連撃、消費・獲得、障壁などの既存技特性も適用する。
- 予約・注目中カードは床上に範囲を表示。小さな画面では詳細を手札直下の説明欄で読める。

## 敵

近接5マスで目覚め、最大4体だけ行動する。8マスより離れると追跡をやめる。遠い敵のタイマーは進まず、全マップの敵が一斉に追ってこない。攻撃は予告の次のターンに判定されるため、上下移動で避けられる。攻撃された敵も目覚める。

敵撃破時に28%で12～23Gを床に落とす。ボスは30Gを落とす。お金はそのマスへ移動して拾う。マップクリアで40G。

## 建物

入り口のあるマスへ移動すると、専用イラスト付きモーダルを開く。入室中は敵の行動・移動を止める。遠くの建物をタップして瞬間移動することはない。

合成カードの名前は素材名を**選択順**に結合する。アクション絵は全素材分を小さく並べる。発動も同じ順で1つずつ絵・声・効果を再生し、途中に敵のターンを挟まない。CDは素材の最大値。セーブ後も順序・各効果・CDを保持する。

## ふわりドリームボウル

オリジナルの雲のボールが夢の王国を転がる、斜め見下ろしの2Dボールアクション。全12コースを順に解禁。

- 左右で方向、上でフライ・下でゴロ。Bで回転を調整。Aでゲージ開始→Aでパワー決定。
- 予測線は実際のショットと同じ物理処理を使う。
- 移動中のAは追加バウンド・水切りのタイミング操作。Bは手に入れた能力を発動。
- 能力は流星ダッシュ、雷の輪、雲の翼、いしころ。星・クリスタルから取得する。
- バンパー、ばね、風、池、砂、氷、坂、危険な水晶を配置。床の摩擦、空気抵抗、回転、重力、反発が弾道へ作用する。
- 星をすべて集めるとゴールの輪が開く。速すぎる進入や空中では入らない。
- ショットで体力を消費、星で回復。落下・水没は直前の発射位置から再開。失敗時はリトライ可能。中断・画面非表示時は停止。
- クリア打数と金・銀・銅の成績を保存する。
