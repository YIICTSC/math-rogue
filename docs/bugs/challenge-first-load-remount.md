# 初回の出題画面が再抽選される不具合

2026-11-17：共通 `deferredScreen` が、初回は `React.lazy`、ロード後の親の再描画では取得済みの画面関数を返していた。Reactに渡す要素の型が変わり、出題画面が再マウントされるため、問題生成が再実行され、先に見えていた問題と入力状態が置き換わった。

マウント中に使う画面の型を `useMemo` で固定する。明示的な読み込み再試行だけ型を選び直し、次の訪問ではキャッシュ済みの画面をすぐに使用する。本編・ミニゲーム共通の4種類の問題画面に適用される。問題の抽選ルール・採点・正解数の記録は変更しない。

`node scripts/test-challenge-mount-stability.mjs` は実際の算数・漢字・英語・汎用問題画面を遅延ロードし、初回／キャッシュ済み訪問、複数回の親の更新、問題リスト・問題番号・入力状態の保持、退室後の新規開始を検証する。`QA_OLD_LOADER=1` では旧コードを検査時だけ再現し、最初の算数のマウント回数が2になることで失敗することを確認した。

既存のローディング表示方針の検査：`CHROMIUM_PATH=/usr/bin/chromium node scripts/test-loading-screen-policy-browser.mjs`。
