# 上部UI・モーダル コントローラー出入り最終確認

確認日: 2026-07-29  
対象: Steam版のメインゲーム、全ミニゲーム、共通ゲームメニュー  
確認状態: 2026-07-29 作業ツリー

## 結論

**合格。**

メインゲームと全ミニゲームについて、上部UIから開くモーダルをコントローラーだけで開閉し、背面の終了操作を誤作動させず、開いたボタンへ戻れることを確認した。

今回まで未保証だった15導線は、次の共通仕様へ統一した。

1. `A`または明示されたショートカットで開く
2. 開いた直後にモーダル内部へ初期フォーカスする
3. `B`で最前面のモーダルだけを閉じる
4. 閉じた後は、モーダルを開いたボタンへフォーカスを復元する
5. Reactの再描画で元ボタンのDOMが差し替わった場合も、ゲームパッドゾーンと順番から復帰先を再取得する

## 合格判定基準

- 開くボタン: `data-gamepad-zone`、`data-gamepad-order`
- モーダル外枠: `data-gamepad-modal`
- モーダル内初期位置: `data-gamepad-initial-scope`と`data-gamepad-initial-choice`
- 閉じる操作: `data-gamepad-back`
- 複数操作がある場合: `data-gamepad-navigation-root`
- `B`入力は背面画面へ漏れない
- 閉じた後は開いたボタンへ復帰する
