# ダンジョンズ1：武器熟練度とひらめき

素手・剣・大剣・細剣・斧・槍・杖・槌・弓・鞭・輪刃の11系統。通常技は各4段階、計44種。技名は古典的な和風RPGの語感を生かした独自名で、既存シリーズの技名は使用しない。

実際に敵を攻撃すると、その武器の経験値が1増える。空振り、店員、道場、ダンジョンズ2は対象外。範囲攻撃でも経験値は1回分。武器Lv nの累計必要経験値は `3*n*(n+1)`、最大Lv10（330回）。

武器Lv1/3/5/7で通常技の段階1/2/3/4が候補になる。段階2以上は直前の技を10回使用（技熟練2）することも必要。条件を満たした敵への攻撃で22%の確率判定を行い、候補のうち段階が最も低い技から1つひらめく。新しくひらめいた技はその攻撃から発動し、使用技に自動設定される。習得した瞬間は使用回数0で、その後の使用で成長する。

技熟練は5回使用ごとに1増え、最大5。技画面で習得済みの技または通常攻撃を選べる。系統が違う武器へ持ち替えた場合は、その系統の選択を使う。通常技の威力倍率は1.15/1.4/1.7/2.1。段階2の細剣・槍・弓は2体貫通・防御半減、段階3は前方なぎ払い、段階4と奥義は周囲8方向。弓は正面6マスまで届き、壁や店員で遮られる。

奥義は対応する3系統すべてを武器Lv8以上、各段階4技を15回使用（技熟練3）すると候補になる。対応武器で攻撃してひらめく。倍率2.7。

| 奥義 | 使用武器 | 必要な系統 |
| --- | --- | --- |
| 万彩黎明 | 剣 | 剣・大剣・細剣 |
| 地天共鳴 | 槌 | 斧・槌・杖 |
| 星巡天翔 | 槍 | 槍・弓・輪刃 |
| 無窮心輪 | 素手 | 素手・鞭・杖 |

熟練度、習得技、技使用回数、使用技の選択は `learning-rogue:school-base:1` の `martial[heroId]` に保存し、帰還・敗北・新しい冒険・再読み込み後も維持する。変身前後は同じ主人公として経験を共有する。既存セーブにこの項目がなくても移行不要。

各装備武器種に練習用武器を追加。町の店で各200、通常のランダム床アイテムにも含まれる。毎階の固定追加支給は行わない。既存武器も種類を判別して同じ熟練度を使う。武器を外すと素手になる。

主人公35人と魔法変身17形態に、空手の横振り・振り下ろし・突き・蹴りを用意。攻撃時は武器を持たない4ポーズを使い、武器イラストと軌跡を別レイヤーで描く。左右は攻撃方向に合わせて反転する。元の方向別移動・非戦闘アクションは維持。描画中の動きはシミュレーションのターンを増やさない。

`assets/dungeons1/martial-art.json` に生成元ハッシュ・参照画像・スケール・出力ハッシュを記録。生成元PNGはセッションのLibraryに保持し、配信には透過WebPだけを使用する。

検証：`pnpm run test:dungeons1:mastery`（ルール・全武器分類・音声制御・アセット）、`pnpm run test:dungeons1:mastery:browser`（実戦・保存・実音声・3D演出）。

## 技専用ボイス

全35主人公 × 全48技 = 1,680本の個別音声。変身前後は同じ主人公の声を共有する。`assets/dungeons1/technique-voice-plan.json` に各主人公の口調、参照音声、技ごとの台詞と読みを記録する。既存の架空キャラクターの生成音声を参照し、同じ声色で技名と固有の掛け声を収録する。

最新公式Irodoriコードと現在公開されているモデルを確認し、CPUで実行可能なv4.1 Small MeanFlowを使用。モデル・音声codecともCPU、透かしを保持する。生成元revision・チェックポイントハッシュ・設定・出力ハッシュは `technique-voice-build.json` に記録する。生成は中断から再開可能で、完成音声を保持する。`--keys` で主人公ID/技IDの一覧を指定すれば分割生成・部分修正が可能。並行処理では `--record` に別々の記録ファイルを指定し、`merge-technique-voice-builds.py` で統合して記録の競合を防ぐ。修正音声は `--extra-seconds` と `--seed-offset` で調整でき、通常の再開で修正済み音声を元へ戻さない。

```bash
node scripts/dungeons1/prepare-technique-voices.mjs
# 公式IrodoriのCPU環境から実行（全量の生成には数時間かかる）
python scripts/dungeons1/generate-technique-voices.py --irodori-root ../Irodori-TTS --device cpu --threads 1 --cpu-autocast --reading
python scripts/test-dungeons1-technique-voices.py
```

技発動時の専用音声に確率による間引きは行わない。同じ技の連打では再生中の掛け声を最初から繰り返さず最後まで再生する。別の技への切り替えやひらめきでは前の音声を停止して新しい技へ切り替え、音声を待ち行列にためない。再生中は一般の攻撃・被ダメージの声を重ねない。音声音量、ミュート、ゲーム中断・非表示に従う。

互換用の3D描画部にも武器イラストの攻撃エフェクトと新武器の拾得表示を反映する。最新mainの2D専用画面と操作方針を維持し、3D切り替えは追加しない。新しい技の演出中は手持ち武器を隠し、武器を描く層をエフェクトへ統一する。演出用テクスチャは終了時に解放し、戦闘計算やターンを変更しない。

音声の全件整合性は `scripts/test-dungeons1-technique-voices.py` で確認する。各主人公の基本技1本と奥義4本、計175本をCPUのWhisper Smallで独立に文字起こしし、読みの類似度0.75未満をWhisper Mediumで再確認する。台詞を認識モデルへ提示せず、両方の認識と音声ハッシュを `technique-speech-qa.json` と `technique-speech-review.json` に記録する。不明瞭な音声だけを修正し、修正後のハッシュで再確認する。

今回の収録は初回4ステップ、読みの明瞭性を確認して7本を8ステップで再収録した（うち1本は長さとseedを再調整）。最終的な設定と修正前の履歴は生成記録に保持する。全1,680本の整合性と、175本の抽出音声の現在のハッシュ・認識結果を最終検証で照合する。
