# 放課後ポーカー：効果拡張・ライバルの特色

## 表示

- ショップ左下の主人公バッジを撤去し、商品を隠さない。
- パック開封の回転光を専用のクリップ領域へ移動。開封後0.85秒で消え、ショップへ戻ると領域ごと除去する。光がスクロール範囲を広げない。動きを減らす設定では回転しない。
- 日本語では「プレイ」「すてる」「ランク」「スート」「使う」「やめる」「選ぶ」、ショップ内のカテゴリや得点内訳も日本語にする。英語設定は従来の英語操作名を保持。

## 追加効果

既存の効果と主人公専用サポーターに加え、サポーター24種・消費カード18種・パック12種を追加。全54アイテムは `expansion.ts` に定義し、既存の素材を流用する。新規パックはハート、黒札、絵札/A、教科書、文具、新入部員、6種類の専用強化に絞った候補を提示する。

| 新規カード強化 | 得点・保持の効果 |
| --- | --- |
| 反響 | 得点時、カード自身の基礎点をもう一度加算 |
| 成長 | 得点時、この挑戦のプレイ累計×12を基礎点に加算 |
| 虹光 | 得点時、異なる得点スート数×2を倍率に加算 |
| 墨 | 出さずに手元に残すと基礎点+45 |
| 幸運 | 得点に使うと必ず部活ポイント+1 |
| 錨 | 出さずに手元に残すと倍率+3 |

6種類のしおりは1枚だけを対象とし、複数選択では消費しない。6冊の上級教科書は各基本役を3レベル強化。6種類の不思議カードは全手札の加点、スチール化、追加ドロー、捨て回数と役記録のリセット、活動費、基本6役の総復習を行う。対象不足で使えない効果は消費しない。

新規サポーターは低ランク・奇数/偶数・4スート・初手/最終手・保持カード・少ない山札・各追加強化・A・絵札・役レベル・累計プレイ数などに反応し、組合せによって方針を変えられる。役レベルの成長は教科書以外の既存のレベル上昇も含む。

## 段階解禁・セーブ

専用キー `pixel_spire_poker_progress_v1` に対戦勝利、クリア、到達幕、直近512対戦の受取記録を保存する。本編の進行やカード引継ぎには触れない。

解禁段階は「到達幕−1」「勝利回数÷3の切捨て」「クリア数×3」の最大値（上限8）。勝利時点で保存し、敗北しても次の挑戦へ解禁を持ち越す。3戦目の勝利では次の幕を到達済みとする。旧スコア履歴・進行中セーブの到達幕・旧クリア解禁も初回判定に取り込み、移行結果を保存し、既存プレイヤーに適用する。

新規サポーターは3種ずつ段階0〜7、消費カードは段階0〜6、パックは段階1〜6で解禁。旧拡張サポーター50種の既存解禁は保護し、累計勝利と到達幕によっても候補に追加する。ショップと全パックは同じ解禁済みプールを使用。以前購入したアイテム・開封中パックは解禁条件で没収しない。

挑戦ごとの `runId` と幕・対戦番号を受取記録にすることで、勝利画面や途中セーブを再開しても解禁数を二重加算しない。旧セーブにはIDを補い、保存済みサポーターの関数は既存/追加双方の全カタログから復元する。

ショップの「効果の解禁」から54種類の一覧・効果・解禁条件を確認できる。

## ライバル60人

通常24人とエンドレス36人全員に名前付きの特色を用意。既存のボス能力・目標スコアは保持し、特色とボス条件を重ねて適用する。接敵時の警告は両方を表示。対戦中も上部の小さな警告から再確認できる。

| 例 | 特色 |
| --- | --- |
| ラッキー七海 | 7を役判定と得点から除外し、保持効果も発動しない。7だけならサポーターによる加点も得点0 |
| 計算番長 | 偶数を役判定・得点から除外 |
| 文具王レオ | 4枚以上出すと倍率が半分 |
| 鉄壁ハヤト | J・Q・Kを役判定・得点から除外 |
| 音楽室のソラ | 直前と同じ役は得点0 |
| 美術部モモ | 得点スートが3種類以上なら倍率70% |
| 図書委員レン | 捨てた後のプレイは倍率65% |
| 卒業王アキラ | 5枚未満を出すと得点0 |

無効カードを除外して役を判定し、プレビューと実際の得点を一致させる。倍率の割合低下は小数を保持し、最終得点で整数化するため、低倍率が一律0にならない。対戦ごとの手数・捨て回数は専用カウンターを使い、手数を増やす引換券にも対応する。
