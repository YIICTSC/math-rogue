# Android追加素材ダウンロード

## 目的

Android版はゲームコード・問題データ・セーブ機能をAABへ同梱し、容量の大きい画像・BGM・効果音・ボイスは必要な分だけアプリ内から追加ダウンロードする。

追加素材を保存した後は、対象パックの画像・音声を端末内から読み込む。ランキング、管理ポータル、課題同期、協力・レースなどのオンライン機能を除き、保存済み素材の範囲では通信なしでプレイできる。

## 素材パック

| パック | 現在の概算 | 内容 |
| --- | ---: | --- |
| 基本映像 | 172 MB | 小学校テーマ、共通カード、敵、背景、ミニゲーム |
| 高校映像 | 57 MB | 高校テーマ専用画像 |
| 魔法映像 | 205 MB | 魔法テーマ専用画像 |
| 共通音声 | 141 MB | 基本BGM、効果音、英語音声、ミニゲーム音声 |
| 高校音声 | 81 MB | 高校テーマ専用BGM・ボイス |
| 魔法音声 | 270 MB | 魔法テーマ専用BGM・ボイス・イベント音声 |

容量は素材更新により変わる。アプリ内ではマニフェストの実サイズを表示する。

## 利用者向け動作

- Android版の初回起動時に素材準備画面を表示する。
- 「おすすめ基本セット」は基本映像と共通音声を取得する。
- 「未取得をすべてダウンロード」は全テーマを取得する。
- 設定の「素材」タブから、パック単位で追加・再開・削除できる。
- ダウンロードが中断した場合、取得済みファイルを再利用して続きから再開する。
- 完了後に「反映して再起動」を押すと、以後は端末内素材を優先する。
- 保存先はアプリ専用データ領域で、外部ストレージ権限は不要。アンインストール時に削除される。
- 未取得または更新が必要なパックは従来どおり配信サイトから読み込むため、オンラインならそのままプレイできる。

## ビルド手順

`pnpm run build:android`は次を自動実行する。

1. `public`内の実行用画像・音声からパックマニフェストを生成する。
2. パック単位の内容ハッシュを生成する。
3. Android向けWebアセットをビルドする。
4. 大容量素材をAABへ入れず、マニフェストだけを同梱する。

その後、`pnpm exec cap sync android`でFilesystemとFile TransferプラグインをAndroidプロジェクトへ反映する。

## 配信上の注意

- マニフェストが参照する素材は `https://yiictsc.github.io/math-rogue/` に同じ相対パスで公開する。
- 素材を変更したパックだけ内容ハッシュが変わり、そのパックは再ダウンロード対象になる。
- GitHub Pagesへ素材を反映する前に、新しいAABを公開しない。
- Google Playの説明とデータセーフティでは、追加素材の取得にインターネット接続を使用することを明記する。
