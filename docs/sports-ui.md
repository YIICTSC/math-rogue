# スポーツの開始前UIとイラスト

4種目（ゴルフ、テニス、ドッジボール、バスケットボール）は共通の `SportsSetupScreen` を使用する。ゴルフのクラブハウスをもとに、プレビュー・参加者一覧、参加名・キャラクター、種目設定、招待・問題、開始操作を配置する。

- 開始操作はスクロール領域の外に固定する。
- 通常のスマホ縦横画面では準備項目も1画面に収める。多数の参加者は一覧枠の中だけでスクロールできる。
- 通信方式の説明と遊び方は折りたたみで表示する。招待URLのコピーが失敗した時は、手動コピー欄を開く。
- ホストだけが問題や試合形式を変更・開始できる。参加者は開始待ちを表示し、キャラクターや自身の役割を選べる。
- 共通の招待画面は4種目をイラストで選び、参加名とコードを入力して各種目のロビーへ直接入る。
- バスケットボールにも、ソロ・部屋作成・招待参加の専用タイトル画面を用意する。

生成元PNGは実行環境の `/workspace/generated_images` に保持し、ゲームにはWebPを配信する。高校編の既存主人公、小学校編ドッジボール主人公、既存のバスケ操作イラストを参照し、用具と動作で種目・操作を判別できる構図とした。縦横のタイトル画面は別構図で生成。アイコンは透明背景・文字なしで生成し、ゲーム内のラベルと併用する。

ドッジボールの操作アトラスは `DodgeActionIcon`、種目選択アトラスは `SportMenuIcon` がCSSで参照する。移動パッドは左、6つの操作ボタンは右下にまとめ、ボール所持に応じて主ボタンの投球／キャッチを切り替える。

`pnpm run test:sports:setup` で5サイズのメニュー、各種目のホスト・参加者ロビー、共通招待からの入室と試合開始を検証する。WebGLの描画はスクリーンショットでも確認する。
