# トランプ集のルール精査（2026-10-23）

対象は導入済み73ゲーム。既存の合法手・得点・終了・伏せ情報の検査を実行し、738対戦・155,816手を確認した。カテゴリ別の既存検査も実行。ルールの異なる家庭卓については、カタログに明記した採用ルールを基準とし、無関係な変則へ変更していない。これは全ゲームの全局面を証明するものではない。

## ジンラミー

「10点を超えてCPUがノックする」という報告について、現行の合法手生成は捨てた後の未組合せ点で判定しており、条件違反は再現しなかった。組の最適分解を別実装の全組合せ計算と2,200候補で照合し、CPU同士100配札・2,577手で発生した100ノックもすべて独立計算で10点以下だった。

改善した点：

- ノックを11枚から合法に1枚捨て、残り10枚の未組合せ点が10以下になる場合に限定する共通判定を追加。重複札や、取った捨て札の即返却も拒否。CPU選択でも同じ条件を再確認。
- 10点は受理し11点は拒否する境界テスト、不正なノックが状態を変更しないテストを追加。
- 選択札を捨てた後の点と、ノックボタン上の確定点を表示。
- 終了時にCPUを含む両者の組・余り札・未組合せ点を公開。付け札後の精算点も区別する。対戦中は相手の札を公開しない。
- 「ノック獲得点」と「未組合せ点」を区別。ノックによる得点が10を超えても、ノック条件が10を超えたことを意味しない。

## クレイジーエイト

カタログは「出せなければ引く」方式だったが、出せる札があっても山札から引けていた。合法なプレイがある間はドローを出さず、通信経由のドローも拒否するよう修正。引いた札でプレイ可能になれば、追加ドローを止める。山がなくプレイもできない場合のパスは維持。

## 66／シュナプセン

まだトリックを取っていない時のマリッジ点を即座に加算していた。最初のトリック獲得まで保留し、一度も獲得しなければ得点にしないよう修正。保留点だけで66点の自動勝利を起こさない。得点内訳とログも「宣言・未加算」と実際の加算を区別する。採用ルールの日本語・英語説明も更新。

従来の「30点を持つプレイヤーがマリッジで66点に達する」テストは、既にトリックを獲得した状態として明示した。未獲得・獲得後の両方を別々に検証する。
