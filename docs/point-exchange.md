# 正解ポイントとごほうびの書庫

## 使い方

正解1問で1ポイント。タイトル左上に「ポイント交換 → CREDIT」の順で並ぶ「ポイント交換」で残高を確認し、背景・BGM・ボイスシアターを交換する。過去の解放カウンターは重複加算経路があるため換算せず、導入後の実際の解答から獲得する。新しい冒険の開始でポイントや購入品は失われない。

- 背景はプレビューしてから交換し、購入後に「この背景を使う」で適用する。最初の背景は10ポイント、通常30〜80、豪華背景100〜150。
- 既存18テーマに22テーマを追加し、40テーマ・縦横80画像。追加分は85人の全固定主人公を採用し、22テーマすべてに縦長・横長の別構図をImageGenで描き直す。ぼかしの余白や額装による画面サイズ対応は使わない。画風のラベルと横／縦プレビューで比較できる。
- 主人公を活かしたアニメ、2〜3頭身デフォルメ、劇画、実写調、水彩、油絵・名画風、切り絵、ドット絵など。静かな勉強部屋から星海・世界樹、巨大プリンや魔法実験まで場面も変える。
- 購入済み背景は何度でも無料で適用できる。お気に入りの背景を次の問題で順に切り替える設定もある。解答結果の表示中には切り替えない。
- 暗さ・ぼかし・標準背景へ戻す操作は無料。背景を手動適用・標準へ戻すときは、おまかせ切り替えを解除する。
- BGMは8曲、30〜80ポイント。未購入の曲も20秒試聴できる。購入曲はタイトルとシアターで選曲でき、通常の音量・音声設定を維持する。
- ボイスシアターは10,000ポイントで解禁（購入済みの旧データは継続利用可能）し、その後の編集・再生・保存は無料。
- 累計10・50・100・200・500・1000正解の学習アルバムは、ポイントを消費せず開く。

## ボイスシアター

戦記の主人公の立ち絵と「通常・喜び・心配・決意」の表情、通常／バカンス衣装を使う。人物の表示は透明余白を除いた高さと上端をアステルに統一。左右の衣装はプレビュー上の選択欄で個別に切り替えられる。左右の人物の選択もその場でプレビューと話者に反映し、選択欄と表示人物の食い違いを防ぐ。左右の人物、各行の話者・表情・立ち位置、収録セリフ、背景、セリフ後の間を選べる。戦記以外の主人公は既存の立ち絵を使う（表情差分やバカンス差分は戦記対応人物のみ）。

ボイスは同じ主人公が登場する各ゲームの既存録音を収録。ゲーム名で絞り込み、セリフやクリップ名で検索できる。原稿が確認できない音声はゲーム名とクリップ名を表示し、セリフを創作しない。音声IDと話者の組み合わせも作品読み込み時に検証する。ことばの暮らしの5人には固定録音がないため自由字幕で利用する。

行は最大100行。追加・複製・並べ替え・削除、1行試聴、最初からオート再生、停止、前後移動に対応。自由字幕も編集でき、収録音声は選択した話者のボイスIDで再生する。字幕を自由編集すると音声選択を解除する。旧作品は話者と文言の一致で再生する。自由入力文の新規音声合成は行わない。

作品は24件まで保存し、JSONで書き出し・読み込みできる。読み込んだ作品は新しいIDになり、既存作品を上書きしない。未知の人物、無効な表情・行数・間、過大ファイルなどは拒否する。未購入背景を使う外部作品は標準背景へ戻す。編集内容は有効な状態で下書き保存し、次回再開できる。戦記本編の進行や既読状態は変更しない。

## ポイントの集計

- 共通の解答記録 `storageService.saveAssignmentAnswer` と、算数・漢字・英語・総合問題の確定処理を接続。
- 共通問題画面から親へのコールバックには同じ `pointReceipt` を引き継ぐ。問題のオブジェクト・出題位置が変わると新しい解答IDにし、多重クリック・コールバック・再描画による二重加算を防ぐ。
- 独自出題を持つスポーツ、カート、クラフト、VRも共通解答記録へ接続。ゴルフには確定結果の記録を追加した。スポーツ・カート・クラフトにはサーバーの出題ID・回答トークンなどを使う識別子を付ける。
- 本編イベントの明示的な正答選択、タイピングの1出題を完了した場合も対象。デバッグの解放カウンター増加・問題プレビュー・観戦での加算はしない。
- 財布は `pixel_spire_point_exchange_v1`。購入品・消費ポイントを同じJSON書き込みで保存し、保存失敗では交換を成立させない。Web Locksとタブ内キューで競合を抑制する。
- `pixel_spire_` のデータ移行対象に、財布・所有品・設定・作品・下書きがまとめて含まれる。

## 素材

原画: `assets/point-exchange/backgrounds/`。配信画像: `public/sprites/point-exchange/`。原画・WebPのハッシュを `assets/point-exchange/art-build.json` に保持する。

```sh
node scripts/prepare-point-exchange-art.mjs
node scripts/verify-point-exchange-art.mjs --preview
node scripts/generate-web-asset-manifest.mjs
node scripts/generate-android-asset-manifest.mjs --update-prefix sprites/point-exchange/
```

## 検証

```sh
pnpm run test:points
pnpm run test:points:browser
pnpm run verify:points:art
pnpm run audit:english:gate
pnpm run build
pnpm run server:build
```

ブラウザ試験は、4種類の実問題画面からの加算、交換・適用・お気に入り、80画像の復号、縦横レイアウト、表情・ボイスの対応、作品保存・書き出し・読み込みの検証、データ移行、BGM選曲、複数タブの重複防止、英語・ひらがなUIを確認する。音声テストでは実セリフの音声IDへの対応を検証し、再生デバイスへの出力はモックする。

## デバッグ解禁

`VITE_ENABLE_DEBUG_FEATURES=true` のテスト環境でデバッグメニューを開くと、そのタブのセッションで全交換物とミニゲームのエンドレス入口が利用可能になる。財布への架空ポイント付与・購入履歴・本編クリア偽装は行わない。タブ終了後や通常の公開ビルドでは購入条件を適用する。実際にデバッグ中に遊んだセーブは通常の保存規則に従う。対象は継界戦記、ダンジョンズ1/2、校長対決、紙飛行機、ポーカー、配置型TCG、麻雀。

固定主人公一覧は `src/point-exchange/cast.json`、出演割り当てと生成方針は `backgroundCast.json`。プレイヤーが自由に作るVR・カート等のアバターは有限の固定主人公一覧に含めない。

```sh
node scripts/build-theater-cast.mjs
node scripts/render-point-companions.mjs
node scripts/prepare-point-cast-references.mjs
node scripts/build-theater-voices.mjs
node scripts/test-theater-voices.mjs
node scripts/test-point-debug.mjs
```

立ち絵の表示用メトリクスは `node scripts/build-point-portrait-metrics.mjs` で再計測し、`node scripts/test-point-portraits.mjs` で検証する。85人の通常立ち絵と44人の既存バカンス立ち絵に対応。旧作品の共通バカンス設定も読み込み、個別衣装を設定すると左右別に保存する。

表示設定のバーとお気に入り切り替えは、操作した値をその場で確定し、保存待ちの間も表示を維持する。設定の直下で濃さ・ぼかしの見え方を確認でき、問題画面も同じ描画処理を使用する。保存失敗時はエラーを表示し、バーを保存済みの値へ戻す。標準背景の場合は交換背景の適用が必要なことを表示する。
