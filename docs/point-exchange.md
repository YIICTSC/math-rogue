# 正解ポイントとごほうびの書庫

## 使い方

正解1問で1ポイント。タイトルの「ポイント交換」で残高を確認し、背景・BGM・ボイスシアターを交換する。過去の解放カウンターは重複加算経路があるため換算せず、導入後の実際の解答から獲得する。新しい冒険の開始でポイントや購入品は失われない。

- 背景はプレビューしてから交換し、購入後に「この背景を使う」で適用する。最初の背景は10ポイント、通常30〜60、豪華背景100〜150。
- 18テーマそれぞれに縦横の新規イラスト、計36構図。画風のラベルと横／縦プレビューで比較できる。
- 主人公を活かしたアニメ、2〜3頭身デフォルメ、劇画、実写調、水彩、油絵・名画風、切り絵、ドット絵など。静かな勉強部屋から星海・世界樹、巨大プリンや魔法実験まで場面も変える。
- 購入済み背景は何度でも無料で適用できる。お気に入りの背景を次の問題で順に切り替える設定もある。解答結果の表示中には切り替えない。
- 暗さ・ぼかし・標準背景へ戻す操作は無料。背景を手動適用・標準へ戻すときは、おまかせ切り替えを解除する。
- BGMは8曲、30〜80ポイント。未購入の曲も20秒試聴できる。購入曲はタイトルとシアターで選曲でき、通常の音量・音声設定を維持する。
- ボイスシアターは200ポイントで解禁し、その後の編集・再生・保存は無料。
- 累計10・50・100・200・500・1000正解の学習アルバムは、ポイントを消費せず開く。

## ボイスシアター

戦記の主人公の立ち絵と「通常・喜び・心配・決意」の表情、通常／バカンス衣装を使う。左右の人物、各行の話者・表情・立ち位置、収録セリフ、背景、セリフ後の間を選べる。

行は最大100行。追加・複製・並べ替え・削除、1行試聴、最初からオート再生、停止、前後移動に対応。自由字幕も編集でき、音声があるのは話者と文言が収録ボイスに一致するときのみ。自由入力文の新規音声合成は行わない。

作品は24件まで保存し、JSONで書き出し・読み込みできる。読み込んだ作品は新しいIDになり、既存作品を上書きしない。未知の人物、無効な表情・行数・間、過大ファイルなどは拒否する。未購入背景を使う外部作品は標準背景へ戻す。編集内容は有効な状態で下書き保存し、次回再開できる。戦記本編の進行や既読状態は変更しない。

## ポイントの集計

- 共通の解答記録 `storageService.saveAssignmentAnswer` と、算数・漢字・英語・総合問題の確定処理を接続。
- 共通問題画面から親へのコールバックには同じ `pointReceipt` を引き継ぐ。問題のオブジェクト・出題位置が変わると新しい解答IDにし、多重クリック・コールバック・再描画による二重加算を防ぐ。
- 独自出題を持つスポーツ、カート、クラフト、VRも共通解答記録へ接続。ゴルフには確定結果の記録を追加した。スポーツ・カート・クラフトにはサーバーの出題ID・回答トークンなどを使う識別子を付ける。
- 本編イベントの明示的な正答選択、タイピングの1出題を完了した場合も対象。デバッグの解放カウンター増加・問題プレビュー・観戦での加算はしない。
- 財布は `pixel_spire_point_exchange_v1`。購入品・消費ポイントを同じJSON書き込みで保存し、保存失敗では交換を成立させない。Web Locksとタブ内キューで競合を抑制する。
- `pixel_spire_` のデータ移行対象に、財布・所有品・設定・作品・下書きがまとめて含まれる。

## 素材

原画: `assets/point-exchange/backgrounds/`。配信画像: `public/sprites/point-exchange/`。原画・WebPのハッシュを `assets/point-exchange/art-build.json` に保持する。

```sh
node scripts/prepare-point-exchange-art.mjs
node scripts/verify-point-exchange-art.mjs --preview
node scripts/generate-web-asset-manifest.mjs
node scripts/generate-android-asset-manifest.mjs --update-prefix sprites/point-exchange/
```

## 検証

```sh
pnpm run test:points
pnpm run test:points:browser
pnpm run verify:points:art
pnpm run audit:english:gate
pnpm run build
pnpm run server:build
```

ブラウザ試験は、4種類の実問題画面からの加算、交換・適用・お気に入り、36画像の復号、縦横レイアウト、表情・ボイスの対応、作品保存・書き出し・読み込みの検証、データ移行、BGM選曲、複数タブの重複防止、英語・ひらがなUIを確認する。音声テストでは実セリフの音声IDへの対応を検証し、再生デバイスへの出力はモックする。
