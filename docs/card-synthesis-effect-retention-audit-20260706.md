# カード合成 効果継承監査メモ

作成日: 2026-07-06

目的: カード合成後に、素材カードの特殊効果が `originalNames` 経由で実戦効果・合成説明へ残るか確認する。特に `時間どろぼう` のように、素材名ではなく合成後カード名だけを見ていたため効果が落ちるケースを潰す。

## 前提

|項目|仕様|
|---|---|
|合成後カード|`synthesizeCards()` が素材カード名を `originalNames` に保持する。|
|汎用効果|`damage`, `block`, `draw`, `energy`, `poison`, `weak`, `vulnerable`, `applyPower` などはプロパティとして合算・継承される。|
|特殊効果|カード名/ID分岐で処理されるものは、`card.name` だけでなく `card.originalNames` も見る必要がある。|
|合成説明|`src/utils/cardUtils.ts` の `specialDescMap` にない特殊効果は、実効果が残っていてもカード面に出ない。|

## 今回修正した継承漏れ

|カード/効果|問題|修正|
|---|---|---|
|時間どろぼう|合成後カード名では `時間どろぼう` 判定に入らず、敵行動遅延が発動しない。|`App.tsx` の判定に `originalNames` と `TIME_THIEF` ID系を追加。合成説明に `敵行動を1ターン遅延` を追加。|
|羅生門|合成後カードで撃破時の手札廃棄選択が発動しない。|`App.tsx` の判定に `originalNames` を追加。合成説明に `撃破時に手札1枚廃棄` を追加。|
|次元跳躍|`cardEffectLogic.ts` 内で `targetName` ではなく `card.name` を見ていたため、合成後は通常の追加ターン扱いになる可能性。|分岐を `targetName === '次元跳躍'` に変更。|
|えんぴつの削りかす|`ACCURACY` の削りかす威力補正が合成後カードに乗らない。|`App.tsx` の判定に `originalNames` を追加。|
|寄生虫|ショップ削除時の最大HP処理が合成後カードに効かない。|`App.tsx` の削除処理2箇所に `originalNames` を追加。|
|ボディスラム|強化時のコスト0化が合成後カードに効かない。|`getUpgradedCard()` に素材名判定ヘルパーを追加。|
|限界突破|強化時の廃棄解除が合成後カードに効かない。|`getUpgradedCard()` に素材名判定ヘルパーを追加。|
|触媒|強化時のドクドク倍率3化が合成後カードに効かない。|`getUpgradedCard()` に素材名判定ヘルパーを追加。|
|モモ / ICE_CREAM|実効果のパワーIDが合成説明で内部ID表示寄りになる。|`describeSynthPower()` に `ICE_CREAM` の説明を追加。|
|虚無|合成後カードとして引いた場合に、ドロー時エナジー減少が発動しない箇所が残る。|通常ドロー、手札入れ替え、追加ドロー処理の `虚無` 判定に `originalNames` を追加。|
|天気予報|合成後カードで英字ID由来の素材名が残る場合、山札確認処理の判定が不十分。|`RIKA_WEATHER` の `originalNames` / ID 判定を追加。|
|銀河鉄道の夜 / 秘密のプレゼント|合成後カードで英字ID由来の素材名が残る場合、重複汎用処理の除外判定が不十分。|`GALAXY_EXPRESS`, `GIRLS_GIFT_BOX` の `originalNames` 判定を追加。|
|火/雷/大掃除系VFX|合成後カード名では素材由来の演出分類が落ちる。|素材名も見て `FIRE` / `LIGHTNING` / `EXPLOSION` を選ぶよう補強。|

## 現在の判断

|観点|状態|
|---|---|
|汎用プロパティ効果|合成後も残る。|
|主要な名前分岐特殊効果|今回確認できた範囲では `originalNames` 対応済み、または追加対応済み。|
|合成説明の特殊効果表示|今回確認した主要特殊カードは追加済み。|
|完全保証|静的監査は通過。選択モーダル依存効果は実機確認も併用する。|

## 残るリスク

|リスク|内容|確認方法|
|---|---|---|
|IDだけの分岐|`card.id?.includes(...)` のみで成立する処理は、合成後IDが `synth-...` になるため落ちる可能性がある。|`scripts/audit-card-synthesis-effect-retention.mjs` で監査。現在0件。|
|説明だけ不足|実効果は `originalNames` で発動しても、`specialDescMap` にないと合成説明に出ない。|`scripts/audit-card-synthesis-effect-retention.mjs` で監査。現在0件。|
|選択UI依存|山札選択、手札選択、対象選択などのモーダル起動効果は、合成カードの複合効果と競合しやすい。|対象カードを合成素材にして実機でモーダルが出るか確認。|
|強化時特殊|`getUpgradedCard()` の個別分岐は、素材名を見ないと合成後の強化で落ちる。|`getUpgradedCard()` 内のカード名分岐を継続監視。|
|戦闘外効果|ショップ削除、報酬、イベントなど戦闘外でカード名を見る処理。|`card.name ===` の全件検索で `originalNames` の併記を確認。|
