# テニスの試合時間と必殺球の返球

- UIおよび新規対戦の初期設定は3ゲームセット。1/3/6ゲームの手動選択は維持。
- 通常球の受付範囲1.65mに対し、必殺球は1.05m以内、ショット入力から80ms以内に制限する。通常の320ms先行入力は必殺球には使えない。
- タイミングを外して返球を試みるか、返球できず身体に当たると、相手の得点となり1.25秒間回転する。ポイント表示中も回転状態の残り時間を進め、次のサーブ時には解除する。
- 速い球がフレーム間で打点へ入った場合も、直撃判定の前に新しい位置で返球の成否を確認する。
- 飛球には独立した`star`属性を保持する。打った本人が次のショットを予約しても、飛んでいる必殺球の強さ・演出は変わらない。
- CPUも同じ狭い受付範囲を使い、打点に入った際に45%でジャスト入力を試みる。常時更新される先行入力で必ず返球することを防ぐ。
- `spinStun`はサーバーの試合状態から配信し、3Dキャラクターの回転に適用する。

検証: `scripts/test-tennis.mjs`（初期値、成功/早すぎる入力/未入力、速い球、既存の試合進行）、`test-tennis-star-browser.mjs`（実3Dの回転と復帰）、`test-tennis-server.mjs`、`test-tennis-browser.mjs`。
