# テニスのスマッシュとゴルフ拡張

## 遊び方と収録内容

- テニス：相手のボールが頭上2.35〜3.7m、水平距離1.35m以内、上昇速度1.8m/s以下の打ちごろに、トップスピン／スターショットがスマッシュ／必殺スマッシュへ変化する。タッチ・キーボードはこの瞬間に押すと即打球。必殺には従来どおりゲージが必要。サーブのノーバウンド返球には使えない。
- ゴルフ3D：クラシック18ホールに加え、冒険18ホールを設定画面で選択できる。丘、すり鉢、山越え、谷、浮島を収録。オンラインはホストが選び、参加者へ同期する。
- ゴルフ2D「星渡り2D」：通常のゴルフ設定のコース選択から、クラシック／冒険／2Dを選ぶ。2Dは「草原と氷晶」「遺跡と雲海」「工房と星屑」「紅蓮と虹」の18ホール×4コース＝72ホール。ひとりプレイと最大40人のオンラインラウンドに対応し、単元選択、3問ごとの3打、スコア、観戦、ラウンド結果の共通フローを使う。

## 操作

- 3Dの風向矢印は、カメラの右・上ベクトルに物理の風を投影して表示する。画面を回した場合も同じ向きで表示する。
- 方向スライダーは左へ動かすと画面左、右へ動かすと画面右へ狙う。キーボード・ゲームパッドも同じ符号を使う。
- 自由視点からショットを押すと、最初の一回でショット視点へ戻る。次の一回からゲージを開始する。Enterはスライダーやボタンにフォーカスが残っていてもショット操作になる。
- 2Dは左右で角度、ショットの1回目でパワーゲージ、2回目で打球。長押しして離す方式にも変更可能。Enter、左右キー、B（空中ブレーキ）、R（時戻し）が初期設定。メニューで割り当てを変更できる。
- 2Dの画面ドラッグでコースを探索、ダブルタップで追従へ戻る。全景ボタンでもコースを見渡せる。

## 学習・仕掛け・救済

開始時と3ショットごとに選択単元の3問を出題。正解は共通の学習ポイントと打球のパワー、必殺ゲージへ反映する。通常球は無制限、特殊アイテムは初期0個。正解してもアイテムは増えない。カップイン後はキャラクターが喜び、専用モーダルの異なる3枚のカードから1枚を選んで1個獲得する。所持品は次のホールへ持ち越す。追加アイテムは吸着、氷渡り、鉄星、反跳、ふわり、幻影、空中ブレーキ、時戻し。吸着は壁・天井から再打球、氷渡りは水面を凍結、鉄星はもろい壁を破壊、幻影は同じ壁を透過する。

2Dの仕掛けは動く足場、バネ、送風、逆重力、ワープ、バンパー、水、溶岩、砂、氷、吸着面、破壊壁、宝石。危険に入ると1打罰で直前の打球位置へすぐ戻る。18打に達すると次ホールへ進める。危険で元の足場が破壊済みの場合も、残った地形から安全な復帰点を探す。打数上限での終了にはカード報酬を付けない。

正解6問で必殺ゲージが満タンになり、破砕スペシャルを選択できる。次の打球でゲージを消費し、衝突した地形を実際のポリゴンから切り出した破片へ分割する。飛散・回転・衝突して止まった破片は足場として使え、吸着球は動く破片にも付着できる。カップの土台は保持する。同じホールの地形破壊はホスト／サーバーで一度だけ計算し、参加者と観戦者へ同期する。時戻しは自分の打球と所持品に作用し、共有地形の破壊は巻き戻さない。

2Dの必殺ショットは、3Dと共通の `SportsPresentation` を使ってキャラクター別カットインとゴルフ必殺ボイスを再生する。通常打球とスコア別の審判コールも共通。カード獲得・次ホールの準備・カップイン・ミス後の立て直しには、選択した主人公の既存のダンジョンズ／帰宅ダッシュの短いボイスを流用し、技名や判定の音声が終わってから再生する。3Dキャラクターは正面を向いてスイングし、喜ぶ、うなずく、構える、悔しがる動きを使い分ける。

## 計算・調整箇所

- `tennis/engine.ts` の `SMASH_WINDOW` と `ballFlight`：スマッシュの高さ・距離・速度と弾道。
- `gakuro-golf/adventureCourses.ts`：冒険18ホールの配置。
- `gakuro-golf/course.ts` の `groundHeight`／`groundSlope`：描画、着地、転がり、弾道予測で共通使用。ティーとカップ周囲は平らにする。
- `gakuro-golf/side-golf/courses.ts`：72ホールの地形・仕掛け、18ホールずつのコース区分、アイテム説明。
- `gakuro-golf/side-golf/physics.ts` の `SIDE_RULES`：240Hzの打球物理。基準速度138、重力103とし、従来より約2倍のテンポに調整。ガイドはパワーや着地を予測せず、発射角の短い矢印だけを表示する。
- `side-golf/debris.ts`：120Hzの共有破片物理。破片は最大96個に制限し、ネットワーク負荷を抑える。
- `engine.ts`：特殊球の消費、6正解の必殺ゲージ、カード3択の生成と取得、同じカードの再取得拒否をホスト／サーバーで判定する。
- ゴルフの通信プロトコル3を維持し、クラシックは旧サーバー・旧クライアントと接続可能。冒険と2Dは追加の対応フラグ（`terrain:1`、`sideGolf:1`）で確認し、全員が対応する場合に選択できる。2Dの個人用スナップショットには自分／観戦対象の所持品と共有破片を含め、各参加者の問題とカード選択は他人に送らない。専用サーバーで新コースを使う際はサーバー側も更新する。Renderのデプロイは通常の手動運用に従う。
