# オンライン・ドッジボール

スポーツクラブの3種目目。既存のゴルフのキャラ部品・主人公3Dモデルを利用する。くにおくん系の内野／外野、体力制、キャッチ、強力な球の遊びを参考にしたオリジナル実装で、同作の画像・キャラクター・音楽は使用しない。

## チームと大会

- 内野は各チーム3人。全員同じ体力3から開始し、キャラの見た目による性能差はない。
- 出場者をシード付き乱数でシャッフルし、ラウンドロビンで各チームへ配る。人間の人数差は最大1人。その後で不足枠だけCPUを入れる。
- 2〜6人は2チームの対戦。7人は3/2/2人、10人は3/3/2/2人。出場は最大24人・8チーム、観戦者を含む部屋全体は最大32人。
- 7人以上ではシングルエリミネーション。端数は不戦勝、複数コートを並行進行し、勝者が次へ進む。大会中の新規参加は観戦。チーム編成は大会中維持し、再試合時に組み直す。
- 被弾で体力がなくなった選手は相手コート奥の外野へ移り、投球・パスで支援できる。相手内野が全滅すると勝利。3分時点は内野人数→残り体力で判定し、同点なら次の命中で決着する。
- 試合前と試合中60秒ごとに、そのコートで3問の学習。学習時間は制限時間に含めない。正解とキャッチ等で必殺ゲージを回復する。

## 操作・画面

方向キー／WASD／パッドで移動、Zで投球、Xでタイミングを合わせてキャッチ、Spaceで回避、Cでパス、Shiftで必殺球。タッチとゲームパッドにも対応。方向バーは廃止し、投げる瞬間の方向入力で狙う列を選ぶ。投球直後0.4秒の新しい方向入力で、速度を増やさず最大約7度まで球筋を調整できる。操作できるのは投げた本人だけで、パスには適用しない。横画面ではコートと入力軸を合わせて左右対決、縦画面では上下対決とする。内野を失ったプレイヤーも外野で操作できる。GPUが利用できない場合は同じシミュレーションの2D表示に切り替える。

テニスとドッジボールは、それぞれ専用保存キーでキャラ作成を保存する。ゴルフと同じ顔・髪・種族・服などの作成に加え、既存主人公の選択は共通の全画面ギャラリーで行う。ゴルフ・カート等の既存のキャラ作成からも同じ大きな主人公選択画面を使用できる。対戦開始後の外見変更は受け付けない。キャラ作成画面では、作成キャラと既存主人公のどちらも、ボールを持って振りかぶり、実際に球を放つ専用の投球練習を繰り返す。

## 通信・運用

- ホスト方式はPeerJS/WebRTC。専用サーバー方式は `/dodgeball` WebSocket。招待URLは `dodgeballRoom=H-xxxxxx` / `S-xxxxxx`。
- 物理、ダメージ、キャッチ判定、チーム分け、大会進行、問題の採点はホスト／サーバーが管理する。クライアントは自分の入力だけを送る。公開状態には他人の問題や未回答問題の正解を含めない。
- 切断した選手の操作はCPUで補完し、人間が全員抜けたチームは不戦敗。専用サーバーではロビーホストを引き継げる。退出時は既存の共通リザルト方式を使う。
- mainへのアップロードだけではRenderはデプロイしない。専用サーバーの新エンドポイントは管理者がRenderを手動反映した後に利用できる。

検証: `node scripts/test-dodgeball.mjs`、`test-dodgeball-server.mjs`、`test-dodgeball-peer-browser.mjs`、`test-dodgeball-browser.mjs`。人数1〜24の均等分け、物理的な命中・キャッチ・回避・パス、7人の両通信方式、大会完了、スマホ縦横、キャラ作成・保存・英語表示を確認する。

方向入力・投球プレビューの検証: `pnpm run test:sports:direction`、`pnpm run test:sports:direction:browser`。ゴルフの操作とキャラ作成画面は変更していない。

## 全画面の試合表示

試合中は3Dアリーナを画面全体に描画し、体力・残り時間は上端、移動パッドは左下、6つの操作ボタンは右下に重ねる。横画面ではヘッダー操作とスコアを同じ高さにまとめ、縦画面ではスコアをその下に配置する。ノッチとホームインジケーターの安全領域を避け、タッチ対象は44px以上を確保する。

コート、両外野、ジャンプ中の頭までがHUDの間に収まるよう、画面比率と利用可能領域から正射影カメラを調整する。画面回転・ウィンドウサイズ変更・操作チームの変更時に追従し、観戦では操作欄の分の空間もコートに使う。GPUが使えない場合の2D表示も同じ領域と縦横の向きに追従する。

`pnpm run test:dodgeball:layout` で320×568〜2560×1080の11サイズ、両チームの視点、HUDの重なり、外野とジャンプの見切れ、44pxの操作対象、安全領域、リサイズ、メニュー、観戦、2D表示を検証する。生成したスクリーンショットは `tmp/dodgeball-layout/` に保存する。
