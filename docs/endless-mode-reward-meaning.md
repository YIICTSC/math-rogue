# エンドレスモード：報酬の意味と運用方針

更新日：2026-09-06

## 1. 方針

エンドレスモードのボスギミックは使用しない。ボス戦は、通常のカードバトルと戦闘後の学習問題で完結させる。ただし、アズキ・ドドメデスなど、物語上の特殊ボスに紐づく専用カード報酬はエンドレスモードでも維持する。

ボス撃破後にプレイヤーが考えることは、次の3つだけにする。

1. 今すぐ生存率を上げるか
2. 次の数戦闘を有利にするか
3. 次回以降の周回や物語を解禁するか

`S01`、学習判定の回数、同じ単元、ATTACK・SKILL・POWERの達成状況などは、ボス撃破条件として使用しない。報酬の説明に学習やカードの条件が残っている場合も、それは報酬を取得した後の任意の効果であり、ボスを倒すための条件ではない。

## 2. 報酬を受け取る流れ

エンドレスモードのボスは、通常モードのボスと同じ報酬処理を使う。戦闘後の問題に答えたあと、正解数に応じたボーナスゴールドを加え、通常のボス報酬画面を表示する。

| 節目 | 固定報酬 | 選択報酬 | 意味 |
|---|---:|---|---|
| エンドレスの通常ボス・大ボス | 通常ボス報酬の100G＋問題正解ボーナス | 通常のカード報酬、レリック、ポーション等 | 通常モードと同じ選択で、次の戦闘へ備える |
| エンドレス第50章ボス | 通常ボス報酬 | 通常のボス報酬 | 報酬後に最終章結果・真エンディングへ進む |
| 真エンドレスのボス | 通常ボス報酬の100G＋問題正解ボーナス | 通常のカード報酬、レリック、ポーション等 | 深い階層を継続するための補給 |

ボス報酬は、ギミック達成の成否に関係なく、問題終了後に通常の報酬画面として表示する。特殊ボスの場合は、この通常の報酬処理に専用カード報酬を追加する。専用3択、専用再抽選、専用の恒久報酬は使用しない。

以下の選択枠・効果一覧は、専用報酬を再設計するときの保留中の設計メモであり、現在のゲーム内報酬には使用しない。

## 3. 選択枠が表す意味

| 枠 | プレイヤー向けの意味 | 選ぶ場面 |
|---|---|---|
| SAFE | 事故を減らし、今の周回を安定させる | HPが少ない、次の区間を安全に進みたい |
| LEARNING | 学習・記録・手札を、継続的な資源へ変える | 問題への取り組みをカードや防御へつなげたい |
| RISK | HP・弱体・将来の制限と引き換えに、大きな一手を得る | 多少の危険を受け入れて一気に強くしたい |
| CORE | 大ボス後の基盤を作る | 防御・ルール対策・戦闘の安定性を優先したい |
| GROWTH | 以後のカード・ルート・戦闘を伸ばす | 直後の回復より、数戦闘先の強さを重視したい |
| CONTRACT | 強力な効果と明確な代償を交換する | 自分のデッキやHPに余裕があり、代償を管理できる |
| PERMANENT | 次回のエンドレス開始時にも残る成長 | 今周回より、次の挑戦を楽にしたい |
| RECORD | 物語・高難度・解禁情報を残す | 真エンディング後の収集や設定解放を進めたい |

## 4. 報酬効果の意味

### 4.1 安定・防御系

| 効果の種類 | 意味 |
|---|---|
| 最初の弱体を無効化 | 事故の連鎖を1回止める保険 |
| 状態異常を解除・開始時に無効化 | ボス後の立て直しを早める |
| 致死ダメージをHP1で耐える | 1回だけ敗北を回避する非常用の命綱 |
| 敵の行動を遅延・行動内容を先読み | 防御や攻撃の準備時間を作る |
| ブロック・エネルギーを得る | 次の戦闘の初動を安定させる |
| 呪いを除去・カードを元へ戻す | デッキの事故要因を減らす |

### 4.2 手札・カード系

| 効果の種類 | 意味 |
|---|---|
| ドロー | 必要なカードへ早くアクセスする |
| カード報酬の候補を増やす・タイプを分ける | 欲しいカードを選びやすくする |
| カードの数値効果を強化 | 少ないカード枚数でもデッキの出力を上げる |
| カードを再取得・再抽選 | 取り逃した選択肢を取り戻す |
| カード効果の再使用・複製 | 強いカードをもう一度使う代わりに、条件や代償を管理する |
| 呪いを除去する代わりに最大HPを失う | デッキの軽量化と耐久力を交換する |

### 4.3 ルート・情報系

| 効果の種類 | 意味 |
|---|---|
| 次のノードやイベントを先読み | 不利な道を避け、必要な報酬へ向かう |
| 分岐を追加表示 | ルート選択の自由度を上げる |
| 階層ルールを1回無視 | 深い階層の不意打ちを受け流す |
| 報酬画面を再抽選 | 現在のデッキに合わない報酬を選び直す |
| 小危険ノードを無視 | HPや資源を温存して次の節目へ進む |

### 4.4 代償付きの逆転系

| 効果の種類 | 代償の意味 |
|---|---|
| ダメージ・攻撃を大幅強化 | HPを支払い、短期決戦で被害を減らす |
| 追加ターン | HP、腐蝕、弱体などを支払って行動回数を増やす |
| レリック効果やカードを強化 | 混乱、疲労、回復禁止などを受け入れて爆発力を得る |
| 敵ブロックを無視 | 自分のブロック上限などを下げ、攻撃を通す |
| ノイズや不要カードを変換 | デッキの不安定さを増やし、目先のエネルギーやダメージに変える |

## 5. 最終ボス報酬の意味

C50の報酬は、通常の一時的な強化と、エンドレス全体の解禁を分けて表示する。

| 選択 | 各編での意味 |
|---|---|
| 開始報酬枠＋1 | 次の周回で、序盤の選択肢を増やす |
| 開始分野・フォーム・チャレンジの解禁 | 次回開始時の自由度を上げる |
| 首領記録・高難度条件の解禁 | 真エンディング後の物語と挑戦目標を増やす |
| マジック編の変身ゲージ10 | 魔法編の序盤から変身戦略を使えるようにする |

PERMANENTはその場で得たカードやHPではなく、プロフィールに記録される長期的な解禁である。RECORDは強さを直接増やす報酬ではなく、物語・高難度・収集要素を進める報酬である。

## 6. 各編の報酬設計

| 編 | 序盤の意味 | 中盤の意味 | 終盤の意味 |
|---|---|---|---|
| 小学生編 | 失敗を減らし、ドロー・ブロック・ルート選択を覚える | デッキ整理、情報取得、カード強化で安定した周回を作る | 呪い除去、復元、致死回避で最終区間を乗り切る |
| 高校編 | 再抽選、科目ごとのドロー、低HP時の資源化で選択を広げる | 状態異常、敵行動、階層ルールへの対応力を上げる | 回復禁止などの代償を管理し、高難度解禁につなげる |
| マジック編 | カード種類の切替と追加ターンで魔法の流れを作る | 属性封印、変身、状態異常、イベント情報を管理する | 変身の持続・複製・固有能力を使い、原典解禁へつなげる |

## 7. 真エンドレスの報酬

C51以降も、ボス撃破後は通常ボス相当の報酬処理を使う。特殊ボスが登場した場合は、アズキ・ドドメデスなどの専用カード報酬を維持し、それ以外の専用深層報酬は保留する。

| 報酬 | 効果 | 意味 |
|---|---|---|
| カード報酬 | 通常のカード候補から選択 | デッキの方向性を伸ばす |
| レリック報酬 | 通常のボスレリックを獲得 | 深い階層での戦略を補強する |
| ゴールド・ポーション | 通常の報酬量を獲得 | 次のショップ・戦闘へ備える |

深い階層でも、プレイヤーは通常モードと同じ報酬表示から意味を判断できる。専用内部IDや未説明の条件を表示して、達成方法を推測させることはしない。

## 8. 画面表示の要件

- ボス撃破後は、戦闘後の問題を経て通常のボス報酬画面を表示する。
- 報酬カードには、通常モードと同じ効果説明を表示する。
- ギミック、弱点、区間、学習判定の進捗、達成済み表示はエンドレスのマップ・戦闘画面に表示しない。
- 報酬の代償は、選択前に常に表示する。例：「次のボスまで回復不可」「HP8」「腐蝕2」。
- 報酬を選択した直後に、付与された効果を章結果または休息画面で確認できるようにする。
