# 帰宅ダッシュ：カード強化と対空戦

## 強化の流れ

経験値でレベルが上がる → 学習問題 → 3枚のカードから1枚選択 → 走行再開。カード選択中は走行・射撃・墜落演出を停止する。

全48種類（従来33種を段階強化に改修、新規15種）。カードには専用イラスト、カテゴリ、現在→次のLv、次段階の効果、星を表示し、下に今回の装備を並べる。各強化は最大Lv5、一部の弾数・ジャンプ系は最大Lv3。同じ装備を選ぶと次段階になり、最大Lvの装備は候補から外れる。全習得後は全回復の補給カードに切り替える。レベルは1回の挑戦内で保持し、新しい挑戦ではリセットする。日替わりモードの選択候補はシードに従う。

えんぴつの派生強化は基本ミサイル取得後に出現する。別の強化を取っても、習得した多段ジャンプや射撃機能が弱体化しないよう、装備レベル全体から効果を計算する。

## 新規15種

| 装備 | 効果・レベルアップ |
| --- | --- |
| 対空ロケット | 飛行敵へ自動発射。威力・連射を強化 |
| スカイレーダー | 飛行敵を追尾するミサイル。威力・連射を強化 |
| 迎撃ドローン | 上方から追尾射撃。威力・連射を強化 |
| 天頂レーザー | 貫通射撃。威力・連射を強化 |
| 雷雲コール | 飛行敵全体へ雷撃。威力・頻度を強化 |
| 重力ネット | 飛行敵の移動を減速し拘束弾を発射。減速・威力・連射を強化 |
| 旋風ブレード | 追尾する貫通刃。威力・連射を強化 |
| 花火バースト | 3発の範囲爆発。威力・爆発範囲・連射を強化 |
| 精密スコープ | 対空武器の会心率を上昇 |
| 爆圧コンデンサー | 対空武器の威力を上昇 |
| 空色グライダー | 落下速度を抑制 |
| リカバリーブーツ | 被弾後の無敵時間を延長 |
| シールド電池 | 予備シールドを自動充電。枚数・充電速度を強化 |
| 集金マグネット | 常時コインを吸引。範囲を強化 |
| コンボリスト | コンボを継続できる時間を延長 |

対空装備を未取得の場合は対空ロケットを強化候補に必ず含める。ボスエリアにも対空ロケットを入手できるカプセルを配置する。装備は自動射撃で、追加ボタン操作を必要としない。

## 飛行敵・撃墜

通常飛行敵12種：チョークドローン、紙装甲ワイバーン、目覚ましゴースト、蛍の斥候、甲虫パトロール、ノコギリ飛魚、鉛筆ファイター、浮遊クラゲボット、機巧フクロウ、飛行教科書ミミック、蒼翼マンタ、空路機関車。進行に伴って登場する種類が増え、HPも段階的に増える。

ボス4種：紅蓮の飛行船（HP12）、黄金機竜（HP16）、星核UFO（HP14）、天空時計城（HP20）。撃破しない場合は20秒で撤退する。既存のエリアごと1回のダッシュによる撃破も維持。

描画と当たり判定は共通座標を使用。高速弾は移動区間を含めて判定し、貫通弾は同じ敵に連続加点しない。HP0で敵の判定を即座に除去し、得点・撃破数は1回だけ加算する。倒れた敵は回転しながら落ち、8コマの爆発と煙を繰り返して消える。画面全体のフラッシュは使わず、動きを減らす設定では回転を止める。演出数には上限を設ける。

## 素材と検証

- ImageGen生成元：`assets/go-home-dash/upgrades/`。48アイコン、16飛行敵、爆発8フレームの原本とSHA-256を保持。
- 実行用：`public/sprites/go-home-dash/upgrades/`、4アトラス計約1.06MB。爆発は各セルを共通倍率で正規化し、フレームごとのサイズ合わせは行わない。
- 加工：`node scripts/prepare-home-dash-upgrades.mjs`。
- ゲーム検証：`node scripts/test-home-dash-upgrades.mjs`、`node scripts/test-home-dash-upgrades-browser.mjs`。
- 既存操作・コース回帰：`node scripts/test-home-dash-rush.mjs`、`node scripts/test-home-dash-course.mjs`。
