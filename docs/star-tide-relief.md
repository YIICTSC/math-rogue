# 星潮の航路：段差と高台の探索

屋外96区画に、既存の主動線から坂で登る段丘を追加。屋内の箱・鏡・回路・氷の仕掛けは変更しない。出入口、野営地、灯台、宝箱、採集地点への到達性を全屋外区画で検証する。

地形の高さは elevation.ts を描画と移動判定で共有する。崖を徒歩で直接抜けることはできず、坂では連続的に足元が上がる。帆で高所から低所へ滑空でき、低所から高い崖へは飛び上がれない。地上の敵と近接攻撃にも高さを反映する。室内・空域の既存挙動は維持する。

段丘の小さな星印を調べると鉱石2・薬草1・10枚を一度だけ獲得する。既存の採集セーブに区画・高台ごとに記録し、再入場で無限取得できない。

バイオームを24から30へ拡充。白波の石灰段丘、古樹の苔庭、水晶の湿原棚、琥珀の峡谷、雪解けの段丘、黒曜の溶岩棚を一部の屋外区画で使用する。

ImageGenで6系統×地表・崖面・南向き階段・滝の24素材を制作。原画、レイアウト、ハッシュを assets/star-tide/relief-art.json に記録。scripts/star-tide/pack-relief.mjs で余白を除いて512×768のWebPにする。地表・崖面は一つの連続した素材として貼り、同じ丸角輪郭で切り抜く。角だけ別の素材が浮いたり、内部タイルの境界線が出たりしない。足元の影を短くし、浮島のように見えないようにする。

検証: test-star-tide-elevation.mjs で全96屋外区画の経路探索、実際の坂移動、崖・滑空判定、採集を検証。test-star-tide-relief-browser.mjs で生成素材と室内仕掛けの実描画を確認。既存の野外探索テスト、通常ビルド、型チェック、英語監査、サーバービルドも実行する。
