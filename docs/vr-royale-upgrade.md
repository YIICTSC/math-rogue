# VR バトルロイヤル改修

GAKURO VRの独自キャラクターと訓練用装備を使い、探索・移動撃ち・遮蔽物を軸にした対戦へ更新。

## 遊び方

- 三人称で開始。一人称、俯瞰、全体マップにも切替可能。
- WASD/左スティックで移動。画面ドラッグ、J/L、右スティックで旋回。R/RT/攻撃ボタンの長押しで射撃。スマホでは攻撃ボタンを押したままなぞると、移動・射撃・照準を左右2本の指で操作できる。
- Shift/左スティック押込み/ダッシュボタンでダッシュ。走力100、毎秒30消費、停止後0.6秒で毎秒22回復。射撃・しゃがみ・ホールド・装填中は走らない。使い切った場合は30まで回復すると再使用可能。
- V/LB/カバーボタンで目の前にパネルを設置。初期資材2、資材箱で+2、最大5。1枚1資材、1人2枚まで。3発命中または25秒で消滅。壁・人・補給箱と重なる場所には設置しない。射線、移動、カメラの衝突に同じ形状を使用。
- シールド箱で防御を1回追加、最大2回。対人攻撃を防ぎ、エリア外ダメージは防がない。
- 1〜6または装備欄で武器を切替。武器ごとに弾数を保存し、切替で装填をキャンセルする。初めて拾う武器は装備、重複武器は対応する弾数だけを補充する。
- 縮小予告・縮小を3回繰り返す安全地帯。HUDの秒数、白い次エリア円、緑の境界、紫のストーム壁を確認して移動する。範囲外では6秒ごとに1回被弾。
- B/右スティック押込み/問題で補給から既存の学習問題3問へ。退避中は戦闘対象外となり、復帰時は安全地帯へ戻れる。
- 3回被弾で勝敗は確定。復活後も練習可能だが、勝敗に関わる参加者や設置カバーには干渉できない。

## 表示と同期

- 体力・シールド・走力、残人数、撃破数、エリア予告、拾った装備、撃破履歴、命中・被弾方向を端に集約。
- 屋外訓練場は十字の通路と色分けした区画、低い箱と背の高い遮蔽物で構成。各種補給は最低42個で、少人数でも全6武器が出現する。
- スマホ縦画面は下部に装備欄、右下2列にアクション。横画面とPCは中央下に装備欄を置き、プレイ画面を広く保つ。縦画面のカメラ中心は上寄りに調整。
- 射撃軌跡・着弾、パネルの出現・破壊、資材・シールド・走力はサーバー側で決定し、差分配信で全参加者へ同期する。表示側は移動を補間する。入力の送信は描画ループと分け、未処理の射撃・設置・道具などは次のサーバー更新まで保持し、描画負荷やパケット到着の間隔で取りこぼさない。
- VR通信の共有バージョンは`VR_PROTOCOL_VERSION=7`。Peerの部屋名にも使用。異なるルールのクライアント混在を防ぐため、クライアントとサーバー双方を同じ版にする。Renderは既存方針どおり手動デプロイで、この作業ではデプロイを実行しない。

## 検証

- `node scripts/test-vr-royale.mjs`: ストーム、走力、カバーの衝突/破壊/期限、シールド、弾数、入力検証、full/delta同期。
- `node scripts/test-vr-royale-server.mjs`: 40実WebSocketでカバー・射撃・走力・問題補給・ホスト引継ぎ。旧バージョン拒否。
- `node scripts/test-vr-royale-browser.mjs`: PC/スマホ5サイズで表示・操作・英語UI。
- `node scripts/test-vr-royale-online-browser.mjs`: 実ブラウザー2台の作成/参加/開始/操作/同期、縦横スクリーンショット。
- 既存のonline、gameplay-polish、solo-battle、solo-browser、server-40テストで協力・爆弾・ソロ導線も検証。
- `pnpm run build`（typecheck、英語UI監査を含む）、`pnpm run server:build`。
