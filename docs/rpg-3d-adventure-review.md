# RPG 3Dワールドの変更・確認記録

既存のReact + Three.js描画を継続使用。ゲームの座標系は1ブロック=1、身長1.78のまま維持し、物理・イベント・算数問題・戦闘は従来のエンジンを使う。追加ライブラリ、外部作品の素材、外部画像生成は使用していない。

## 実装

| ファイル | 変更 |
| --- | --- |
| `src/rpg/adventureStyle.ts` | オリジナルの材質用シェーダー。粒子感、地層、縁のハイライト、ブロック下端の暗部、ワールド座標に沿う目地。丸みを付けたデフォルメ人物、待機・歩行・空中姿勢、柔らかな接地影。人物は胴体と各手足を結合して描画回数を削減。 |
| `src/rpg/adventureTerrain.ts` | 新規ワールド用の山岳高度分布。既存マップの内部に3つの山塊を配置。標高34以上は雪、22以上は岩肌と高山草地に変化。道・水辺・拠点から離れた場所を新規開始時に選び、位置を保存。seed 42の実測最高標高48ブロック。 |
| `src/rpg/engine.ts`, `src/rpg/voxel.ts` | 新規ワールドに保存可能な `terrainStyle: 1` を設定。既存セーブには設定を補わず、以前の高度計算・建築座標を維持。既存の道・イベント地点の平地化と採掘可能な実ブロックを使用。道・水辺までの距離場で連続的に地形を接続し、細い柱状の地形を防止。NPC移動では地形を変更しない。 |
| `src/rpg/adventureHydrology.ts` | 山腹の湧水が下り方向へ流れる水路を生成。1ブロックの川底を実際に掘り、木・葦の根元は川底まで接続して浮遊を防止。水泳・建築の判定も同じ水域を使用。段差に縦の水面を接続し、滝を描画。 |
| `src/rpg/adventureCamera.ts` | 三人称カメラの体積を考慮した衝突判定。未描画の実ブロックと建物の壁を検査。自動画質時の解像度調整と緩やかな回復。 |
| `src/rpg/WorldScene3D.tsx` | 三人称追従・回転・ズーム、一人称への切替。遮蔽物で即座に近づき、離れる時は滑らかに復帰。建築はキャラクターの目から判定し、操作可能距離を延長しない。草地表面が土に埋もれる問題を修正。通常NPCを立体化し、既存の歩行先へ滑らかに追従。持ち込み画像・着替え画像は既存表示を使用。町の建物に窓枠・花箱・梁・煙突・看板、ボス拠点に2本の塔と上階窓を追加。遠景用の軽量な建物を配置。 |
| `src/rpg/landscapeScene.ts` | 遠景の斜面を実際の段状地形に合わせ、崖の側面も描画。マップ周囲の海、遠景の水面・川底・雪の斜面、雲の位置・移動を改善。近景と遠景の水面の二重描画を抑制。動物の高度・水域判定を実マップに合わせ、鳥・山岳動物が現行高度で出現するよう修正。 |
| `src/rpg/adventureNature.ts` | 草と小石をインスタンシング。風による草の動き、環境粒子。描画範囲を限定し、移動・建築時に再生成、離れた描画資材を解放。 |
| `src/rpg/voxelRendering.ts` | オリジナル生成テクスチャの粒状ノイズを抑制、拡大時の補間を滑らかに変更。 |
| `src/rpg/CameraControls.tsx`, `world3d.css`, `landscapeViewport.css`, `src/data/debugUiExact.ts` | 1P/3P切替、カメラ操作列の余白調整と翻訳。背景の全面描画と操作UIのSafe Area配置を維持。 |
| `scripts/fixtures/rpg-landscape.tsx` | 旧拡張マップ高度ではなく、現行マップの実高度を使う撮影・操作用fixture。 |
| `scripts/test-rpg-adventure-camera.mjs` | 壁・角・床・高度・セーブ不変性・自動画質の回帰テスト。 |
| `scripts/test-rpg-adventure-browser.mjs` | 実際のThree.js描画を撮影。町・城・山・森・水辺、一人称／三人称切替と採掘操作、シェーダーエラーを検証。 |
| `scripts/test-rpg-edge-to-edge-browser.mjs` | 自動画質で変更される描画解像度を考慮して画面の寸法を検証。 |

## 確認済み

- カメラの壁・床・角との衝突、保存データ非変更、自動画質の低下と回復、明示指定の画質維持。
- seed 42の新規ワールドで山の標高48、自然地形の隣接段差は最大3。旧ワールドの高度計算維持。
- seed 42の山の水路16セル・落差14か所、下り方向のみの流れ、実ブロックの川底、水域の保存・復元。
- 採掘・設置、資材と端数のエネルギー、段差移動、落下、2D切替、地下資源、道具、セーブ復元。
- 6バイオームの到達性、イベント分岐、個人進行、報酬の再受取防止。
- 戦闘・宝箱・回復・共有HP・ボス制限と報酬。
- 実際のサーバークライアント2接続で座標・建築・採掘・エネルギー同期と遠隔操作の拒否。

## 実装上の範囲と未確認事項

- 既存セーブの山を高くすると建築やプレイヤーが埋まるため、大きな山は**新規ワールド**に反映。材質・照明・人物・カメラ・建築の描画改善は既存セーブでも反映。
- 3D人物には待機・歩行・ジャンプ姿勢を実装。武器ごとの3D攻撃モーションは追加せず、既存の問題・カード戦闘表示を維持。
- NPC会話・戦闘の既存ポートレート、持ち込み人物、着替え差分、オンラインの他プレイヤー画像は維持。全ポートレートから個別の3D衣装を自動生成する機能は含めていない。
- 水面は既存の流れ・きらめきに透明感を追加。鏡面反射の別カメラやSSAOの重い後処理は使用せず、材質内の陰影と影で立体感を出す。
- 既存の地下洞窟・採掘・水泳を維持。山腹の水路と滝は実装済み。学校イベントや建物内部の新規マップの追加は含めていない。
- PC・スマホの60fpsは実機での測定が必要。この環境はChromiumのソフトウェアWebGLであり、描画機能とレイアウトを検証する。Windows/iPhone/Android実機のfps、発熱、長時間のメモリ推移は未確認。
- GitHubへのcommit・push・アップロード・デプロイは実施しない。

## 再現

```sh
node scripts/test-rpg-adventure-camera.mjs
RPG_ADVENTURE_DIR=tmp/rpg-adventure node scripts/test-rpg-adventure-browser.mjs
RPG_EDGE_VIEW=3D RPG_EDGE_DIR=tmp/rpg-adventure-ui node scripts/test-rpg-edge-to-edge-browser.mjs
pnpm run build
pnpm run server:build
```
