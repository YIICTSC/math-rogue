# 英語翻訳の全量調査と修正（2026-10-14）

## 調査の範囲

- TS/TSXから49,055種類の文字列を抽出し、共通翻訳器の出力を比較。
- 英語の辞書・専用翻訳表35ファイル、14,348項目を検査。英語・ひらがなの表を区別して集計する。
- RPGの物語・装備898文、配置TCG584枚の実際の英語効果文、支援者プロフィール45フィールドをテスト。
- 日本語残存、汎用文への置き換え、重複語、単複、ターン条件、数値脱落の候補を抽出。

広い抽出には内部ID、教材、翻訳表のキー、ゲーム専用の翻訳経路を持つ文も含まれる。共通 `trans` の単独結果を実画面の未翻訳件数とは扱わない。数値が英単語になる場合（1→one、3回目→thirdなど）も誤訳と断定しない。学習問題、正式な単元名、人名を保護する既存の例外を維持し、教材を勝手に英語へ書き換えない。

## 確認できた問題と修正

1. 支援者の名前・題名・紹介文を、既存プロフィールの英語表記へ統一（21項目）。「とし→year」「ごいた→gore」「ちゃたまご→chat eggs」を解消。Toshi、Goita、Chatamagoなどの既存表記を使用。
2. RPGの装備・効果文134項目を修正。「Choose Option's Technique」「Event Details's Strategy Crest」などを敵の固有名に戻し、「再生の証→Play Crest」をRenewal Crestに統一。「敵全体に8ダメージ」が休憩・回復文になる誤訳も修正。
3. 敵32体の英語名を登録し、敵と専用装備の表記を一致させる。日本語の名前や内部IDは変更しない。
4. 戦闘開始ボーナス190文を、筋力・ブロック・追加ドロー・HP回復の値を保って整える。1 extra cardsを1 extra cardへ修正。
5. 配置TCGの説明は実際の効果コードから書き直す。対象・数量・条件・持続を保ち、手札を山札に戻して引き直す処理、強制捨て札、サポート耐久減少を明確化。SP比較の相手、空きレーンの持ち主も明示。STUNに実装されていない複数ターンの持続を付けない。対戦処理・効果の署名・セーブデータは変更しない。
6. 一般の丸括弧ラベルを友情ルートとして扱っていた判定を制限。VRの長押し、制限時間、読み上げ用の読みなどのラベルを文単位で登録。
7. 金額の正規表現が報酬文の前半まで取り込む問題を修正。数値だけを受け付け、クレーン・投票・学習報酬の文章、条件、金額を保持。総まとめの学年表示も整える。

## 再検査

```powershell
pnpm run audit:english:quality
pnpm run audit:english:corpus
pnpm run audit:translations
pnpm run build
pnpm run server:build
node scripts/test-placement-tcg-complete.mjs
```

- `audit:english:quality`：辞書の日本語残存・汎用文・重複語・単複・ターン逆転を検査し、固有名・装備・効果・支援者・動的ログの回帰テストを実施。
- `audit:english:corpus`：`tmp/english-corpus-review.json`、`tmp/english-corpus-candidates.tsv` に全量調査の結果を保存。候補は自動修正しない。
- `audit:translations`：英語・ひらがな・表示コピー・実行時監査を3巡連続で通過。
- 配置TCGの既存回帰テスト：カタログ、デッキ、実際の効果処理を通過。
- 本番ビルド：通過。既存の大きなチャンクの警告は残る。
- サーバービルド：通過。Renderは手動運用を維持し、デプロイしない。
- 型チェック：既存と同じ475件のエラーが残る。変更した翻訳・TCG説明モジュールに新規エラーなし。

## 留保

全文章を人手で逐語校正したという意味ではない。未知の固有名詞、ユーザー入力、画像に焼き込まれた文字の翻訳を保証しない。英語実行時監査は既存のブラウザーテストを用いる。全画面の新しいスクリーンショット巡回は実施していない。

既存のローカル変更を保持。commit、push、Renderデプロイは行わない。
