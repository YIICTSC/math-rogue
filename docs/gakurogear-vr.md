# GAKURO VR Training

タイトル画面または一人用ゲーム一覧から起動する、学校が舞台の独立した3Dステルスゲーム。初代PS時代の低解像度・ローポリ表現に着想を得たオリジナルのキャラクター、学校モデル、50ミッション。ネットワーク接続やオンラインホストは不要。

## 遊び方

- WASD / 矢印 / 画面のスティックで移動。
- C / しゃがむボタンで姿勢を切り替え。しゃがむと足音を消し、机や花壇にも隠れられる。
- 青い資料の1.2m以内で停止し、E / 回収ボタンを0.8秒長押し。
- 全資料回収後に緑の出口へ入るとクリア。
- Q / 音のデコイで前方に音を出し、8m以内の見回りを誘導（各任務3個）。
- Esc / 一時停止。別タブや別ウィンドウへ移ると自動停止。
- 警戒100%または時間切れで失敗。遮蔽物で視線を切ると警戒が減少。
- Sは目標時間以内・警戒ゼロ、Aは目標時間の1.5倍以内・最大警戒50%未満、それ以外の成功はB。
- 各任務の最高評価、同評価での最短時間をブラウザに保存。全任務を最初から自由に選択可能。入門・初級・中級・上級・達人の各10任務。

## 構成

`src/mini-games/gakurogear/engine.ts`: ミッション、衝突、視界、巡回・音源調査、迂回経路、結果。

`scene.ts`: Three.js俯瞰カメラ、学校、視界扇形、Blenderモデル読み込みと終了時の解放。

`GakuroGear.tsx`: 選択画面、操作、HUD、レーダー、結果、記録保存。

`scripts/blender/build-gakurogear.py` をBlenderのバックグラウンドモードで実行すると、編集可能な `assets/gakurogear/school-kit.blend` と配信用 `public/models/gakurogear/school-kit.glb` を再生成。生徒、机、本棚、花壇はオリジナル形状。モデル読込に失敗した場合は軽量な代替形状を表示。

## ローカル確認

`pnpm dev` で起動。一人用ゲームから「GAKURO VRトレーニング」を選択。

`node scripts/test-gakurogear.mjs`: 全任務の経路・回収・脱出、視界、警戒、時間切れ等。

`node scripts/test-gakurogear-browser.mjs`: localhost:5173 起動中に実行。全任務の3Dモデル、実操作でのクリアと記録保存、縦横画面、一時停止、終了を確認。専用の一時テスト画面は `tmp/gakurogear/` に生成。

## おやすみアクションと50任務

- 敵の背後1.15m以内で停止してFまたは「ホールド」を0.9秒長押し。途中で離すと中断。対象だけがホールド中に停止し、ほかの敵やカメラには見つかる。
- Rまたは「シャボン銃」で向いている方向へ6mのねむりシャボン。照準の破線が目安。壁や机で止まり、空振りでも1発消費。連射間隔0.65秒。
- 眠った敵は横になってZzz表示。視界・巡回・音への反応が停止し、時間経過で復帰する。
- 難易度順に睡眠22/19/16/13/10秒、弾数6/5/4/3/2発。巡回速度、視界、警戒上昇率も変化。
- 10種類の学校配置に対して、5段階ごとに配置の回転、資料追加、増員、カメラ追加を組み合わせた50任務。
- 各難易度の7番はホールド、8番はシャボン、9・10番は両方が追加課題。異なる敵への初回成功を数え、同じ敵の同じ技での再睡眠は加算しない。
- 追加課題と全資料回収が揃って初めて出口が有効になる。弾切れ時は一時停止から再挑戦可能。

## 視点と通路ギミック

- Vまたは画面上部で俯瞰・一人称・三人称を切替。一人称・三人称ではW/Sが前後、A/Dが横移動、J/L・左右矢印・画面ドラッグ・旋回ボタンで向きを変える。スマホは移動スティックと画面ドラッグを併用。
- 三人称カメラは壁や家具の手前まで近づき、めり込みを防ぐ。一人称ではしゃがむと目線も下がる。
- 黄色い低いシャッターはしゃがみ時だけ通過。中では立ち上がれず、抜けると立てる。見回りはこの通路を通れない。
- オレンジのスイッチ付近でE／回収長押しで青い扉が開く。開いた扉は移動・視線・シャボンを通す。
- 赤い光センサーは周期的に点灯。点灯中に立って触れると警戒が上がる。しゃがむか、消灯を待って通過。
- `node scripts/test-gakurogear-views.mjs` で3視点、視点基準の移動、ドラッグ旋回、縦横画面、低い通路と扉の実操作を確認。


## ソロ・オンライン・主人公作成

- 名称は「GAKURO VRトレーニング」。学習ローグのタイトルに専用の開始ボタンを追加。既存オンライン3種と共通の表示条件（タイトルロゴ3回クリック）で表示。
- 専用タイトルからソロ、オンライン部屋作成、コード参加、キャラクター作成を選ぶ。レースと同じ単元選択画面・4択問題生成を使用。
- ソロと協力は各ミッションの成功・失敗後に3問出題。答えると結果表示や再挑戦へ進む。学習履歴に保存。
- 主人公はレース・ゴルフの共通編集UI・3Dパーツを使用。VR用保存キー `gakuro-vr-avatar-v1` で種族、顔、目、髪型、色、表情、アクセサリーを保存。ソロ・オンライン共通。部屋では全参加者に見た目を共有。
- オンラインはホスト通信（PeerJS）。`VITE_RPG_PEER_HOST/PORT/PATH/SECURE` はレースと共通。専用サーバー方式はこの実装には含まない。ホストはプレイ中に画面を閉じず、非表示時は全員一時停止。
- 最大8人。協力では人数分の17m角エリアを連結し、全員にそれぞれ資料回収・追加課題・出口を用意。担当をクリアした人は他エリアの資料回収と見回りの睡眠で支援。敵の睡眠、扉は全員で共有。失敗時は3問回答後に担当エリアから再挑戦。
- バトルロイヤルはホスト開始ごとにシードを変えた広いフィールドを生成。人数で広さも変化。ホールドかシャボンで3回やられるとアウトになり、その場で観戦を継続。最後の1人またはホスト指定60〜900秒で終了。時間切れは被弾数が最少の生存者を表示。
- ホールド20エネルギー、シャボン装填25エネルギー・3発・1.1秒。射撃R、装填T。使えるエネルギーと弾が尽きると3問出題。回答中は移動・攻撃不可。補充量は40＋正解数×20（最大100）。補充後は装填して再参加。
- 通信はホストで移動・命中・弾数・エネルギー・解答を判定。参加者は操作と選択肢番号を送る。
- 確認: `test-vr-online.mjs`（進行）、`test-vr-network.mjs`（2ブラウザの実通信・キャラクター共有）、`test-vr-solo-quiz.mjs`（成功と失敗後の3問）。
