# 学習ローグ 問題イラスト導入優先度（小1〜中3）

## 方針

- **A**: イラスト・図が理解や正答に直結する。優先実装。
- **B**: 図があると理解しやすいが、文章だけでも成立する。
- **C**: 装飾効果が中心。問題の本質には必須ではない。
- **動的**: 問題値に合わせて Canvas / SVG で描画する。ImageGenの固定画像は使わない。
- **ImageGen**: 実物・生き物・場面など、固定教材イラストが有効なもの。
- 画像内に文字・数字・答えラベルを入れない。必要なラベルはゲームUI側で付ける。

## 既存の動的ビジュアル基盤

`GeneralChallengeScreen` では現在、次の問題図を Canvas / 専用画像で表示できる。

- 時計 `clock`
- 多角形 `polygon`
- 角度 `angle`
- 円 `circle`
- 立方体 `cube`
- 角柱 `prism`
- 円柱 `cylinder`
- 角すい `pyramid`
- 円すい `cone`
- 放物線 `parabola`
- 棒グラフ `bar_chart`
- 個数図 `dots`
- 数列 `number_sequence`
- 分数 `fraction`
- 分数計算 `fraction_operation`
- 地図記号 `map_symbol`

時計は**固定画像にしない**。問題ごとの `hour` / `minute` から針を描画する現在方式を採用する。これにより「1時」「4時30分」など問題ごとに針が変わる。

## B優先：ImageGenまたは資料図

- 小3〜小5 社会: 町ではたらく人、商店、農業、工場、交通、水道、ごみ処理、災害、伝統文化、農業、水産業、工業、貿易。
- 小6〜中2 社会: 各歴史時代の生活場面、代表的な建築・道具・服装。人物名を直接答えさせる問題では、人物そのものが答えを露骨に示さないよう使用範囲を限定する。
- 中1 地理: 世界の地域・気候・産業は、写真風素材より**正確な地図/気候図をSVGで作る方を優先**。
- 国語: 低学年の「ことばあつめ」「おはなしをつくる」など、場面想像用の挿絵。読解問題では本文内容を答えとして見せすぎない。

## C優先

- 文法、漢字、計算手順など、図がなくても学習効果が変わりにくい単元。
- 中学英語の抽象文法（現在完了・関係代名詞・仮定法など）は、まず文章/音声UIを優先する。
- 公民の抽象制度は、装飾イラストより制度図・フロー図を将来的にSVGで作る。

## ImageGen共通仕様

- 教材向け、明快で親しみやすい2Dイラスト。
- 正方形 1024×1024 を基本。
- 背景は白または淡色。単体素材は可能なら透過。
- 文字、数字、記号ラベル、透かし、ロゴを入れない。
- 小学生向けは輪郭を明瞭にし、細部を複雑にしすぎない。
- 中学生向け理科は写実寄りでもよいが、教材として構造が見分けやすいことを優先。
- 正答そのものを文字で示さない。
