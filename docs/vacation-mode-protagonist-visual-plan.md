# バカンスモード主人公イラスト企画書

## 1. 目的

エンドレスモードの最終ボス撃破を記念する恒久解禁要素として、高校編とマジック編に「バカンスモード」を追加する。

バカンスモードでは、主人公の能力・カード・戦闘バランスは変更せず、主人公の見た目だけを夏休み仕様へ切り替える。冒険開始時の主人公選択画面でオン／オフを選べ、オンにした周回では選択画面・戦闘中のすべての主人公イラストをバカンス衣装にする。

対象は高校編とマジック編のみとする。小学生編には適用しない。

## 2. 解禁条件と仕様

### 2.1 解禁条件

| 編 | 解禁条件 | 解禁単位 |
|---|---|---|
| 高校編 | 高校編エンドレスモード第50章の最終ボスを撃破し、最終報酬処理を完了する | 高校編のバカンスモード |
| マジック編 | マジック編エンドレスモード第50章の最終ボスを撃破し、最終報酬処理を完了する | マジック編のバカンスモード |

- 解禁は最終ボス撃破後にプロフィールへ自動記録する。
- 通常のカード報酬・レリック報酬の選択結果に左右されない恒久解禁とする。
- 真エンドレスモードの追加階層を進める必要はない。
- 片方の編をクリアしても、もう片方の編は解禁しない。
- デバッグメニューからの解禁は本番のプロフィールには反映しない。

### 2.2 冒険開始時の操作

主人公選択カードに、対応する編の解禁後だけ次の切替を表示する。

```text
主人公の見た目
○ 通常衣装
● バカンスモード（解禁済み）
```

- 初期値は「通常衣装」。意図せず見た目が変わらないようにする。
- 未解禁時は切替自体を表示しない。ロック表示だけを出す場合は、解禁条件を「エンドレス第50章クリア」と明記する。
- 主人公を選び直した場合も、最後に選んだ切替状態を保持する。
- 「冒険を始める」を押した時点の状態を周回データへ保存する。
- 続きから再開した場合は、その周回開始時の状態を復元する。途中で通常衣装へ戻したり、未解禁状態に戻したりしない。
- バカンスモードは見た目のみの変更とし、初期デッキ、固有能力、HP、攻撃力、カード解禁、イベント発生率は通常衣装と完全に同じにする。

### 2.3 画面ごとの適用範囲

| 画面・場面 | バカンス表示 |
|---|---|
| 主人公選択カード | バカンス用の選択画像と衣装名を表示 |
| マップ画面の主人公表示 | バカンス用の待機画像を表示 |
| 戦闘中の待機 | バカンス用の idle シート |
| 通常攻撃 | バカンス用の attack シート |
| スキル | バカンス用の skill シート |
| 被弾 | バカンス用の hit シート |
| 瀕死 | バカンス用の low-hp シート |
| 勝利・戦闘後 | 既存の主人公表示部をバカンス用画像へ差し替え |
| エンドレス導入・エンディング | 既存の物語用イラストは変更しない。必要な場合は別途CGを追加する |

戦闘用シートが未登録のときは、画面を空白にせず通常衣装へ安全にフォールバックする。選択画面だけバカンスで、戦闘中だけ通常衣装に戻る状態は避ける。

## 3. 画面・素材の共通方針

### 3.1 デザイン原則

- 現行の髪型、髪色、目、表情、武器、魔法属性、主人公としてのシルエットを維持する。
- 「別人の水着キャラクター」ではなく、「いつもの主人公が休暇を楽しみながら戦っている」絵にする。
- 水着は競技用・ラッシュガード・ワンピース型など、戦闘動作に耐える健康的なデザインを基本とする。
- 浴衣・甚平を使う場合も、袖や裾が攻撃・スキル演出に干渉しないように短めの差分や結び方を選ぶ。
- 未成年の高校生を含むため、性的な強調、過度な露出、下着に見える表現、身体の一部だけを強調する構図は使わない。
- 全員を同じ水着にせず、部活・役割・属性・性格が一目で分かる小物を一つ以上残す。
- 背景、文字、UI、吹き出し、ロゴは画像に焼き込まない。既存の透明背景・背景処理に合わせる。
- 戦闘中の攻撃方向、武器を持つ手、足元の接地、視線の向きは通常シートと揃える。

### 3.2 シートの必要数

#### 高校編

主人公1人につき、次の6種類を作成する。

1. 選択画面・通常立ち絵
2. idle シート
3. attack シート
4. skill シート
5. hit シート
6. low-hp シート

合計は9人×6種類＝54素材。既存の高校編シートと同じフレーム数、縦横比、透明余白、表示基準点を使用する。

#### マジック編

マジック編は通常形態と変身後形態を別に管理しているため、主人公1人につき、通常形態・変身後の両方を用意する。

各形態について、次の6種類を作成する。

1. 選択画面・通常立ち絵
2. idle シート
3. attack シート
4. skill シート
5. hit シート
6. low-hp シート

合計は17人×2形態×6種類＝204素材。変身前後で衣装を完全に別物へ変えるのではなく、同じバカンス衣装を土台に、変身後だけ魔法の光・属性装飾・武器の発光を追加する。

### 3.3 既存素材との対応

現在の実装で使っている素材体系を基準にする。

| 編 | 通常の参照先 | バカンス用の追加先（案） |
|---|---|---|
| 高校編 | `sprites/high-school/characters/`、`characters-idle-sheets/`、`characters-attack-sheets/` など | `sprites/high-school/vacation-characters/` と各 action 用シートフォルダ |
| マジック編・女性 | `sprites/magic/characters/`、`characters-idle-sheets/`、`characters-attack-sheets/` など | `sprites/magic/vacation-characters/` と各 action 用シートフォルダ |
| マジック編・男性 | `sprites/magic/male-characters/`、`male-characters-idle-sheets/`、各 action 用シート | `sprites/magic/vacation-male-characters/` と各 action 用シートフォルダ |

ファイル名は既存の番号・`assetId`・`before/after` の命名規則を引き継ぎ、衣装切替だけで通常素材を上書きしない。実装時は、通常／バカンスのパスを一か所のマッピングから解決し、action ごとの手書き分岐を増やさない。

- 基本色は昼の空色、プールの青、夕方の校舎の橙。

## 7. 画像生成・作画時の共通プロンプト

既存の主人公画像を参照画像として使い、人物そのものを新規デザインし直さない。以下は各主人公の個別指示に加える共通文とする。

```text
既存の主人公の顔、髪型、髪色、目、年齢感、体格、武器、魔法属性、キャラクター性を完全に維持する。
学習ローグの既存戦闘スプライトと同じ、明快なアニメ調の高品質イラスト。
全身が見える戦闘用の立ち姿、通常の攻撃方向と足元の接地を維持。
バカンスを楽しんでいる健康的で明るい表情と、役割に合った小物。
衣装は安全に動ける水着、ラッシュガード、浴衣、甚平のいずれか。
性的な強調、過度な露出、下着風の衣装、挑発的な構図、身体の一部だけの強調は禁止。
文字、ロゴ、UI、吹き出し、透かし、背景に埋め込まれた説明文は禁止。
既存の戦闘シートと同じ透明余白、フレーム内の人物サイズ、視線、武器の向き。
```

### 7.1 形態別の追加指示

| 形態 | 追加指示 |
|---|---|
| 選択画面 | バカンス衣装全体が分かる正面寄りの立ち絵。小物は一つに絞る |
| idle | 休暇を楽しみながらも戦闘に備えた自然な待機。髪・衣装・属性粒子を小さく動かす |
| attack | 既存攻撃シートと同じ向き・重心。衣装の布と属性エフェクトが攻撃の勢いに連動 |
| skill | 主人公の固有能力とバカンス小物を一つの演出にまとめる。小物が武器の代わりにならないようにする |
| hit | 驚き・痛み・体勢の崩れを表現するが、衣装の破損はさせない |
| low-hp | 疲労、汗、息、乱れた髪、弱い属性光で表現。露出や破れによる表現は禁止 |
| 変身後 | バカンス衣装は維持し、属性の光輪・装飾・武器発光のみを追加。衣装チェンジで別キャラに見せない |

## 8. 保存データと実装時の設計案

### 8.1 プロフィール解禁フラグ

既存の恒久解禁効果と同じプロフィール保存領域に、次の2フラグを追加する案とする。

```text
HIGH_SCHOOL_VACATION_MODE
MAGIC_VACATION_MODE
```

実際の保存形式は既存の permanent unlock 管理に合わせる。名称は仕様上の仮名であり、実装時に既存の effect key 命名規則へ統合する。

### 8.2 周回内の見た目モード

周回開始時に次の値を保存する。

```text
characterAppearanceMode: 'STANDARD' | 'VACATION'
```

- `VACATION` は対応する編の恒久解禁フラグがある場合だけ許可する。
- 高校編での `VACATION` は高校編の画像だけに適用する。
- マジック編での `VACATION` は女性・男性の両方に適用する。
- 小学生編や通常モードの別編には影響させない。
- セーブデータが古く値を持たない場合は `STANDARD` として扱う。

### 8.3 パス解決

実装では、通常のパス取得関数へ見た目モードを渡し、次の順で解決する。

1. 編、主人公、action、変身状態に対応するバカンス素材を探す
2. 見つからない場合は同じ条件の通常素材へフォールバックする
3. それでも見つからない場合は既存の共通フォールバックを使う

表示部品ごとにバカンス判定を複製せず、選択画面・戦闘・マップが同じ解決関数を使う。これにより、選択画面だけ切り替わる、被弾時だけ通常衣装になる、といった不整合を防ぐ。

## 9. 解禁表示とプレイヤーへの伝え方

第50章の最終ボス撃破後、既存の最終報酬・真エンディングの流れを壊さない短い記録表示を追加する。

```text
バカンスモード解禁
この編の主人公たちが、夏の装いで冒険できるようになった。
次回から「冒険を始める」の主人公選択で見た目を切り替えられます。
```

主人公選択画面では、解禁済みの編だけ次を表示する。

```text
バカンスモード
能力は変わらず、見た目だけが夏休み仕様になります。
```

「バカンスモード」は強さに関係する解禁ではなく、最終ボス撃破の記念・収集要素であることを明記する。
