# クラウドファンディング支援者向け先行プレイ配布手順

更新日: 2026-07-30

## 目的

クラウドファンディングの返礼として、支援者へ「学習ローグ」の開発中ビルドを先行提供する。
一般販売用アプリの譲渡ではなく、各ストアのテスト配信機能を利用した期間限定の先行プレイとする。

## 現在の配布可否

| プラットフォーム | 現在のビルド | 状態 | 支援者への配布方法 |
| --- | --- | --- | --- |
| iPhone / iPad | TestFlight Build 23 | 配布可能 | 公開TestFlightリンクを案内 |
| Android | クローズドテスト Alpha `9 (1.0.0)` | 配布可能 | Googleアカウントをテスター登録後、参加リンクを案内 |
| Steam / Windows | `internal` Build ID `24465098` | ビルドは準備済み、外部配布は未解禁 | Steamキー解禁後に1名1キーを個別送付 |

### iOS

- 公開TestFlightリンク: https://testflight.apple.com/join/Swgfe66z
- 現在の公開リンク上限: 100人
- 支援者のApple Accountメールアドレスを収集する必要はない。
- TestFlightアプリをインストールし、上記リンクから参加してもらう。
- TestFlightビルドにはAppleの有効期限がある。期限切れ前に後継ビルドを配信する。

### Android

- 応募フォーム: https://docs.google.com/forms/d/e/1FAIpQLSf6FH3FMp70YJgiBSbMDLq46sABfUouNjdzCqrlX7ztGL6UwA/viewform
- ウェブ参加リンク: https://play.google.com/apps/testing/jp.yusukeishige.learningrogue
- Android端末用リンク: https://play.google.com/store/apps/details?id=jp.yusukeishige.learningrogue
- Alphaトラックは有効で、日本を対象に `9 (1.0.0)` が公開済み。
- Android応募は継続して受け付ける。Googleフォームの新規回答を定期確認し、Google Play Consoleのメーリングリストへ追加する。
- 現在は「学習ローグ内部テスター」メーリングリストに登録されたGoogleアカウントだけが参加できる。
- 先に支援者がGoogle Playで使用しているGoogleアカウントのメールアドレスを登録し、その後にウェブ参加リンクを開いて「テスターになる」を選んでもらう。
- 参加リンクを知っているだけでは、登録されていないGoogleアカウントからは参加できない。

### Steam / Windows

- 最新テストビルドは非公開の `internal` ブランチに反映済み。
- SteamworksにはBeta Testingパッケージがあるが、2026-07-30時点では、アプリ作成から3週間経過するまでSteamキーのリクエスト機能を利用できない。
- `internal` ブランチ名だけを案内しても、ゲームを所有していない支援者はインストールできない。
- キー発行が解禁されたら、Beta Testing用キーを必要数だけ申請し、支援者ごとに異なる1回限りのキーを個別送付する。
- 大人数へ継続的に配布する場合はSteam Playtestの別アプリ運用も候補。ただし、現在は未作成なので今回の初回案内には含めない。

## 推奨する配布フロー

1. 支援者へ「希望プラットフォーム確認メール」を送る。
2. iOS希望者にはTestFlight公開リンクを返信する。
3. Android希望者から、Google Playで使用中のGoogleアカウントだけを回収する。
4. Androidのメーリングリストへ追加後、参加リンクを返信する。
5. Steam希望者は待機リストへ登録し、キー発行解禁後に1名1キーを返信する。
6. 配布日時、プラットフォーム、送付状態だけを管理表へ記録する。
7. 新ビルド配信時は、変更点と既知の問題を全参加者へ知らせる。

## 支援者から回収する項目

- クラウドファンディング上の支援者名または支援番号
- 希望プラットフォーム: iOS / Android / Steam
- 連絡先メールアドレス
- Android希望者のみ: Google Playで使用するGoogleアカウント
- 18歳未満の場合: 保護者の同意確認

Apple Accountのパスワード、Googleアカウントのパスワード、SteamのIDやパスワードは回収しない。

## 先行プレイ時の案内事項

- 開発中版のため、不具合、仕様変更、セーブデータの初期化が発生する可能性がある。
- 先行プレイ参加費や追加料金は求めない。
- 毎日プレイする義務はない。
- Androidの14日間テストに協力する場合も、「毎日プレイ」ではなく、テストから退出せず参加状態を維持することを依頼する。
- スクリーンショット、動画配信、SNS投稿の可否はキャンペーン方針に合わせて明記する。未決定の間は「公開前の画像・動画の投稿は事前確認をお願いします」と案内する。
- 不具合報告先: https://yiictsc.github.io/math-rogue/support.html
- 問い合わせ先: yishigeict@gmail.com

## 配布前チェックリスト

- [ ] 支援コースに含まれる対象OSと人数を確定
- [ ] iOS公開リンクの参加人数が100人以内であることを確認
- [ ] Android希望者のGoogleアカウントをメーリングリストへ登録
- [ ] Android参加リンクから対象アカウントでインストールできることを確認
- [ ] Steamキー申請が解禁されたかを確認
- [ ] Steamキーを対象人数分だけ申請
- [ ] 各Steamキーを重複送付しないよう管理表へ記録
- [ ] 配布するビルドでデバッグ導線が無効であることを確認
- [ ] 既知の問題とフィードバック先をメールへ記載
- [ ] 送信前に宛先をBCCまたは個別送信にし、支援者同士へメールアドレスを開示しない
