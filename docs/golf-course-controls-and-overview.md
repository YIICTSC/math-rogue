# ゴルフの縦・横画面とコース全景

- 画質・コース全景・スコアボード・コースマップを同じ操作パネルに配置する。
- 縦画面でも4つの操作を表示し、ショット操作はその下の領域内でスクロールできる。
- 横画面は操作パネルとショット操作を右下にまとめ、幅を最大390px・画面幅の46%に制限する。
- コースマップは操作列から上へ開くポップアップにし、開いてもショット操作の配置を押し広げない。
- 観戦では、上の観戦者操作と下のコース操作が重ならないよう高さを制限する。

## 全景表示

全景ではショットパネルを畳み、3Dコースをスワイプ／マウスドラッグで平行移動する。
カメラの高さと実際の表示領域から1pxあたりの移動距離を求め、ティーからグリーンと周辺を確認できる範囲内に収める。
通常表示のドラッグは従来どおりボール周辺の視点回転。
全景切り替え・ホール変更・観戦対象変更では移動位置とドラッグ状態をリセットする。

コース操作列はショットメーターの画面タップ判定から除外する。
全景へ切り替える際はメーターを無効にして中止し、スワイプがショット確定になることを防ぐ。
