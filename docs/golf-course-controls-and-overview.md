# ゴルフの縦・横画面とコース全景

## ショット準備

- クラブ・打点の折りたたみを廃止する。
- 左下のクラブ表示全体をタッチすると、端末標準の選択UIでドライバー・アイアン・ウェッジ・パターを直接選べる。クラブ名と推定飛距離を常時表示する。
- 打点はクラブ表示の上に常時表示する。ボール上のタッチ・ドラッグ、またはスライダーでトップスピン／バックスピンを調整できる。キーボードでボールを押すと中央へ戻る。パターでは打点を中央に固定する。
- 画面下部の残り幅を横長のショットバーに割り当て、方向調整・必殺ゲージ・タイミング・ショットボタンを置く。スマホ縦は同じ領域内でコンパクトな縦並びにする。
- 画質・コース全景・スコアボード・コースマップは右上の操作列へ配置する。マップを開いてもショット操作の位置は動かない。
- ショット計測中と一時停止中はクラブ・打点・方向の変更を無効にする。操作列・設定項目のタッチはタイミング確定として扱わない。
- 必殺ゲージが満タンのとき、ショットバーを金色に発光させる。動きを減らす設定では点滅せず、静止した発光で準備完了を示す。自動発動条件・威力・判定は従来どおり。
- 初回ショット・初回必殺ショットの停止式チュートリアルは維持する。

問題回答・結果・観戦画面は従来の専用領域を利用する。

## 全景表示

全景ではショット操作を非表示にし、3Dコースをスワイプ／マウスドラッグで平行移動する。
カメラの高さと実際の表示領域から1pxあたりの移動距離を求め、ティーからグリーンと周辺を確認できる範囲内に収める。
通常表示のドラッグは従来どおりボール周辺の視点回転。
全景切り替え・ホール変更・観戦対象変更では移動位置とドラッグ状態をリセットする。

全景へ切り替える際はメーターを無効にして中止し、スワイプがショット確定になることを防ぐ。
