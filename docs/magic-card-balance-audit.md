# マジック編 専用カード バランス監査

> 2026-06-15: 第一回推奨調整を初期専用カードと変身後の魔法カードへ共通定義で反映。追加した即時効果は、変身中に既存仕様どおり2倍になる。

## 比較基準

- 魔導打撃: 1コスト、7ダメージ
- 魔力障壁: 1コスト、ブロック6
- 術式集中: 1コスト、ブロック4、1ドロー
- 専用カードは使用時に専用ルールが1段階進む
- 変身中はダメージ、ブロック、回復、ドロー、エナジー、状態異常、自傷が2倍
- `applyPower` の付与量は変身しても2倍にならない
- 変身中はターン終了時にHP20を失うため、即効性のないカードは評価を下げる

評価:

- S: 明確に強い
- A: 十分強い
- B: 標準的
- C: 状況依存で弱さが目立つ
- D: 基本カードや他の専用カードに対して明確に弱い

## 共通ブラッシュアップ方針

1. 2コストパワーには即時効果を付ける
2. 変身中もパワー付与量を2倍にするか、パワーだけ1コストにする
3. 専用ルールの3枚目は、完成効果を含めて2コスト相当以上にする
4. 状態異常・生成カード依存のパワーは、使用時にも最低限の効果を出す
5. 強すぎるドロー+エナジーカードは弱カード修正後に再評価する
