# 英語表示 完全翻訳修正計画

作成日: 2026-07-14

## 目的

英語モードで通常のゲーム進行、設定、確認画面、イベント、カード・アイテム説明に日本語が残らず、文脈に合う英語で操作できる状態にする。

## 対象外

- ミニゲーム内部の問題文、説明文、ゲーム固有表示
- 日本語の読み取り自体がルールとなる問題
- 固有名として原文表示するクレジット名
- 画像そのものに描かれた文字

ミニゲームへ入る前後の共通UI、終了確認、報酬、エラー表示は対象に含める。
