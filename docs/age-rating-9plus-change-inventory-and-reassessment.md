## 1. 疑似ギャンブル要素

次のプレイ可能要素を撤去した状態を維持する。

- ゲーム内資産を賭ける選択肢
- 勝敗やランダム結果による掛け金の没収・倍率払い戻し
- 裏カジノ、ルーレット、777、全掛け等のカジノイベント

「放課後ポーカー」、ポーカー役、カードショップ、ゲーム内`pt`は使用する。
これらには掛け金や換金機能を持たせない。

## 2. ランダムパック

- `pt`で購入した後にランダム候補を開示し、その中から1件を受け取る。
- 購入後のキャンセル・払い戻しは設けない。
- App Store Connectでは「ルートボックス: はい」と回答する。

## 3. 名称と専用イラストを変更したカード

反復表示される具体的な学校内危害だけを変更対象とする。
すべての変更カードに、元カードと同等の枠・ロゴ・描画密度を持つ個別イラストを用意する。
汎用イラストへの振り分けは使用しない。

| 内部の原名称 | 製品版表示 | 専用イラスト |
| --- | --- | --- |
| カンチョー | 指さし確認 | `public/card-illustrations/指さし確認.webp` |
| 袋叩き | 連続発表 | `public/card-illustrations/連続発表.webp` |
| ヘッドロック | チームミーティング | `public/card-illustrations/チームミーティング.webp` |
| 画鋲投げ | クリップ渡し | `public/card-illustrations/クリップ渡し.webp` |
| 割れた窓ガラス | ステンドグラス | `public/card-illustrations/ステンドグラス.webp` |

日本語・ひらがな・英語表示と、通常カード、合成カード、拡大表示、図鑑表示で同じ専用画像を使用する。

## 4. 原仕様を維持する主な境界

次は年齢評価対応による変更対象にしない。

- HP、攻撃、防御、ブロック、ダメージ、敵、撃破、戦闘
- 炎、雷、斬撃、衝撃、投射等のファンタジー演出
- 幻影の刃、雷神の鉄拳、影縫いの太刀等の架空カード名
- 放課後ポーカー、ポーカー役、カードショップ
- 兵十の火縄銃とその原イラスト
