# VRソロ対戦

VRタイトルの「ソロ対戦」から、バトルロイヤルまたは爆弾バトルを選び、他のプレイヤーやサーバーなしで対戦を開始できる。既存の「ソロトレーニング」は潜入ミッション用として残す。

- CPU人数は1・3・7・15・39人。自分を含めて最大40人の描画・視点・操作を試せる。
- 制限時間と問題を選択でき、爆弾バトルは3つのマップから選べる。
- CPUは人間と同じ移動・武器拾得・ダメージ・爆弾・学習補充のルールで行動する。CPUの自動解答は学習記録へ保存しない。
- バトルロイヤルのCPUは障害物を迂回し、武器を拾い、射撃・装填・補給を行う。
- 爆弾CPUは爆風を予測し、逃げ道がある位置で箱や相手に爆弾を使い、アイテムを回収して補充する。移動中の曲がり角で経路を反転させない。
- 一時停止・再開、結果表示、同じ条件での再戦に対応。キャラクター編集や非表示タブではローカル時間を停止する。
- オンラインの最低人数、定員制限、プロトコルは変更しない。ソロ開始ではPeer／WebSocketを作らず、退出時にローカルのタイマーとイベントを解除する。

## 検証

- `pnpm run test:vr-solo`：両モード×4シード・爆弾の3マップでCPUの移動・実際の攻撃・箱破壊・勝敗を確認。40席のローカル対戦、一時停止と編集の独立した停止、プレイヤーの補充、再戦・終了処理も確認。
- `pnpm run test:vr-solo-browser`：実際のタイトル・設定・問題選択から開始。CPUの移動、爆弾設置と正答による補充、バトルロイヤルの3問補給、編集時の停止、結果からの再戦、退出を確認。PC／縦・横画面、ソロ開始時に対戦用のWebSocketを開かないことも検証。
- 型検査・英語監査を含むクライアントビルド、サーバービルドと既存の40接続テスト。

HMDの実機FPS・酔いは検証していない。アップロード後の完了監視は、2026-10-14のユーザー指示に従い、明示依頼がある場合だけ行う。
