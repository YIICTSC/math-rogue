# 学習ローグ RPGオンライン（開発中）

通常公開用モードではありません。ホストのタイトル入口・起動操作・画面描画は `isDebugModeActive` で制限しています。`VITE_ENABLE_DEBUG_FEATURES=true` のビルドでは、招待URLを開いた参加者に限り、アプリ内デバッグモードを有効にしなくても参加できます。保存データ経由の起動は不可です。

## 起動

```powershell
pnpm run dev:debug
```

Windowsにも対応した起動スクリプトです。通常の `dev` や本番ビルドの設定は変更しません。

1. 表示されたローカルURLを開く。
2. 初回の学年設定等を終える。
3. タイトル下のバージョン表示を押し、`System Release Notes v1.0.7` を10回押して既存のデバッグモードを有効にする。
4. デバッグ画面から「戻る」でタイトルへ戻る。
5. タイトルで編を選び、「RPGオンライン　開発中・デバッグ限定」を選択する。
6. 本編の問題選択 → 難易度選択 → 主人公選択（必要に応じて初期レリック等）を行う。FREE課題が選択済みなら、本編同様に課題を問題ソースにして難易度選択から始まる。
7. 部屋を作成・参加するか、ひとり練習を開始する。

部屋を作成すると画面下部に「招待URLをコピー」が表示されます。コピーしたURLを開いた参加者は、タイトルでデバッグモードを有効にしたりRPGボタンを押したりせず、ルームコードを入力せずにホストへ自動接続します。ホストが選んだ編・問題・難易度を受け取って問題選択と難易度選択を省略し、主人公選択から開始できます。ホストがFREE課題を選んでいる場合は課題の問題と進行単位も同期します。主人公を選ぶと初期レリック等の追加画面を挟まず、すぐに同じワールドへ入ります。

ゲーム画面にも「開発中」を表示します。アプリを再読み込みすると既存仕様に従ってデバッグ状態は解除されます。

## 現時点で遊べる内容

- オリジナルの16pxドット描画。64×44マスの地形、森、川、道、町、時計塔。シードごとのランダム生成と全拠点への到達保証。
- 最大40人の自由探索、最大4人の任意加入チーム。矢印キー・WASD・タップ経路移動・スマートフォン方向ボタン。
- タイトルで選んだ小学生編・高校生編・魔法編と、問題・難易度・主人公の設定を引き継ぐ。
- 戦闘は `App.tsx` の本編の敵生成・カード処理・戦闘画面を使用。戦闘後の問題画面・報酬画面も本編と同じ。RPG独自の6カード戦闘・問題生成は削除した。
- 町2か所・焚き火1か所は本編の休憩マス、？イベント4か所は本編のイベント生成（派生するミニゲーム等も含む）、宝箱5か所は本編の宝箱画面と報酬を使用。
- 町・焚き火・？イベントは、プレイヤーごと・地点ごとに3勝につき1回。初回も3勝必要で、入場時に利用枠を消費する。勝利数は戦闘後の問題・報酬を完了して探索へ戻ったときに増える。逃走・敗北は数えない。宝箱は各プレイヤー1回で入場時に消費する。
- 通常敵14地点は繰り返し戦闘可能。試験官3体は本編の第1・2・3章ボスの計算を使用し、最初に挑戦した人の難易度・デッキによるHPを部屋で固定する。試験官のHP・討伐状態は共有。
- 校長は本編の第3章ボスのHP計算を使い、初回入場時の部屋の人数を掛ける。途中参加で再計算しない。3体の試験官を倒すと挑戦でき、撃破後も各参加者は本編の問題・報酬を終えてから共通の勝利画面へ戻る。
- 任意の4人チーム。5マス以内の同じチームの仲間1人につき、戦闘開始時に本編の攻撃力を2加算する。通常戦闘の手札・ターンは個人で進める。
- 敗北時は問題を6問正解すると木漏れ日の町へ戻り、最大HPの60%（端数切り上げ）へ回復し、所持金が半分になる。
- FREE課題の出題、回答実績、課題達成、ご褒美カードは本編の共通処理を使用。CHALLENGE_ONLY課題・起動ロックの制約も本編に従う。

## 通信

既存プロジェクトのPeerJSを使用しています。ホスト1台が移動速度・距離・入場資格・クールダウン・宝箱・人数を検証し、最大39接続へ250msごとに変更状態を配信します。地形は入室時のみ送信します。シーンごとのトークンと連番付き累積ダメージにより、二重送信を除外し、共有HPを更新します。敵の回復も共有します。戦闘・カード・回答・報酬の処理は各端末の本編が行います。異なるプロトコルの旧開発版は参加できません。

標準ではPeerJSの標準シグナリング接続を使用します。ローカル検証・独自サーバーは次のVite環境変数で切り替えられます。

```text
VITE_RPG_PEER_HOST=127.0.0.1
VITE_RPG_PEER_PORT=9000
VITE_RPG_PEER_PATH=/rpg
VITE_RPG_PEER_SECURE=false
```

開発用環境変数を本番設定に追加しないでください。

## 開発段階の制限

- ホストが退出・再読み込みすると部屋は終了します。ホスト移譲、再接続、冒険の途中保存は未実装です。メインの冒険のセーブには干渉しません。
- 40接続テストは同一PC・ローカルシグナリング環境での検証です。実際の40台の学校端末、学校回線、別ネットワーク間の接続・負荷は未検証です。NATや学校の通信制限によっては別途TURN対応が必要です。
- 本編の画面・処理を再利用していますが、全主人公×全カード×全イベントの組み合わせを網羅した検証ではありません。RPGの部屋・進行は本編のランキングや章クリアとして登録しません。
- 本番の認証・永続サーバー・不正対策は未導入です。参加者はルームコードを知る開発テスターを想定しています。
- 通常公開ビルドではホスト入口を表示しません。ホスト起動にはデバッグフラグとアプリ内デバッグモードの両方が必要です。招待参加はデバッグ機能を有効にしたWebビルドで、アプリ内デバッグモードなしに行えます。
- 招待URLはルームコードを含む一時的な共有リンクです。URLを知っている開発テスターが参加でき、ホストが退出・再読み込みすると使えなくなります。招待URLの自動参加もデバッグ機能を有効にしたWebビルドでのみ動作します。

## 追加された冒険要素（通信バージョン8）

カードトレードはマップの近くのプレイヤーを選び、トレードボタンで申し込みます。相手が承諾後、双方が最大5枚を提示し、両方が確定した場合だけ交換します。提示を変えると確定が解除され、交換後はデッキ5枚以上が必要です。申し込みは2分で失効し、切断でも取り消されます。冒険中のカードだけを交換し、保存済みのカードコレクションは変更しません。

協力ダンジョンは「森の協力ダンジョン」(18,19)と「星の協力ダンジョン」(47,27)にあります。1〜4人で募集し、全員の準備完了後に募集主が開始します。本編のリアルタイム協力モードの戦闘・カード・敵HP・問題・報酬・休憩・宝箱を使用します。通常戦闘2部屋、休憩、ボス、宝箱の全5部屋で、攻略後は参加者全員に60コインを追加しワールドへ帰還します。ダンジョンのカード攻撃による実ダメージも総ダメージに集計します。ダンジョン内の通信は参加者だけに中継し、参加者の操作は募集主が処理します。参加者の退出・切断で攻略を中断します。敗北時は従来の6問正解・最大HP60%（切り上げ）・所持金半減で帰還し、時間切れは問題画面等からも全員をランキングへ戻します。

町にはゲームセンターがあります。1回10コイン、初期3回、戦闘3勝ごとに1回追加です。カードめくりは3択の当たりでカードと20コイン、ルーレットは3色の当たりで20コインと最大HP20%回復、スロットは6分の1の大当たりで50コイン。選択後に冒険中の問題・課題を使って学習し、1問以上正解した場合に当たり景品を受け取ります。3問以上の正解は抽選結果によらず10コイン追加です。料金・抽選・報酬はホストが確定し、同じ抽選の再送で二重に景品を受け取れません。

ワールド共通イベントは全員の戦闘勝利、問題正解、3か所の封印装置の操作が順に入れ替わります。イベント期間は最大3分、終了後1分で次のイベントが始まり、ワールド全体の制限時間内で進行します。達成報酬は全員に配り、貢献者は追加コインを受け取ります。知識のイベントでは回復と施設の再利用、封印イベントでは校長の攻撃力低下が発生します。戦闘やダンジョン中に得た報酬はワールドへ戻った時点で一度だけ反映します。

地図の断片は3か所に隠れていて、近づくと表示されます。発見は全員に共有し、3つそろうと(57,21)の秘密の遺跡で各プレイヤーが1回だけカードと40コインを獲得できます。封印装置は(17,7)、(35,23)、(48,6)に配置しています。
