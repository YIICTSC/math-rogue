# バトル画面ステータス表示 学校テーマ文言案

作成日: 2026-07-05  
更新日: 2026-07-06

対象は通常バトル画面に表示されるプレイヤー/敵のステータス名、クリック時の説明、ステータスVFXラベル。基本方針は、カードで付与される名称を維持し、硬いRPG語や説明だけを学校テーマに合わせて整える。

## 更新方針

- `ブロック`、`HP`、`エナジー`、`捨て札` は現状維持。
- `金属化`、`じわじわ回復` はカード/パワー名を維持。
- 付与されるカード名・効果名は原則維持する。
- 変更対象は、カード文やVFXラベルとズレている表示名、説明が実仕様と違うもの、硬すぎる説明文に絞る。
- `キラキラ` は `ドクドク` も含め、次に受けるデバフを1回ふせぐ仕様へ変更する。

## キラキラ仕様確認

|確認箇所|実装内容|結論|
|---|---|---|
|`src/App.tsx` player debuff処理|プレイヤーに妨害を付与する時、`ARTIFACT` があると1減らして妨害を無効化する。|`へろへろ`、`びくびく`、`混乱`、粘液追加系の妨害を1回防ぐ。|
|`src/App.tsx` enemy debuff処理|敵の `artifact` がある時、`WEAK` / `VULNERABLE` / `POISON` を1回防ぐように変更。|敵側も `ドクドク` を含むデバフを1回防ぐ。|
|`src/services/cardEffectLogic.ts` poison処理|`POISON` も `artifact` の防御対象に変更。|追加カード側の `ドクドク` 付与もキラキラで防ぐ。|
|現行説明|`受けるダメージを1にする。`|実仕様と不一致。ダメージ軽減ではない。|

推奨説明:

> キラキラ / 次に受けるへろへろ・びくびく・ドクドク・混乱などのデバフを1回ふせぐ。

短く収める場合:

> キラキラ / 次に受けるデバフを1回ふせぐ。

## 優先度

1. `キラキラ` の仕様を `ドクドク` も含むデバフ無効にし、説明も合わせる。現行の「受けるダメージを1にする」は誤り。
2. 敵ステータスtooltipの `脆弱` -> `びくびく`、`弱体` -> `へろへろ`。カード文とVFXラベルに統一する。
3. プレイヤー `筋力` -> `ムキムキ`。カード文・ログと統一する。
4. `No Relics` -> `もちものなし`。英語残りを解消する。
5. `HP` の説明だけ `死亡` -> `リタイア` にするか検討する。HP名称自体は維持。
6. `バフ/デバフ` は現状維持。
