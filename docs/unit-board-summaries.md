# 単元板書モーダル原稿

問題画面から開く「単元ノート」用の板書原稿。実装時は `mode` または `unitId` に紐づけて、初回単元開始時と問題画面のノートボタンから表示する。

## 表示フォーマット

```md
### {unitId} {単元名}
- mode: `{mode}`
- めあて: ...
- 板書:
  - ...
  - ...
  - ...
- よくあるミス:
  - ...
- 例:
  - ...
```

## 算数・数学

### 計算 基礎
- 対象: `ADD_1DIGIT`, `ADD_1DIGIT_CARRY`, `SUB_1DIGIT`, `SUB_1DIGIT_BORROW`, `ADDITION`, `SUBTRACTION`, `MULTIPLICATION`, `DIVISION`, `MIXED`
- めあて: 四則計算を、位と計算の意味を意識して正確に解く。
- 板書:
  - たし算は合わせる、ひき算は残りや差を求める。
  - かけ算は同じ数ずつ、わり算は同じ数ずつ分ける。
  - 筆算は位をそろえ、くり上がり・くり下がりを書く。
- よくあるミス:
  - 位をそろえずに計算する。
- 例:
  - `34 + 28` は一の位から計算し、10こ集まったら十の位へ送る。

### MATH_G1_U01 かずとすうじ（10までのかず）
- mode: `MATH_G1_U01`
- めあて: ものの数を数えて、数字で表せるようにする。
- 板書:
  - 1つずつ指で押さえながら数える。
  - 最後に言った数が全部の数。
  - 数字は「いくつあるか」を表すしるし。
- よくあるミス:
  - 同じものを2回数える。
- 例:
  - りんごを 1、2、3 と数えたら、答えは3こ。

- よくあるミス:

- 例:

## 実装メモ

- まずは `mode` 単位で表示し、単元モードがある教科は `unitId` を優先する。
- 自動表示の既読キー案: `unitBoardSeen:${mode}:${unitId ?? "default"}`。
- モーダル本文は `めあて`、`板書`、`よくあるミス`、`例` の4ブロックに分ける。
- 1画面に収めるため、各ブロックは最大3行程度にする。
