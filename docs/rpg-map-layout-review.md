# RPGオンライン・拡大マップの配置見直し

対象は192×88マス（拡大前の6倍）。マップの広さと各場所の利用条件は維持する。

## 調査結果

施設の旧座標を横3倍・縦2倍にするだけでは、草原に町と休憩所、遺跡に町が偏り、森・湿原・砂丘・雪原に回復施設がなかった。
通常敵・イベント・宝箱は全域から抽選していたため、シード7では砂丘に通常敵5体、雪原と遺跡には各1体。森と湿原には？イベントがなく、草原と湿原には宝箱がなかった。

- 合計は町2、休憩所4、通常敵18、？イベント6、宝箱12。敵の再抽選、各場所で3勝ごとの再利用、宝箱の個人単位の利用制限は既存ルールを使う。
- 通常敵は地域拠点から30マス以内。開始地点近くにも3体を確保し、最初の施設利用までの3勝を稼げる。
- ショップとゲームセンターを持つ2つの町は草原と遺跡に分け、開始側と終盤側の両方から利用しやすくする。
- イベントと宝箱は地域の周辺側へ配置し、拠点付近の戦闘と周辺探索を両立させる。
- 抽選する場所は同じ地域内でシードに応じて変化し、他の施設・イベントから7マス以上離す。
- 試験官3体、校長、協力ダンジョン2か所、地図の断片・秘密の遺跡・封印装置、物語の人物と目的地は役割と配置を維持する。

## 道路

地域拠点間に東西2本・南北3本の幹線道路を通し、周回できる網にする。各施設・イベントは所属地域の拠点へ接続する。
各施設の周辺整地を先に行ってから道路を引き、後からの整地で道路が消えないようにする。

## 検証

`node scripts/audit-rpg-map-layout.mjs`（または `pnpm run test:rpg:layout`）で100シードを検証する。
地域ごとの配置数、座標範囲、場所の重複、7マスの間隔、全施設への道路・歩行接続、序盤の敵3体、同じシードで同じ配置になることを確認する。

距離統計は4マス間隔の標本を使う。実歩行距離は町から到達可能な標本地点のみを対象に、森と水を避ける上下左右の最短経路で計算する。回復施設の利用クールダウンは距離統計に含めない。
変更前の24シードでは回復施設まで平均40.5マス、95%の地点で76マス以内。改善後の100シードでは平均25.6マス、95%の地点で42マス以内になった。

町だけを対象にした歩行距離は平均47.3→50.4マスと少し増える一方、観測上の最大距離は128→110マスに減る。星見の宿場を校長寄りに置くことで、宿場と校長の上下左右の距離は55→17マスとなり、終盤の買い物をしやすくした。全地点の買い物距離を一律に短縮する配置ではなく、序盤と終盤の準備を重視している。

`--report-only --baseline` はGitのHEADの生成処理と比較するための調査用オプション。改善をコミットした後はHEAD自身が改善後になる。
