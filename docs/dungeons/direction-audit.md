# ダンジョンズ全主人公の向き確認

2026-10-25、main b7bea534 の画像を対象に確認。
ダンジョンズ1の52形態（小学生9・高校生9・マジック17×通常/変身）と、
ダンジョンズ2の9人×通常/変身18形態、計70形態を対象とした。

待機画像560コマと追加アクション画像4,480コマを並べて目視比較した。
方向順は南・北・東・西・南東・南西・北東・北西。
ダンジョンズ1では反転・入れ替えを要する明確な不整合を確認せず、描画を維持した。
ダンジョンズ2の通常リリアには東の位置に西向きの絵がある。
斜め方向には複数人物で前後の混在があり、例としてフローラ・ノクティア・
イグニス変身後・レオン・オリオンの北西などに前寄りの絵が入っていた。

人物・装備の左右を鏡像にせず、ダンジョンズ2の斜め4方向と通常リリアの東は
既存の方向別待機画像から手足を動かすアクションを生成して描画する。
斜め方向は全18形態で同じ基準を使い、良否が曖昧な列も混在させない。
それ以外の上下左右は追加イラストを維持する。待機・町・ダンジョンは同じ方向番号を使う。
3D表示は画像の列を使わず、移動ベクトルからモデルの回転を計算している。

修正後はブラウザー上でダンジョンズ1の3,328通りとダンジョンズ2の1,152通りを描画。
通常・変身画像の選択、アクション終了後の待機復帰、各方向のソース選択を検証した。
このうち584通りが元の方向別画像からの動作であり、「584コマが誤っていた」という意味ではない。
目視確認は自動テストの列番号検査とは区別する。
画像を変更した場合に再確認できるよう [画像ハッシュ記録](./direction-audit.json) を保存した。

```sh
node scripts/audit-dungeons-directions.mjs
node scripts/test-dungeons1-actions-browser.mjs
node scripts/test-dungeons-directions-browser.mjs
node scripts/test-dungeons2-actions-browser.mjs
```

## アクション内の差分確認と改善

main 255b4c8b から、全70形態の8方向×8画像行（歩行2行、他6動作）を再比較した。
前回は身体の向きと画像列の対応が中心だったが、今回は各アクション内のフレームと
武器・手・投射方向も対象にした。元画像4,480コマは変更せず保存している。

追加で見つかった共通の問題:

- 元の補間処理は左右の符号だけで武器・投射を配置しており、南北や斜めの方向成分を使っていなかった。
- 描き下ろしの非歩行動作は1動作1コマで、再生中の構え・実行・戻りに画像差分がなかった。
- ダンジョンズ2の方向補正歩行は、歩数の偶奇を使わず、各歩行が同じ足から始まっていた。
- 補間歩行の足は全方向で画面左右に動き、北向きの本や道具も身体より前に重ねていた。

攻撃・投擲・杖・射撃の4動作は両作全70形態で、元の方向別画像から作る3段階の
動作へ統一した。武器と投射の向きは8方向ベクトルで計算し、構えと戻りでも
逆方向を向かない角度に制限する。手までの腕をつなぎ、背面方向では小物を先に描いて
身体で隠す。顔・髪型・衣装・左右は元画像から保持し、人物全体の反転・回転はしない。

補間歩行は移動ベクトルに沿って足を動かし、ダンジョンズ2では歩数の偶奇を6フレームの
位相に反映する。描き下ろしの正常な歩行・読書・道具画像は引き続き利用する。
全形態・全動作の採用方向は direction-audit.json の canonicalActionDirections に記録した。

追加検証では全24動作フレーム×8方向×70形態＝13,440通りを実ブラウザーで描画。
攻撃系2,240シーケンスで3段階の画素差分があり、向きが反転しないこと、ダンジョンズ2の
全18形態で同じ経過時刻でも連続した一歩の足が交互になること、待機復帰を確認する。
列番号・画素差分のテストだけで美術的な正しさを保証せず、比較画像の目視確認も併用する。

```sh
node scripts/test-dungeons-action-phases-browser.mjs
```

実行時の全形態プレビューは tmp/action-phases/ に生成する。
