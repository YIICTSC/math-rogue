- 雨ふらしの傘は射線の最初の敵へ20ダメージ。敵HPを1で止めず、撃破・経験値・飲み込み品の返却を処理。

- つるはし名の道具・武器は、手持ちまたは装備中なら正面の壁へAで掘れる。装備やメニュー使用は不要。

## ダンジョンズ2の専用アニメーション

ImageGenを各主人公の既存8方向画像を参照して18回実行し、9人×通常/変身後の専用画像を作成した。
原本は assets-source/dungeons2/dedicated-animations/ にロスレスWebPで保存し、元PNGのSHAも記録した。
素材・参照・行の切り出し位置・採用行・出力SHAは assets/dungeons2/dedicated-animations-build.json に保存。
生成された素材の行数・順序にはずれがあるため、目視で確認して sourceRowMap を定義した。
一部の構えや保持姿勢には同じ人物の生成済みポーズを再利用する。人物の身体の切り貼り・反転・拡縮による差分生成は行わない。

実行時は各方向4コマの歩行と、各動作2枠の専用イラストを再生する。全18形態の2,304枠（保持ポーズの再利用を含む）。
同じ足から毎回開始せず、歩数に応じて歩行の位相を交互にする。
待機も新しい方向別画像を使い、以前の簡易差分・元の方向の取り違えを再導入しない。
ダンジョンズ1の全52形態は既存の方向対応を回帰確認する。

```sh
node scripts/dungeons2/build-dedicated-animations.mjs
node scripts/test-dungeons2-dedicated-animations.mjs
node scripts/test-dungeons-tools.mjs
node scripts/test-dungeons-revision-browser.mjs
node scripts/test-dungeons1-actions-browser.mjs
node scripts/test-dungeons-action-phases-browser.mjs
node scripts/test-dungeons-directions-browser.mjs
pnpm run build
pnpm run server:build
```

実ゲームの8方向移動・通常/変身・物語の色・傘・敗北画面のスクリーンショットは tmp/dungeons-revision/ に出力する。
