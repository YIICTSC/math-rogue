# エンドレスモード全ボス 特殊行動導入案・実装仕様

## 1. 目的

エンドレスモード以降のボス戦に、通常の攻撃パターンとは別の「予告される特殊行動」を追加する。
75F区間を前提に、毎回同じ種類の行動だけにならないよう、編と章で順番をずらす。行動は学習判定やマップギミックの達成条件に依存させず、戦闘中の判断だけで解決できるようにする。

対象は、固定テーブルにある3編・第5〜50章の30体と、第55章以降に自動生成される真エンドレスの章ボス。アズキ、ドドメデスなどの物語イベントから発生する特殊ボスは、既存の固有戦法と専用カード報酬を維持し、この共通行動を重ねない。

## 2. 共通ルール

- 特殊行動は、ボスの「次の行動」表示に先に出す。
- ボスの敵ターンが5回進むごとに、2回目の敵行動を特殊行動にする。内部ターン値では `turn % 5 === 2`。
- 特殊行動は戦闘中だけ有効。周回、デッキ、章結果、報酬には影響しない。
- COOPでは、その敵ターンに生存している全プレイヤーへ適用する。
- 特殊行動は学習判定の成否、教科、単元、カード報酬の内容を参照しない。
- 特殊行動の効果が無効になる状況でも、予告と戦闘ログは表示する。

## 3. 特殊行動一覧

### 3.1 手札攪乱（`DISCARD_HAND`）

予告後、手札からランダムに1枚を戦闘中の捨て札へ送る。捨て札に送られるだけであり、デッキからの永久削除やカード報酬の消失は発生しない。手札が空の場合は「手札は空だった」とログに残し、追加効果は発生しない。

プレイヤー側の対策は、重要カードを先に使う、手札を増やして選択肢を残す、捨て札回収カードやレリックを使うこと。通常のカード廃棄ではないため、カードの恒久的な損失と誤認させない。

### 3.2 追加コスト（`CARD_TAX`）

予告後、次に使うXコスト以外のカード1枚だけ、表示コストと必要エネルギーを1増やす。Xコストカードは対象外。ターン終了までに使わなかった場合は解除する。

手札上のカード表示にも加算後のコストを反映し、エネルギー不足なら使用不可にする。Corruptionなどでコストが0になるカードも、Xコストでなければ追加コストの対象とする。

### 3.3 カード種別封印（`TYPE_LOCK`）

予告後、ATTACK・SKILL・POWERのうち1種類を、次のプレイヤーターンだけ使用不可にする。SUMMON、STATUS、CURSEなどは封印対象外。封印中は手札カードを使用不可表示にし、カードを失わせない。

封印対象は、ボス章とフェーズから決定するため、リロードやCOOP参加者間でも同じ結果になる。実装式は次の通り。

```text
対象種別 = [ATTACK, SKILL, POWER][(ボス章番号 - 5) / 5 の整数値 + フェーズ] mod 3
```

## 4. 全ボスへの割り当て

### 4.1 固定30ボス

同じ章番号でも編ごとに行動がずれる。表中の「5/20/35/50章」は、その4章で同じ行動を使うことを示す。

| 編 | 5・20・35・50章 | 10・25・40章 | 15・30・45章 |
|---|---|---|---|
| 小学生編 | 手札攪乱 | 追加コスト | カード種別封印 |
| 高校編 | 追加コスト | カード種別封印 | 手札攪乱 |
| マジック編 | カード種別封印 | 手札攪乱 | 追加コスト |

### 4.2 真エンドレス（第55章以降）

固定30ボスと同じローテーションを継続する。章が5増えるたびに次の行動へ進み、編のずれも維持する。

```text
行動番号 = ((章番号 - 5) / 5 の整数値 + 編オフセット) mod 3
小学生編オフセット = 0
高校編オフセット = 1
マジック編オフセット = 2
行動番号 0 = 手札攪乱
行動番号 1 = 追加コスト
行動番号 2 = カード種別封印
```

## 5. プレイヤーへの表示

- ボス戦の行動予告アイコンを表示し、タッチ／クリック時に具体的な効果を確認できる。
- 手札攪乱：「手札からランダムに1枚を捨て札へ送る」
- 追加コスト：「次に使うXコスト以外のカードのコスト+1」
- カード種別封印：「ATTACK／SKILL／POWERのうち、表示された1種類を次の自分ターンだけ使用不可」
- 効果が解決したら戦闘ログに結果を追記する。
- マップ上の学習ギミック達成条件や報酬条件は変更しない。

## 6. 実装時の状態管理

| 状態 | 保存場所 | 消去タイミング |
|---|---|---|
| 追加コスト | `player.relicCounters.ENDLESS_BOSS_CARD_TAX` | 対象カード使用時、またはターン終了時 |
| ATTACK封印 | `player.relicCounters.ENDLESS_BOSS_LOCK_ATTACK` | 次のプレイヤーターン終了時 |
| SKILL封印 | `player.relicCounters.ENDLESS_BOSS_LOCK_SKILL` | 次のプレイヤーターン終了時 |
| POWER封印 | `player.relicCounters.ENDLESS_BOSS_LOCK_POWER` | 次のプレイヤーターン終了時 |

これらは一時カウンターであり、休息、章遷移、報酬、セーブデータの恒久解禁には持ち越さない。

- [ ] 固定30体すべてに特殊行動のキーと説明がある。
- [ ] 第55章以降の生成ボスにも同じ式で特殊行動が付く。
- [ ] ボスの行動予告に特殊行動が表示され、タッチ／クリックで説明を確認できる。
- [ ] 手札攪乱は1枚を捨て札へ送り、デッキから削除しない。
- [ ] 追加コストは次の非Xカード1枚だけに適用し、未使用ならターン終了で消える。
- [ ] カード種別封印は次のプレイヤーターンだけ有効で、対象外カードは使える。
- [ ] COOPでは生存中の全プレイヤーに同じ特殊行動が適用される。
- [ ] アズキ・ドドメデスの既存固有挙動と専用カード報酬が変わらない。
- [ ] 通常モードの敵、通常モードのボス、物語イベントの特殊ボスへ影響しない。
