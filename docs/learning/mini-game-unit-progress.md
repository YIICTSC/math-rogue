# ミニゲーム内の単元別正解数

## 修正対象

- `MiniGameProblemChallenge` を使うダンジョンズ1・2、継界戦記、星潮の航路、校長対決、帰宅ダッシュ、紙飛行機、ポーカー、トランプゲーム集などの共通出題経路。
- GPのオンライン解答記録。
- VRの通常問題・爆弾補充問題。
- クラフトの通常問題と家具ゲームの問題（プレビューを除く）。

これらは解答履歴の保存と単元別累計正解数の更新が接続されていなかった。正解ごとに `recordMiniGameUnitProgress` を呼び、出題結果の実際の `mode` に1問を加算する。複数単元を混ぜた場合も代表単元にまとめず、それぞれの単元へ帰属させる。

スポーツ4種はAppの `SportsHub` 解答コールバックですでに単元別加算を行っているため、その経路は維持し、新しい通知を重ねない。本編や問題チャレンジの既存通知にも新しい通知を重ねない。

## 保存とマスター

Appは正解通知を受け取り、既存の保存・マスター処理に渡す。Appのない単独起動では単元別累計だけを保存する。誤答・単元のないオリジナル課題は単元別加算の対象外。同一解答の `pointReceipt` を再通知しても重複加算しない。別の解答として同じ問題に再度正解した場合は加算する。

100問正解の単元マスター条件を維持する。まとめて届いた複数解答でも、正解数を落とさず、100問到達報酬を重複発行しないようApp側の最新累計とマスター状態を同期する。RPGと本編の進捗・報酬の分離条件は既存処理に従う。

既存の累計はリセットしない。過去の解答履歴にはミニゲーム由来か本編で加算済みかを確定できる記録がないため、過去分を推測して一括加算しない。

## 検証

`node scripts/test-mini-game-unit-progress.mjs`

実際のAppカウンター・通知受信処理を使用し、誤答除外、単元別帰属、同一解答の重複通知、Appなしの保存、再描画前の連続加算、99→100→101問とマスター報酬1回を確認する。
