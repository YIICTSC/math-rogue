# RPGの音ゲー家具「学ロリズム」

家の「家具を作る → ゲーム家具」から音ゲー筐体を作り、室内に配置します。材料は木の板5・鉄鉱石3・魔晶石4。近くへ移動して「ここで遊ぶ」から参加します。

新BGM71曲と旧BGM72曲、合計143曲を収録。高校編・マジック編・ダンジョン・ミニゲーム曲も選択できます。Web用のOpusファイルは同じ曲の別形式なので曲数に重複計上していません。

- リーダーが楽曲・難易度・フル演奏／90秒モードを選びます。
- 各参加者が読み込み後に「準備する」を押すと音声を有効にできます。全員の準備後、リーダーが開始します。
- 1〜4人の同時演奏。4秒のカウントダウン後、同じ譜面でスコアを競います。
- D/F/J/K、矢印キー、タッチボタンで操作。同時押しと長押しに対応。長押しは終端で離します。
- PERFECT（±45ms）、GREAT（±95ms）、GOOD（±170ms）、MISS。スコアは最大100万点で、長押しは開始と終了をそれぞれ判定します。
- コンボ・最大コンボ・ゲージ・ランク・フルコンボ・自己ベストを表示。30コンボからFEVER演出が入ります。
- ノーツ速度とタイミング調整（±200ms）は端末に保存。自己ベストは曲・難易度・演奏モードごとに保存します。
- リーダーの一時停止／再開は全員に同期。一人が退出しても残りの参加者は演奏を継続します。画面を離れた参加者は退出し、音を停止します。

譜面は楽曲のスペクトル変化・拍・強い音を解析して作成しています。追加曲や音源変更後は `python scripts/generate-rpg-rhythm-catalog.py` で全曲の解析データを更新します（ffmpeg・numpyが必要）。配信時は選択曲だけを読み込み、全曲を一括ダウンロードしません。

検証: `node scripts/test-rpg-rhythm.mjs`（全143曲×3難易度×2モード、家具設置、権限・判定・4人対戦）、`node scripts/test-rpg-rhythm-browser.mjs`（実MP3の読み込み・演奏、入力・記録・停止・画面サイズ）。
