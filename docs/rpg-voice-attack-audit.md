# オリジナル音声の立ち上がり調査

基準コミット: `e7a87822`。表は破裂音調整時点の `feccc092` との比較。通常音・拗音・外来音を含む115音、3文脈（語頭・母音の後・促音の後）、4種の高さ／速さ／話し方、4声質の計5,520窓を比較した。生成文字数の上限を越えないよう18例ずつ合成し、全測定窓の存在と有限値を検証する。

破裂・摩擦の重なり、急な有声前置き、速い母音の立ち上がりが、タ・ダ・パ・バ行と「ち・つ・じ」に残っていた。マ・ナ行には強い鼻音の出だしもあった。

指標は閉鎖解除から基準話速換算12msのRMS合計を、母音後半のRMS合計で正規化したもの。鼻音は音節開始から同じ幅の窓を使う。音量とキャラクター表現を維持しながら短い打音を抑えるための波形指標であり、聞こえ方の評価には試聴も併用する。

| 発音群 | 調整前 | 調整後 | 母音比の低下 |
|---|---:|---:|---:|
| タ行（た・て・と等） | 0.675 | 0.267 | 60.5% |
| ダ行（だ・で・ど等） | 0.497 | 0.201 | 59.5% |
| パ行 | 0.685 | 0.271 | 60.4% |
| バ行 | 0.504 | 0.208 | 58.8% |
| ち | 0.506 | 0.186 | 63.2% |
| つ | 0.573 | 0.215 | 62.5% |
| じ | 0.390 | 0.142 | 63.7% |
| ちゃ・ちゅ・ちょ | 0.999 | 0.338 | 66.2% |
| じゃ・じゅ・じょ | 0.735 | 0.258 | 64.9% |
| マ行 | 2.560 | 1.248 | 51.3% |
| ナ行 | 2.544 | 1.235 | 51.5% |

破裂音は短い柔らかな包絡へ統一し、破擦音では破裂成分と摩擦成分の重複ピークを抑える。有声子音の前置き鼻音は閉鎖解除までに減衰させ、母音への移行は滑らかにする。マ・ナ行の鼻音にも短い立ち上がりと音量調整を適用する。既存のカ行調整、長音、声質、ケロケロした抑揚設定を保つ。
