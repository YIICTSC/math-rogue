# マジック編 エンドレス／真エンドレス汎用イベント90本

更新日: 2026-09-03  
対象: マジック編のエンドレス第1～50章、真エンドレス第51章以降  
用途: `?`マスで発生するマジック編専用の汎用イベント本文案

## 1. 方針

マジック編のエンドレスイベントは、通常モードの恋愛・好感度選択イベントとは別の汎用イベントプールとして追加する。主人公の選択、学園生活、9属性の魔法、変身、使い魔、黒帳機関、真エンドレスの世界境界を描き、周回しても同じ日常だけにならないようにする。

この90本は、既存の以下のイベントとは重複させない。

- ドドメデス連続イベント
- あずきとの出会い
- 高校編サポーターNPCイベント
- 通常モードのマジック編恋愛・選択イベント
- 名前付きエンドレスボスの固有ギミックイベント

5の倍数章では、5章ごとの名前付き／汎用ボスを優先する。ただし、特殊ボス用イベントだけを停止し、以下の90本の通常汎用イベントは通常通り抽選対象にする。

## 2. 発生帯と抽選ルール

| 章帯 | 解禁イベント | 内容の深さ |
|---|---|---|
| エンドレス第1～3章 | MGE-001～030 | 学園の日常、授業、寮、放課後 |
| エンドレス第4～9章 | MGE-001～060 | 属性訓練、使い魔、街、季節行事 |
| エンドレス第10～50章 | MGE-001～075 | 黒帳機関の痕跡、反復、深層学園 |
| 真エンドレス第51章以降 | MGE-001～090 | 章の外側、世界境界、記録者、明日を選ぶ物語 |

イベントマスの出現率は既存マップのEVENT重み15%を維持する。イベントマスに入った後、既存の小さな宝箱・クレーンゲームの割り込みを処理し、割り込みがなければ次の順で本文を決める。

```text
ドドメデス／あずき（5の倍数章では候補から除外）
  ↓
高校編サポーターNPC
  ↓
マジック編エンドレス汎用イベント MGE-001～090
```

通常モードのマジック編は従来どおり恋愛・選択イベントを使う。エンドレスと真エンドレスでは、この90本を含む共通生成器を使い、恋愛ルートの進行を自動で変更しない。

## 3. 主人公の差分ルール

イベント本文の「中心人物」は、そのイベントのイラストと会話の中心になる人物である。選択中の主人公が中心人物でない場合もイベント自体は発生し、中心人物は同級生・仲間として登場する。選択中の主人公には、属性または専門に応じた1行を差し込む。

| 主人公 | 日常差分 | 魔法差分 |
|---|---|---|
| 星宮あかり | まず動き、仲間に声をかける | 星光が周囲の魔力をつなぐ |
| 水城しずく | 状況を観察し、手順を整理する | 月鏡が隠れた式や分岐を映す |
| 花咲ひより | 相手の不安や痛みに気づく | 花の治癒が傷と疲れを包む |
| 火神つばさ | 迷う前に試してみる | 炎が道具や結界を動かす |
| 黒羽れい | 慎重に秘密と危険を見抜く | 影札が封印と記録を読み取る |

中心人物が複数いるイベントでは、選択中の主人公を「主人公」として必ず画面内に置く。恋愛対象との一対一の告白・デート描写は行わず、友情、チームワーク、日常の本音に留める。

## 4. 選択結果の記法

以下の効果記号は本文案用の仮キーであり、実装時に既存のイベント効果へ割り当てる。

| 記号 | 効果 |
|---|---|
| `HEAL+8` / `HEAL+12` | HPを指定値回復 |
| `GOLD+20` / `GOLD+30` | ゴールドを獲得 |
| `CARD+1` | 通常のカード報酬を1枚提示 |
| `UPGRADE+1` | デッキのカードを1枚強化 |
| `REMOVE_CURSE+1` | 呪いカードを1枚除去 |
| `DRAW+1` | 次の戦闘開始時に1枚追加ドロー |
| `MAX_HP+3` | 最大HPを3増加 |
| `MAGIC_TRACE+1` | マジック編深層記録カウンターを1進める |
| `TEAM+1` | チーム結束の記録を1進める |
| `LEARNING` | 1問の学習判定。成功時は前半効果、失敗時は後半効果 |
| `RISK:HP-5` | 選択時にHPを5失う |
| `RISK:CORRUPTION+1` | 次の戦闘開始時に腐蝕を1付与 |

`MAGIC_TRACE` と `TEAM` は、対応する進行値がまだないビルドでは結果ログだけを表示し、将来の深層解禁条件へ接続できるようにする。

## 11. 画像・表示仕様

### 11.1 イベントIDと画像キー

```text
eventId: MGE-001 ... MGE-090
imageKey: magic-endless-generic/MGE-001 ... magic-endless-generic/MGE-090
```

画像は後工程で作成する。1イベント1枚の16:9イベント画像を基本とし、同じ背景を使う場合も人物の配置と魔法エフェクトはイベントごとに差し替える。

```text
public/sprites/magic/events/endless/MGE-001.webp
...
public/sprites/magic/events/endless/MGE-090.webp
```

### 11.2 画像の共通要件

- 主人公は選択中の9人のいずれかを中心に置き、髪型・制服・属性色を固定する。
- 変身後を使うイベントは、MGE-031～045とMGE-076～090を中心にする。日常編は通常衣装を基本にする。
- 恋愛対象との一対一の密着構図、告白、デート専用演出は使わない。
- 魔法陣、属性エフェクト、カード、使い魔、星界の窓、黒帳機関の記号を、本文と対応する位置に置く。
- 画像内に文字・ロゴ・ウォーターマーク・UIを入れない。黒板や答案など本文上文字が必要な場合は、画像には読めない記号として配置し、実際の文章はUI側に表示する。

## 12. 実装時の接続方針

1. `src/data/magicEndlessGenericEvents.ts` に90本をデータ化する。
2. `generateEvent` で `visualTheme === 'magic' && isEndless` の場合にこのプールを選ぶ。
3. `currentAct` が1～3ならMGE-001～030、4～9ならMGE-001～060、10～50ならMGE-001～075、真エンドレスなら全90本を候補にする。
4. 5の倍数章でもMGEイベントは発生させる。ただしドドメデス／あずきの特殊ボス用イベントだけを候補から除外する。
5. MGEイベントの選択で、名前付きボス、特殊ボス、恋愛好感度、真エンドレス突入状態を直接変更しない。
6. 協力プレイではホストが選んだMGEイベントを全員へ共有し、選択肢の結果も既存のイベント同期ルートに載せる。
7. `MAGIC_TRACE` と `TEAM` の記録値が未実装の場合は、まず結果ログと実績用記録だけを保存し、カード・HP・ゴールドの即時効果を先に実装する。
