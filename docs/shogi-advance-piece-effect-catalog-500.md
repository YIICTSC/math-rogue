# ミニ将棋 Advance 駒500種 効果一覧

作成日: 2026-09-18
対象: ミニ将棋 Advance
目的: アドバンス駒500種のID・駒名・駒字・移動・特殊効果・制限を、実装前の正本候補として一覧化する。

## 1. 基本方針

- No.001〜050は現在実装済みの既存50種を維持する。
- No.051〜250は、通常将棋の延長として理解できる移動・跳越・スライド・捕獲・味方連携を中心にする。
- No.251以降は、通常の将棋には存在しない「盤面そのものへ作用する能力」を段階的に解禁する。
- 上位ほど、爆発、ワープ、レーザー、分身、時間停止、重力、吸引、反射、地形生成、連鎖、復活、未来予知など、見た瞬間に驚きがある挙動を増やす。
- 派手な能力ほど、回数制限・発動条件・射程・自傷・次手停止などの代償を必ず持たせる。
- 特殊能力で王を直接ワープ、交換、押出、引寄せ、爆破してはならない。王への勝利判定は通常の合法手・王手ルールを通す。
- 盤外、占有マス、王手放置など通常ルールに反する結果になる特殊効果は不発とする。
- 「追加手」は重複しない。1手番の着手数は最大2回とする。
- 5×5盤で解決可能な効果に限定する。

## 2. 強さ・演出の段階

| No. | 区分 | 方向性 |
| ---: | --- | --- |
| 001〜100 | BASIC | 将棋の移動拡張。特殊効果は小さく分かりやすい |
| 101〜200 | TECH | 跳越、長距離、方向制御、条件付き移動 |
| 201〜250 | TACTIC | 捕獲、味方連携、盤面操作の入門 |
| 251〜300 | EXTRA | 小規模ワープ、押引、残像、範囲効果を解禁 |
| 301〜350 | SUPER | レーザー、爆風、磁力、反射、地形効果を本格導入 |
| 351〜400 | CHAOS | 分身、時間、重力、連鎖、状態変化を導入 |
| 401〜450 | MYTHIC | 複数能力の組み合わせ、盤面ルール一時変更 |
| 451〜500 | LEGEND | 最も派手な超常能力。強い代償つきの最終級 |
