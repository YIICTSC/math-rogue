# 高校編 主人公ボイス・戦闘セリフ案

高校編の主人公立ち絵と固有戦術をもとにした、音声生成前の演技方針と発話一覧。

## 共通方針

- 1発話は戦闘中に聞き取りやすい短さを基本とする。
- 攻撃、召喚、ブロック、パワー、被ダメ、アイテム使用、フィニッシュ、戦闘不能を各5種類用意する。
- 被ダメは痛みの反応、戦闘不能は敗北が明確に伝わる内容に分ける。
- 召喚は使い魔や仲間を呼ぶ場面を想定し、特定の召喚対象名には固定しない。
- 音声生成時は、記載したセリフ以外の語句、説明、相づちを発話させない。

**声質・演技:** 17～18歳の男子。優しく落ち着いた中音。包容力は出すが老成させず、植物が育つ場面では素直な喜びを表す。
