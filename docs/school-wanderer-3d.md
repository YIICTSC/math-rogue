# 風来の小学生シリーズ：3D表示

シリーズ1・2の既存ターン制エンジンに、Three.jsの見下ろし3D表示を追加。
ゲーム画面右下の「3D / 2D」で切り替える。初期値は従来の2Dで、選んだ表示設定は端末内に保存する。3Dに切り替えた場合、次回の起動・再開時も3Dで表示する。
装備の拡大表示は既存の「Sts」→「装備」にある。

## 現在の品質版

主人公は `hero-quality.glb`、仲間・敵・アイテムは `cast-quality.glb` を使用する。詳しくは `school-wanderer-hero-quality.md` と `school-wanderer-cast-quality.md` を参照。以下の57モデルのキットは初期試作として保持している。

## 初期試作の素材

- 編集用Blenderファイル：`assets/school-wanderer/school-wanderer.blend`
- 実行用glTF：`public/models/school-wanderer/school-wanderer.glb`
- 再生成：`blender --background --python scripts/blender/build-school-wanderer.py`
- 57種類のオリジナルモデル。主人公は既存イラストの赤い鉢巻、白いシャツ、短パン、ランドセルを基に制作。
- 主人公、仲間3種、先生、商人、忍者、各種モンスター、文房具の武器、衣服・頭装備・ランドセル、消耗品、学校家具、橋、植生、露店など。
- アイテムは用途に対応するモデル群へ割り当て、種類ごとの色と強化値の発光を追加。同じ道具は床と装備時に同じモデルを使用。
- 武器、防具、飛び道具、腕輪の4枠を表示。ランドセル・頭装備は元のパーツを隠し、脱着に追従する。

## 表示と互換性

- 教室、体育館、理科室、音楽室、図書室、屋上、校長室の配色・家具に対応。
- 旅先の川・橋・竹林・雪景色、町の施設、仲間、地形、階段、道場にも対応。
- 未探索タイル・夜間や霧の視界制限・透視の腕輪・罠の可視性を既存ルールから受け取る。
- 未識別アイテムには種類固有の見た目を出さず、分類に対応した形を使う。
- 描画はゲーム状態を変更しない。移動、当たり判定、ターン、装備能力、セーブは従来のエンジンで処理。
- glTFは必要時に読み込み、素材を材質単位でまとめて描画負荷を抑える。切り替えと終了時にGPU資源を解放する。
- WebGL初期化・素材読み込み失敗、コンテキスト喪失時は2Dへ戻る。
- 初回起動時の空マップ保存を防止し、空マップの古い保存データは新規開始する。初期探索配列もマップサイズで確保する。
