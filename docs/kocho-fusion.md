# 校長対決のカード合成

2026-11-17：お蔵入りのフィールドバトルから、カード合成だけを通常の校長対決に採用。フィールドモードの入口・盤面は復活させない。

章終了後のショップ上部に「カード合成」を配置。20G、ショップ1回につき1回。既存のカード強化の回数とは別に管理する。素材を選んだ順に2〜3枚を合成し、最大4個の元アクションを保持する。合成カード同士も、合計4アクションまでなら合成できる。完成済みの超必殺技カードは素材にできない。

通常の合成カードは「ダッシュ＋定規スラッシュ」のように選択順に名前が連なり、元のアクション絵を小さく並べる。元の強化内容を保持し、CDは選択した素材カードの最大値。予約枠は1つ、実行では元のアクションを既存の戦闘処理で順に動かす。コンボの途中に敵のターンは挟まらない。合成後の攻撃力強化は、最後の攻撃アクションに加算し、CD短縮も完成カードへ適用する。

3アクションの並びが主人公の超必殺技レシピに一致すれば、名前とイラストが専用の超必殺技カードへ変化する。1枚の実行で元のアクションと決め技を連続発動し、既存のカットイン・専用ボイス・エフェクトを使用する。従来の3枚予約による超必殺技も維持する。3主人公36技、代替素材を含む1,422通りに対応。

合成内容・元の強化・使用済みフラグをセーブへ保存。旧セーブは未使用として読み込み、各元カードのアイコンと技情報を再構築する。確定処理は最新の状態で所持金・回数・素材を再検証し、連打しても二重購入しない。

デバッグメニューへの入場でセッションの一時解禁を有効にし、全主人公とエンドレスを利用できる。バージョン表示の連続タップからの入場も対象。通常のクリア履歴を書き換えない。主人公選択後のエンドレスは、選んだ主人公の初期デッキで開始する。
