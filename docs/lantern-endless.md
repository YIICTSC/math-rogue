# 継界戦記：無窮航路

18章をクリアしたデータのエンディング、またはクリア後フィールドから開始する。既存の編成・経験値・絆・武器強化・所持金を保持し、本編のクリア記録を上書きしない。キャンプから部隊を変更でき、本編のフィールドへ戻っても到達航路と加護は保持する。

## 航路の構成

毎回3つの航路から選ぶ。セーブされたシードと到達数・航路選択で戦場が決まり、敗北時は同じ戦場で再挑戦できる。10×12の地形・軍勢・気象・目的を生成する。最初の4航路では専用ストーリーを経て敵将ヴェスパー、離反狙撃手セーブル、夏衣装のあかり、夏衣装のレンが順に加入する。以後は4つの後日譚のテーマと天候・戦場に応じた会話へ移る。航路数にゲーム上の上限は設けない。

勝利条件：敵全滅／敵将撃破／星門制圧／全生存部隊撤退／旅人護送／180秒防衛／灯台3基確保／秘宝回収と本拠帰還。

- 城壁：2か所の門を破城攻撃、または薬草2個の爆薬で破壊。破壊前に南北を往来する経路はない。全戦場で門の破壊後の経路を保証する。
- 砲台・狙撃手：8秒おきに砲撃／後衛狙撃。城壁は射線を遮り、濃霧は射程を短縮する。隣接して奪取すると敵軍を攻撃する。
- 灯台：3か所を占領。敵部隊が進入すると再占領される。
- 地雷：進入すると部隊へダメージ。隣接して解除できる。
- 架橋：水場に橋を架けて新しい経路を作る。
- 泉：薬草を使って部隊HP・スタミナを回復する。
- 増援：60秒ごと、最大3回。撃破対象が増える前に作戦目標を達成する。
- 天候：晴天・雨（移動遅延）・濃霧（射程短縮）・熱波（スタミナ減少）・雷雨（森以外で落雷）。
- 継続成長：各勝利の後に全員の攻撃+2／防御+1／HP+6から加護を選び、エンドレス出撃時に累積適用する。本編の基礎能力は変更しない。

砲撃・地雷などの設備は進軍中に動作する。一時停止中に戦況と隣接コマンドを確認でき、設備の操作後は3秒の待機がある。敗北による仲間の永久離脱はない。出撃ごとに部隊HPを回復する。

## 素材

`public/sprites/lantern-war/endless/` に4人分の専用素材を配置する。

- `dialogue-end-*.png`：各4表情（平静・喜び・心配・決意）の横並び透過シート。主人公の既存立ち絵と同程度の頭部サイズ・太ももまでの写りに合わせて生成し、ストーリーで使用する。各セルを個別にクリップして隣の表情が混入しないようにする。
- `actions-end-*.webp`：待機・予備動作・攻撃・防御・被弾・必殺の6差分。3列×2行、2304×1792、1セル768×896。共通縮尺と足元の基準760pxを保ち、縦横35%以上の空きを確保する。編成・隊列・戦闘演出に使用する。
- `cutins.png`：4人分の専用必殺カットイン。
- `battle.png`：最初に作成した全身4人のデザイン参照。実際の戦闘描画は上記のアクションシートを使用する。

ImageGenで新規生成。`node scripts/build-lantern-action-reference.mjs` で既存アスターの実際の6アクションを1枚に合成し、この合成シートとキャラクターのデザインを参照して4人分を生成した。既定の出力先は `.codex-artifacts/lantern-endless/aster-actions-reference.png`（`LANTERN_ARTIFACT_DIR` で変更可）。今回の確認画像は `/workspace/artifacts/lantern-endless/` にも保持。その後 `node scripts/normalize-lantern-actions.mjs <end-id> <raw-sheet>` で間隔・縮尺・足位置を整え、`endlessBattleMetrics.json` に描画座標を記録する。新しい録音ボイスは追加していない。

## 表示方向

既存40人と追加4人の元画像を確認し、`artFacing.json` に会話4表情と戦闘6行動×4コマの元方向を記録する。`artFacing.ts` を会話、編成、戦闘予測、Canvas隊列で共用する。イベントでは左側が右、右側が左を向く。戦闘では味方が右、敵が左を向く。元画像が逆なら表示時に反転する。

キャラクターの所属だけで一律に方向を決めない。例えば園芸部長は会話が右向き、攻撃2コマ目（0始まり）は左向き。図書委員の攻撃1コマ目は右向き。暗殺者は待機・被弾が左向き、攻撃・必殺が右向きである。新規素材にも同じ表を適用する。正面の絵は構え・武器の進行方向を基準に扱う。

`node scripts/audit-lantern-facing.mjs` で既存素材の確認用一覧を `.codex-artifacts/lantern-facing/`（`LANTERN_FACING_DIR` で変更可）に再生成できる。新規素材の採用や差し替え時も向きを確認し、この表を更新する。

## 検証

- `pnpm run test:lantern-war:endless`：500戦場の再現性・到達可能性、8勝利条件、通常天候と雨天の移動差、砲撃・奪取、破城・爆薬、再挑戦、加入、加護、報酬一回限り、本編状態の保持、不正セーブの拒否。
- `pnpm run test:lantern-war:endless:browser`：エンディング→航路選択→会話→戦場の実操作、デスクトップ／モバイル画面、画像読み込み。ブラウザーは `CHROMIUM_PATH`、LinuxのシステムChromium、Playwright標準の順で解決する。
- `pnpm run test:lantern-war:facing`：44人の方向定義、左右配置への補正、混在コマの回帰、6アクションの選択・余白・透過・足位置。
- `pnpm run typecheck`、`pnpm run audit:english:gate`、`pnpm run build`。

ストーリー・戦場・報酬を自動生成するエンドレス追加の初期バージョン。数百時間にわたる難易度バランスやiOS実機での操作は別途継続検証が必要。
