# 学習ローグ・通常主人公35人のボクセル3Dモデル

既存の通常イラスト35人を参照し、Blender 4.3.2で新規造形した確認用モデルです。髪・服・装飾の特徴を整理し、約3頭身の共通体型で制作しました。魔法編は変身前を使用しています。既存の商用作品のアセットは使用していません。

参照元はリポジトリ `e1d0d926e7e09cc39982c529bd3c33cbd485e9b4`。小学生編9人は `src/constants.ts` の通常SVG、高校生編9人と魔法編17人は既存の通常WebPです。前面しか描かれていない部分の背面形状は、髪の長さ・服の色・裾の構造から独自に補完しています。

## 確認するファイル

- `index.html`：全35人。元画像と正面・背面・側面・斜め・後方俯瞰を並べた画像一覧。HTMLを直接開けます。
- `all-35.jpg`：全員の一覧。
- `elementary-overview.jpg` / `high-school-overview.jpg` / `magic-female-overview.jpg` / `magic-male-overview.jpg`：各編の一覧。
- `animation-demo.gif`：4人で待機・歩行・ジャンプ・攻撃を示した短い実モデルの動作見本。
- `<id>/<id>.blend`：各主人公の編集用データ。参照画像を内部に格納しています。
- `<id>/<id>.glb`：各主人公の軽量化済みモデル。4つのアニメーションを収録。
- `<id>/review.jpg`：参照画像と5方向の比較。
- `<id>/motions.jpg`：待機・歩行・ジャンプ・攻撃の実ポーズ。
- `viewer.html`：モデル回転・ズーム・動作の切り替え。HTTPサーバー経由で使用します。

画像はThree.jsで実際のGLBを描画したものです。背景と照明は確認用スタジオです。RPG本編への組み込みは行っていません。

## 造形・構造

- 髪型は短髪、跳ね髪、流した前髪、ボブ、波打つボブ、長髪、ポニーテール、片側ポニー、ツインテールを使い分け、段状の束で構成。
- 小学生編は元の単純な色分けを優先。高校生編は制服、小物、部活動の装備。魔法編は髪色、制服、マフラー、ロングコート、裏地を識別要素にしています。
- スカートのひだ、背中のフード・エプロンの紐、コートの裏地、髪飾りも造形。後ろ姿を確認する俯瞰画像を全員分用意しました。
- 各主人公12ボーン。編集用は顔・髪・服・小物・骨ごとの名前付きメッシュ。ゲーム用は結合してメッシュ1個・マテリアル1個。
- マテリアルは頂点色とPBR。ゲーム用の外部テクスチャは不要。辺に小さな面取りを入れ、角張った形を維持。
- BlenderはZ上・前面−Y。GLBはY上・前面＋Z。足元が原点、1単位＝1m。
- `Idle`（2.4秒）、`Walk`（1秒）、`Jump`（1.2秒）、`Attack`（0.8秒）。30fpsで制作。
- 長いスカートは歩幅・膝上げを抑え、脚が衣装を突き抜ける問題を修正。短いスカートにも歩幅調整を入れています。
- ボクセルの面を維持する剛体ウェイト。布・髪の物理演算、表情差分、武器種別の攻撃クリップは含みません。Attackは共通の右腕による攻撃動作です。

## Blenderでの編集

1. 各 `.blend` を開きます。初期画面は頂点色が見える斜めの表示です。
2. `CHARACTER` コレクション内で `hair_*`、`shirt`、`skirt`、`cape` などのパーツを選択して編集できます。
3. `HeroRig` を選び、NLA Editorで **再生するトラック1本だけ** のミュートを解除します。保存時は全トラックをミュートし、中立姿勢にしています。
4. Action Editorでも `Idle` / `Walk` / `Jump` / `Attack` を選択できます。各クリップは単独で使用します。
5. `REFERENCE` の画像とBlender内のREADMEを参照できます。`STUDIO` は確認用で、GLBには含めていません。

## 既存RPGとの関係

既存の `src/rpg/WorldScene3D.tsx` はThree.jsを直接使用し、`adventureAvatar()` の汎用アバターを表示しています。今回の制作はモデル資材と検証・再生成ツールのみです。既存のゲームコード、キャラクター選択、会話画像、戦闘、セーブデータへの追加変更はありません。

組み込み時の識別子例：小学生編 `WARRIOR` → `elementary-warrior`、高校生編 `WARRIOR` → `high-school-warrior`、魔法編 `AKARI` → `magic-akari`。魔法編は `magicProtagonistId` を使用して区別します。

Jumpには見本用のルートの上下移動（最大約0.3m）があります。物理側でジャンプ高さを制御する場合、組み込み時にはこのトラックを除くか、表示用子オブジェクトの動きとして扱ってください。

## 検証結果

- 35個の `.blend` を再度開き、12ボーン、4アクション、頂点色、正規化されたウェイト、アーマチュア参照、格納された参照画像を確認。35/35成功。
- glTF Transformで重複削除・ウェルド・アニメーション再標本化・量子化・未使用データ削除。Khronos glTF Validator：35/35、エラー0、警告0。
- 最終GLBは1体 197.5〜356.8 KiB。35体合計 9,825,788 bytes（約9.83 MB）。
- 1体 2,564〜4,996 三角形。各1メッシュ・1プリミティブ・1マテリアル。
- Chromium / Three.jsで35体すべてを読み込み、足元の原点、外寸、4クリップの存在と実際の頂点移動を確認。各動作4時点、計560時点を検査。ページ例外・コンソールエラー0。
- 5方向×35＝175枚、4動作×35＝140枚、計315枚の実モデルPNGを保存。比較シート・編ごとの一覧も作成。
- 小学生編・高校生編・魔法編の一覧と、背面・長い衣装の動作を目視確認。衣装側面の金色の面積、ソックス・長靴の配色、ロングスカートの歩行を修正して再検証。
- 実機のiPhone・Androidでのfpsや発熱は未測定です。モバイル向けの形状・描画回数・ファイルサイズの予算を抑えたモデル資材です。
- GitHubへのcommit・push・アップロード・デプロイは行っていません。

検証記録：`validation.json`、`blend-verification.json`、`browser-verification.json`。参照画像のSHA-256：`reference-hashes.json`。

## 再生成ツール

ソース：`scripts/blender/voxel-heroes/`（配布ZIPでは `source/`）。

- `designs.json`：35人の配色・髪型・衣装・小物・特徴。
- `prepare-references.py`：正規リポジトリの通常画像を抽出。WebPはGitのハッシュと照合。
- `build.py`：Blenderでのモデル、スキニング、4動作、GLB出力。
- `optimize.mjs`：GLBの軽量化と形式検証。
- `verify-blend.py`：Blenderファイルの再読み込み検証と初期表示設定。
- `viewer.html`：Three.jsの実モデルビューア。
- `verify-browser.mjs`：全モデル・動作・外寸の検証とスクリーンショット。
- `render-motion-demo.mjs` / `assemble-motion-demo.py`：短い動作見本の撮影・組み立て。
- `package-review.py`：静的な画像一覧と比較シート。

Blender 4.3.2、Python（Pillow / CairoSVG）、Node.js、ツール専用の `package.json` を使用。ゲーム本体の依存関係は変更していません。Three.jsは既存プロジェクトと同じ0.186.1を確認用ビューアに同梱し、LICENSEも同梱しています。

再生成例（リポジトリのルートで実行）：

```sh
python -m pip install -r scripts/blender/voxel-heroes/requirements.txt
npm install --prefix scripts/blender/voxel-heroes
python scripts/blender/voxel-heroes/prepare-references.py --out /path/to/output
blender -b -t 3 --python scripts/blender/voxel-heroes/build.py -- --out /path/to/output
node scripts/blender/voxel-heroes/optimize.mjs /path/to/output
blender -b --python scripts/blender/voxel-heroes/verify-blend.py -- /path/to/output
```

画像を見るだけなら `index.html` を開けば十分です。3Dビューアを使う場合は、配布フォルダで `python -m http.server 8768 --bind 127.0.0.1` を実行して `http://127.0.0.1:8768/viewer.html` を開けます。外部CDNへの接続は不要です。
