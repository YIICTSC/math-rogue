# 35人の主人公モデルをRPG・VR・レース・ゴルフに統合

通常イラストから制作した35人のBlenderモデルを、4ゲームの実際の描画に組み込みました。ゲーム用GLBと選択用サムネイルは `public/models/protagonists/`、編集用35ファイルは `assets/protagonists/`、再生成ツールは `scripts/blender/voxel-heroes/` に配置しています。

## 操作

- RPG：既存の主人公選択で小学生編・高校編・マジック編の主人公を選ぶと、3D表示に反映。魔法編の男女それぞれのIDをプロフィールへ引き継ぎます。
- VR、レース、ゴルフ：開始前のキャラクタークリエイトに「主人公選択」を追加。各編の35人、または従来のキャラクタークリエイトを選べます。レースではカートの形を独立して選べます。
- ミニゲームでは既存のアバター設定に `protagonist` を保存し、オンラインの参加者にも共有。旧設定も引き続き有効です。

## 表示と動作

`src/three/protagonistCatalog.ts` でIDとRPGの対応を管理し、`protagonistModel.ts` がGLBの読み込み、インスタンスごとのスキン複製、アニメーション、破棄を担当します。

- RPGは待機・歩行・ジャンプ・採掘／設置時の攻撃動作に対応。物理側と重複するジャンプの高さトラックは除き、姿勢の動きを使用。近くのオンライン参加者も3D表示します。
- 写真・カスタム主人公、敵主人公、バカンス版には通常衣装モデルを強制しません。既存表示を維持します。
- VRは選択モデルを通常プレイ・プレビュー・オンライン・爆弾モードのキャラクター生成で共有。
- レースは従来のカートに着座。骨の元の角度を維持して関節を曲げ、車体と一緒に移動・ジャンプします。
- ゴルフは両手を構え、手の実際の位置へクラブのグリップを追従させます。既存のクラブ、スイング、ボールの物理は維持します。
- 読み込み中や失敗時には既存モデルを表示。モデルの切り替え中に旧読み込みが完了しても、破棄済みシーンへ追加しません。キャッシュは8モデルまでとし、個々の描画リソースを分離しています。

前回確認したRPGの地形・山・水流・建築・照明・カメラ改善も、この統合が使用する `WorldScene3D` と依存モジュールとして含みます。

## 検証

- `test-protagonist-profiles.mjs`：35人のRPG対応、選択IDの検証、保存・復元、魔法編ID、旧設定・カスタム・バカンスの互換性。
- `test-protagonist-games-browser.mjs`：実際のRPG／VR／Kart／Golfの描画で、35人の選択肢、編をまたぐ切り替え、モデル読込完了、旧アバターへの復帰を確認。共通ローダーで35体すべての生成・破棄を検証。
- 各ゲームのスクリーンショットを保存し、レースの着座、ゴルフのグリップ位置、VRプレビュー、RPGの三人称表示を確認。
- RPGのカメラ・地形・水流、カスタム主人公の通信、ゴルフの40人シミュレーション、VRの40人・爆弾・ソロCPU、カートの40人・通信・8コースのシミュレーションを検証。
- 既存テストの古い「VRは武器を持たず開始する」という期待値を、現在の基本武器付き開始に合わせました。カートのSSRテストは、同一の配置を持つBlender部品も区別できるよう選択部品の識別方法を修正し、SSRではブラウザ用GLBの読み込みを開始しないようにしました。

実機のiPhone・Androidでのフレームレートは未測定です。GitHub mainへのアップロードとRenderのデプロイは独立しており、今回はRenderへデプロイしません。
