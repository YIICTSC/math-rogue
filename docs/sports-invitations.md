# スポーツ共通の招待参加

スポーツタイトルに「招待に参加する」を追加。共通画面で招待された種目、参加名、6桁コードを指定すると、テニス・ゴルフ・ドッジボールの該当ロビーへ接続する。参加名の再入力は不要。コードは種目ごとに独立しているため、参加する種目を明示して取り違えを防ぐ。

既存の `golfRoom` / `tennisRoom` / `dodgeballRoom` 招待URLは、従来どおり参加名の入力から始める。ホスト方式／専用サーバー方式、全角数字の正規化、既存のH-/S-付きコードにも対応。接続失敗後もタイトルから共通画面を開き直せば入力を修正できる。名前は画面内の状態として保持し、新しい保存先を追加しない。

`useSportsInvitation` は送信済みの参加情報だけを自動接続する。StrictModeの再実行時に接続が二重にならないよう、開始を1タスク遅らせてキャンセル可能にし、同一の参加情報は一度だけ処理する。既存の通信プロトコルを使用し、サーバーの変更やRenderデプロイは不要。

縦画面にはImageGenで新規生成した3種目の専用イラストを `<picture>` で読み込む。横画面は既存のイラストを使用する。「ドッジボール」の見出しは1行を維持し、アイコン・種目番号と重ならない行に配置。生成元・参照・ハッシュは `assets/sports/portrait-art.json` に記録する。

検証: `pnpm run test:sports-invitations`。320/390px縦、568/844px横、1280px、英語・ひらがな、全3種目×2通信方式の実接続、参加名・全角コード、StrictModeの重複防止、失敗後の再入力、既存URLを確認。画像・レイアウトだけの確認は `--layouts-only`。写真は `tmp/sports-invitations/` に出力する。
