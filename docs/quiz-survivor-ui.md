## みんなでクイズ

- 全体を `100dvh` の画面に固定。端末のセーフエリアを確保し、主要操作を画面外へ押し出さない。
- 入り口: タイトルと司会／参加フォーム。10ルールの一覧は「10種類のルールを見る」で開く。
- ロビー: 大きな6桁コード・QR、参加者一覧、下端の開始／司会設定。40人などの長い一覧は枠内でスクロール。
- 出題: 問題・残り時間を上側、参加者の回答操作を下側。横画面は左右に分割。4択は記号・A〜D・色・回答文を併記。
- 公開: 問題と全員の回答。手書きの判定、投票もこの一覧から実行。
- 順位／最終結果: ランキングと回答一覧を切り替える。最終結果では上位3人を表彰し、全員の順位も枠内で確認できる。同点は同順位。
- 司会の出題設定・参加者調整・正解表示等は別パネル。ネイティブ `dialog` によりキーボードフォーカスを囲い、Escape／閉じるで元の操作へ戻す。
- 長文・図・描画・40人の回答は必要な領域だけをスクロール。内容を省略して非表示にするだけの対応はしない。
- 人狼の秘密情報やお絵かきの秘密のお題など、公開範囲と通信・採点ルールは維持。

## 校庭サバイバー

- タイトル: 既存の縦横専用絵を活用し、出撃準備を主操作として強調。
- 準備: 主人公一覧だけをスクロールし、選択中の主人公・戦場・出撃は固定配置。未解放主人公を維持。
- 戦闘: 上端に全幅の経験値レール、HP・経過時間・ウェーブ／撃破数・装備枠をまとめ、中央の戦場を広く残す。6枠は獲得済み武器を表示し、空き枠は控えめに表示。
- 強化: アイコン・名前・星・効果・相性・選ぶボタンを3枚のカードに整理。武器／支援／回復／進化を区別し、進化は金色で強調。
- 決着: 生存時間・スコア・撃破数に加え、到達レベル・ウェーブを表示。勝利と敗北は背景と見出しを分け、再挑戦へ誘導。
- 回避とバーストは親指で押しやすい右下を維持。チャージ満了時に視覚的に強調。学習問題を挟む既存のゲーム進行は維持。
- 動きを減らす端末設定では登場・発光アニメーションを停止。

## 検証

`test-responsive-browser.mjs` は実際の2参加者の通信と追加38クライアント（計40人）を用いて、1280×720・390×844・844×390・320×568の入り口／ロビー／出題／回答／公開／順位／最終結果と設定パネルを撮影し、主要要素の表示範囲と全体のはみ出しを検査する。

校庭サバイバーは既存のブラウザ操作試験で戦場・強化・ボス・勝敗・タッチ回避／バーストを確認し、縦横の強化カードとリザルトも追加撮影する。

追加の `pnpm run test:survivor:ui` は同じ4サイズでタイトル画像の実デコード、出撃準備、HP・経験値・装備のHUD、強化カード、敗戦リザルトを撮影・検査する。
