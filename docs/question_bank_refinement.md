# 問題ブラッシュアップ仕様・進捗

最終更新: 2026-06-15

## 1. 目的

学習ローグの問題を、単語と説明文を機械的に入れ替えた問題群から、学習者が考えて選べる実用的な4択問題へ段階的に差し替える。

対象は高校以上・大人向けに限定しない。今後は小学1年生から中学3年生までの既存問題も、学年、教科、単元ごとに監査し、同じ品質基準で改善する。

## 2. 基本仕様

### 2.1 作問方針

- テンプレートによる一括生成を行わず、1問ずつ内容を設計する。
- 既存の問題数を減らさない。必要な場合は問題数を増やす。
- 一つの単元内で、知識確認、具体例、比較、資料読解、判断、応用を混ぜる。
- 問題文だけで正答が分からないようにする。
- 問題文に正答をそのまま記載しない。
- 「クイズマスター」「先生の一問」など、内容に不要な定型句を入れない。
- 同じ問いを言い換えただけの水増しを行わない。
- 解説は正答の根拠や、誤りやすい点が分かる文章にする。
- 学説、制度、科学的事実などは、単純化し過ぎて誤解を生まない表現にする。
- 時事、法律、医療、金融など更新性や正確性が重要な分野は、作業時点の一次資料で確認する。

### 2.2 4択の仕様

- 配列は原則として `問題文 / 正答 / 誤答1 / 誤答2 / 誤答3 / 解説` の6要素とする。
- 4つの選択肢内に同一文言を入れない。
- 正答だけが極端に長い、具体的、専門的になる形を避ける。
- 明らかな冗談や、分野違いですぐ除外できる誤答に偏らせない。
- 誤答は正答と同じ分類・粒度から選ぶ。
- 祭りの問題なら他地域の祭り、鉄道なら他の鉄道、市町村なら他の市町村を誤答候補にする。
- 都道府県問題では、正答が市町村名の場合、同じ都道府県内の他市町村を誤答に使ってよい。
- 計算問題では、典型的な計算ミスから生じる値を誤答に利用する。
- 国語・英語では、文脈上もっともらしいが条件を満たさない選択肢を用意する。

### 2.3 難易度

- 単なる用語暗記だけで単元を埋めない。
- 基礎問題、標準問題、考える問題を混在させる。
- 難しさは、知識の細かさだけでなく、比較、理由、場面判断でも作る。
- 小中学生向けでは、未習語句や学年を超えた計算方法を不用意に使わない。
- 高校以上・大人向けでは、生活上の判断や現実の事例へ接続する。

## 3. 禁止する典型パターン

次の4問セットを用語ごとに繰り返す形式は、原則として差し替え対象とする。

1. 「○○の説明として正しいものは？」
2. 「説明文に当てはまる語は？」
3. 「○○と特に関係が深いものは？」
4. 「○○で注意すべき点は？」

ほかに、次の状態も差し替え対象とする。

- 解説が全問ほぼ同じ。
- 正答と問題文が同じ語を含み、読めば答えが分かる。
- 誤答が別教科・別分野で簡単に除外できる。
- 同じ事実を主語だけ変えて繰り返している。
- 単元名の説明だけで、実際の知識や技能を問うていない。
- 正答が曖昧で、複数の選択肢が成立する。
- 「必ず」「完全に」「一切」など、不自然な断定が誤答の目印になっている。

## 4. 単元ごとの作業工程

1. 対象単元の既存問題数と保存ファイルを確認する。
2. 定型句、重複問題、重複選択肢、正答露出を監査する。
3. 単元で扱う知識・技能を小領域に分ける。
4. 既存数以上の問題を1問ずつ作成する。
5. 誤答を正答と同じ分類・粒度へ調整する。
6. 解説が正答の根拠を説明しているか確認する。
7. 問題数、配列要素数、設問重複、選択肢重複を機械検査する。
8. TypeScript構文を検査する。
9. 必要な場合のみゲーム画面で出題を確認する。
10. 本文書の進捗と次回対象を更新する。

## 5. 完了判定

「完了」は、次の条件をすべて満たした状態とする。

- 対象単元のテンプレート問題を差し替えている。
- 既存の問題数を維持または増加している。
- 設問の完全重複がない。
- 各問題の4択内に重複がない。
- 全行が所定の配列形式になっている。
- TypeScript構文エラーがない。
- 内容上の明確な誤りや、複数正答がないことを確認している。

機械検査済みでも、事実関係の精査が終わっていない単元は「要内容監査」とする。

## 7. 小中学生問題のブラッシュアップ計画

### 7.1 対象

- 小学1年生から6年生: 国語、漢字、算数、生活、理科、社会、英語
- 中学1年生から3年生: 国語、漢字、数学、理科、社会、英語
- ICT・情報、地図・日本、漢検など、学年横断カテゴリ

主なファイル群:

- `kokugo_g1.ts` から `kokugo_g9.ts`
- `kanji_g1.ts` から `kanji_g9.ts`
- `math_g1.ts` から `math_g9.ts`
- `english_g3.ts` から `english_g9.ts`
- `science_g3.ts` から `science_g9.ts`
- `social_g3.ts` から `social_g9.ts`
- `life_g1.ts`, `life_g2.ts`
- `science_units.ts`, `social_units.ts`
- ICT・情報関連ファイル

### 7.2 小中学生向け追加基準

- 学習指導要領と、一般的な教科書の年間単元配列に合わせる。
- 同じ学年でも年度前半と後半で未習内容が混ざらないようにする。
- 低学年では問題文を短くし、漢字には学年相応の表記を使う。
- 読解問題は、本文を読まず一般常識だけで答えられる選択肢にしない。
- 算数・数学は答えだけでなく、式、単位、図形の性質、考え方を分散して問う。
- 理科・社会は用語暗記だけでなく、観察、資料、地図、グラフ、日常場面を扱う。
- 英語は日本語訳だけに偏らず、語順、場面、対話、読み取りを含める。
- 漢字は読み書きだけでなく、意味、熟語、同音異義語、文中での使い分けを含める。
- 誤答には、その学年で起こりやすい勘違いや計算ミスを反映する。
- 正答率が極端に高い問題と低い問題は、問題文と選択肢を再点検する。

### 7.3 推奨する実施順

最初から全学年を一括処理せず、1教科・1学年・1単元ずつ進める。

1. 小学1・2年生の国語、算数、生活
2. 小学3・4年生の国語、算数、理科、社会
3. 小学5・6年生の国語、算数、理科、社会、英語
4. 中学1年生の主要5教科
5. 中学2年生の主要5教科
6. 中学3年生の主要5教科
7. 漢検、ICT・情報、地図・日本などの横断カテゴリ

各学年の開始時に、次を先に集計する。

- 単元数
- 単元ごとの問題数
- 完全重複数
- 選択肢重複数
- 定型句の出現数
- 正答が問題文に含まれる件数
- 学年外漢字や未習事項の候補

## 8. 進捗更新ルール

- 1単元の差し替え完了ごとに、本ファイルの進捗表を更新する。
- 問題数を変更した場合は、変更前と変更後を記録する。
- 未コミットの場合は、その旨を記載する。
- Push後は、可能であれば対象コミットを記載する。
- 内容監査を後回しにした場合は「要内容監査」を残す。
- 次回対象を必ず一つ明記し、「次」の指示でその単元から再開できるようにする。
