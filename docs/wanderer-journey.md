# 風来の学生：街道と旅の開始

両作品は専用タイトルで開始し、「続きから」で従来形式のセーブも読み込む。タイトル表示中は冒険の入力と自動保存を止める。ニューゲームは35人の主人公から選択する。表示は2Dを初期値とし、3Dモデルのプレビューとダンジョン表示を切り替えられる。

## 街道の町

はじまりの町と中継町は、横方向に移動する共通の街道画面。左右キー・タッチの左右ボタンで歩き、上キー・Enter・「入る」で目の前の施設に入る。建物やNPCをタップすると、その入口まで歩いてから入る。施設を一括選択するモーダルは使用しない。

町の施設は宿、道場、購買部、工作工房、郵便・貯金、倉庫、広場。案内人・学生・先生と攻略や解禁状況を話せる。街道の右端に迷宮の門がある。はじまりの宿は無料、中継町の宿は80。購買部は直接購入・売却し、商品を床に生成しない。町での移動や買い物ではターン・空腹を進めない。中継町の出口では既存の算数の試練を使って次の階へ進む。

解禁順は「放課後の大冒険 → 放課後の一手 → いたずら工作室 → なぞなぞ校舎 → 作戦ノート → 体操服の挑戦 → 手ぶらの99階」。踏破後の会話と町の門で次のルートを案内する。過去に踏破済みのルートは維持する。救助依頼は独立した臨時ルート。

## 仲間と物語

新しい旅の開始時には同行者を選択しない。ストーリーダンジョン3階で主人公と同じ編の別の主人公に出会い、3段階の会話を終えた時に加入する。加入済みの同行者がいると再生成しない。加入した人物は2D、3D、手帳で同一の主人公素材を使い、町を経由した次の旅にも引き継ぐ。

物語の6段階（出発、約束、記録、道しるべ、最終試練、帰還）にはImageGenで生成した場面背景を使用する。各場面に選択主人公の既存8方向イラストを重ね、35人×6段階の主人公別カットとして表示する。章の物語を維持し、主人公名と視点を反映する。エンディング後は道具を倉庫に送り、はじまりの町へ戻る。会話中の段階もセーブし、「続きから」で同じ台詞から再開する。物語モーダルには冒険の通常ログを表示しない。

冒険手帳は記録／道具のタブと6件単位のページ送りを使用し、スマホ縦・横とも画面内に収める。町では手帳から装備を交換できる。従来のダンジョンの道具メニューと戦闘・算数処理は継続して利用する。

## 画像

`public/sprites/wandering-student/journey/` に最適化したWebPを配置。

- `title.webp`: 3つの編の主人公が街道を旅する専用タイトル画。
- `story-scenes.webp`: 3列×2行の物語背景。主人公素材はゲームの描画で合成。
- `town-buildings.webp`: 3列×2行の施設の正面絵。町の建物に使用。
- `items-gear.webp`: 6列×6行。各編の固有装備36種。
- `items-common-0.webp` ～ `items-common-4.webp`: 各5列×5行。通常装備・道具125種。

アイテムの割り当ては `itemArt.tsx` に集約。購買部、倉庫、手帳、2Dの床アイテムで同じ絵を使用する。既に個別画像のある学用品・追加道具は引き続き使用する。生成元PNGは制作環境の `generated_images` に保持し、配信はWebPのみ。WebとAndroidのアセット一覧にも登録する。

## 検証

- `node scripts/test-wanderer-journey.mjs`: 順序解禁、救助回数、全35人の同編の仲間、210段階、161種のアイテム画像割り当て。
- `node scripts/test-wanderer-browser.mjs`: デバッグ用Vite起動後に実行。初回タイトル、ニューゲーム、3Dプレビュー、町の移動・会話・道場、スマホ縦横の手帳、セーブ・再開、仲間加入前後と会話途中の再開、中継町の宿と出口の算数、エンディング、シリーズ2の開始。
- ブラウザーテストの途中階・エンディングは通常のセーブ形式を使った固定データで確認する。全ダンジョンの実際の通し踏破は自動実行しない。
- `pnpm run audit:english:gate`、`pnpm run build`、`pnpm run server:build` を実行してからアップロードする。
