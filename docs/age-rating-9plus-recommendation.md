# 学習ローグ 日本9+向け年齢評価方針

更新日: 2026-07-22

## 対象

この文書は、年齢評価に関係する現在仕様だけを記載する。
課金、製品版デバッグ停止、バージョン番号、画面余白等の製品化対応は含めない。

## 現在方針

- 日本のApp Store表示で9+を目標とする。
- 一般的なカードバトル用語、ポーカー役、架空の技・武器・魔法表現は使用する。
- 賭け、掛け金、勝敗による資産没収、倍率払い戻し、ルーレット、777、全掛けは使用しない。
- 購入後に内容が決まるランダムパックを使用するため、App Store Connectでは
  「ルートボックス: はい」と回答する。
- ランダムパックによるオーストラリア等の地域別レーティング上昇は許容する。
- 「兵十の火縄銃」は国語作品の題材を活かした固有カードとして、原題・原イラストを維持する。

## App Store Connect回答時の注意

- 疑似ギャンブルは、実装上の賭け行為がないことを再確認して回答する。
- ルートボックスは「はい」とする。
- ファンタジー暴力、武器表現の頻度は提出する実ビルドを通しで確認し、実際の表示頻度どおりに回答する。
- 日本9+になることは、回答保存後の地域別結果画面で最終確認する。
