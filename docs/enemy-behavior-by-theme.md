# 敵行動仕様: 編別リスト

この資料は、各編の敵名から決まる戦闘行動の管理表です。実装上は `src/App.tsx` の `determineEnemyType` と `getNamedEnemyIntent` が参照元になります。

数値は Act や最大 HP によって変動します。この MD では、敵ごとの行動傾向を管理します。

## 行動カテゴリ

| カテゴリ | 主な行動 |
|---|---|
| 試験・評価型 | びくびく付与、攻防、へろへろ付き攻撃。評価圧で崩す。 |
| 情報ノイズ型 | 混乱、貫通攻撃、攻防。情報攪乱で手札判断を乱す。 |
| 統制型 | 自己強化、びくびく付き攻撃、防御。規律で場を固める。 |
| 星光防衛型 | 防御、攻防、貫通攻撃。光の守りから鋭く刺す。 |
| 植物・毒型 | 毒付き攻撃、攻防、へろへろ。継続ダメージで削る。 |
| 火力突破型 | 強攻撃、びくびく付き攻撃、貫通攻撃。正面火力で押す。 |
| 風・攪乱型 | 攻撃、混乱、攻防。素早い揺さぶりが中心。 |
| 幻惑型 | へろへろ、混乱付き攻撃、攻防。視覚/精神を崩す。 |
| 時間妨害型 | 攻防、混乱、攻撃。テンポを狂わせる。 |
| 知識妨害型 | 混乱、防御、へろへろ付き攻撃。知識で行動を縛る。 |
| 傘ガード型 | 攻防、防御、攻撃。守りを挟みながら粘る。 |
| 騒音型 | 混乱、へろへろ付き攻撃、強攻撃。音で集中を崩す。 |
| 突進型 | 強攻撃、攻防、貫通攻撃。直線的に押し込む。 |
| 霊障型 | へろへろ、びくびく付き攻撃、攻防。弱体化が得意。 |
| かく乱飛行型 | 混乱付き攻撃、攻撃、攻防。持ち物を狙うように乱す。 |
| 毒針型 | 毒付き攻撃、連続攻撃寄り。毒で削る。 |
| 刺突罠型 | 貫通攻撃、びくびく付き攻撃、攻防。防御を抜く。 |
| しぶとい群体型 | 攻防中心。小さく粘って削る。 |
| 教師型 | 自己強化、攻防、びくびく付き攻撃。指導で圧をかける。 |
| 文具妨害型 | 混乱、攻防、攻撃。記録や文字で乱す。 |
| 耐久型 | 防御/攻防寄り。長期戦に持ち込む。 |
| 攻撃型 | 攻撃中心。短い周期で高打点を狙う。 |
| トリック型 | 混乱または毒、攻防、攻撃。状態異常で崩す。 |
| 群体型 | 毒/へろへろ/攻撃。数や継続効果で削る。 |
| 精鋭型 | 自己強化、貫通攻撃、へろへろ付き攻撃、防御。強敵向け。 |
| 汎用型 | 攻撃、攻防、自己強化のランダム寄り。個性語彙がない敵の標準行動。 |

## 運用メモ

- ボス敵は名前に関係なく `GUARDIAN` として生成されます。ただし表示名と画像は各編のカタログに従います。
- 真ボスは `THE_HEART` 固有行動です。小学生編は校長先生、高校編は校長、マジック編は大魔女校長/星災の女王の表示体系です。
- 同じ敵名が複数キーワードに該当する場合は、`getNamedEnemyIntent` の上から順に優先されます。たとえば `火花コウモリ` は `花` が `火` より先に判定されるため、現行実装では植物・毒型です。
- 捕獲カードのイラストは敵名、`enemyType`、`phase`、`visualTheme` を保存して再解決します。この MD のカテゴリ変更だけでは捕獲イラストは変わりません。
