# ことば日和

ミニゲーム一覧から初期解放で遊べる、会話と小さな暮らしのゲーム。むぎ（カピバラ）、もも（うさぎ）、そら（カワウソ）、こはく（きつね）、ぴこ（ペンギン）は、それぞれ語彙・親密度・性格・思い出・町の友好度を持つ。実写風8部屋と町3箇所をImageGenで作成し、柔らかなリアルタイム3Dの動物を重ねる。

言葉を新しく教えるとエネルギー1を消費。初期値・最大値6、学習問題の正解1問につき2回復。重複語・失敗した入力は消費せず、キャラ変更でも回復しない。会話、お世話、外出は無料。漢字や英字の単語には、独自音声のためのかな読みも教える。600語まで各キャラクターに保存できる。

会話は12テーマ144話題と、各テーマに5キャラ専用の返答を持つ。部屋8種、時間帯4種、親密度、教えた語彙・分類、返答の選択を組み合わせる。話題の巡回順は保存した会話回数から決まり、144話題を一巡する前に同じ主話題へ戻らない。町では3住人の生活に根ざした9つの掛け合いに、144話題の観察や各キャラの感想・覚えた言葉を重ねる。組合せ数は固定台詞数とは区別し、無制限のAI生成会話とは扱わない。

日本語はRPGと共通の `conversationSpeech` 推奨モードで、言語に合う明瞭な端末音声を優先し、未対応端末では改良した `residentVoiceSynth` のかな合成で補う。5動物・3住人に別の高さ・声質・速さ・話し方を設定。生成済み読み辞書とプレイヤーが教えた読みを合成し、ミュート、音量、画面非表示、会話の切替・中断に追従する。英語も言語に合う端末音声を使用する。読み辞書の再生成は `node scripts/generate-kotoba-readings.mjs`。

保存キー: `learning-rogue:kotoba-life:v1`。端末の保存領域が使えない場合は警告し、セッション内のプレイは継続する。WebGL非対応時にはキャラクターのSVG表示へ切り替える。

検証: `node scripts/test-kotoba-life.mjs`、`node scripts/test-kotoba-life-browser.mjs`、既存 `node scripts/test-rpg-resident-voice.mjs`。ブラウザテスト画像は `tmp/kotoba-life-browser/` に保存する。生成画像の元と来歴は `assets/kotoba-life/`。
