# ダンジョンズ1・既存武器の系統一覧

既存52種すべてをIDで分類。旧セーブの名前・強化値・校章を維持し、読み込み時に同じ系統へ解決する。種類の判定に文字列の部分一致は使わない。新規10種は装備自体に weaponKind を持ち、その項目がない保存データも武器IDから補完する。

金持ちの時計は手首を使う体術として素手系統。分度器・三角定規は回転する刃として輪刃、大型の通知表・卒業ばさみ・黒板・ワックス刃は大剣、実験トングは長い棒状の打撃具として杖に分類。投げ道具（RANGED）、傘の魔法道具（STAFF）、防具・アクセサリは武器装備の熟練度と分離する。
