# エンドレス／真エンドレス 敵強化・イベント発生マトリクス（現状）

更新日: 2026-09-03  
対象: 小学生編・高校編・マジック編  
基準: 現行実装（`src/App.tsx`、`src/services/mapGenerator.ts`、`src/services/eventService.ts`、`src/data/endlessMode.ts`、`src/data/visualThemes.ts`）と、特殊ボスの重複を解消する修正仕様

この版では、5の倍数章の名前付きボスと、ドドメデス／あずきの特殊ボスを同じ章に出現させない。5の倍数章では特殊ボス用イベントを停止し、特殊ボスは5の倍数以外の章末だけで発生可能とする。

## 1. 現在の全体構造

| モード | 章の範囲 | 1章の長さ | ボス発生 | 備考 |
|---|---:|---:|---|---|
| エンドレス | 第1～50章 | 15F | 5章ごと（第5・10・…・50章） | 第1～4章など、ボス章でない章の最終Fは通常戦闘 |
| 真エンドレス | 第51章以降 | 15F | 5章ごと（第55・60・…章） | 第50章クリア後に選択して突入。第51章から章カウンターを継続 |

1章15Fのマップを毎章生成するため、累計到達Fの目安は次の式になる。

```text
累計F = 15 × 章番号
```

したがって、第50章は累計750F相当、第51章は765F相当になる。敵の強化倍率はマップ内のFでリセットされず、章番号を使って継続する。

`endlessTrueMode` は真エンドレスへのルート・画面制御に使われるフラグで、敵強化式そのものはエンドレス時と同じである。

## 2. 敵の強化式

### 2.1 章倍率

戦闘開始時の章倍率 `m` は以下の通り。

```text
通常モード: m = Act番号
エンドレス／真エンドレス: m = max(5, 章番号)
```

このため、現状は第1～5章が `m=5` の強化済み開始帯になり、第6章以降は章番号に比例して上昇する。

| 章 | 累計F | 敵章倍率 m | 強化の状態 |
|---:|---:|---:|---|
| 第1～4章 | 15～60F | 5 | エンドレス開始時点で通常Act1より高い。ボスなし |
| 第5章 | 75F | 5 | 名前付き中ボス |
| 第6～9章 | 90～135F | 6～9 | 章ごとに線形上昇。ボスなし |
| 第10章 | 150F | 10 | 名前付き大ボス |
| 第20章 | 300F | 20 | 名前付き大ボス |
| 第30章 | 450F | 30 | 名前付き大ボス |
| 第40章 | 600F | 40 | 名前付き大ボス |
| 第50章 | 750F | 50 | 名前付き最終大ボス |
| 第51～54章 | 765～810F | 51～54 | 真エンドレス。ボスなし |
| 第55章 | 825F | 55 | 真エンドレス最初の汎用ボス |

### 2.2 通常敵・エリート・汎用ボス

マップ内の内部座標を `y`（開始Fを0、最終Fを14）とすると、基礎HPは次の式で決まる。

```text
floorDifficulty = y × (1 + 0.5 × m)

baseHp = (ボスなら150、通常敵なら20) × m
       + 2 × floorDifficulty
       + (エリートなら40、その他は0)

最終HP = baseHp × 協力プレイ補正 × 難易度の敵HP倍率
```

複数体出現時は、最終HPの約8%を基準に個体差が付く。難易度1・ソロ補正なしの場合、通常敵の基礎HPは次の範囲になる。

| 章 | m | y=1の通常敵 | y=14の通常敵 | y=14のエリート（目安） |
|---:|---:|---:|---:|---:|
| 第1～5章 | 5 | 107 | 198 | 238 |
| 第10章 | 10 | 212 | 368 | 408 |
| 第20章 | 20 | 422 | 708 | 748 |
| 第30章 | 30 | 632 | 1,048 | 1,088 |
| 第40章 | 40 | 842 | 1,388 | 1,428 |
| 第50章 | 50 | 1,052 | 1,728 | 1,768 |
| 真エンドレス第51章 | 51 | 1,073 | 1,762 | 1,802 |

上表は「敵1体・難易度1・協力補正なし」の概算であり、ゲーム中は丸め処理、複数体の個体差、難易度補正が加わる。

汎用ボスについては、算出した基礎HPよりデッキから推定した最大攻撃ダメージ `maxAtkDmg` が大きい場合、次のラバーバンド補正が入る。

```text
汎用ボス baseHp = ceil(maxAtkDmg × (2 + m))
```

この補正は通常敵ではなく、名前付きエンドレスボスが存在しないボス戦のフォールバック処理である。

### 2.3 名前付きエンドレスボス

第5章から第50章までの名前付きボスは、通常敵とは別のHP式を使う。

```text
名前付きボスHP = ceil((120 + 9 × 章番号) × tier倍率 × 難易度・協力補正)

BOSS       tier倍率 = 1.65
MAJOR_BOSS tier倍率 = 2.35
```

難易度1・ソロ補正なしでの基礎HPは次の通り。編によるHP差はなく、章とボス種別で決まる。

| 章 | 種別 | 基礎HP | 難易度1で追加される強さ |
|---:|---|---:|---:|
| 5 | BOSS | 273 | 0 |
| 10 | MAJOR_BOSS | 494 | 1 |
| 15 | BOSS | 421 | 1 |
| 20 | MAJOR_BOSS | 705 | 2 |
| 25 | BOSS | 570 | 2 |
| 30 | MAJOR_BOSS | 917 | 3 |
| 35 | BOSS | 718 | 3 |
| 40 | MAJOR_BOSS | 1,128 | 4 |
| 45 | BOSS | 867 | 4 |
| 50 | MAJOR_BOSS | 1,340 | 5 |

名前付きボスの強さは次の式で加算される。

```text
strength = 難易度の敵Strength加算値 + floor(章番号 / 10)
```

そのため、HPだけでなく第10章以降は10章単位でも敵の行動威力が上がる。大ボスは初期フェーズ1・アーティファクト2、中ボスは初期フェーズ0・アーティファクト1で開始する。

### 2.4 特殊ボスの例外と出現章の分離

特殊ボスは、5章ごとの名前付きボスと同じ章に出現させない。章番号を `c` としたときの優先順位は次の通り。

```text
c % 5 === 0
  → 名前付きエンドレスボスを出現
  → ドドメデス／あずきの特殊ボス用イベントは発生させない

c % 5 !== 0
  → 特殊ボス用イベントを抽選可能
  → 特殊イベントを最後まで進めた場合、章末の通常戦闘を特殊ボス戦へ置換
  → 特殊イベントがなければ、章末は通常戦闘
```

この分離は標準エンドレスと真エンドレスの両方に適用する。真エンドレスの5の倍数章では名前付きボス定義がないため汎用ボスになるが、それでもドドメデス／あずきの特殊ボスとは重複させない。

| 特殊ボス | HPの現行式 | 章による強化 | 発生条件 |
|---|---|---|---|
| ドドメデス＋ゲンゾー | ドドメデス `ceil((170×m + 2×floorDifficulty)×補正)`、ゲンゾーはドドメデスの45% | あり（`m`を使用） | `c % 5 !== 0` の章で、エンドレス共通イベントを最終段階まで進める |
| あずき | デッキ内の最大ブロック値 `×10` | なし。難易度のStrengthのみ | `c % 5 !== 0` の章で、「あずきがこの階層のボスになる」を選択する |
| 真エンドレスの汎用ボス | 通常の汎用ボス式＋デッキ攻撃力ラバーバンド | あり（`m`を使用） | 第50章後、5の倍数章で名前付きボス定義がない場合。ただし特殊ボスとは排他 |

あずきだけはデッキのブロック値依存であり、章番号に比例しない。特殊ボス用イベントは章開始時点で `c % 5 === 0` の章では候補から除外し、既存の特殊ボス準備フラグがあっても名前付き／汎用の5章ボスを優先する。

## 4. イベント発生の前提

1章15Fマップの内部座標は `y=0～14`。開始地点は `y=0`、最終地点は `y=14`。

| 内部F | ノードの現状 |
|---:|---|
| y=0 | START。複数の入口から開始 |
| y=1 | COMBAT固定 |
| y=2～6 | COMBAT / EVENT / SHOP / REST / ELITE / TREASUREを抽選 |
| y=7 | TREASURE固定 |
| y=8 | COMBAT / EVENT / SHOP / REST / ELITE / TREASUREを抽選 |
| y=9 | ELITE固定 |
| y=10～12 | COMBAT / EVENT / SHOP / REST / ELITE / TREASUREを抽選 |
| y=13 | REST固定。ボス前の休息地点 |
| y=14 | 5の倍数章は名前付きBOSS。その他の章はCOMBAT。特殊ボス達成章はこの章末戦闘を特殊ボス戦へ置換 |

抽選対象の行では、EVENTの重みは15%。これは「イベントマスになった場合」の重みであり、実際の1周あたりのイベント回数はルート選択と各行のノード数で変動する。

イベントノードに入ったあとも、レリックによる小さな宝箱や、条件を満たしたクレーンゲームがイベント本文より先に発生する場合がある。以下のマトリクスは、これらの割り込みが発生しなかった場合のイベント本文の分岐を示す。

## 5. モード×各編 イベント本文マトリクス

| モード | 小学生編 | 高校編 | マジック編 |
|---|---|---|---|

重要なのは、真エンドレス化してもイベント生成器は切り替わらない点である。`endlessTrueMode` はクリア後の選択と継続処理を分けるためのフラグで、イベントの各編分岐は `isEndless` によってエンドレス側へ入る。

### 抽選順と確率の注意

ランダム発生時の評価順は次の通り。

```text
ドドメデス連続イベント（c % 5 !== 0 の章のみ）
  ↓ 発生しなかった場合
あずきとの出会い（c % 5 !== 0 の章のみ）
  ↓ 発生しなかった場合
高校編サポーターNPC
  ↓ 発生しなかった場合
各編の通常イベント
```

したがって、12%・35%・12%・55%は互いに独立した同時抽選ではない。上位のイベントが選ばれなかったときだけ、次の候補が評価される。また、セーブ復元や指定タイトルからの再生成では、確率を使わず該当イベントを直接復元する。

## 9. 現状の確認ポイント

- エンドレス第1～5章は `m=5` であり、章ごとの敵倍率は横ばい。第6章以降は章番号どおりに上昇する。
- 真エンドレス第51章以降も章番号がそのまま `m` に使われるため、通常エンドレスより弱くなるリセットはない。
- 第50章までは編ごとの名前付きボスと固有ギミックがあるが、第55章以降は名前付きボス・固有ギミック・固有ボス報酬の追加定義がない。現状は汎用ボス処理へフォールバックする。
- 5の倍数章では名前付きボス（真エンドレスでは汎用ボス）を優先し、ドドメデス／あずきの特殊ボス用イベントを発生させない。特殊ボスは5の倍数以外の章末戦闘だけで発生可能とする。
- あずきのHPだけは章倍率ではなく、デッキ内最大ブロック値に依存するため、他の敵と同じ上昇曲線ではない。
- 小学生編・マジック編のエンドレスでも高校編サポーターNPCが発生する。これは現在の共通プール仕様であり、マジック編専用汎用イベント追加時には発生比率と優先順を再確認する必要がある。
- 特殊イベントの「発生率」はイベントノードに入った後の候補抽選であり、マップ上にイベントノードが出現する15%とは別の確率である。
