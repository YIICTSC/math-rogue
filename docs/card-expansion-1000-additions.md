# 学習ローグ 1000枚拡張・追加カード一覧

作成日: 2026-08-08

## 目標と数え方

- 現在のカード定義: **776枚**（`CARDS_LIBRARY` 725枚 + `MAGIC_CARDS` 51枚）
- 本資料の追加カード: **224枚**
- 実装後のカード定義: **ちょうど1000枚**
- カウント対象は固定IDを持つカード定義。戦闘中のコピー、捕獲で生成された個体、合成結果の個体は数えない。
- 「ハートフル・ブルーム」は音声付きのひより専用カード `MAGIC_HIYORI_3` に残す。重複していた通常カード `GIRLS_HEART_BLOOM` は「ピンク・ペタルガード」へ改名する。

## 追加枚数の配分

|区分|追加枚数|追加後の内訳|
|---|---:|---:|
|小学生編・共通カード|84|既存通常ライブラリへ追加|
|高校生編|56|既存通常ライブラリへ追加|
|横断テーマ・実生活カード|68|17テーマ × 4枚|
|状態異常・呪い・イベント系|16|既存通常ライブラリへ追加|
|合計|224|全カード定義1000枚|

## 固有共鳴の実装方式

追加224枚は、カード説明に番号ラベルを付けず、16種類の発動条件と14種類の報酬を重複なしで総当たりした固有効果を持つ（16 × 14 = 224）。同じ条件と報酬の組み合わせは存在しない。

- 条件: 手札の左右位置、手札枚数の偶奇、使用後エナジー、ブロック、HP、敵の行動予定、山札・捨て札枚数、ターン内使用状況、カード種別、最高コスト
- 報酬: ドロー、ブロック、エナジー、回復、次ターン強化、筋力・器用さ、敵への毒・弱体、捨て札回収、手札強化・割引、手札枚数ブロック
- カード説明には固有共鳴の番号ラベルを付けず、条件と追加効果を記載する。発動・未達は既存の戦闘ログへ表示し、発動時は既存の強化エフェクトを使用する

## 全224枚のUI追加不要方針

追加カードはすべて固有効果を持たせるが、専用ボード、メーター、タイムライン、装備スロットは新設しない。判定と選択には現在表示されている情報と既存UIだけを使う。

|利用する既存UI・情報|新規効果での使い方|
|---|---|
|手札と並び順|左端・右端、引いたターン、保留ターン数を条件にする|
|エナジー・HP・ブロック|使用後が0、同値、偶数・奇数、過不足を条件にする|
|敵の行動予定|攻撃・防御・バフ・デバフの種類や予定値を参照する|
|山札・捨て札・廃棄札|枚数、先頭カード、選択回収、領域間移動を参照する|
|既存のカード選択画面|コピー、変換、強化、予約対象の選択に再利用する|
|既存の状態・パワーアイコン|1ターン限りの予約効果や解除条件を通常の状態として表示する|
|戦闘ログ|連続使用、予測結果、3ターン条件などの進捗を文章で通知する|

### 除外するもの

- 教科別・テーマ別の専用盤面と点灯マス
- マジック主人公への新規ゲージや固有ルール
- カード専用の進行ボード、装備枠、常設サブ画面
- プレイヤーが既存画面から確認できない隠しカウント

各条件はカード説明と戦闘ログで確認できる。専用UIは追加しない。

## 実装順と確認項目

1. 手札位置、カードを引いたターン、生成元、使用順、各領域の枚数、敵予定値を共通の効果条件として参照できるようにする。専用UIコンポーネントは追加しない。
2. 複数ターンにまたがる条件は既存の状態・パワーとして保持し、残り条件を既存ツールチップと戦闘ログへ表示する。マジック専用処理には接続しない。
3. 追加カードは全件で `新規:` ギミックを1つ以上必須とし、既存UIから条件と結果を確認できない実装を許可しない。
4. コピー・再発動・生成効果は、対象候補が複数なら必ず選択UIを表示する。対象なし・1枚のみ・キャンセル時も確認する。
5. カード効果によるカード移動は、手札・山札・捨て札・廃棄札のどこからどこへ移るかをテストする。新しい預かり領域は作らない。
6. 予約効果と使用履歴は、戦闘終了・敵撃破・ウェーブ移行・変身・セーブ再開ごとに仕様どおり維持または破棄されることを確認する。
7. 1000枚到達判定は表示名ではなくID件数で行い、ID・表示名・正規化効果文・数値除外効果テンプレートの重複検査をビルド前チェックに追加する。
8. 各カードは通常版・強化版の効果値、説明文、対象選択、敵全体／単体、廃棄・保留、UI追加不要条件を同時に定義する。
