# オンラインの試合継続と途中参加

## スポーツ

- テニス・バスケットボール・ドッジボールは人間の参加数が均等になるよう組み分けし、空席をCPUで補う。不戦勝を作らず、各コートは同時に進行する。
- 勝敗に応じた組み合わせで全チームが最後の順位決定戦まで出場する。優勝争いから外れても操作を続けられる。
- 早く終了したコートは公式結果を確定して練習へ移行する。他のコートが終われば全員で次の回戦へ進む。練習の勝敗や個人記録は公式結果に加算しない。
- 途中参加はCPUの席を優先して引き継ぐ。空席がない場合は新しい2チームのコートを追加する。進行中のコートを作り直さない。
- ゴルフは全員が独立してラウンドを進める。先に完走した人は公式スコアを保ったまま練習ラウンドを遊べる。全員の完走または退出で結果へ移る。

## VR / GP / RPG

- VR協力は開始時の担当エリア座標を固定する。途中参加者は既存エリアの仲間として加わり、個別の目標を進める。
- VRバトルロイヤルは順位確定後の復帰戦を継続する。爆弾バトルは独立した練習アリーナへ復帰する。対戦型VRへの途中参加は練習側に入り、進行中の勝敗には影響しない。
- GPは途中参加を受け付け、ゴール後も順位・タイムを確定して自由走行を続ける。
- RPGは名前を登録して入室した後に主人公・レリック・ご褒美カードを選ぶ。ホストは1人で開始でき、開始前には任意で問題設定を変更できる。開始後の仲間も同じ入口から参加できる。
- RPGの敗戦後は既存の学習・復帰手順で冒険を再開できる。本編とのカード・所持品・冒険進行の引き継ぎは行わない。RPGのランキングカードもRPG内へ保存し、本編のアルバムに加えない。全体の学習正解数は従来どおり記録する。

満員の部屋・大会全体の終了後は参加を受け付けない。明示的に観戦を選んだホストの観戦機能は維持する。

## RPGの開始導線

| 入口 | ゲームが始まるまでの画面 |
| --- | --- |
| ひとりで遊ぶ | 問題選択（課題選択済みなら省略）→ 難易度 → 主人公選択（主人公ビルダーを含む）→ レリック → ご褒美カード → ひとり用ワールドを自動開始 |
| オンラインで遊ぶ（ホスト） | 名前・ゲームモード・制限時間・通信方式 → 部屋を作る → ROOM → 主人公選択 → レリック → ご褒美カード → ROOMでゲーム開始 |
| 招待に参加する | 参加名・招待コード → 参加する（入室完了）→ 主人公選択 → レリック → ご褒美カード → ROOMで待機／開始済みならワールドへ |
| 招待URL | URLから参加名入力 → 参加する（入室完了）→ 以降は招待コードと同じ |
| 続きから | RPG専用セーブの主人公・レリック・デッキ・ワールドを再開。今回の起動時に課題を選択していれば、その課題を出題 |

- 本編タイトルのRPG入口でも、他ゲームと同じ課題確認を表示する。「課題を始める」で選んだ課題と、すでに選択済みの配信課題をRPGへ引き継ぐ。「あとで」なら通常の問題選択を行う。ホストのROOMで「問題の設定」を開く場合も、課題があれば問題選択を飛ばして難易度だけ選ぶ。オリジナル問題・回答形式・単元指定をワールドへ共有する。
- ひとり用にはオンライン部屋作成・招待の切り替えを表示しない。オンライン部屋作成フォームも、名前・ゲームモード・制限時間・通信方式に絞る。
- 招待はホストから入室完了の応答を受けてから主人公選択へ進む。準備中もホストの参加者一覧に表示する。準備が終わるまでは操作・初期プロフィール送信を抑止する。
- ホストの「問題の設定」で問題・難易度を変更できる。主人公選択済みならROOMへ戻し、レリック・ご褒美カードを重複付与しない。主人公の選び直しでは、新しい主人公の初期状態からレリック・ご褒美カードを選び直す。
- ご褒美カードは省略可能。アカウントのご褒美カード帳から選んだカードのコピーをRPGの初期デッキへ加える。本編の進行中デッキ・引き継ぎカード・セーブは読み込まず、元のご褒美カードを削除・消費しない。RPGのこの画面には削除ボタンを出さない。
- 「待っている間に遊ぼう」はROOMへ集約し、主人公選択画面には表示しない。主人公の種類の切替はコンパクトな44px以上のボタンでまとめ、残りの高さを主人公の表示に使う。スマホ横画面では編の選択と種類の切替を上部の1段にまとめる。
- 主人公ビルダーは主人公選択画面に集約する。既存主人公を選んだ場合、保存済みのオリジナル主人公へ自動で置き換えない。
- ROOMの選択ボタンは44px以上のタップ領域を保ち、スマホ横画面では設定・参加者と招待・開始を左右にまとめる。参加者が多い場合は一覧をスクロールできる。

## 検証

- `node scripts/test-online-active-participation.mjs`：人数別の全回戦、敗退後の操作、途中参加、通信データ形式の検証、ゴルフ公式スコア保護、RPG再開時の独立状態。
- `node scripts/test-tennis-server.mjs` / `test-dodgeball-server.mjs`：実WebSocketでの同時進行、途中参加、完走、再戦、ホスト移譲。
- `node scripts/test-sports-invitations-browser.mjs`：4種のスポーツ、ホスト通信とサーバー通信、途中参加、練習コート、縦横表示。
- `node scripts/test-vr-active-browser.mjs`：実通信・表示・キーボード操作、敗退後の練習と開始後の参加。
- `node scripts/test-rpg-entry-isolation-browser.mjs`：実Appのタイトルからの3導線、課題確認・問題選択の省略・課題変更後の再開、オリジナル問題の実出題、主人公ビルダー、入室完了後の準備、レリック・ご褒美カード、単独ホスト開始、途中参加、縦横ROOMと主人公選択、本編の状態とセーブ保護。`--layout-only`で3編の縦横表示、`--assignment-only`で課題・再開を個別に検証できる。
