# ダンジョンズ2：縦画面の操作と主人公アクション

## 操作

スマホ縦画面では必殺技3個とSHOTを44pxの同じ列に配置する。技名は2行までとし、長押し（500ms）で、実際の技データから名前・威力・範囲・回復・状態異常・クールダウンを確認できる。町やクールダウン中も説明を開ける。短押しは使用可能な技だけを発動する。

長押しの解放で技を発動せず、指が12px以上移動した場合も発動を取り消す。説明を開いている間はゲームへのキー入力を遮断し、Escapeまたは閉じるボタンで戻る。PCでは右クリック・F1でも説明を開ける。説明の確認にターンやアイテムを消費しない。

冒険手帳と変身は十字キーの下の左側、手札は右側にまとめる。変身中も補助ボタンの大きさを保つ。横画面では既存の退出ボタンの下の配置を維持する。ダンジョンズ1の配置は変更しない。

## 画像と再生

9主人公の通常姿・変身後の18セットをImageGenで生成した。各セットは8方向×8ポーズで、合計1,152コマ。ポーズは左右の足踏み、攻撃、投擲、杖を振る、読む、使う、射撃。

歩行は2コマを交互に表示する。ほかの動作は実際の成功した操作・使用処理で切り替え、短時間で待機絵へ戻る。アニメーションの完了を次の操作の条件にせず、セーブ形式や戦闘のターン処理は変更しない。町、通常マップ、道場で同じ描画処理を使う。画像は選択中の主人公の通常姿・変身後を先に読み込む。

`assets/dungeons2/hero-actions-sources.json` は生成元の一覧、`hero-actions-build.json` は元画像・参照画像・出力画像のSHA、切り出し位置、倍率を記録する。コマ割りの検査で8行の素材であることを確認し、全64コマに共通の倍率を使って既存の体格と足元へ合わせる。出力は96pxセルの768×768 lossless WebP、18枚で約7.3MiB。装備やエフェクトの余白を含むため、描画時は既存の128px参照画像の基準点へ合わせる。

再整理する場合は生成元PNGを用意して、次を実行する。生成元は上書きしない。

```sh
node scripts/dungeons2/normalize-hero-actions.mjs assets/dungeons2/hero-actions-sources.json /path/to/generated_images
```

## 確認

```sh
node scripts/test-dungeons2-hero-actions.mjs
node scripts/test-dungeons2-actions-browser.mjs
```

素材検査は18枚のSHA・全1,152コマの欠け・足踏み2コマの下半身の差を確認する。ブラウザ検査は320×568、390×844、430×932、844×390、1280×800で操作の干渉を確認し、町・クールダウン中の長押し、短押し1回、ドラッグ中止、説明中のキー遮断、冒険手帳と変身、実際の移動・攻撃・投げる・振る・読む・使う・射撃への接続、全18枚の描画を確認する。ダンジョンズ1の必殺技のクリックも回帰検査する。

最終の型検査・英語UI監査・Webビルド・サーバービルドを通過。18枚のアクションアトラスについて、Web/Androidの一覧およびdistのSHA一致を確認した。Android全6パックのバージョン定数も一致している。
