## 1. 方針

女性主人公用の `MGE-001～090` とは別に、男性主人公を選択したときだけ抽選される `MGEM-001～090` を用意する。主人公の役割、固有魔法、男子寮・生徒会・魔法街・深層学園での立ち位置をイベント本文へ反映し、女性主人公用イベントの名前や導入を流用しない。

男子主人公用イベントは、通常モードの恋愛・好感度イベントとは別の汎用プールである。ヒロインや男子仲間が登場する場合も、友情、協力、対立の解消、学園生活の本音を中心に描き、恋愛ルートの進行を自動変更しない。

この90本は、既存の以下のイベントとは重複させない。

- ドドメデス連続イベント
- あずきとの出会い
- 高校編サポーターNPCイベント
- 通常モードのマジック編恋愛・選択イベント
- 女性主人公用マジック編エンドレス汎用イベント `MGE-001～090`
- 名前付きエンドレスボス、特殊ボスの固有ギミックイベント

5の倍数章では、5章ごとの名前付き／汎用ボスを優先する。ただし、特殊ボス用イベントだけを候補から除外し、通常の `MGEM` 汎用イベントは通常どおり抽選対象にする。


## 4. 選択結果の記法

効果キーは、女性主人公用の汎用イベントと共通にする。`LEARNING` はイベント固有の数学・英語などを要求せず、現在の出題単元に対する通常の学習判定を1回行う。

| 記号 | 効果 |
|---|---|
| `HEAL+8` / `HEAL+12` | HPを指定値回復 |
| `GOLD+20` / `GOLD+30` | ゴールドを獲得 |
| `CARD+1` | 通常のカード報酬を1枚提示 |
| `UPGRADE+1` | デッキのカードを1枚強化 |
| `REMOVE_CURSE+1` | 呪いカードを1枚除去 |
| `DRAW+1` | 次の戦闘開始時に1枚追加ドロー |
| `MAX_HP+3` | 最大HPを3増加 |
| `MAGIC_TRACE+1` | マジック編深層記録カウンターを1進める |
| `TEAM+1` | チーム結束の記録を1進める |
| `LEARNING` | 現在の単元で1問の学習判定。成功時は前半効果、失敗時は後半効果 |
| `RISK:HP-5` | 選択時にHPを5失う |
| `RISK:CORRUPTION+1` | 次の戦闘開始時に腐蝕を1付与 |

`MAGIC_TRACE` と `TEAM` の進行値が未実装の場合は、結果ログへ達成内容を表示し、将来の解禁条件へ接続できる記録として保存する。

## 11. 表示・画像・固有セリフ方針

### 11.1 イベントIDと画像キー

```text
eventId: MGEM-001 ... MGEM-090
imageKey: magic-endless-generic-male/MGEM-001 ... magic-endless-generic-male/MGEM-090
```

個別画像へ切り出す前の3×3シートは、女子用シートと混同しないよう男子用フォルダへ分ける。

```text
public/sprites/magic/events/endless/male/MGEM-001-009.png
...
public/sprites/magic/events/endless/male/MGEM-082-090.png
```

実装時に個別WebPへ切り出す場合は、次のキーへ対応させる。

```text
public/sprites/magic/events/endless/male/MGEM-001.webp
...
public/sprites/magic/events/endless/male/MGEM-090.webp
```

### 11.2 固有セリフの最低要件

- 蓮は「守る」「待つ」「風を通す」を中心に、相手を急かさない。
- 颯真は「確認する」「順番を決める」「責任を引き受ける」を中心にする。
- 湊は丁寧語を基調にし、後輩らしい素直さと治癒への努力を出す。
- 理玖は軽い調子で話しながら、最後に時間・情報の核心を一つ指摘する。
- 大和は短い乱暴な言い方を使うが、行動では仲間を最優先する。
- レオンは勝負や演奏を口にするが、敗北や他人の技量を正面から認める。
- エリオットは礼儀正しく、星界の知識を断定せず、学園の仲間へ問い返す。
- 朔夜は必要なことだけを話し、危険な情報を自分一人で抱え込まない。

恋愛対象との一対一の告白、密着、デート専用構図は使わない。画像では、男子主人公の立ち位置、固有魔法の色、役割に対応する小道具を明確にする。黒帳機関や記録片を扱う場面でも、恐怖・流血・過度な暴力表現は避ける。

## 12. 実装時の接続方針

1. `src/data/magicEndlessGenericMaleEvents.ts` に `MGEM-001～090` をデータ化する。
2. `visualTheme === 'magic'`、エンドレス状態、`magicProtagonistGender === 'male'` のときだけ男性主人公用プールを候補にする。
3. `currentAct` が1～3なら `MGEM-001～030`、4～9なら `MGEM-001～060`、10～50なら `MGEM-001～075`、真エンドレスなら全90本を候補にする。
4. 5の倍数章でも `MGEM` は発生させる。ただしドドメデス／あずきの特殊ボス用イベントだけを候補から除外する。
5. 男性主人公用イベントの選択で、名前付きボス、特殊ボス、恋愛好感度、真エンドレス突入状態を直接変更しない。
6. 協力プレイでは、男性主人公を選んだホストの `MGEM` 選択を既存のイベント同期ルートへ載せる。ゲストの性別だけで別イベントへ差し替えない。
7. `LEARNING` は現在の通常学習判定を使い、本文上の専門科目を必須条件にしない。これにより、1サイクル内で同じ単元が続く場合でもイベント進行が不可能にならない。
8. `MAGIC_TRACE` と `TEAM` が未実装の場合は、即時効果を先に適用し、達成内容を結果ログへ表示する。
