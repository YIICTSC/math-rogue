# バカンス戦闘アニメーションシート生成キュー

## 目的

バカンス用の基準立ち絵と、現在の基本衣装の2×2戦闘シートをImageGenへ同時に参照させ、衣装だけを置き換えた実戦用シートを作成する。CSSの動きだけで済ませず、各主人公・各形態・各アクションを個別画像として用意する。

## 完成対象

- 高校編：9人 × 6種（idle / idle-special / attack / skill / hit / low-hp）＝54枚
- マジック編：女性9人＋男性8人、各変身前後 × 6種＝204枚
- 合計：258枚
- すべて正方形、2×2の4フレーム、既存シートと同じフレーム順・足元基準・全身表示。
- 背景はチェッカー模様ではなく、実際の透過アルファチャンネルにする。

## 保存先

高校編：`public/sprites/high-school/vacation-characters-{action}-sheets/{index}.webp`

マジック編女性：`public/sprites/magic/vacation-characters-{action}-sheets/heroine-{nn}-{before|after}.webp`

マジック編男性：`public/sprites/magic/vacation-male-characters-{action}-sheets/{assetId}-{before|after}.webp`

## 進捗（2026-09-08）

- バカンス基準立ち絵：高校編9枚、マジック編女性18枚・男性16枚を作成済み。
- 戦闘アニメーションシート：高校編54枚、マジック編女性108枚・男性96枚を作成済み（合計258枚）。
- 高校編・マジック編女性の水着系立ち絵を役割別に再生成し、飼育委員は通常衣装のうさぎを実体のある相棒として残した。ImageGenがチェッカーを返す場合も、配置前にアルファ0へ正規化する。
- 6状態の258枚をImageGenで各コマの姿勢・四肢・小道具・エフェクトを個別生成し、`scripts/align-vacation-animation-sheets.mjs` で各フレームを同じアイドル基準の足元・横位置へ補正した。
- `scripts/audit-vacation-animation-sheets.mjs` で258枚を検査し、1254×1254・RGBA・四分割の描画・フレーム差分・透過コーナーを確認する。
- 6状態すべてをゲーム側のバカンス戦闘シート参照へ登録済み。主人公選択画面では解禁前の案内を表示せず、バカンスON時はカードとサムネイルをバカンス立ち絵へ切り替える。

## 採用条件

1. 基準立ち絵の人物・バカンス衣装と一致する。
2. 2×2の4フレームが独立したポーズになっている。
3. 既存シートと同じ向き、スケール、足元基準である。
4. WebPがRGBAで、各セルの背景が完全に透過している。
5. アイドル第1コマを基準に、各フレームの立ち位置・足元が揃っている。
6. 文字、UI、枠線、透かし、別キャラクター、焼き込みチェッカーがない。

採用条件を満たさないシートはゲーム側のマッピングへ登録せず、通常衣装のシートへフォールバックする。
