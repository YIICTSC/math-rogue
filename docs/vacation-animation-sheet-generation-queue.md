# バカンス戦闘アニメーションシート生成キュー

## 目的

バカンス用の基準立ち絵と、現在の基本衣装の2×2戦闘シートをImageGenへ同時に参照させ、衣装だけを置き換えた実戦用シートを作成する。CSSの動きだけで済ませず、各主人公・各形態・各アクションを個別画像として用意する。

## 完成対象

- 高校編：9人 × 5種（idle-special / attack / skill / hit / low-hp）＝45枚
- マジック編：女性9人＋男性8人、各変身前後 × 5種＝170枚
- 合計：215枚
- すべて正方形、2×2の4フレーム、既存シートと同じフレーム順・足元基準・全身表示。
- 背景はチェッカー模様ではなく、実際の透過アルファチャンネルにする。

## 保存先

高校編：`public/sprites/high-school/vacation-characters-{action}-sheets/{index}.webp`

マジック編女性：`public/sprites/magic/vacation-characters-{action}-sheets/heroine-{nn}-{before|after}.webp`

マジック編男性：`public/sprites/magic/vacation-male-characters-{action}-sheets/{assetId}-{before|after}.webp`

## 進捗（2026-09-06）

- バカンス基準立ち絵：高校編9枚、マジック編女性18枚・男性16枚を作成済み。
- 戦闘アニメーションシート：高校編45枚、マジック編女性90枚・男性80枚を作成済み。
- 合計215枚を `scripts/audit-vacation-animation-sheets.mjs` で検査し、1254×1254・RGBA・四分割それぞれに描画があることを確認済み。
- ImageGenの透過キャンバスがチェッカー表示になる場合に備え、`scripts/normalize-sprite-sheet-alpha.mjs` で外周に接する背景模様だけをアルファ0へ整形した。
- 215枚すべてをゲーム側のバカンス戦闘シート参照へ登録済み。未完成の将来追加分は、採用条件を満たすまで通常衣装へフォールバックする。

## 採用条件

1. 基準立ち絵の人物・バカンス衣装と一致する。
2. 2×2の4フレームが独立したポーズになっている。
3. 既存シートと同じ向き、スケール、足元基準である。
4. PNGがRGBAで、各セルの背景が完全に透過している。
5. 文字、UI、枠線、透かし、別キャラクター、焼き込みチェッカーがない。

採用条件を満たさないシートはゲーム側のマッピングへ登録せず、通常衣装のシートへフォールバックする。
