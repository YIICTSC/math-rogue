# 住人・ことば日和の会話音声

住人の会話音声と試聴は、既定の推奨モードで言語に合う端末の自然音声を優先する。端末音声が使えない場合や独自音声モードでは、Web Audioのかな合成を使う。独自合成は録音素材や外部音声APIを必要とせず、母音の共鳴周波数と子音のノイズを組み合わせる。

住人作成・編集の音声設定から、4種類の声質、高さ、速さ、抑揚、6種類の話し方を調整できる。「端末の読み上げ」にも切り替え可能。既存の保存データは新しいフィールドなしでも読み込める。追加フィールド `engine` は省略時に `auto`（推奨）として扱う。明示的に選んだ `original` / `device` は保持する。

独自音声モードの日本語会話は既存の `speech` と `hiragana` のうち合成可能な読みを優先する。かな、カタカナ、拗音、促音、長音、句読点に対応する。独自の漢字辞書や英語の発音辞書は持たないため、対応外の文字を含む会話は端末の読み上げで補完する。端末にも音声機能がない場合、会話字幕のみとなる。人名や自由入力語をかなで設定すると独自音声を利用できる。

初回のクリック・キー操作で音声を有効化する。音量設定、ミュート、アプリの非アクティブ化、会話の置換・中断に従い、合成エンジンが所有する再生だけを停止する。入力は最大240文字、単一のPCMバッファに制限する。

確認コマンド: `node scripts/test-rpg-resident-voice.mjs`。実際の聞き取りやすさとiOS/Androidの音声有効化は実機での確認が必要。

女子住人（ミナ・スイ・ユキ・ノノ・ネム）は高さ1.65〜1.85と明るい声質を組み合わせ、性格ごとのテンポ・話し方を保った高くかわいい声にする。「小さくかわいい」プリセットも高さ1.8・明るい声質で試聴できる。カスタム住人と主人公は保存済みの声設定を優先する。

男子住人にも固定の声を用意する。アオは明るく弾む声、レンは低く温かい声、サハはなめらかな中音、フィルは軽く遊び心のある声、トワは静かで柔らかな声、キノは穏やかな中高音、ミオは深く抑揚を抑えた声。高さだけでなく声質・速さ・抑揚を変えて区別する。

主人公は小学生編・高校編の9キャラと魔法編の17キャラに応じた会話音声を初期設定にする。小学生編は高校編より少し高い声。手動で保存した設定はキャラ別に優先し、選び直すと復元する。オリジナル主人公も選択した音声キャラ別に保存し、旧来の共通設定は最初に選択した音声キャラへ移行する。戦闘用の録音音声や会話の性格設定には影響しない。

## 会話のバリエーション

日常会話は40話題と四季それぞれの季節会話、誕生日・空腹・気分・仲直り前などの状況会話を、性格別の返しと親密度別の締めにつないで会話として再生する。選択式の小話は24本あり、以前の12件の順番は保って追加した。おでかけ6コースは、各3場面・選択3通りに専用の掛け合いがあり、計54通り。贈り物・食事・謝罪・仲裁にも内容に合わせた返答を用意する。会話の読みはすべてかなで定義し、オリジナル音声で再生できる。

確認コマンド: `node scripts/test-rpg-resident-conversations.mjs`。全台詞の日本語・英語・かな読み、音声合成対応、24件のストーリー循環、おでかけ分岐を確認する。


## 明瞭な読み上げの推奨設定

既定値は `auto`。日本語・英語それぞれに一致する端末音声を選び、ローカル音声・完全な言語一致・高品質の声を優先する。他言語の音声で日本語を読ませない。`getVoices()` が未準備なら `voiceschanged` を最大900ms待つ。iOS向けには、ことば日和・RPGとも最初の操作で無音の読み上げを準備する。

推奨モードは文単位で端末に渡し、キャラクターごとの声質・相対的な高さ・速さを維持しながら、端末ピッチを0.85〜1.25、話速を0.82〜1.08へ抑える。この範囲は本作の調整値であり、Web Speech APIの仕様上の推奨値ではない。明示的な「端末の読み上げ」は従来の手動調整範囲を使う。端末に言語の声がない場合や、発声開始前に失敗した場合だけ、対応するかなを改良した独自合成で補う。途中まで読んだ台詞や中止・消音した台詞は繰り返さない。OSにより利用できる声や音質は異なる。

独自合成ではモーラの母音を十分に保ち、子音から母音への移行を短縮、長音は同じ音を持続させる。過剰なフォルマント移動・高ピッチ・母音の無声化を抑え、接続部のクリックと低域の濁りを軽減する。保存・オンライン同期では `engine` と `intonation` も維持する。

検証: `node scripts/test-conversation-clear-speech.mjs`、`node scripts/test-rpg-resident-voice.mjs`、`node scripts/test-rpg-conversation-voice.mjs`。自動検証はルーティング・PCM・停止制御が中心。端末固有の自然音声の実聴評価は、各OSの日本語音声で行う。

参考: [MDN getVoices](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/getVoices)、[voiceschanged](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis/voiceschanged_event)。音声ファイルの新規生成は行わず、既存の端末読み上げ機能とリアルタイムかな合成を改善した。
