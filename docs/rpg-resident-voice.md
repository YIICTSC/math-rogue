# 住人・ことば日和の会話音声

住人の会話音声と試聴は、Web Audioの独自かな合成を標準にする。ケロケロした音程の跳ねと震えを加え、キャラクターごとの面白い声を作る。独自合成は録音素材や外部音声APIを必要とせず、母音の共鳴周波数と子音のノイズを組み合わせる。

住人作成・編集の音声設定から、4種類の声質、高さ、速さ、抑揚、6種類の話し方を調整できる。「端末の読み上げ」にも切り替え可能。既存の保存データは新しいフィールドなしでも読み込める。追加フィールド `engine` は省略時に `original` として扱う。前バージョンの `auto` も独自合成を優先する。明示的に選んだ `original` / `device` は保持する。

独自音声モードの日本語会話は既存の `speech` と `hiragana` のうち合成可能な読みを優先する。かな、カタカナ、拗音、促音、長音、句読点に対応する。独自の漢字辞書や英語の発音辞書は持たないため、対応外の文字を含む会話は端末の読み上げで補完する。端末にも音声機能がない場合、会話字幕のみとなる。人名や自由入力語をかなで設定すると独自音声を利用できる。

初回のクリック・キー操作で音声を有効化する。音量設定、ミュート、アプリの非アクティブ化、会話の置換・中断に従い、合成エンジンが所有する再生だけを停止する。入力は最大240文字、単一のPCMバッファに制限する。

確認コマンド: `node scripts/test-rpg-resident-voice.mjs`。実際の聞き取りやすさとiOS/Androidの音声有効化は実機での確認が必要。

女子住人（ミナ・スイ・ユキ・ノノ・ネム）は高さ1.65〜1.85と明るい声質を組み合わせ、性格ごとのテンポ・話し方を保った高くかわいい声にする。「小さくかわいい」プリセットも高さ1.8・明るい声質で試聴できる。カスタム住人と主人公は保存済みの声設定を優先する。

男子住人にも固定の声を用意する。アオは明るく弾む声、レンは低く温かい声、サハはなめらかな中音、フィルは軽く遊び心のある声、トワは静かで柔らかな声、キノは穏やかな中高音、ミオは深く抑揚を抑えた声。高さだけでなく声質・速さ・抑揚を変えて区別する。

主人公は小学生編・高校編の9キャラと魔法編の17キャラに応じた会話音声を初期設定にする。小学生編は高校編より少し高い声。手動で保存した設定はキャラ別に優先し、選び直すと復元する。オリジナル主人公も選択した音声キャラ別に保存し、旧来の共通設定は最初に選択した音声キャラへ移行する。戦闘用の録音音声や会話の性格設定には影響しない。

## 会話のバリエーション

日常会話は40話題と四季それぞれの季節会話、誕生日・空腹・気分・仲直り前などの状況会話を、性格別の返しと親密度別の締めにつないで会話として再生する。選択式の小話は24本あり、以前の12件の順番は保って追加した。おでかけ6コースは、各3場面・選択3通りに専用の掛け合いがあり、計54通り。贈り物・食事・謝罪・仲裁にも内容に合わせた返答を用意する。会話の読みはすべてかなで定義し、オリジナル音声で再生できる。

確認コマンド: `node scripts/test-rpg-resident-conversations.mjs`。全台詞の日本語・英語・かな読み、音声合成対応、24件のストーリー循環、おでかけ分岐を確認する。


## ケロケロした明瞭なキャラクター音声

既定は `original`。ことば日和の5動物・3住人、RPGの標準設定を同じ独自エンジンで発音する。以前の `auto` 保存設定も独自合成へ戻し、端末音声を優先しない。端末の読み上げは明示的に選ぶ代替手段として残す。かな以外・英語の補完は従来どおり。

各モーラに小さな段階的音程と滑らかなつなぎ、母音部分だけの細かな震えを加える。明るい話し方は跳ねを大きく、落ち着いた話し方は控えめに、ロボットは一定音程にする。4声質ごとに声帯波形も変える。市販ゲームの音声や録音素材は使用しない。

明瞭さのため、母音の共鳴位置は震えで動かさず、帯域制限した倍音源を補って母音の違いを保つ。子音のノイズが母音を隠さないように調整し、長音は再発音せず持続する。短い接続補間、低域の濁り除去、過度な高ピッチ・早口の抑制も維持する。こんにちは・こんばんはは挨拶の発音へ変換する。

検証: `node scripts/test-conversation-clear-speech.mjs`、`node scripts/test-rpg-resident-voice.mjs`、`node scripts/test-rpg-conversation-voice.mjs`。既定と旧autoが端末TTSを呼ばないこと、24種類の声質・話し方のPCM、消音・中断・保存を確認する。独自エンジンは自然音声TTSと異なるキャラクター音声であり、聞き取りやすさと表現の両方を調整する。

### 打音の抑制

破裂子音のノイズを瞬間的に立ち上げず、短い正弦二乗の包絡で丸める。破擦音の立ち上がりにも5msの補間を入れる。新しい子音でノイズ共鳴器の残響をリセットし、句間の無音では各共鳴器の状態を解放する。母音の共鳴周波数も前の母音から連続的に移行し、音節境界は6msの滑らかな補間でつなぐ。声量とケロケロの音程変化を保ち、過渡的な打音を抑える調整。

「きかせて」のカ行の入りは、破裂ノイズだけでなく母音の立ち上がりも緩める。カ・ガ行ではノイズのピークをさらに抑え、広めの帯域で共鳴を分散し、母音へ滑らかにつなぐ。破裂音後の小さなノイズも急に加算せず補間する。`node scripts/test-resident-voice-attacks.mjs` で、試聴例の「き」「か」のリリースピーク低減と母音の音量維持を検証する。

発音群の追加調査と測定結果は [立ち上がり調査](./rpg-voice-attack-audit.md) を参照。破裂・破擦音全般とマ・ナ行の出だしを調整し、`node scripts/audit-resident-voice-attacks.mjs --check` で代表的な設定を検証する。
