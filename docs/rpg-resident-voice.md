# 住人のオリジナル音声

住人の会話音声と試聴に、Web Audioで動く独自のかな合成を導入。録音素材や外部音声APIは使わず、母音の共鳴周波数と子音のノイズを組み合わせる。自然音声TTSとは異なる、素朴で機械的なキャラクター音声を目指している。

住人作成・編集の音声設定から、4種類の声質、高さ、速さ、抑揚、6種類の話し方を調整できる。「端末の読み上げ」にも切り替え可能。既存の保存データは新しいフィールドなしでも読み込める。追加フィールド `engine` は省略時に `original` として扱う。

日本語会話は既存の `speech` と `hiragana` のうち合成可能な読みを優先する。かな、カタカナ、拗音、促音、長音、句読点に対応する。独自の漢字辞書や英語の発音辞書は持たないため、対応外の文字を含む会話は端末の読み上げで補完する。端末にも音声機能がない場合、会話字幕のみとなる。人名や自由入力語をかなで設定すると独自音声を利用できる。

初回のクリック・キー操作で音声を有効化する。音量設定、ミュート、アプリの非アクティブ化、会話の置換・中断に従い、合成エンジンが所有する再生だけを停止する。入力は最大240文字、単一のPCMバッファに制限する。

確認コマンド: `node scripts/test-rpg-resident-voice.mjs`。実際の聞き取りやすさとiOS/Androidの音声有効化は実機での確認が必要。

女子住人（ミナ・スイ・ユキ・ノノ・ネム）は高さ1.65〜1.85と明るい声質を組み合わせ、性格ごとのテンポ・話し方を保った高くかわいい声にする。「小さくかわいい」プリセットも高さ1.8・明るい声質で試聴できる。カスタム住人と主人公は保存済みの声設定を優先する。
