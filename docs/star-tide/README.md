# 星潮の航路 / Star Tide

オリジナルの見下ろし2D探索ARPG。既存のReact/Canvasミニゲームに統合。人物・地名・物語・画像は本作専用に制作し、既存作品の素材は使用しない。

## 遊び方

ミニゲーム一覧の「星潮の航路」から開始。最初の島の星灯を取り戻すと、好きな順番で他の島へ航海できる。未調査の島へは集落の船着場から、地図を登録した島へは転移できる。塔のそばでAを押すと、その島の地図と転移先を登録する。

各星灯の鍵は三経路の報酬。経路ごとに指定された5室のうち3室を、敵の群れを倒すか仕掛けを解いて攻略すればよい。敵を避け、仕掛けで進むこともできる。各島の地下の宝箱で新しい道具が手に入り、剣以外の戦い方が広がる。最終島にも早く挑めるが、他の島の道具・料理・成長が攻略を助ける。

- 移動：矢印 / WASD / 左スティック / アナログ仮想パッド
- A：Z / J / パッドA。剣・調べる・採集・塔の登録・鏡や回路の操作
- B：X / K / パッドB。選択した道具
- 回避：Space / パッドX。スタミナを消費。近接回避で崩せるボス防御もある
- 滑空：G / パッドY。水や穴を越えられるがスタミナを消費。尽きたら安全な岸へ着地
- 手帳：Escape / Menu / 画面の冒険手帳。地図、道具、食料、料理、強化、依頼、ヒント。再度Escapeで再開

## 実装内容

- 12地域、各24区画の6×4分岐、計288区画。地上96区画と地下192区画。プレイヤーが島の順序と戦闘・仕掛けの攻略方法を選ぶ。
- 8道具、実時間の接近戦・射撃、回避・盾・滑空・スタミナ。敵追尾と弾幕、固有画像を持つ12ボス、防御の開閉・道具や回避による防御崩し・転移・援軍。
- 順番の灯、対の灯、道具、拍子、押し箱、反射鏡、反転回路、滑る像。解法探索で配置を検証。途中状態も保存し、手帳から仕掛けだけをリセットできる。回路・鏡・滑る像には次の一手のヒント。
- 36件の住民依頼と48件の会話、地域の導入、選択と行動による2種類のエピローグ。最終戦後も未踏の島や依頼へ戻れる。
- 採集・料理・食事、鉱石による武器強化、星片による体力・スタミナ強化。岩の採掘、爆発樽、草への着火、雨による消火、風と上昇気流を利用した滑空。
- 戦闘後の区切りと星灯で共通 `MiniGameProblemChallenge` を使用。教科・課題・回答形式・回答記録を引き継ぐ。誤答時は再挑戦し、未解決ゲートは保存。学習中は戦闘も本編タイマーも停止。
- ポインター解除、ポーズ、フォーカス喪失、システムメニュー、問題画面で入力を解放。共有ゲームパッドAPIを使い、探索中にAがメニューの退出へ誤送信されない。
- 日英表示。ImageGenの人物・武器演出・敵・環境64セル、地上背景12点、地下背景12点、ボス12体、探索用品16セル。5枚のロスレスWebPをWeb/Android双方の配信一覧へ登録。

## プレイ時間

目標は**学習を除いた本編約30時間**。これは探索、地域攻略、依頼、仕掛け、装備と料理の準備を含む設計目標であり、人間による初見30時間の通しプレイで実測した値ではない。自由探索のため、準備や寄り道を省いて早く最終島へ挑むこともできる。待機タイマー、同じ戦闘の強制反復、問題数で所要時間を引き延ばす制約は設けない。

自動検証は進行可能性・戦闘・保存・画面と入力の検証であり、プレイ時間のベンチマークではない。

## 検証と構成

- `pnpm run test:star-tide`：全マップと敵の到達性、配置の解法、戦闘・消費・保存・自由航海・環境。全地域を巡り276戦、192仕掛け、72出題の区切り、12星灯、36依頼からエンディングまで進行。
- `pnpm run test:star-tide:browser`：開始、物語、キーボード、仮想/標準パッド、料理、滑空、島の自由選択、仕掛けの途中保存、問題・最終戦・エンディング。390×844、844×390、1000×1000の画像は `tmp/star-tide/`。
- `node scripts/test-star-tide-assets.mjs`：生成記録・透過・Web/Android配信一覧。
- `pnpm run audit:english:gate`、`pnpm run build`、`pnpm run server:build`。

保存キーは `learning-rogue:star-tide:v1`。シミュレーションと保存はengine/wild/puzzleSave、描画はrender、地域と物語はcontent/quests、仕掛けは各Puzzles、UIと出題接続はStarTideに分離。画像の生成元・ハッシュは `assets/star-tide/art.json`。原本はセッションの生成画像フォルダへ保持する。
