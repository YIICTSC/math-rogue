# 星潮の航路 / Star Tide

オリジナルの見下ろし2D探索ARPG。既存のReact/Canvasミニゲームに統合。人物・地名・物語・画像は本作専用に制作し、既存作品の素材は使用しない。

## 遊び方

ミニゲーム一覧の「星潮の航路」から開始。最初の島の星灯を取り戻すと、好きな順番で他の島へ航海できる。未調査の島へは集落の船着場から、地図を登録した島へは転移できる。塔のそばでAを押すと、その島の地図と転移先を登録する。

各星灯の鍵は三経路の報酬。経路ごとに指定された5室のうち3室を、敵の群れを倒すか仕掛けを解いて攻略すればよい。敵を避け、仕掛けで進むこともできる。各島の地下の宝箱で新しい道具が手に入り、剣以外の戦い方が広がる。最終島にも早く挑めるが、他の島の道具・料理・成長が攻略を助ける。

- 移動：矢印 / WASD / 左スティック / アナログ仮想パッド
- A：Z / J / パッドA。装備武器・調べる・採集・塔の登録・鏡や回路の操作
- B：X / K / パッドB。装備武器（A/Bとも手帳で変更）
- 回避：Space / パッドX。スタミナを消費。近接回避で崩せるボス防御もある
- 滑空：G / パッドY。水や穴を越えられるがスタミナを消費。尽きたら安全な岸へ着地
- 手帳：Escape / Menu / 画面の冒険手帳。地図、道具、食料、料理、強化、依頼、ヒント。再度Escapeで再開

## 実装内容

- 12地域、各24区画の6×4分岐、計288区画。地上96区画と地下192区画。プレイヤーが島の順序と戦闘・仕掛けの攻略方法を選ぶ。
- 8道具、実時間の接近戦・射撃、回避・盾・滑空・スタミナ。敵追尾と弾幕、固有画像を持つ12ボス、防御の開閉・道具や回避による防御崩し・転移・援軍。
- 順番の灯、対の灯、道具、拍子、押し箱、反射鏡、反転回路、滑る像。解法探索で配置を検証。途中状態も保存し、手帳から仕掛けだけをリセットできる。回路・鏡・滑る像には次の一手のヒント。
- 36件の住民依頼と48件の会話、地域の導入、選択と行動による2種類のエピローグ。最終戦後も未踏の島や依頼へ戻れる。
- 採集・料理・食事、鉱石による武器強化、星片による体力・スタミナ強化。岩の採掘、爆発樽、草への着火、雨による消火、風と上昇気流を利用した滑空。
- 戦闘後の区切りと星灯で共通 `MiniGameProblemChallenge` を使用。教科・課題・回答形式・回答記録を引き継ぐ。誤答時は再挑戦し、未解決ゲートは保存。学習中は戦闘も本編タイマーも停止。
- ポインター解除、ポーズ、フォーカス喪失、システムメニュー、問題画面で入力を解放。共有ゲームパッドAPIを使い、探索中にAがメニューの退出へ誤送信されない。
- 日英表示。ImageGenの人物・武器演出・敵・環境64セル、地上背景12点、地下背景12点、ボス12体、探索用品16セル。5枚のロスレスWebPをWeb/Android双方の配信一覧へ登録。

## プレイ時間

目標は**学習を除いた本編約30時間**。これは探索、地域攻略、依頼、仕掛け、装備と料理の準備を含む設計目標であり、人間による初見30時間の通しプレイで実測した値ではない。自由探索のため、準備や寄り道を省いて早く最終島へ挑むこともできる。待機タイマー、同じ戦闘の強制反復、問題数で所要時間を引き延ばす制約は設けない。

自動検証は進行可能性・戦闘・保存・画面と入力の検証であり、プレイ時間のベンチマークではない。

## 検証と構成

- `pnpm run test:star-tide`：全マップと敵の到達性、配置の解法、戦闘・消費・保存・自由航海・環境。全地域を巡り276戦、192仕掛け、72出題の区切り、12星灯、36依頼からエンディングまで進行。
- `pnpm run test:star-tide:browser`：開始、物語、キーボード、仮想/標準パッド、料理、滑空、島の自由選択、仕掛けの途中保存、問題・最終戦・エンディング。390×844、844×390、1000×1000の画像は `tmp/star-tide/`。
- `node scripts/test-star-tide-assets.mjs`：生成記録・透過・Web/Android配信一覧。
- `pnpm run audit:english:gate`、`pnpm run build`、`pnpm run server:build`。

保存キーは `learning-rogue:star-tide:v1`。シミュレーションと保存はengine/wild/puzzleSave、描画はrender、地域と物語はcontent/quests、仕掛けは各Puzzles、UIと出題接続はStarTideに分離。画像の生成元・ハッシュは `assets/star-tide/art.json`。原本はセッションの生成画像フォルダへ保持する。

## グラフィック拡充とスマホ表示（2026-10-25）

- 操作キャラクターはナギのみ（2026-10-26更新）。旧ミオ・セナの選択記録も進行を保持してナギへ移行する。
- 初期の72フレームに加え、下記のナギ専用アニメーションを使用する。4方向歩行、上下・左右の斬撃と道具、回避、滑空、被弾を別状態で再生する。体の画像は武器を持たず、8道具の演出を攻撃方向に重ねる。歩行停止・ポーズ中に歩行を続けない。
- 通常敵は8種類から24種類へ拡充し、各6フレーム、計144フレーム。追跡・周回・予告後の突進・間合いを取る射撃・跳躍・扇状射撃の6行動を地域ごとに配置。12ボスも各4フレーム、計48フレームの構え・攻撃・回復動作を持つ。
- 地上24バイオーム、地下12地域の素材。床面24、地形96、樹木・岩・花・遺跡など96のImageGen素材を組み合わせる。地上は単独の障害物を散らす配置から、樹林・岩場・水辺をまとめた配置に変更し、移動路と調べる場所への接近路を確保。
- 前後順に描く樹木・人物・敵、足元の影、背後の主人公を隠しすぎない樹冠、命中の火花、方向と連撃に応じた斬撃、水面・雪・火の粉・光の粒子。攻撃予告と当たり判定を視覚的に対応させる。
- スマホ縦画面は画面幅いっぱいの縦長フィールド＋下部操作エリア。横画面は全幅フィールドに半透明の仮想パッド・A/Bを重ね、両脇の固定余白を廃止。安全領域を避けて配置し、表示の縦横比に応じて主人公を追うカメラを使う。画像を引き伸ばさず、回転後もプレイ状態を保持。画面の実寸と端末倍率に追従するCanvasを使用する。

新規画像15枚は約6MiBのロスレスWebP。生成元の記録とフレーム正規化情報は `assets/star-tide/graphics.json`、再パック用スクリプトは `scripts/star-tide/normalize-art.mjs`。スケールはキャラクター・敵種・ボスの各アニメーション内で共通にし、足元を同じアンカーへ揃える。既存5枚はフォールバックと既存演出用に保持する。Web・Android双方の配信一覧を更新する。

`pnpm run test:star-tide:assets` は新旧すべての画像、R素材192種と周囲256配置、全フレームの内容・余白・重複、生成ハッシュ、保存移行、24敵種の実出現と6行動、配信一覧を検証する。ブラウザ検証には24バイオーム・ナギの各動作・全ボス・通常敵24種と、360×640 / 390×844 / 430×932 / 844×390 / 932×430での幅・高さの使用率、操作系の収まり、スクロール不要を含む。

岸辺・崖のR接続素材は12地域それぞれの凸角4方向・凹角4方向、計192種。隣接する地形から自動選択し、草地も同じ曲線マスクで丸める。岸の直線部はつなぎ目だけを描き、同じ水面同士の内部には枠線を描かない。地上の水辺・崖は丸みを当たり判定にも反映し、採掘や地形変更後は接続を更新する。
iOSの共通ステージでも安全領域を重ねないよう、星潮の航路を専用の全画面レイアウトとして登録。縦は上端・ホームインジケーターの余白を一度だけ確保し、横はフィールドを全幅に保ったまま操作系をノッチの内側へ寄せる。ブラウザ検証ではアプリのステージ構造とiOS用CSSクラスも再現する。


## ナギの操作・アクション改善（2026-10-26）

- 通常歩行は3.2→3.8タイル/秒（約19%増）。左右は接地・沈み込み・脚の通過・上昇を含む各8フレーム、上下は各12フレーム。歩行時計を実際の移動距離で進め、低速のパッド入力や壁に当たった際の足滑りを防ぐ。
- ナギ用ImageGenシートを4枚追加。4方向歩行48セル、左右専用歩行16セル、近接コンボ56セル、射撃・槌・盾63セル。左右歩行は専用シートを優先し、近接の左向きは右向きの反転、下向きの返し斬りは順序を反転して使用。元の回避・滑空・被弾シートを継続利用する。
- 冒険手帳でA・Bへそれぞれ入手済みの8武器を割り当て、両ボタンとも武器固有のアクションを使用可能。Aは会話・仕掛け操作を兼ね、必要な道具の仕掛けはA/Bどちらからでも作動する。既存B装備を保持し、旧保存のAは剣で初期化。
- 3段コンボと1入力分の先行受付。斬り→返し→踏み込み、射撃の連射→複数弾、槌の振り下ろし、盾の防御と押し込み、槍・鉤の突き。3段目で威力・間合い・射数が変化。0.28秒を超える中断、武器交換、回避、被弾、区画移動で連続入力を解放する。
- 攻撃の42%地点で一度だけ命中・発射。向きを攻撃中固定し、移動速度を抑える。武器を別レイヤーで振り、斬撃・突き・弓の弦・槌の衝撃・盾の光を方向とアクションの進行に合わせる。連打しても鏡・床の仕掛けを勝手に再操作しない。
- `scripts/test-star-tide-actions.mjs` は旧保存移行、A/B両スロット×8武器、先行入力と3段目、1攻撃1命中、射撃、攻撃中の方向固定、回避・被弾による中断、歩行距離、Aでの道具仕掛けを検証する。
