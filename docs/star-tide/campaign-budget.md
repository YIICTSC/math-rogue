# 本編の時間目標と攻略の自由

ユーザー確認：学習問題を除いた本編約30時間を目標とし、その後「2D版の自由探索・環境利用」を目指す方向へ更新。

12地域を一つずつ攻略・探索する標準モデルを各150分として、合計30時間を設計予算に置く。内訳は探索・依頼35分、道具と再訪25分、複数経路と仕掛け65分、ボス15分、物語と帰還10分。**この予算は実測結果ではない。**

最初の星灯以降は地域の順序を固定しない。鍵の経路は戦闘か仕掛けのどちらでも攻略でき、最終島への早期挑戦も可能。したがって全プレイヤーに30時間を強制しない。全島・依頼・成長・物語を追う遊び方を想定した目標で、最短クリアや全ヒントを使う場合には短くなり得る。

本編タイマーは学習中・手帳でのポーズ・非表示中に進まない。待機条件、同じ敵の倒し直し、クイズ数を所要時間のために強制しない。

現在の自動通し検証は276戦、192仕掛け、72出題の区切り、12星灯と36依頼を確認するが、空間配置をテスト用に指定するため所要時間の根拠には使わない。初見プレイヤーの実測による時間目標の検証は別途必要。
