# トランプゲーム集の操作・配置改善（2026-11-17）

カシノ／ロイヤルカシノの手札だけを出す操作は「場に置く」、獲得札付きの操作は「獲得」と表示する。選択式の獲得ボタンは実際に獲得する場札があり、合法な場合だけ表示する。合法な場置きの判定は従来どおり保持する。

加点時にプレイヤー名・得点理由・増加点を通知する。カシノのA、ビッグ／リトルカシノ、最多枚数・スペード、スコパの最多枚数・ダイヤ・プリミエラ・ダイヤ7を記録。スイープやマリッジ等も表示する。自分の加点には主人公本人の既存勝利ボイスを再利用し、連続再生を抑制する。通知は操作を遮らず、別ゲームへの切り替え時に消去する。

ミッチの山札・捨て札脇に引かれたAの数を3枠で表示。Aのスートは推測表示せず、枚数の指標とする。スート別場札と汎用の手札・場札・公開札は、幅が足りない場合はランクとスートの隅を見せた重ね配置を使用する。長い札列は複数行と内側スクロールを併用し、メモリーやゴルフ等の位置を意味する盤面は保つ。

大富豪はホストが8切り・11バック・スートしばり・スペ3返し・5スキップ・9リバースを選択し、説明と設定を参加者へ共有する。地域・グループで名称や運用が違うため、特定県が唯一の起源とは表示しない。4枚革命と階段は基本ルール。ラウンド数は1／3／5／10／20、ロビーの初期値は5。1配札ごとに順位点を加算し、設定ラウンド終了時に累計で勝者を決定する。エンジンの既存呼び出しは1ラウンドを標準とし互換性を保つ。
