# 単元板書モーダル 内容・文字表示 精査メモ

単元板書モーダルに掲載する内容と、学年別の文字表示を全単元で精査するためのチェックリスト。原稿本体は `docs/unit-board-summaries.md`、実装データは `src/data/unitBoardSummaries.ts`、表示コンポーネントは `src/components/UnitBoardModal.tsx` を対象にする。

## 精査対象

- 対象原稿: `docs/unit-board-summaries.md`
- 現在の板書原稿見出し数: 168件
- 対象画面: 問題チャレンジの算数・数学、国語、漢字、漢検、英語、生活、理科、社会、まとめ、地図・日本、ICT・情報、高校生以上カテゴリ
- 表示タイミング: 単元初回開始時、問題画面の単元板書ボタン押下時
- 対象モード: `mode` または `unitLabel` から `getUnitBoardSummary()` が返す全モード

## 精査の合格条件

各単元は次の条件を満たすこと。

| 項目 | 合格条件 |
| --- | --- |
| 単元名 | ユーザーが選んだ単元名と一致し、英字IDや内部名が表示されない |
| めあて | 1文で、その単元で何ができるようになるかが分かる |
| 考え方 | 2から3項目で、問題を解く時の手順や見方が具体的 |
| よくあるまちがい | 1から2項目で、実際の誤答につながる注意点になっている |
| 例 | 低学年は短い具体例、高学年以上は式・用語・資料読解の例を含む |
| 学年別文字 | 当該学年で未習の漢字を過度に使わない。不自然な交ぜ書きがない |
| レイアウト | スマホ縦・スマホ横・PC幅で黒板の内側に収まる |

## 学年別文字表示ルール

### 小1

- ひらがな中心。
- 漢数字や簡単な数字は使ってよい。
- 教科名は `さんすう`、`こくご` のようにする。
- `問題文` は `もんだいぶん`、`順番` は `じゅんばん`。
- `算数・数学` のような中高混在表記は出さず、低学年算数は `さんすう` にする。
- 単語の一部だけを置換しない。
  - NG: `算かず・かず学`
  - OK: `さんすう`

### 小2

- 1年配当の漢字は使ってよいが、説明語は読みやすさ優先。
- `問題`、`答え`、`文章` などは必要に応じてひらがなにする。
- `主語`、`述語` など単元名として学ぶ語は、単元名では残してもよい。本文では必要ならふりがな相当の説明にする。

### 小3

- 1から2年配当の漢字は基本的に使用可。
- `表`、`図`、`地図` など単元の中心語は残してよい。
- `資料`、`条件`、`原因` などは、文脈に応じて `しりょう`、`じょうけん`、`わけ` にする。

### 小4から小6

- 学習済み漢字を基本使用。
- 抽象語が連続する場合は、低学年同様に短い文へ分ける。
- 社会・理科は用語を残し、必要に応じて説明を短く添える。

### 中学生

- 教科用語は原則そのまま使う。
- ただし板書本文は短文にし、用語の定義・見方・解法手順を分ける。

### 高校以上

- 専門用語を使用してよい。
- ただしモーダル内では、定義、使い方、注意点、例を分ける。
- 長文説明ではなく、問題直前に確認できる要約にする。

## 置換処理の禁止事項

文字表示の自動調整では、次を禁止する。

| 禁止例 | 理由 | 修正方針 |
| --- | --- | --- |
| `算かず・かず学` | `数` だけを機械的に置換している | 教科名は文単位・語単位で `さんすう` に変換 |
| `じゅん番` | 熟語の一部だけを置換している | `順番` 全体を `じゅんばん` に変換 |
| `もんだい文` | 熟語の一部だけを置換している | `問題文` 全体を `もんだいぶん` に変換 |
| `たしかめする` | 名詞化した語に `する` が残っている | `確認する` 全体を `たしかめる` に変換 |
| `Math G1 U02` | 内部IDが表示されている | `1年 さんすう` または単元名を表示 |
| `Upper Math Num Expr` | 内部ID由来の英字名 | 日本語のカテゴリ名・単元名に変換 |

## 内容精査チェック

各単元の原稿を次の順で見る。

1. 単元名がゲーム内の選択肢と一致しているか。
2. `mode` が実在するか。
3. めあてが単元内容とずれていないか。
4. 考え方が、問題を解く行動に変換できるか。
5. よくあるまちがいが、その単元の誤答と対応しているか。
6. 例が短く、学年相応か。
7. 低学年で未習漢字・交ぜ書き・機械置換がないか。
8. 高学年以上で説明が幼すぎないか。
9. スマホ横画面でタイトルが大きすぎないか。
10. スクロール時に戻るボタンや閉じるボタンが本文に重ならないか。

## 表示確認ビューポート

## 実装修正時の注意

- 低学年向け文字調整は、漢字1文字だけを広く置換しない。
- 先に長い語句を置換し、短い語句は最後にする。
- 教科名・単元名は本文と別扱いにする。
- `unitLabel` がある場合は、原則 `unitLabel` を優先する。
- `mode` 由来の英字名をそのままタイトル化しない。
- 既読判定キーは `summary.id` に依存するため、タイトル調整だけでIDが不必要に変わらないようにする。
- レイアウト調整は `UnitBoardModal.tsx` の構造と `styles.css` の横画面メディアクエリを両方確認する。
