# 校長対決：ゲスト主人公・アクション拡張

## 主人公の解放

- 赤ジャージの勇者：初期から利用可能。
- 叛逆の高校生：既存主人公で通常の7ステージをクリアすると解放。
- 星宮あかり：叛逆の高校生で通常の7ステージをクリアすると解放。
- 過去にクリア済みのセーブは、既存の難易度解放または通常クリア記録から高校生の解放を引き継ぐ。
- エンドレス・デバッグ・UIプレビューでは新しい主人公を解放しない。
- 実行中の主人公・資源・カード効果はセーブと再開に対応。古いセーブは元の主人公・資源0として復元する。

## それぞれ80種類の専用カード

内訳：基本6枚、18系統×4派生72枚、奥義2枚。派生は名前だけの違いではなく、CD・威力・資源獲得・シールド・資源消費が異なる。

- 速攻：短いCDと低い威力。
- 蓄勢：闘志／星光を多く獲得。
- 連携：攻撃強化と追加シールド。
- 解放：最大3の資源を消費し、攻撃または防御を強化。
- 奥義：最大10の資源を消費する終盤の全体攻撃。ステージ6以降の報酬に登場。

系統：連撃、突進、すり抜け、前後攻撃、反撃、押し出し、引き寄せ、反動後退、最遠狙撃、貫通、行動遅延、吸収、防御、次回攻撃強化、回復、CD短縮、バリア、反転退避。

高校生は近距離の攻撃力、あかりは射程と防御・回復・再詠唱を強めている。通常移動・特殊アクション成功で資源+1。資源は上限10で、ゲージに表示される。専用カードによる増減は各説明文を参照。

初期デッキは各3枚。専用カードは使用中の主人公の報酬にだけ登場し、ステージ進行で種類が増える。ゲストの報酬は3択とし、未所持の専用カードが候補にあれば最低1枚を提示する。タイトル画面から全80枚の説明・イラストを閲覧できる。既存のカード図鑑では発見状態を維持する。

## 固有の特殊アクション

| 主人公 | 特殊アクション |
| --- | --- |
| 既存主人公 | 目の前の敵との位置交換。従来の挙動を維持。 |
| 叛逆の高校生 | 敵自身の向きを基準に背後のマスへ回り込み、敵の方を向く。敵は移動しない。 |
| 星宮あかり | 目の前の敵へ前進すると、最大3マス押し出して元の敵のマスへ進む。特殊アクションボタンでも発動可能。 |

CDは3。壁・他の生きた敵で行き先が塞がっている場合、または既に敵の背後にいる場合は不発。失敗時に移動・ターン・CDを消費しない。押し出しは別の敵を貫通せず、画面外にも押し出さない。

## 美術と表示

- 専用タイトルキーアート、ゲスト主人公の待機・被弾・勝利ポーズ、専用カードのアクション絵をImageGenで生成。
- 地面は校庭・廊下・屋上・図書室・体育館・校長室の6素材をImageGenで生成。
- 四角い枠と四角い背景を廃止し、楕円形の地面を足元に配置。
- 自分のマスは水色、攻撃予告のマスは赤い輪と「!」で識別。地面に1〜7のマス番号を表示。
- 日本語・ひらがな・英語に対応。画像自体にUI文言を焼き込まない。

生成プロンプトは `docs/kocho-imagegen-prompts.md`、原画は `docs/assets/kocho/`、ゲーム用画像は `public/sprites/kocho/`。再切り出し：`node scripts/prepare-kocho-sprites.mjs`。生成時の原画PNGがない環境では同梱の原画WebPを使う。

## 検証

`pnpm run test:kocho:browser` は実際の戦闘実行関数で160種類すべてのダメージ・回復・シールド・資源・バリア・次回強化・CD短縮を確認する。テスト用の状態注入はViteテストプラグイン内だけにあり、製品コードには含まれない。

同テストで解放順序、重複記録防止、古いセーブ、元主人公の位置交換、左右両方向の背後移動、押し出し、移動先衝突、プレビュー時の進捗保護、縦横表示、英語の説明を検証する。スクリーンショットは `tmp/kocho-qa/` に保存。

全体確認：`pnpm run audit:english:gate`、`pnpm run build`。

この作業ではGitHubへのpush、ネイティブアプリ作成、ストアへのアップロードは行わない。
