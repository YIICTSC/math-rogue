## C01 地図の縮尺：実際の距離に直す

- 設計ID: `EXP_C01` ／ 第3期 ／ 小6 ／ 細分化
- 既存との対応: 地図帳の使い方（`SOCIAL_4_U07`）、拡大図 と 縮図（`MATH_G6_U07`）
- 独立させる内容: 地図帳の知識から縮尺の数量操作を独立させる
- 学習目標: 縮尺と長さの単位を使って距離を求める
- 前提知識: 縮図・単位換算
- 問題例: 縮尺1：25,000の地図で4cm。実際の距離は？
- 正解: **1km**
- 解説: 4×25,000＝100,000cm＝1,000m＝1km。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 100m | cmからmへの変換を誤る |
| 10km | 桁を1つ増やす |
| 25km | 地図上の長さを掛けない |

## C02 地図の凡例：通れる道を判断する

- 設計ID: `EXP_C02` ／ 第3期 ／ 小4〜5 ／ 細分化
- 既存との対応: 地図の見方（`SOCIAL_3_U02`）
- 独立させる内容: 地図記号の暗記から凡例に基づく判断へ分ける
- 学習目標: 凡例と経路条件を対応させる
- 前提知識: 方位・地図記号
- 問題例: 地図の凡例で実線は歩道、点線は工事中で通行不可。目的地まで選ぶべき道は？
- 正解: **実線の歩道だけを通る経路**
- 解説: 距離だけでなく、凡例が示す通行可否を満たす必要がある。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 短ければ点線を通る経路 | 通行条件を無視する |
| 必ず北へ進む経路 | 方位を目的化する |
| 凡例を見ず直線で進む経路 | 地図の条件を使わない |

## C03 雨温図：降水量の季節差を読む

- 設計ID: `EXP_C03` ／ 第3期 ／ 小5〜中1 ／ 細分化
- 既存との対応: 日本の気候（`SOCIAL_5_U02`）
- 独立させる内容: 気候名の暗記から資料で言える範囲の読解へ分ける
- 学習目標: 月別降水量から季節の特徴を説明する
- 前提知識: 棒グラフ・月
- 問題例: ある地点の降水量は1月20mm、7月200mm。示された資料から言えるのは？
- 正解: **7月は1月より180mm多い**
- 解説: 200−20＝180mm。2か月の値だけでは国や毎年の量を断定できない。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| この地点は必ず日本である | 2点の値だけで国を断定する |
| 7月は1月の2倍 | 倍率を誤る |
| 毎年必ず同じ量が降る | 観測値を固定的法則とする |

## C04 食料自給率：分母を確かめる

- 設計ID: `EXP_C04` ／ 第3期 ／ 小5〜6 ／ 細分化
- 既存との対応: 食料問題（`SOCIAL_5_U09`）
- 独立させる内容: 食料問題から指標の基準と単位の読み取りを独立させる
- 学習目標: 指標が何を基準に計算されたか確認する
- 前提知識: M10・食料生産
- 問題例: 重量で比べるとし、消費100kgのうち国内産40kgなら重量ベースの自給率は？
- 正解: **40％**
- 解説: 重量という基準を明示して40÷100×100＝40％。カロリーベース等とは区別する。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 60％ | 輸入の割合を答える |
| 250％ | 分母を逆にする |
| 40kg | 量と割合を混同する |

## C05 歴史：出来事の順と因果を分ける

- 設計ID: `EXP_C05` ／ 第3期 ／ 小6〜中1 ／ 細分化
- 既存との対応: 明治時代（`SOCIAL_6_U09`）
- 独立させる内容: 時代別知識から年表の証拠の使い方を独立させる
- 学習目標: 年表上の前後関係と原因の断定を区別する
- 前提知識: 年表・前後の比較
- 問題例: 資料に「Aは1868年、Bは1872年」とだけある。必ず言えるのは？
- 正解: **AはBより先に起きた**
- 解説: 年表から分かるのは順序。原因の判断には内容の資料も必要。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| AがBの唯一の原因だ | 前後を因果とする |
| BがAを引き起こした | 時間関係を逆にする |
| 2つは同じ年だ | 年を読み落とす |

## C06 三権：担当する機関を場面から選ぶ

- 設計ID: `EXP_C06` ／ 第4期 ／ 小6〜中3 ／ 細分化
- 既存との対応: 国会（`SOCIAL_6_U13`）、内閣（`SOCIAL_6_U14`）、裁判所（`SOCIAL_6_U15`）
- 独立させる内容: 3つの既存単元を役割の対比として再編する
- 学習目標: 機関名の暗記を具体的な役割に結び付ける
- 前提知識: 国会・内閣・裁判所
- 問題例: 裁判を通して法律に基づき争いを解決するのは？
- 正解: **裁判所**
- 解説: 裁判所が司法を担当する。国会は立法、内閣は行政を担う。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 国会 | 立法と司法を混同する |
| 内閣 | 行政と司法を混同する |
| 選挙管理委員会 | 選挙事務と司法を混同する |

## C07 税と公共サービス：みんなで負担する理由

- 設計ID: `EXP_C07` ／ 第4期 ／ 小6〜中3 ／ 細分化
- 既存との対応: 税金（`SOCIAL_9_U10`）
- 独立させる内容: 税の名称から負担と公共性の理由に絞る
- 学習目標: 共同利用するサービスと税の関係を説明する
- 前提知識: 公共施設・費用
- 問題例: 地域の道路や消防を税で支える主な理由として適切なのは？
- 正解: **多くの人の暮らしを支えるサービスを共同で負担するため**
- 解説: 個人だけでは維持しにくい共同の仕組みを税で支えている。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 利用者以外は影響を受けないから | 公共性を見落とす |
| 税を払えば道路を私物化できるから | 共同利用を所有と混同する |
| 費用が一切かからないから | 必要経費を無視する |

## C08 多数決：最多票と過半数の違い

- 設計ID: `EXP_C08` ／ 第4期 ／ 中3 ／ 細分化
- 既存との対応: 選挙（`SOCIAL_9_U09`）
- 独立させる内容: 選挙制度から集計用語の意味を独立させる
- 学習目標: 最多得票と全体の半分超を区別する
- 前提知識: 割合・選挙
- 問題例: 100票の内訳がA45票、B35票、C20票。Aについて正しいものは？
- 正解: **最多票だが過半数ではない**
- 解説: 過半数は50票を超えること。45票は最多でも過半数でない。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 過半数である | 最多を半分超とする |
| ちょうど半数である | 45と50を混同する |
| 最少得票である | 大小を逆にする |

## C09 需要と供給：条件を固定した価格変化

- 設計ID: `EXP_C09` ／ 第4期 ／ 中3 ／ 細分化
- 既存との対応: 市場経済（`SOCIAL_9_U11`）
- 独立させる内容: 市場経済全般から条件付きの変化方向に絞る
- 学習目標: 他条件一定という前提付きで市場を考える
- 前提知識: 価格・需要と供給
- 問題例: 他の条件が同じで、人気が高まり買いたい人だけが増えた。一般に価格にはどんな圧力がかかる？
- 正解: **上がる方向**
- 解説: 供給などが変わらなければ需要増は価格を押し上げる方向に働く。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 下がる方向 | 需要増の向きを逆にする |
| 必ず半額になる | 具体的な値を断定する |
| 売り手がいなくなる | 需要と供給を混同する |

## C10 統計資料：年・地域・単位をそろえる

- 設計ID: `EXP_C10` ／ 第4期 ／ 中2〜3 ／ 細分化
- 既存との対応: 日本の人口（`SOCIAL_7_U13`）
- 独立させる内容: 人口の知識から資料比較の前提チェックを独立させる
- 学習目標: 異なる資料を比較する前に定義を確認する
- 前提知識: 表の見出し・単位
- 問題例: A市の2020年人口とB市の2025年世帯数を、そのまま人口の大小として比べてよい？
- 正解: **年と指標が違うので、そのままでは比べられない**
- 解説: 時点・地域範囲・指標の定義を合わせて比較する。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 数字が大きい方が人口も多い | 単位を無視する |
| 同じ国内なら必ず比べられる | 指標の違いを無視する |
| 年だけ合わせればよい | 人口と世帯数を混同する |
