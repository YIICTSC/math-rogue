# 国語の単元設計

[全体設計へ](README.md)

対象学年は配列を決めるための目安です。低学年の語彙・表記や学習指導要領上の配当は作問時に確認します。問題例は設問の核を示す原稿で、ゲーム登録前の教育内容レビューを要します。

## J01 指示語：何を指すかを本文から探す

- 設計ID: `EXP_J01` ／ 第1期 ／ 小3〜4 ／ 細分化
- 既存との対応: 説明文の読み取り（`KOKUGO_G3_U05`）
- 独立させる内容: 説明文読解から照応関係の解決を独立させる
- 学習目標: 指示語を具体的な語句に置き換える
- 前提知識: 短文読解
- 問題例: 「花子は赤い傘を買った。それを玄関に置いた。」の「それ」は何？
- 正解: **赤い傘**
- 解説: 置ける物を前の文から探すと「赤い傘」。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 花子 | 近くの人名を選ぶ |
| 玄関 | 後ろの語を選ぶ |
| 買うこと | 物と動作を混同する |

## J02 接続語：原因と結果のつながり

- 設計ID: `EXP_J02` ／ 第1期 ／ 小3〜4 ／ 細分化
- 既存との対応: 説明文の読み取り（`KOKUGO_G3_U05`）
- 独立させる内容: 説明文から接続関係の判断に絞る
- 学習目標: 因果・逆接に合う接続語を選ぶ
- 前提知識: 2文の意味の理解
- 問題例: 「雨が降った。（　）、運動会は延期になった。」に合うのは？
- 正解: **そのため**
- 解説: 雨が原因で延期が結果なので因果を示す「そのため」。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| しかし | 逆接にする |
| また | 並列にする |
| たとえば | 例示にする |

## J03 説明の順序：手順を入れ替えない

- 設計ID: `EXP_J03` ／ 第1期 ／ 小3〜4 ／ 細分化
- 既存との対応: 順序よく話す（`KOKUGO_G2_U11`）
- 独立させる内容: 順序よく話す学習を手順文の読解・検証へ細分化する
- 学習目標: 条件を読み、作業順序を組み立てる
- 前提知識: 順序を表す言葉
- 問題例: 説明書に「種をまいた後に水をやる」とある。合う順序は？
- 正解: **種をまく→水をやる**
- 解説: 「後に」が指定する前後関係をそのまま並べる。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 水をやる→種をまく | 前後を逆にする |
| 水をやるだけ | 必要な手順を落とす |
| 種をまく前に必ず水をやる | 書かれていない条件を足す |

## J04 事実と意見：確かめられる表現

- 設計ID: `EXP_J04` ／ 第1期 ／ 小5〜6 ／ 細分化
- 既存との対応: 意見文を書く（`KOKUGO_G5_U06`）
- 独立させる内容: 意見文の作成から事実・評価の識別を独立させる
- 学習目標: 観測できる事実と評価を区別する
- 前提知識: 文の要点
- 問題例: 「来場者は30人だった。とても楽しい会だった。」で事実を述べた文は？
- 正解: **来場者は30人だった**
- 解説: 人数は記録で確認できる。「楽しい」は人による評価。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| とても楽しい会だった | 感想を事実とする |
| 両方とも意見 | 数えられる情報を無視する |
| 両方とも必ず事実 | 評価も全員共通と考える |

## J05 要約：条件と結論を落とさない

- 設計ID: `EXP_J05` ／ 第1期 ／ 小5〜6 ／ 細分化
- 既存との対応: 要約と要旨（`KOKUGO_G5_U05`）
- 独立させる内容: 要約全般から条件・例外の保持を重点化する
- 学習目標: 中心となる結論と条件を保って短くする
- 前提知識: 主題・要点
- 問題例: 「図書館は通常17時までだが、土曜は15時に閉まる。」の要約として正しいものは？
- 正解: **通常17時まで、土曜は15時まで**
- 解説: 通常と土曜の両方を残すと、利用に必要な情報を保てる。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 毎日17時まで | 例外条件を落とす |
| 毎日15時まで | 土曜だけの条件を全体に広げる |
| 土曜は開館しない | 本文にない内容を足す |

## J06 同訓異字：文脈で漢字を選ぶ

- 設計ID: `EXP_J06` ／ 第2期 ／ 小4〜5 ／ 細分化
- 既存との対応: 漢字の使い方（`KOKUGO_G4_U01`）
- 独立させる内容: 既存の漢字使い分け問題を文脈判断の子単元として分離する
- 学習目標: 同じ読みの漢字を対象に合わせて選ぶ
- 前提知識: 漢字の意味
- 問題例: 「時計をなおす」「けがをなおす」の漢字の組合せは？
- 正解: **時計を直す／けがを治す**
- 解説: 物の故障や誤りには「直す」、病気やけがには「治す」を使う。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 時計を治す／けがを直す | 対象を逆にする |
| 時計を直す／けがを直す | 病気やけがにも直すを使う |
| 時計を治す／けがを治す | 物の修理にも治すを使う |

## J07 熟語の構成：どちらがどちらを説明するか

- 設計ID: `EXP_J07` ／ 第2期 ／ 小4〜5 ／ 細分化
- 既存との対応: 熟語（`KOKUGO_G4_U02`）
- 独立させる内容: 熟語の読み・意味から構成の分類を独立させる
- 学習目標: 漢字間の意味の関係を説明する
- 前提知識: 漢字の意味
- 問題例: 「強風」の漢字の関係として正しいものは？
- 正解: **前の漢字が後の漢字を詳しくする**
- 解説: 「強い風」と読めるので「強」が「風」を説明する。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 反対の意味を重ねる | 上下型と混同する |
| 同じ意味を重ねる | 森林型と混同する |
| 動作とその相手 | 読書型と混同する |

## J08 敬語：動作の主体を見分ける

- 設計ID: `EXP_J08` ／ 第2期 ／ 小5〜6 ／ 細分化
- 既存との対応: 敬語（`KOKUGO_G5_U02`）
- 独立させる内容: 敬語一覧から動作主体の確認を独立させる
- 学習目標: 相手の動作と自分の動作で敬語を使い分ける
- 前提知識: 主語・基本敬語
- 問題例: 先生が話したことを表す文として適切なのは？
- 正解: **先生がおっしゃった**
- 解説: 相手である先生の「言う」には尊敬語「おっしゃる」を使う。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 先生が申した | 相手に謙譲語を使う |
| 先生が申し上げた | 話者側の謙譲と混同する |
| 先生が参った | 別の動作の敬語にする |

## J09 否定の範囲：全部と一部の違い

- 設計ID: `EXP_J09` ／ 第2期 ／ 小6〜中1 ／ 細分化
- 既存との対応: 文の成分（主語・述語など）（`KOKUGO_G7_U06`）
- 独立させる内容: 文の構造から量化と否定の範囲を切り出す
- 学習目標: 部分否定と全体否定を区別する
- 前提知識: 主語と述語・否定文
- 問題例: 「全員が賛成したわけではない」から必ず言えることは？
- 正解: **賛成しなかった人がいる**
- 解説: 否定されているのは「全員が賛成した」ということ。反対の人数までは分からない。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 全員が反対した | 部分否定を全体否定にする |
| 全員が賛成した | 否定を読み落とす |
| ちょうど半分が反対した | 人数を補ってしまう |

## J10 引用：誰の発言かを区別する

- 設計ID: `EXP_J10` ／ 第2期 ／ 小5〜6 ／ 細分化
- 既存との対応: 報告文を書く（`KOKUGO_G5_U07`）
- 独立させる内容: 報告文から情報の発信者・引用境界の特定を分離する
- 学習目標: 引用文と書き手の説明を区別する
- 前提知識: かぎ括弧の読み方
- 問題例: 「先生は『明日は休みです』と言った。私はうれしかった。」で休みと伝えたのは？
- 正解: **先生**
- 解説: 「先生は」と「と言った」が引用した発言の主を示す。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 私 | 書き手と引用元を混同する |
| 友達 | 本文にない人物を加える |
| 分からない | 発言者の表示を見落とす |

## J11 推論：本文の根拠を付ける

- 設計ID: `EXP_J11` ／ 第3期 ／ 中1 ／ 細分化
- 既存との対応: 物語文の読み取り（`KOKUGO_G7_U01`）
- 独立させる内容: 物語読解から根拠のある推測と断定を区別する
- 学習目標: 明示情報から無理のない推論を選ぶ
- 前提知識: 指示語・心情表現
- 問題例: 「太郎は何度も時計を見て、改札の方を見つめた。」から根拠が最もある推測は？
- 正解: **誰かや何かを待っている**
- 解説: 時計と改札への注目は待つ行動と結び付くが、理由の断定はできない。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 昨日試合に勝った | 無関係な背景を足す |
| 必ず電車が遅れている | 原因を断定する |
| 時計が壊れたと確定できる | 可能性を事実にする |

## J12 反論：相手の主張に応答する

- 設計ID: `EXP_J12` ／ 第3期 ／ 中2 ／ 細分化
- 既存との対応: 討論（`KOKUGO_G8_U11`）
- 独立させる内容: 討論一般から論点の一致を評価する子単元にする
- 学習目標: 論点に対応した反論を選ぶ
- 前提知識: 主張と理由
- 問題例: 「雨の日も本を返せるよう返却箱を屋内に置こう」への、論点に合う反論は？
- 正解: **閉館後に入れず返せなくなるのでは**
- 解説: 返却のしやすさという提案の目的に、利用時間の観点から応答している。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 図書館の壁は白い | 論点を変える |
| 提案者の字が汚い | 人への批判に替える |
| 読書は必ず悪い | 根拠なく話題を広げる |

## J13 根拠と主張：資料は本当に支えているか

- 設計ID: `EXP_J13` ／ 第3期 ／ 中2〜3 ／ 細分化
- 既存との対応: 意見文（`KOKUGO_G8_U09`）
- 独立させる内容: 意見文から証拠と結論の対応を独立させる
- 学習目標: 根拠が主張を支持する範囲を判断する
- 前提知識: J04・表の読み方
- 問題例: 「昼の利用者が増えた」という資料だけで「朝の開館を早めるべき」と言える？
- 正解: **朝の利用希望など追加の根拠が必要**
- 解説: 昼の資料は昼の需要を示すが、朝の需要は別に確かめる必要がある。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 昼が増えれば朝も必ず増える | 時間帯を一般化する |
| 利用者資料は一切役立たない | 資料の役割を全否定する |
| 人数が多ければどんな提案も正しい | 根拠と結論の対応を無視する |

## J14 条件文：例外を含むルールの読解

- 設計ID: `EXP_J14` ／ 第3期 ／ 中1〜2 ／ 細分化
- 既存との対応: 説明文の読み取り（`KOKUGO_G7_U02`）
- 独立させる内容: 説明文から条件・例外の適用を独立させる
- 学習目標: ただし書きの適用範囲を判断する
- 前提知識: J05・否定表現
- 問題例: 「全員参加。ただし欠席届を出した人は除く。」欠席届を出した人の参加義務は？
- 正解: **この規則では参加義務がない**
- 解説: 「ただし」が、前の原則から除く条件を示す。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 必ず参加しなければならない | 例外を無視する |
| 全員参加しなくてよい | 例外を全体に広げる |
| 欠席届を出さなくてもよい | 条件を消す |

## J15 言い換え：程度と範囲を変えない

- 設計ID: `EXP_J15` ／ 第3期 ／ 中3 ／ 細分化
- 既存との対応: 要約（`KOKUGO_G9_U08`）
- 独立させる内容: 要約から程度・範囲・確実性の保存を重点化する
- 学習目標: 要約で確実性や対象範囲を保つ
- 前提知識: J09・J13
- 問題例: 「一部の商品は値上がりする可能性がある」の言い換えとして適切なのは？
- 正解: **値上がりする商品が出るかもしれない**
- 解説: 「一部」と「可能性」を保つ表現を選ぶ。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 全商品が必ず値上がりする | 範囲と確実性を強める |
| 値上がりする商品はない | 意味を逆にする |
| すべての商品が値下がりする | 対象と方向を変える |
