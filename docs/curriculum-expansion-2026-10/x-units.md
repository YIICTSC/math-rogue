# 教科融合の単元設計

[全体設計へ](README.md)

対象学年は配列を決めるための目安です。低学年の語彙・表記や学習指導要領上の配当は作問時に確認します。問題例は設問の核を示す原稿で、ゲーム登録前の教育内容レビューを要します。

## X01 備蓄計画：人数・日数・必要量

- 設計ID: `EXP_X01` ／ 第4期 ／ 小6〜中1 ／ 教科融合
- 既存との対応: 比 と その 利用（`MATH_G6_U05`）、災害とくらし（`SOCIAL_4_U06`）
- 独立させる内容: 防災の条件読解と比例による計画を合わせる
- 学習目標: 防災資料の数値から必要量を計画する
- 前提知識: M17・L04
- 問題例: 訓練上の目安を1人1日3Lとする。4人で3日分の水は？
- 正解: **36L**
- 解説: 3×4×3＝36L。訓練条件に基づく計画で、現実の備蓄は地域の案内も確認する。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 12L | 人数だけ掛ける |
| 9L | 日数だけ掛ける |
| 10L | 数を足す |

## X02 避難計画：通れる道の中で所要時間を比べる

- 設計ID: `EXP_X02` ／ 第4期 ／ 小6〜中1 ／ 教科融合
- 既存との対応: 速さ（`MATH_G5_U10`）、災害とくらし（`SOCIAL_4_U06`）
- 独立させる内容: 計算前に経路の条件を判定する2段階の融合課題にする
- 学習目標: 危険条件を満たした経路の時間を比較する
- 前提知識: M15・C02・L04
- 問題例: 訓練で橋は通行不可。A道は橋経由600m、B道は安全な900m。分速60mなら選ぶ経路と時間は？
- 正解: **B道で15分**
- 解説: まず安全条件でAを除き、900÷60＝15分と計算する。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| A道で10分 | 通行不可を無視する |
| B道で9分 | 速さの計算を誤る |
| A道で15分 | 経路と時間を混同する |

## X03 実験報告：平均と結論をつなぐ

- 設計ID: `EXP_X03` ／ 第4期 ／ 中1〜2 ／ 教科融合
- 既存との対応: 平均（`MATH_G5_U08`）、植物の発芽と成長（`SCIENCE_5_U03`）、報告文を書く（`KOKUGO_G5_U07`）
- 独立させる内容: 平均計算と科学的な限定表現を同時に評価する
- 学習目標: 繰り返し測定を要約し、結論の範囲を示す
- 前提知識: M09・S03・J04
- 問題例: 同じ条件で伸びを3回測り4cm、5cm、6cmだった。適切な報告は？
- 正解: **この3回の平均は5cmだった**
- 解説: 合計15÷3＝5cm。対象と測定回数を残して報告する。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 毎回必ず5cm伸びる | 平均を各回の値にする |
| 全植物が5cm伸びる | 対象を一般化する |
| 平均は15cmだった | 合計を平均とする |

## X04 包装設計：面積から材料を見積もる

- 設計ID: `EXP_X04` ／ 第4期 ／ 小6 ／ 教科融合
- 既存との対応: 面せき（`MATH_G4_U08`）、環境問題（`SOCIAL_5_U08`）
- 独立させる内容: 面積換算を材料計画へ接続し、使用量と環境負荷の同一視は避ける
- 学習目標: 同条件で包装材料の使用量を比較する
- 前提知識: 面積・単位
- 問題例: のりしろと重なりを無視すると、箱1個に600cm²の紙を使う。10個には何m²必要？
- 正解: **0.6m²**
- 解説: 6,000cm²。1m²＝10,000cm²なので0.6m²。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 6m² | 面積の換算を10倍と考える |
| 60m² | cmとmの換算をそのまま使う |
| 0.06m² | 桁を1つ余分に下げる |

## X05 旅の支払い：英語の料金表と換算

- 設計ID: `EXP_X05` ／ 第4期 ／ 中2〜3 ／ 教科融合
- 既存との対応: 長文読解（`ENGLISH_G9_U08`）、小数の かけ算（`MATH_G5_U03`）
- 独立させる内容: 英語読解と費用の合算・単位換算を組み合わせる
- 学習目標: 英語の料金条件を読み、与えられた換算率で計算する
- 前提知識: 英語の基本料金語・小数の乗法
- 問題例: 料金表は「Ticket $8 + service fee $2」。1ドル150円で、他の費用なし。合計は？
- 正解: **1,500円**
- 解説: チケットと手数料で10ドル。10×150＝1,500円。換算率は設問の架空条件。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 1,200円 | feeを読み落とす |
| 300円 | 手数料だけ換算する |
| 10円 | 通貨の単位を無視する |

## X06 電気代：電力・時間・単価のつながり

- 設計ID: `EXP_X06` ／ 第4期 ／ 中2〜3 ／ 教科融合
- 既存との対応: 電流（`SCIENCE_8_U07`）、単位量あたりの 大きさ（`MATH_G5_U09`）
- 独立させる内容: 物理量の関係と単位量料金の計算を接続する
- 学習目標: 電力量を求め、与えられた料金条件で計算する
- 前提知識: 単位量・時間換算
- 問題例: 1kWの機器を2時間使う。1kWh30円で基本料等を考えない場合、料金は？
- 正解: **60円**
- 解説: 電力量は1×2＝2kWh、2×30＝60円。料金は与件であり実際の契約額とは分ける。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 30円 | 利用時間を無視する |
| 15円 | 時間で割る |
| 600円 | 単位の桁を誤る |

## X07 アンケート改善：偏りを減らす提案

- 設計ID: `EXP_X07` ／ 第4期 ／ 中2〜3 ／ 教科融合
- 既存との対応: 標本調査（`MATH_G9_U09`）、意見文（`KOKUGO_G8_U09`）
- 独立させる内容: 統計の批判を改善提案という文章判断へつなげる
- 学習目標: 抽出の問題を根拠に調査計画を改善する
- 前提知識: M20・J13
- 問題例: 全校の図書館への要望を調べるのに図書委員だけへ質問した。改善案は？
- 正解: **各学年・学級から偏りを抑えて回答者を選ぶ**
- 解説: 対象の偏りを説明し、全校の意見を拾える抽出に変える。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 図書委員に同じ質問を10回する | 人数と代表性を混同する |
| 結論に合う回答だけ残す | 結果を選別する |
| 質問の文字を大きくするだけ | 抽出の問題を直さない |

## X08 投票結果：数値で主張を検証する

- 設計ID: `EXP_X08` ／ 第4期 ／ 中3 ／ 教科融合
- 既存との対応: 選挙（`SOCIAL_9_U09`）、論説文を書く（`KOKUGO_G9_U09`）、割合（`MATH_G5_U14`）
- 独立させる内容: 公民用語・割合・根拠付き反論を一問で統合する
- 学習目標: 最多票の結果から言える主張を選ぶ
- 前提知識: C08・J13・割合
- 問題例: 100票中A45、B35、C20。「全投票者の過半数がAを支持」は正しい？
- 正解: **誤り。Aは最多票だが過半数ではない**
- 解説: 45％は50％を超えない。結論とその理由の両方をそろえる。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 正しい。1位なら過半数である | 順位と割合を混同する |
| 正しい。45は35より多い | 別候補との比較だけで判断する |
| 誤り。Aは最少得票である | 否定の理由を誤る |

## X09 食品表示：1食分への換算

- 設計ID: `EXP_X09` ／ 第4期 ／ 中1〜2 ／ 教科融合
- 既存との対応: 料理・栄養（`UPPER_PRACTICAL_COOK_NUTRITION`）、比 と その 利用（`MATH_G6_U05`）
- 独立させる内容: 食品表示の読解と比例計算を統合する
- 学習目標: 表示の基準量と実際に食べる量を区別する
- 前提知識: 比例・小数
- 問題例: 架空の食品表示は100gあたり食塩相当量2g。30g分の食塩相当量は？
- 正解: **0.6g**
- 解説: 2×30/100＝0.6g。個人の適正摂取量や健康状態の判断はしない。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 2g | 表示基準量をそのまま使う |
| 6g | 割合を10倍にする |
| 60g | 単位を混同する |

## X10 企画計画：予算と締切を同時に満たす

- 設計ID: `EXP_X10` ／ 第4期 ／ 中2〜3 ／ 教科融合
- 既存との対応: プロジェクト管理（`UPPER_ESSAY_PROJECT_MANAGEMENT`）、説明文の読み取り（`KOKUGO_G7_U02`）、文字式（`MATH_G7_U04`）
- 独立させる内容: 文章の条件抽出と数量による案の比較を統合する
- 学習目標: 複数の条件を満たす案を選び理由を述べる
- 前提知識: L01・J14・条件整理
- 問題例: 予算3,000円、準備期限2日。A案2,500円・3日、B案2,800円・2日、C案3,200円・1日。選べるのは？
- 正解: **B案**
- 解説: Bだけが金額3,000円以下と日数2日以下の両方を満たす。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| A案 | 費用だけを見る |
| C案 | 日数だけを見る |
| 全部選べる | 複数条件を同時に見ない |
