## S01 対照実験：変える条件を1つにする

- 設計ID: `EXP_S01` ／ 第2期 ／ 小5 ／ 細分化
- 既存との対応: 植物の発芽と成長（`SCIENCE_5_U03`）
- 独立させる内容: 発芽の知識から実験計画の妥当性を独立させる
- 学習目標: 調べたい条件以外をそろえる
- 前提知識: 植物の発芽・観察記録
- 問題例: 水の有無で発芽が変わるか調べる。そろえる条件は？
- 正解: **種の種類と温度など、水以外の条件**
- 解説: 水だけを変え、他をそろえると違いの原因を考えやすい。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 水だけ同じにする | 調べる条件を固定する |
| 温度も種も変える | 複数条件を同時に変える |
| 結果が出た種だけ記録する | 都合のよい結果だけ選ぶ |

## S02 観測記録：同じ時刻で比べる

- 設計ID: `EXP_S02` ／ 第2期 ／ 小4 ／ 細分化
- 既存との対応: 天気と気温（`SCIENCE_4_U01`）
- 独立させる内容: 天気と気温から公平な測定条件に絞る
- 学習目標: 気温比較で観測条件をそろえる
- 前提知識: 気温の読み取り
- 問題例: 2日間の昼の気温を比べたい。適切な測り方は？
- 正解: **同じ場所・同じ時刻・同じ測り方で測る**
- 解説: 場所・時刻・測り方をそろえて比較する。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 片方だけ日なたで測る | 場所の条件を変える |
| 一方は朝、他方は昼に測る | 時刻の条件を変える |
| 高い値だけ記録する | 記録を選別する |

## S03 実験結果：言えることと言えないこと

- 設計ID: `EXP_S03` ／ 第2期 ／ 小5〜6 ／ 細分化
- 既存との対応: 植物の発芽と成長（`SCIENCE_5_U03`）
- 独立させる内容: 発芽から結果解釈と一般化の範囲を独立させる
- 学習目標: 観測した範囲を超えて断定しない
- 前提知識: S01・表の読み方
- 問題例: 同じ種類の種を水あり・なしで3個ずつ試した。水ありだけ発芽した。適切な結論は？
- 正解: **この実験条件では水ありの方に発芽が見られた**
- 解説: 観察できた条件と個数の範囲を明示し、繰り返して確かめる。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 全ての植物は必ず同じ結果になる | 対象範囲を広げすぎる |
| 水以外は全く関係しない | 未検証条件を否定する |
| 今後の実験は不要 | 少数の結果だけで確定する |

## S04 溶解：見えなくなっても質量は残る

- 設計ID: `EXP_S04` ／ 第2期 ／ 小5 ／ 細分化
- 既存との対応: 物のとけ方（`SCIENCE_5_U08`）
- 独立させる内容: 溶け方の知識から物質量の保存を切り出す
- 学習目標: 溶質が溶けた後の全体質量を求める
- 前提知識: 質量の加法・溶解
- 問題例: 水100gに食塩10gを全て溶かし、こぼれも蒸発もない。全体の質量は？
- 正解: **110g**
- 解説: 溶けても食塩の質量は残り、100＋10＝110g。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 100g | 見えない食塩を消えたと考える |
| 90g | 溶けた分を引く |
| 10g | 溶質だけ答える |

## S05 測定器：温度計の読み方

- 設計ID: `EXP_S05` ／ 第2期 ／ 小4 ／ 細分化
- 既存との対応: 天気と気温（`SCIENCE_4_U01`）
- 独立させる内容: 気温の知識から測定操作と視差を独立させる
- 学習目標: 目盛りに対する視線の位置を選ぶ
- 前提知識: 温度の単位・目盛り
- 問題例: 液体温度計の目盛りを読むとき、視線はどこに置く？
- 正解: **液柱の先端と同じ高さ**
- 解説: 視線を液柱の先端と同じ高さにして目盛りを読む。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 真上 | 斜め読みで誤差が出る |
| 真下 | 斜め読みで誤差が出る |
| 離れるほどよい | 視差の条件を無視する |

## S06 回路：直列と並列の電流の道

- 設計ID: `EXP_S06` ／ 第3期 ／ 小6〜中1 ／ 細分化
- 既存との対応: 電気のはたらき（`SCIENCE_4_U05`）
- 独立させる内容: 回路単元から経路の独立性を診断する。図示を必須とする
- 学習目標: 回路を切ったときの通り道を考える
- 前提知識: 閉回路
- 問題例: 電池と同じ豆電球2個を並列につないだ。一方の枝だけを切ると、もう一方は？
- 正解: **電流が流れる道が残るので点灯する**
- 解説: 並列では枝ごとに電池へ戻る通り道がある。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 必ず両方消える | 直列と混同する |
| 電池なしでも点灯し続ける | 電源の条件を無視する |
| 電流が逆向きになる | 切断と方向を混同する |

## S08 月の満ち欠け：太陽との位置関係

- 既存との対応: 月と太陽（`SCIENCE_6_U04`）

## S09 食物連鎖：矢印の向きを読む

- 設計ID: `EXP_S09` ／ 第3期 ／ 小6〜中1 ／ 細分化
- 既存との対応: 生き物と環境（`SCIENCE_6_U09`）
- 独立させる内容: 生態の知識から図の凡例と方向の読み取りを独立させる
- 学習目標: 食べられる側から食べる側へ矢印を描く
- 前提知識: 生物と食べ物
- 問題例: 「草をバッタが食べ、バッタをカエルが食べる」。食物の移動を示す矢印は？
- 正解: **草→バッタ→カエル**
- 解説: ここでは食べられるものから食べるものへ矢印を引く。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| カエル→バッタ→草 | 矢印の向きを逆にする |
| 草→カエル→バッタ | 関係を入れ替える |
| バッタ→草→カエル | 食べる関係を取り違える |

## S10 気体の同定：性質を組み合わせる

- 設計ID: `EXP_S10` ／ 第3期 ／ 中1 ／ 細分化
- 既存との対応: 気体の性質（`SCIENCE_7_U05`）
- 独立させる内容: 気体の暗記から複数証拠による識別に分ける
- 学習目標: 1つの性質だけで気体を断定しない
- 前提知識: 代表的気体の性質
- 問題例: 火を消し、石灰水を白く濁らせる気体は？
- 正解: **二酸化炭素**
- 解説: 石灰水を白く濁らせる性質を組み合わせて二酸化炭素と判断する。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 窒素 | 火を消す性質だけで選ぶ |
| 酸素 | 燃焼を助ける気体と混同する |

## S11 密度：体積が違う物質を比べる

- 設計ID: `EXP_S11` ／ 第3期 ／ 中1 ／ 細分化
- 既存との対応: 身のまわりの物質（`SCIENCE_7_U04`）
- 独立させる内容: 物質全般から体積をそろえた比較に特化する
- 学習目標: 質量と体積から物質の密度を求める
- 前提知識: 除法・体積
- 問題例: 質量54g、体積20cm³の物体の密度は？
- 正解: **2.7g/cm³**
- 解説: 密度＝質量÷体積なので54÷20＝2.7g/cm³。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 1,080g/cm³ | 質量と体積を掛ける |
| 0.37g/cm³ | 割る向きを逆にする |
| 34g/cm³ | 差を求める |

## S12 地震：初期微動継続時間の比較

- 設計ID: `EXP_S12` ／ 第3期 ／ 中1 ／ 細分化
- 既存との対応: 地震（`SCIENCE_7_U12`）
- 独立させる内容: 地震の名称から記録比較と推定の範囲へ分ける
- 学習目標: 同条件でS−P時間から距離を比較する
- 前提知識: 時刻差・地震波
- 問題例: 同じ地震の記録でAのS−P時間は3秒、Bは6秒。一般に震源から遠いのは？
- 正解: **B**
- 解説: 同じ伝わり方を仮定すると、P波とS波の到着差が大きいほど遠い。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| A | 時間差と距離の関係を逆にする |
| 必ず同じ | 波の速さの違いを無視する |
| 震央がBだと断定できる | 距離比較だけで位置を確定する |

## S15 運動エネルギー：速さが2倍のとき

- 設計ID: `EXP_S15` ／ 第3期 ／ 中3〜高1 ／ 細分化
- 既存との対応: 仕事とエネルギー（`SCIENCE_9_U09`）、力学演習（`UPPER_SCIENCE_MECHANICS`）
- 独立させる内容: エネルギー全般から条件付きの二乗関係の読解へ分ける
- 学習目標: 式を根拠に速さとエネルギーの変化を比較する
- 前提知識: 比例・式への代入
- 問題例: 同じ質量で運動エネルギーは速さの2乗に比例するとする。速さが2倍なら何倍？
- 正解: **4倍**
- 解説: 2の2乗は4。中学向けは比例関係を問題文に明示する。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 2倍 | 単純比例と考える |
| 8倍 | 3乗と取り違える |
| 変わらない | 速さの影響を無視する |
