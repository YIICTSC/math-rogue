[全体設計へ](README.md)

対象学年は配列を決めるための目安です。低学年の語彙・表記や学習指導要領上の配当は作問時に確認します。問題例は設問の核を示す原稿で、ゲーム登録前の教育内容レビューを要します。

## L01 買い物：予算内に収める

- 設計ID: `EXP_L01` ／ 第1期 ／ 小3〜4 ／ 生活場面への再設計
- 既存との対応: ひき算（3けた・4けた）（`MATH_G3_U04`）、お金・金融（`UPPER_PRACTICAL_MONEY`）
- 独立させる内容: 高校の家計知識を小学生の1回の買い物に再設計する
- 学習目標: 合計金額と残金から購入可否を判断する
- 前提知識: 整数の加減算
- 問題例: 予算500円で180円と240円の商品を買う。残金は？
- 正解: **80円**
- 解説: 180＋240＝420円、500−420＝80円。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 420円 | 支払額を残金とする |
| 260円 | 一方の商品だけ引く |
| 920円 | 合計を予算に足す |

## L02 時刻表：出発と所要時間を読む

- 設計ID: `EXP_L02` ／ 第1期 ／ 小3〜4 ／ 生活場面への再設計
- 既存との対応: 時こく と 時かん（`MATH_G3_U05`）、交通・旅行（`UPPER_PRACTICAL_TRAVEL_TRANSPORT`）
- 独立させる内容: 旅行の広い知識から小学生向け時刻表の数量読解にする
- 学習目標: 時刻と時間を区別して到着を求める
- 前提知識: 時刻・時間の加算
- 問題例: 9時40分発、乗車時間35分のバス。到着予定は？
- 正解: **10時15分**
- 解説: 9時40分に20分で10時、残り15分で10時15分。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 9時75分 | 60分を繰り上げない |
| 10時35分 | 分の扱いを誤る |
| 9時5分 | 所要時間を引く |

## L03 料理：人数に合わせて分量を変える

- 設計ID: `EXP_L03` ／ 第1期 ／ 小6 ／ 生活場面への再設計
- 既存との対応: 比 と その 利用（`MATH_G6_U05`）、料理・栄養（`UPPER_PRACTICAL_COOK_NUTRITION`）
- 独立させる内容: 栄養知識から人数比例だけを扱う生活場面単元にする
- 学習目標: 人数と分量の比例を使う
- 前提知識: 比・分数の乗法
- 問題例: 4人分で米300gの料理を6人分作る。同じ1人分の量なら米は？
- 正解: **450g**
- 解説: 6/4＝1.5倍なので300×1.5＝450g。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 200g | 人数比を逆にする |
| 600g | 倍だと決め付ける |
| 302g | 人数の差を足す |

## L04 防災：条件付きの避難経路を選ぶ

- 設計ID: `EXP_L04` ／ 第1期 ／ 小4〜6 ／ 生活場面への再設計
- 既存との対応: 災害とくらし（`SOCIAL_4_U06`）、防災・安全（`UPPER_PRACTICAL_SAFETY`）
- 独立させる内容: 一般的な防災用語から与件付きの経路選択へ再設計する
- 学習目標: 与えられた危険情報を経路判断に使う
- 前提知識: 地図の凡例・J03
- 問題例: 訓練資料で「川沿いは通行不可」と指示された。避難経路として適切なのは？
- 正解: **指示された安全な経路で、川沿いを避ける**
- 解説: 訓練で与えられた通行条件と指示に従う。現実の行動は最新の自治体等の情報を確認する。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 最短なら川沿いを通る | 危険条件を無視する |
| 去年の経路を必ず使う | 今回の指示を無視する |
| 資料を確認せず川へ向かう | 根拠のない判断をする |

## L05 ネット公開：写真に含まれる個人情報

- 設計ID: `EXP_L05` ／ 第1期 ／ 小4〜6 ／ 生活場面への再設計
- 既存との対応: モラル・セキュリティ（`IT_SECURITY`）、ネット生活安全（`UPPER_PRACTICAL_NET_SAFETY`）
- 独立させる内容: 高校のネット安全から小学生の写真公開場面に絞る
- 学習目標: 写真の背景にある情報にも気付く
- 前提知識: 住所・氏名・ネット公開
- 問題例: 作品写真を公開したいが、背景に自宅住所のラベルが写っている。まずどうする？
- 正解: **住所が見えない写真にして、公開範囲を確認する**
- 解説: 作品以外にも個人情報が写る。公開前に背景と範囲を確認する。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 作品が主役ならそのまま公開する | 背景を無視する |
| 名前だけ隠せば住所はよい | 情報を一部しか確認しない |
| 一度公開してから考える | 公開後の拡散を軽視する |

## L06 買い物：単価と使い切れる量を両立する

- 設計ID: `EXP_L06` ／ 第4期 ／ 小5〜6 ／ 生活場面への再設計
- 既存との対応: 単位量あたりの 大きさ（`MATH_G5_U09`）、家計管理発展（`UPPER_PRACTICAL_BUDGET_ADV`）
- 独立させる内容: 単価比較に保存・廃棄という生活条件を追加する
- 学習目標: 最安単価と必要量を分けて判断する
- 前提知識: M14・残金計算
- 問題例: 今日中に使う牛乳は200mLで、残りは保存できない。200mL120円と1L300円では支出を抑えるのは？
- 正解: **200mL120円**
- 解説: 使える量と保存条件を考えると、今回必要な200mLだけ買う方が支出は少ない。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 1L300円 | 単価の安さだけで選ぶ |
| 両方買う | 必要量を無視する |
| どちらも0円 | 費用を計算しない |

## L07 定期購入：初月だけで比較しない

- 設計ID: `EXP_L07` ／ 第4期 ／ 中1〜3 ／ 生活場面への再設計
- 既存との対応: 消費者トラブル（`UPPER_PRACTICAL_CONSUMER_TROUBLE`）、文字式（`MATH_G7_U04`）
- 独立させる内容: 大人向け契約知識を継続費用の読み取りへ再設計する
- 学習目標: 継続期間の総額と契約条件を確認する
- 前提知識: 整数の計算・条件読解
- 問題例: 初月0円、2か月目から月500円。途中解約なしで6か月利用すると合計は？
- 正解: **2,500円**
- 解説: 有料は5か月分なので500×5＝2,500円。別途の費用がない条件を明記する。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 0円 | 広告の初月表示だけを見る |
| 3,000円 | 無料の初月を数える |
| 500円 | 1か月分しか数えない |

## L08 充電と利用時間：足りる残量を見積もる

- 設計ID: `EXP_L08` ／ 第4期 ／ 小6〜中1 ／ 生活場面への再設計
- 既存との対応: 割合（`MATH_G5_U14`）、デジタル効率化（`UPPER_PRACTICAL_DIGITAL_PRODUCTIVITY`）
- 独立させる内容: 端末活用を、仮定を明示した数量見積もりに分ける
- 学習目標: 一定消費を仮定して残量と時間を比べる
- 前提知識: 割合・比例
- 問題例: 電池を1時間に20ポイント使うと仮定する。残量60％で2時間使うと残量は？
- 正解: **20％**
- 解説: 2時間で40ポイント使い、60−40＝20％。現実の消費は使用条件で変わる。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 40％ | 使った量を残量とする |
| 30％ | 時間で割る |
| 80％ | 消費分を加える |

## L09 認証：パスワードと確認コードを守る

- 設計ID: `EXP_L09` ／ 第4期 ／ 中1以上 ／ 生活場面への再設計
- 既存との対応: モラル・セキュリティ（`IT_SECURITY`）、ネット生活安全（`UPPER_PRACTICAL_NET_SAFETY`）
- 独立させる内容: 安全一般から確認コードを狙う場面へ細分化する
- 学習目標: 本人確認情報を他人へ渡さない
- 前提知識: アカウントの意味
- 問題例: 友人を名乗る相手から「届いたログイン確認コードを教えて」と連絡が来た。適切なのは？
- 正解: **教えず、別の確かな連絡手段で本人を確認する**
- 解説: 確認コードも本人確認の秘密情報。相手の名乗りだけで渡さない。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 友人らしいので教える | 名乗りをそのまま信じる |
| パスワードと一緒に送る | 認証情報をまとめて渡す |
| SNSで公開して確認する | 秘密情報を公開する |

## L10 偽の連絡：公式窓口で確かめる

- 設計ID: `EXP_L10` ／ 第4期 ／ 中1以上 ／ 生活場面への再設計
- 既存との対応: 情報リテラシー（`IT_LITERACY`）、ネット生活安全（`UPPER_PRACTICAL_NET_SAFETY`）
- 独立させる内容: 情報リテラシーを偽通知への検証手順に落とし込む
- 学習目標: 急がせる通知を独立した経路で検証する
- 前提知識: URL・公式サイト
- 問題例: 「今すぐ支払わないと停止」と知らない送信元から通知。まずどう確認する？
- 正解: **通知のリンクを使わず、公式アプリ等から確認する**
- 解説: 見た目や緊急性だけで判断せず、普段の公式経路から状況を確かめる。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 急いで通知のリンクで支払う | 緊急性を信用の根拠とする |
| ロゴがあれば信用する | 外見だけで判断する |
| 要求された秘密情報を返信する | 本人確認前に渡す |

## L11 データ保護：同期とバックアップの違い

- 設計ID: `EXP_L11` ／ 第4期 ／ 中1以上 ／ 生活場面への再設計
- 既存との対応: 情報リテラシー（`IT_LITERACY`）、デジタル効率化（`UPPER_PRACTICAL_DIGITAL_PRODUCTIVITY`）
- 独立させる内容: 端末操作から消失場面と復元可能性に絞る
- 学習目標: 同期による削除反映と復元用保存を区別する
- 前提知識: ファイル・保存場所
- 問題例: 同期中のファイルを消すと他端末からも消える設定だった。復元に備えるには？
- 正解: **別の復元可能なバックアップを用意する**
- 解説: 同期は同じ状態を共有する仕組み。削除前の状態を戻せる保存を別に確認する。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 同期だけなら必ず復元できる | 同期をバックアップと同一視する |
| 全端末から同時に消す | 復元元をなくす |
| ファイル名だけ覚える | 内容を保存しない |

## L12 生活時間：日をまたぐ時間計算

- 設計ID: `EXP_L12` ／ 第4期 ／ 小5〜6 ／ 生活場面への再設計
- 既存との対応: 時こく と 時かん（`MATH_G3_U05`）、時間管理（`UPPER_PRACTICAL_TIME_MANAGEMENT`）
- 独立させる内容: 時間管理から日付境界の計算を子どもの生活で扱う
- 学習目標: 日付をまたぐ経過時間を計算する
- 前提知識: L02・24時間
- 問題例: 22時30分に寝て翌朝6時30分に起きた。経過時間は？
- 正解: **8時間**
- 解説: 24時まで1時間30分、その後6時間30分で計8時間。適切な睡眠量の診断は扱わない。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 16時間 | 同じ日として引く |
| 7時間 | 深夜までの時間を誤る |
| 9時間 | 時間を1つ多く数える |

## L13 健康情報：表示と相談先を読む

- 設計ID: `EXP_L13` ／ 第4期 ／ 小6〜中1 ／ 生活場面への再設計
- 既存との対応: 健康・医療リテラシー（`UPPER_PRACTICAL_HEALTH`）、応急手当（`UPPER_PRACTICAL_EMERGENCY_FIRSTAID`）
- 独立させる内容: 健康リテラシーを条件読解と相談行動に限定する
- 学習目標: 医薬品の表示を読み、自己判断で変更しない
- 前提知識: 年齢条件・注意書き
- 問題例: 家庭にある薬の表示に「12歳未満は使用しない」とある。11歳の人はどうする？
- 正解: **自己判断で使わず、保護者や薬剤師等に相談する**
- 解説: 表示の年齢条件を守り、必要な相談につなげる。投薬量の計算や診断は出題しない。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 半分なら使ってよい | 量を勝手に調整する |
| 効きそうなら表示を無視する | 年齢条件を無視する |
| 友達の体験だけで決める | 個人例を根拠にする |

## L14 申請と締切：必要な条件を照合する

- 設計ID: `EXP_L14` ／ 第4期 ／ 中1以上 ／ 生活場面への再設計
- 既存との対応: 公共サービス（`UPPER_PRACTICAL_PUBLIC_SERVICES`）、説明文の読み取り（`KOKUGO_G7_U02`）
- 独立させる内容: 行政知識を学校の架空要項の照合へ再設計する
- 学習目標: 要件・締切・提出先を照合する
- 前提知識: J14・日付
- 問題例: 学校の申込要項に「10月20日までに申込書と同意書を提出」。19日に申込書だけ出した。条件を満たす？
- 正解: **同意書も必要なので、まだ満たしていない**
- 解説: 期限と2種類の書類の両方を満たす必要がある。

| 誤答例 | 検出したい誤解 |
| --- | --- |
| 締切前なら書類は1枚でよい | 必要書類を落とす |
| 21日でも必ず受理される | 締切を無視する |
| 同意書だけあれば申込書はいらない | 要件の一方を消す |

## L15 作品利用：画像の利用条件を確かめる
