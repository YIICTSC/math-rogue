# ミニゲーム主人公の動作・音声確認

デバッグ機能が有効な環境で「デバッグメニュー → ミニゲーム主人公」を開く。
通常版のデバッグ機能の有効範囲・解放条件は変更しない。

- ゲーム・主人公で絞り込み、ファイル名の一部を検索できる。
- ダンジョンズ1・2は実ゲームの描画関数を使用。8方向、各動作、対応主人公の変身前後を確認できる。「動作を再生」は1回再生し、終了後の待機姿まで表示する。
- 画像素材は1コマ表示、コマ送り、連続再生、シート全体表示に対応。既知のアトラスは列・行数を自動設定し、それ以外は手動調整できる。連続再生は素材検査用のコマ巡回であり、ゲーム中の行動順序の再現ではない。
- 音声素材は同名のMP3・OGG・WAVを1項目にまとめ、ブラウザが対応する形式で試聴できる。素材変更やパネル終了時に前の試聴を停止する。
- 主人公スプライトや専用音声を使わないゲームは、その旨を表示する。3Dモデルのアニメーションを2Dスプライトとして捏造しない。共通の主人公素材は「全素材」で検索できる。
- 素材ファイルの読み込みは選択時のみ。セーブデータ、解放状態、ゲーム音量は変更しない。

## ダンジョンズ2の停止姿修正

従来は動作が終了していてもアクションアトラスの歩行先頭コマを表示していた。
リリアの右向きでは目が細いコマだったため、停止時も目を閉じているように見えた。
動作がないときはアクション描画を終了し、既存の方向別立ち絵へ戻す。
全9主人公・変身前後に適用し、元の画像資材は変更しない。

## 維持・検証

`pnpm run generate:minigame-media-index` で実在する画像・音声の索引を更新する。
通常の `pnpm run build` 前にも自動更新される。

`pnpm run test:minigame-hero-media` は索引の鮮度・全ファイルの存在・翻訳キーの一致と、
9人×2形態×7動作の終了時フォールバックを確認する。
変更後は `pnpm run audit:english:gate` と `pnpm run build` も実行する。
