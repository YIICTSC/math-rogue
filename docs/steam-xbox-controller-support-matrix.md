## 1. 判定の読み方

この表では「コードに対応があること」と「製品版を実機で確認したこと」を分ける。

| 記号 | 実装判定 |
| --- | --- |
| `○` | 画面専用の初期フォーカス、操作ゾーン、ショートカット、またはキー変換を実装済み |
| `△` | 共通フォーカス移動では操作できるが、画面専用の初期位置・戻る動作・全状態のいずれかが不足 |
| `×` | コントローラーだけでは完了できない、または対応未確認 |
| `―` | Steam製品版では表示しない開発用機能 |

| 実機判定 | 意味 |
| --- | --- |
| `確認済み` | Xboxコントローラー相当の物理入力で対象操作を確認済み |
| `シミュレーション確認` | Gamepad APIへXbox標準配列を注入する自動試験で確認済み |
| `一部確認` | 基本操作だけ確認済み。派生画面または一部ボタンが未確認 |
| `要確認` | コード／ブラウザー確認のみ。Steam提出用ビルドと物理コントローラーで未確認 |

> 現時点の結論: Gamepad APIによるXbox標準配列の接続・切断・再接続、主要画面、全デバッグプレビュー状態、通常戦闘、風来シリーズ2作、モーダル、文字入力、スクロールは自動確認済み。物理コントローラーとSteam提出用ビルドでの最終確認が終わるまでは、ストア上の「フルコントローラーサポート」確定を保留する。

## 2. 共通ボタン割り当て

| Xbox入力 | 共通動作 | 実装メモ |
| --- | --- | --- |
| 左スティック | 上下左右の移動／フォーカス移動 | 軸0・1、しきい値 `0.55` |
| 方向パッド | 上下左右の移動／フォーカス移動 | 標準Gamepad APIの12～15番 |
| A | 決定、フォーカス中のボタン実行 | Enter相当 |
| B | 戻る、閉じる、キャンセル | Escape相当。最前面モーダルを優先 |
| X | 画面固有ショートカット | 通常戦闘ではアイテム／支援一覧、ポーカーでは捨てる |
| Y | 画面固有の確定・実行 | 通常戦闘ではターン終了 |
| LB | 前のタブ／画面固有ショートカット | 通常戦闘ではアイテム一覧 |
| RB | 次のタブ／画面固有ショートカット | 通常戦闘では変身／友情コンボ |
| RT | 画面固有ショートカット | 通常戦闘では次の敵を選択 |
| View / Back | ゲームメニュー | ゲーム中のどの画面からでも、継続／タイトルへ戻る／ゲームを閉じるを選択 |
| Menu / Start | 決定 | Aと同じ。共通ポーズには未割当 |
| LT | 未使用 | 今後の割当候補 |
| 右スティック | 縦スクロール | 最前面モーダル、フォーカス周辺、画面中央の順でスクロール領域を選択 |
| LS / RS押込み | 未使用 | ― |

左スティックの長押しは、最初の `280ms` 後に `110ms` 間隔でリピートする。

## 3. 通常戦闘のボタン配置

### 3.1 画面内の操作ゾーン

```text
┌────────────────────────────────────────────────────┐
│ 戦闘ログ                                  SET  LOG │ battle-top
├────────────────────────────────────────────────────┤
│ プレイヤー／同行者        敵1  敵2  敵3            │ battle-enemies
│ アイテム・支援一覧                                  │ battle-items / battle-coop
├────────────────────────────────────────────────────┤
│ エナジー／山札       友情コンボ・変身      ターン終了│ battle-actions
├────────────────────────────────────────────────────┤
│              手札カード1 2 3 4 5 ...               │ battle-cards
└────────────────────────────────────────────────────┘
```

上下入力は操作ゾーン間を移動し、左右入力は同じゾーン内を移動する。手札の左右端では他の列へ飛ばない。アイテム列の右端と敵列の左端だけは相互に移動できる。

ゾーンの内部順は次のとおり。

1. `battle-top`: SET → LOG
2. `battle-coop`: 協力支援の表示／カード
3. `battle-enemies`: 敵1 → 敵2 → 敵3
4. `battle-items`: レリック／ポーション等
5. `battle-actions`: 友情コンボ／ON-OFF／変身／ターン終了
6. `battle-cards`: 手札左端 → 右端
7. `battle-race-items`: レース専用カード

### 6.1 校長対決のSteam戦闘配置

ターン制の一対一ライン戦闘で、移動・方向転換・行動予約・一括実行を短い入力で
繰り返せる対戦アクション型の配置にした。メニュー画面ではこの専用配置を使用せず、
共通の方向入力、A決定、B戻るへ戻す。

| Xbox入力 | 校長対決の戦闘動作 |
| --- | --- |
| 左スティック／方向パッド | 手札・予約列・操作UIのフォーカス移動 |
| A | 選択中カードを予約 |
| B | 予約済みカードの末尾を1枚取り消す |
| X | 予約したカードを順番に実行 |

| LB | 何もせず1ターン待機 |
| RB | クールダウンがなければ敵と位置交換 |

## 7. ゲーム内モーダル対応

1. `data-gamepad-back`
