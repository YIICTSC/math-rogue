# ドッジボール

既存の3D主人公とキャラクタークリエイトを使う、内野3人対3人の対戦。
[参考記事](https://gigazine.net/news/20150314-kunio-db-ios/)の、投げる・受けるタイミング、ダッシュからの強打、ジャンプ、外野との連係を参考に、独自の操作と演出を実装している。

## 操作

| 動作 | キーボード | ゲームパッド |
| --- | --- | --- |
| 移動・投球方向の調整 | 方向キー | 左スティック・十字キー |
| 投げる | Z | A（所持中） |
| キャッチ | X | A（未所持）・B |
| しゃがんで回避 | Space | X |
| パス | C | Y |
| ダッシュ | D | LB |
| ジャンプ | V | LT |
| 選択した必殺球 | Shift | RB |
| 操作ガイド・中断 | Escape | Menu |

スマホでは画面下のパッドと6つのボタンで操作できる。主ボタンは、所持中なら投球、未所持ならキャッチになる。

## 駆け引き

- ダッシュ開始から約0.22〜0.52秒の発光中に投げると、ゲージ消費なしのダッシュシュート。
- 接触する直前にキャッチするとジャストキャッチ。1.5秒以内に投げ返すとカウンター。
- ジャンプ中は低い球を飛び越えられ、空中で投げれば高い位置からの投球になる。
- 必殺球は試合前に「直球ドライブ」「ウェーブ」「スカイアーク」から選択。ダッシュシュートとカウンターにも選んだ軌道が適用される。
- 通常の命中は体力1、必殺球は体力2のダメージ。体力を失った選手は外野から支援できる。
- キャッチ・パス成功・学習の正解などで必殺ゲージが増える。ボールの長時間保持は自動投球となる。
- 3分で内野人数、続いて体力の合計を比較。同点なら次の有効な命中で差がつくまで続く。

参加者はランダムに振り分け、各チームの参加者数の差を最大1人に抑える。不足枠はCPUが入り、7人以上はトーナメント。新しい操作と演出イベントはホストまたはサーバーで確定し、観戦者を含むクライアントへ同期する。

## 検証

`scripts/test-dodgeball-actions.mjs` は投球軌道・ダッシュ・ジャンプ・キャッチを検証する。既存のエンジン、ブラウザー、WebRTC、サーバーの各テストで試合進行とオンライン同期を確認する。
