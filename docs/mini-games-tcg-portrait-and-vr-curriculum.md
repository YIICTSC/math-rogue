# TCG縦画面とVR100ミッション

## TCG

スマホ縦画面では、開始・対戦・各ダイアログの外枠を画面幅に収め、中央配置する。
報酬5枚は2列で表示し、5枚目を中央に置く。短い画面ではパネルを縦にスクロールして確認できる。
カード公開の効果音は公開枚数が増えたときに一度だけ再生する。報酬保存や親画面の再描画では再生しない。

## VR

| 範囲 | 難易度 | 構成 |
|---|---|---|
| 1–20 | 入門 | 学校10件、野外の安全経路確認10件 |
| 21–40 | 初級 | 学校10件、坂道と資料搬出10件 |
| 41–60 | 中級 | 学校10件、救助・端末復旧10件 |
| 61–80 | 上級 | 学校10件、警戒網突破と一部防衛10件 |
| 81–100 | 達人 | 学校10件、総合任務と最終防衛10件 |

野外は屋上・港・山岳・地下基地・都市・森林・空中回廊・雪原・砂漠・宇宙基地。
章が進むにつれ広さ・高低差・巡回人数・視認速度が増え、睡眠時間は短くなる。
武器解禁は1/11/21/41/61/81、アイテム解禁は1/21/41/61。ソロと協力の章分け、バトルロイヤルの装備選択も統一する。

旧学校50件のクリア記録は同じ内容の新IDへ読み替える。旧野外250件の記録は元の保存領域に保持し、新ミッションの記録と混同しない。
VRオンラインはホスト側で処理するため、更新したアプリで新構成が反映される。ルームの通信バージョンを5にし、旧300件版との混在を防ぐ。
