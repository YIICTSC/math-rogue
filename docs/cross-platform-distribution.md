# Steam・iOS・Android同時展開方針

更新日: 2026-07-22

## 製品構成

同じゲームソースから、配布先ごとに以下の製品を作る。

| チャネル | `VITE_APP_PLATFORM` | `VITE_PAID_EDITION` | 時間制限 |
| --- | --- | --- | --- |
| Web | `web`（既定） | 未設定 | あり |
| Steam | `steam` | `true` | なし |
| iOS | `ios` | `true` | なし |
| Android | `android` | `true` | なし |

有料版では総プレイ時間の記録は続けるが、1日プレイ時間の加算、時間切れ判定、
時間切れ画面、マスター達成時の5分延長表示を無効にする。開始画面には
`FULL VERSION: UNLIMITED`を表示する。有料版のマスター達成時は、時間延長の代わりに
課題クリア時と同じ生成ルールの報酬カードを1枚付与し、報酬カードアルバムへ保存する。

## 製品版のデバッグ制御

- Webを含むすべての本番ビルドで、計算スキップ、敵HP変更、ミニゲーム解放、デバッグメニューへの導線を無効化する。
- 保存済みのデバッグ設定は本番起動時に削除し、デバッグ画面の保存状態も復元しない。
- ローカル開発中に限り、`npm run dev:debug`で明示的に有効化できる。

## 販売方式

- Steam、App Store、Google Playでアプリ本体を有料販売する。
- 初版にはアプリ内課金を入れない。
- ストアごとに購入が必要であることをストア説明へ明記する。
- Web版は無料体験版として継続し、有料版への機能差を時間制限の有無に絞る。
- セーブデータ形式とゲーム内容は可能な限り共通化する。

## 権利確認

ビルドフラグは製品差を作るためのもので、強固な不正コピー対策ではない。

- iOSはApp Storeの有料ダウンロードとして配布する。
- Androidは必要に応じてPlay Integrity／ライセンス確認を追加する。
- SteamはSteamworks連携時にアプリ所有権とSteam経由起動を確認する。
- 3ストア共通購入を将来導入する場合は、共通アカウントとサーバー側権利管理を別途設計する。

## 同時リリースのゲート

1. Webと3ストア版を同一コミットからビルドできる。
2. Web版だけが1日制限へ到達し、3ストア版は到達しないことを自動テストする。
3. セーブデータの互換性、オフライン起動、アップデート後の復元を各OSで確認する。
4. 各ストアの審査素材、プライバシー回答、年齢区分、価格を同時に凍結する。
5. SteamのComing Soon期間と各モバイル審査の余裕を含めて発売日を決める。
