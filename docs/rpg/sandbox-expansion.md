## 実装で使う境界

- `World.voxels` が座標と建材の正本。装置を追加しても既存の座標・建築・所有者IDを維持する。2Dの表示高度を変える操作は端末内で処理する。
- ソロ、Peerホスト、WebSocketサーバーは同じ `advanceWorld` と `applyAction` を使用する。表示画面からの要求は操作だけを伝え、装置の動作確定や資材の付与は権威側で行う。
- 小さい入力・出力装置から始め、既存工房のクラフトと資材で接続できるようにする。信号の数値・向き・停止した理由が画面に出ることを各段階で確認する。

## 検証

- 本編の難易度9で初回特別教育から理科室に入り、保存再開後の第2回に通常の確率が使われることを確認した。難易度10では最初から通常の閉室条件が適用される。
- Chromiumで2Dの設置、高さ断面、3Dでの操作、ポインターロックと解除、ドラッグ視点、異世界の往復と保存再開を確認した。地下・高架・乗車中も高さと装置の状態を共有する。
- 27件の技術研究を通常入力で達成した。22施設は一般の設置コマンドによる組み立てと設計図からの一括建築を試し、2D・3Dの画面で表示した。実行手順は `scripts/test-rpg-technology-plans.mjs` と `scripts/test-rpg-showcase-browser.mjs` に記録した。
- WebSocketの2ブラウザーで2Dの設置と3Dの操作を共有した。別の試験では40人のWebRTC接続、ホスト交代、元の招待URLでの途中参加、異世界の差分同期を確かめた。
- 生き物はGLB内の造形・可動部位、方向別のWebP、接地基準、親子の体格を検査した。Chromiumの低画質設定で近くの生き物を描画し、図鑑、牧場、騎乗を操作した。
- Web・サーバーのビルドと英語表示監査を通過した。全体のひらがな監査には継界戦記の既存の指摘22件がある。PC操作はChromiumの実マウス相当の入力とドラッグを検証し、物理タッチパッドとモバイル実機での確認は別途必要となる。
- カートのバックグラウンド進行試験は、作業ブランチと `main` の `5aa672f7` で同じ箇所のタイムアウトを再現した。
