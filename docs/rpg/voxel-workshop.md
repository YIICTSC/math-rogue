# 3D建築工房

RPGオンラインの3D画面で「建築工房」を開きます。素材・クラフト・建築・農業を中心とした拡張です。

- 建材78種類。木材・石材・鉱石・ガラス・色付き羊毛・コンクリート・設備を検索、分類、所持数で絞り込めます。
- レシピ67種類。手加工、作業台、かまど、堆肥箱を使い、1・4・16回のまとめ加工ができます。設備から3.5ブロック以内で作業します。
- 木材から板、作業台、かまど、道具を作ります。精錬には石炭・木炭・木材のいずれかを燃料として消費します。
- 石・鉄・鋼・ダイヤのツルハシ、斧、シャベル。対象素材に合う道具で採掘エネルギーを節約します。学習問題に正解してエネルギーを回復します。
- 半段、階段、フェンス、板ガラス、設備11形状はBlender製GLB。Three.jsでインスタンス描画し、90度回転と配置プレビューに対応します。半段は高さ0.5として歩行判定します。階段やフェンスはグリッド単位の衝突判定です。
- 共有チェストは24種類、各64個まで保管可能。近距離で出し入れし、中身が残っている間は破壊できません。
- 既存農園と連携し、有機肥料を堆肥へ補充、通常品質の収穫物2個から種3個を回収できます。灌漑タンクは水源から4マス以内、作物から3マス以内で給水し、既存の日次成長に反映します。
- 材料、道具、回転、チェストはワールド保存に含まれ、オンラインではサーバー側で距離・材料・燃料・操作値を検証します。

道具のアイコンはImageGenで個別生成した `public/images/rpg/workshop/*-v1.webp` を使用します。シャベル・斧・ツルハシ・クワは形で区別し、素材の強さはレシピ名で表示します。クラフトカードには用途、建材のツールチップには加工先を表示します。色や木の種類による建材の違いは主に外観であり、すべての建材に固有の特殊効果があるわけではありません。

Minecraftの全バージョンの全要素を再現するものではありません。回路、ディメンション、モブ、生態系は今回の対象外です。テクスチャとモデルは独自に生成しています。

## 素材の再生成

`scripts/blender/build-voxel-workshop.py` をBlenderのバックグラウンド実行で開くと、編集用 `assets/storybook/voxel-workshop.blend` と配信用 `public/models/storybook/voxel-workshop-v1.glb` を生成します。続けてWeb・Androidのアセットマニフェストを再生成してください。

## 検証

- `node scripts/test-rpg-voxel-workshop.mjs`: 加工、燃料、道具強化、保管の権限、入力検証、半段、灌漑、種、保存復元。
- `node scripts/test-rpg-workshop-browser.mjs`: GLB11形状の読み込み、検索、加工、回転、PC・スマホ縦横のスクロール。
- `node scripts/test-rpg-voxel.mjs`: 既存の採掘・配置・移動。
- `node scripts/test-rpg-building-browser.mjs`: 既存の住宅登録・共有・家具・農作業。
