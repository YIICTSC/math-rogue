# RPG enemy hero unlocks

- The RPG lobby header has one return button. The brand is a noninteractive heading.
- Standard enemy heroes are listed only when their name is registered in the main game's bestiary. Selection rechecks the record before starting.
- Vacation variants additionally require Vacation Mode unlocked for that theme and a main-game encounter with that enemy while Vacation Mode is active. The selector uses the existing vacation artwork; equipment and starting deck retain the base enemy's abilities.
- Main-game battle encounters now record all enemies, including special bosses and the second headmaster form. RPG battles do not add unlock records.
- Historical bestiary entries remain valid. Old saves did not distinguish vacation encounters, so vacation variants require a new encounter after this change; no encounter history is inferred from simply unlocking the mode.
- Existing RPG adventures remain playable. Unlock requirements apply when choosing a hero for a new adventure.
