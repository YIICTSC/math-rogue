# RPGの任意3D建築目標

「目標」タブに次の任意目標を追加する。冒険クリアの必須条件にはしない。

| 目標 | 幅×奥行き×高さ（外寸、1ブロック単位） |
|---|---|
| はじめての立体住宅 | 6×6×4 |
| 見晴らしの塔 | 6×6×12 |
| 立体建築の大邸宅 | 12×12×12 |
| ランドマーク | 20×20×20 |

各寸法は指定以上でも達成する。計測ボタンはホスト／サーバー側で実際の建築を検査する。
地形・生成済み施設・2Dの家は対象外。自分が建材を置いた構造、登録済み自宅、旧版で作った未帰属の建築は入口から6ブロック以内で計測できる。
新規配置は配置者を記録し、撤去でその記録も削除する。

## 完成の条件

- 接続している建材の外接直方体の寸法を計測する。
- 最下層の床と最上層の屋根が全面にあり、四方の壁に穴がない。
- 床の上の外壁にドアがあり、ドアから室内へ入れる。
- 室内は2ブロック分の高さを確保し、最低4セル、かつ内側の床面積の25%以上を連続して歩ける。
- 幅・奥行き・高さがそれぞれ最大64ブロックの直方体を検査対象とする。

ガラスや色付き建材も壁に使える。中実の塊・独立した柱・平面だけの配置では完成しない。
追加の足場や舗装が建物へ接続して外寸を広げると、床・屋根の条件が変わるため、計測時は仮設の足場を外す。

## 保存と負荷

計測はボタン操作時だけ実行し、1秒の連続操作制限を設ける。結果と達成記録は既存のlifeデータに保存する。
変更後は再計測を案内する。達成記録は解体しても残り、同じ目標が重複して記録されることはない。
小住宅100G・塔200G・大邸宅400G・ランドマーク1,000Gを、それぞれ達成時の全参加者（観戦者を除く）へ配布する。金額は1人あたりの固定額で、参加人数で割らない。

各目標の配布記録はワールドに保存し、再計測・別の建築・別の参加者による達成・保存からの再開では重複配布しない。達成後の参加者への遡及配布はない。旧版ですでに達成した目標は、計測時に保存済みの達成記録を参照して初回報酬を配布する。

大きな建物で複数の目標を同時に満たす場合は、それぞれの未配布報酬を合算して配布する。全4目標を初めて同時達成すると1人あたり1,700G。既存のゴールド変更キューを使うため、戦闘中の参加者にも同期される。
オンラインの判定処理はRenderの手動デプロイで反映される。
