# RPG画面・作成装備・住人音声の改善

農園のドックアイコンは、周囲と同じLucideの線画`Sprout`に統一する。目標画面は試験官の撃破と魔王城への挑戦を案内する。

共通イベントの達成報酬は、全員20 G、貢献者に追加15 G。戦闘イベントはカード1枚、学習イベントは最大HPの25％回復と町・休憩・イベントの再利用、封印イベントは魔王の攻撃力低下。達成後には、実際に付与したゴールド・HP回復量・カードを参加者ごとの記録から表示する。この記録はワールド保存に含む。

鉄の剣と霜木の弓はカードではなくレリックとして作成する。鉄の剣は所持中、毎戦闘でムキムキ（筋力）+2を付与し、次の戦闘でも適用する。弓は戦闘準備時に15％で先制を抽選し、最初の敵フェーズの全行動を止める。通常の攻撃を受けても解除されず、追加のプレイヤーターンでも消失しない。敵フェーズの開始時に消費し、後続ターンには持ち越さない。協力戦では参加者の先制効果で敵フェーズを止める。PvPの対戦順序処理は独立する。旧バージョンで作成した専用カードは、マップに戻り同期が完了してからレリックへ移行し、保存された移行済み印とmutationの確認で二重付与を防ぐ。

探索の施設選択は縦画面2列、横画面・広い画面3列のグリッドにし、親画面の高さに応じて行とイラストを縮める。5施設に加え、カード消しゴムを持つ場合の6施設も一画面へ収める。

オリジナルの住人音声は音源と共鳴フィルターを組み合わせる。破裂音の閉鎖・破裂・息、摩擦音、破擦音、鼻音、ラ行の短い閉鎖を別々に生成し、「し・ち・つ・じ・ふ・ひ」を区別する。子音から母音への共鳴の移動、連続する母音、無声化、文の抑揚を調整する。女子住人5人のピッチは1.90〜2.00、明るい共鳴を使う。男子の個別声質は各プロフィールに従う。

確認: `node scripts/test-rpg-ui-equipment-voice.mjs` は作成・旧データ移行・報酬記録・音声の出力を確認し、実際のAppの敵ターンで攻撃とバフの抑止、一度限りの先制、次戦闘の剣効果を確認する。5〜6施設の配置は320×568、390×844、568×320、844×390、1440×900で確認する。音声の再生ライフサイクルは既存の`test-rpg-resident-voice.mjs`も使う。
