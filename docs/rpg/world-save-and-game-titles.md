# RPG・カートの専用タイトルとワールド保存

RPGに入ると「木漏れ日のフロンティア」のタイトルを表示する。「ひとりで遊ぶ」「続きから」「オンラインで遊ぶ」を選び、新規冒険では問題・難易度・主人公を選択して開始する。カートでは専用タイトルからひとり・オンライン作成・招待参加を選ぶ。

導入画面は `100dvh` に収め、問題一覧・参加者名簿などの長い内容だけをスクロールする。開始ボタンは画面内に残す。共通タイトルはキーボードのフォーカスを囲い、Escapeで閉じる。

## ひとり用RPGの保存

IndexedDB `learning-rogue-rpg-world` に最新の冒険を1件保存する。同じ端末・ブラウザで再開できる。ブラウザのサイトデータを削除すると保存も消える。

ワールド全体と主人公のPlayerデータを一緒に保存する。位置、マップ、NPC、素材、魚のサイズ記録、家と家具、交流、デッキ、レリックなどを保持する。探索中は30秒ごと、画面が非表示になった時、退出時に保存を試みる。「詳細」から手動保存、保存してRPGタイトルに戻ることもできる。

戦闘・採取・ミニゲーム・取引などの処理中はチェックポイントを更新しない。主人公のHP・所持金・デッキ・変更番号とワールド内のプロフィールの一致を確認し、両者が同期した安全な状態を保存する。再開ではオフライン中に残り時間や再生待ち時間が減らないよう、実行用の絶対時刻をずらす。捕獲日などの記録日時は変更しない。

終了した冒険も終了状態を保存し、タイトルでは続きからを無効にする。オンラインの共有部屋にはこの端末保存を適用しない。

## 制限時間なし

ひとり用は初期値が「制限時間なし」。オンライン作成でも選択できる。`timeLimitMinutes=0`、`deadlineAt=0` を無制限として扱い、サーバーも受け付ける。ワールド共通イベントなど個々の時間制イベントは通常通り進む。

## 背景素材

ImageGenでRPG専用の小屋・川・森林・遺跡・遠景の山がある夕景を生成。文字なし、中央を縦画面に切り出しても成立する構図。`public/sprites/rpg/title/frontier.webp` に幅1536px、品質84、約421KBで導入した。生成元PNGは作業環境の `generated_images` に保持する。Web・Androidのアセット一覧に追加する。カートは既存の3Dコースをタイトル背景に使う。

## 検証

- `node scripts/test-rpg-world-save.mjs`: 完全スナップショット、コピー分離、オフライン時計、無制限、処理中の保存防止、破損データ検査。
- `node scripts/test-game-launch-browser.mjs`: 320×568、390×844、568×320、844×390、1024×768、1440×900。タイトル・開始設定・問題・難易度・40人のRPG名簿・カート待機の開始操作が画面内にあることを検査。実際のIndexedDB保存、リロード、再開、家・家具・釣り記録・位置の復元と移動を確認。
- `node scripts/test-rpg-energy-app-browser.mjs`: 実際のAppから専用タイトルを経て開始し、学習問題から冒険へ戻る流れを確認。
