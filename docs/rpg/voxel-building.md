# RPG 3D block building

Three.js renders shared, authoritative voxel edits using a unit cube exported by Blender. Run `blender -b --python scripts/blender/build-voxel-block.py` to recreate `public/models/storybook/voxel-block.glb` and the editable `assets/storybook/voxel-block.blend`. Exact unit dimensions avoid gaps between adjacent blocks. Existing Blender scenery and billboard NPCs remain in use.

In 3D, WASD/arrow keys or the touch controls move continuously. The virtual stick supports analog diagonal movement. Fractional `position3D` is authoritative; integer `x/y` is always its containing tile. Returning to 2D clears the fractional position and centers the player on that same tile. Host/server validation caps speed, checks player-radius collisions and rejects nonfinite input. Existing map interactions continue to use integer tile coordinates. Crossing a built house tile still enters its interior automatically; entry/exit clears stale fractional positions.

Open **ブロック建築**, select a material, aim at a block and choose **壊す** or **置く**. Vertical swipes adjust the view angle. Tap the 3D view to mine the aimed block. Mining uses one gathering energy and grants one matching material in the existing shared crafting inventory. Recover energy by answering questions through the existing gathering interface. Placing consumes one material; breaking a placed block returns its material. Wood, stone, planks, bricks, frostwood, ore and crystal are supported.

Natural resource tiles become one-block rocks or three-block wood columns; fully mining one clears the corresponding 2D resource tile. Protected NPC/event/house areas, farms, city lots, water and the outer border cannot be edited. Blocks must be within 4.5 world units, have a neighboring support above ground level, and cannot trap another player. Ground is not excavated. Structures are currently limited to eight layers and 6,000 edited cells per world. No block gravity simulation; connected overhangs are allowed.

Sparse edits and fractional positions are included in existing world snapshots, automatic saves and host/server broadcasts. 2D shows the topmost placed block per tile and shares ground-level collision checks. Existing worlds have no edits and need no destructive migration. Peer room protocol version is 21.

Validation: `node scripts/test-rpg-voxel.mjs` exercises authority, position mapping, mining, energy, material accounting, supported placement, collisions, protections, spectator rejection and save/resume. `node scripts/test-rpg-world3d-browser.mjs` checks the real game on 390×844, 844×390 and 1440×900 layouts, controls and nearby farming actions. `node scripts/test-rpg-voxel-server.mjs` verifies placement/mining, inventory, energy, fractional movement and 2D snapping between two actual WebSocket clients. Also run the English gate, full build and server build before publication.
