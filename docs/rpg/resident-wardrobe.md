# 住人の衣装・リアクション

既存住人12人が対象。会話画面の「衣装」、または「贈り物 → 衣装をプレゼント」から利用する。

|---|---:|---:|
|普段着|20 G|5|
|冒険服|30 G|10|
|水着|35 G|25|
|浴衣|30 G|15|
|礼装|45 G|30|
|ウェディング|60 G|50|

住人の好きなスタイルは必要友好度が5少ない。ゲーム画面では、その住人に衣装を贈るまで好みと着替え条件を伏せ、衣装イラストは「？」で表示する。贈ると本人の反応と好きなスタイルが分かり、その住人へ贈った衣装のイラストが解禁される。贈ると衣装の所持数が1減り、住人のクローゼットへ永続保存される。同じ衣装は同じ住人へ二重に贈れない。必要な友好度が足りれば、その場で着替える。足りなければ保管し、後で着替えを依頼できる。「いつもの衣装に戻す」で元に戻せる。

衣装プレゼントの友好度ボーナスは、プレイヤーと住人の組ごとに1日1回。好きなスタイルは+7、ほかは+4。着替えの依頼では友好度を稼げない。衣装は最大40点まで所持できる。購入ゴールドは本編と共有するRPG mutation経由で反映する。

住人との会話、小話、おでかけの選択、花・料理・衣装の贈り物、着替え依頼、仲直り、住人への誘い、言葉を教える操作には交流エネルギーを1使う。エネルギー上限は採集と共通の6。足りない時は「問題で回復」から学習問題へ進み、正解1問で2回復する。時間経過による自然回復はない。おでかけを途中で切り上げる操作は消費しない。

着用状態は会話・2Dマップ・3Dマップ・住人の自宅訪問に反映する。住人の位置判定とNPCイベントの紐付けは元の画像パスを保持する。作成住人は主人公ビルダーの画像を使い、他人の顔の衣装画像に置き換えない。

リアクションは喜び・照れ・驚き・落ち込みの4種類。料理の好み、花の贈り物、衣装の受け取り・着替えで切り替わる。衣装着用中は選んだ服を維持し、別枠のリアクション絵を表示する。衣装・クローゼット・所持数はワールド保存に含まれる。

衣装は住人12人×8着の96枚。従来のリアクション48枚は通常衣装の予備表示として残し、着用衣装に合わせたリアクション384枚（住人12人×8着×4表情）を追加する。衣装別画像は `public/sprites/rpg/wardrobe/<住人>/<衣装>-<表情>.webp` に置き、着用中の喜び・照れ・驚き・落ち込みに使う。衣装と通常リアクションを含むアセット総数は528枚。

追加リアクションはImageGenで住人ごとに衣装8着の立ち絵を参照して生成。喜び・照れ・驚き・落ち込みを4列、衣装を8行に並べたシートから画像を切り出してWebP化した。元生成画像はクラウド環境の `/workspace/generated_images` に保持している。
