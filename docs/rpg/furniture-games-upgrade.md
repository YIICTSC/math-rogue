# ゲーム家具の改修（2026-10-13）

対象はダーツ、ビリヤード、ブロック崩し、リバーシ、四目並べ、神経衰弱、すごろく、ライトリアクション、学ロリズム、コインドーザーの10種類。

## 画面

- 専用タイトル背景をImageGenの組み込みツールで個別に10枚制作。`public/sprites/rpg/game-room/titles/*.webp` に1440px幅・品質85で保存。タイトルと操作ボタンは翻訳可能なHTMLで表示。
- 家具から参加するとポータルで画面全体を使い、家のモーダルや祖先のサイズ制限を回避。プレイ中はflexで盤面へ残りの領域を割り当てる。狭い端末はスクロールを許容し、コイン台の操作欄を下部へ配置。
- リバーシは木枠・緑の布・白黒の厚い駒。四目は金属枠・穴・立体駒。カードは縁と紙の厚み、すごろくは卓上タイル・駒、反応ゲームは金属パネルと発光ボタン。ブロック崩しは筐体枠・星空スクリーン。ビリヤードの2Dにも木目・フェルト・球の反射を追加。
- SVGのタップ位置は画面の変換行列で計算し、縦横比による余白があっても狙った位置へ入力。
- フォーカスの復帰・Tab移動・背景スクロールの抑制。既存の2D/3D切り替えを利用。

## 共通冒険

- 新規冒険は8階層。既存の5階層状態は `floors ?? 5` で継続可能。
- ホストが毎階層で癒しの庭・宝石の回廊・王者の試練を選択。回復、獲得コイン、目標、得点が異なる。
- 4階・8階は高目標のボス試練。ブロック崩しには装甲の強化も適用。
- 18種類のレリックから対応するゲームの3択を提示。パドル幅、カード確認時間、移動補助、得点・コインの相乗効果、失敗時のリスクなど。
- 共有コインを休憩所で使い、回復・全員への追加レリック・候補引き直し・泉のリスク選択。ホストのみ利用、階層間1回、二重入力や古い階層の入力を拒否。
- リバーシ・四目に毎階層変わる宝石マス。すごろくにはランダムな加速・後退・再行動マス。
- 音ゲーは既存譜面・判定を維持し、コンボと精度に応じたレリック効果を冒険点へ反映。

## コインドーザー

- 新規プレイは8層、旧状態は5層継続。28種類のレリック。
- 磁石、宝石シャワー、損失コイン再生、組み合わせ強化を追加。
- 毎層の宝石・金貨・横風などの環境変化。4階・8階の王冠コイン。既存の分岐・イベント・ショップは後半層にも出現。
- 既存セーブの家具・プレイヤー資産は変更しない。冒険コインは各ラン内で使用。

## 画像制作

組み込みImageGenを使用。各プロンプトは `stylized-concept`、専用タイトル画面、原作ゲームの盤面や筐体を右側2/3へ、左側にHTMLのための暗い余白、紺・青緑・金の照明、材質の分かる3Dイラスト、16:9、文字やロゴなしを共通指定。

個別題材：ダーツ＝学園天文台の的、ビリヤード＝月夜のサロン、ブロック崩し＝宇宙の宝石ブロック、リバーシ＝森の木製テーブル、四目＝真鍮と青の盤、神経衰弱＝図書室の宝物カード、すごろく＝島と橋の卓上冒険、反応＝4色発光ボタン、音ゲー＝4レーン音楽筐体、コイン＝金貨と竜の宝庫。

## 確認

`node scripts/test-furniture-adventure.mjs`：全10ゲーム起動、8階層の進行、CPU手番、ホスト権限、二重/古い入力の拒否、レリックのゲーム別候補、休憩所コスト、コイン物理を検証。

開発用表示確認：`http://localhost:5173/scripts/fixtures/furniture-room.html?kind=reversi`。`kind` を対象ゲームへ変更。ゲーム状態はメモリ内で、既存プレイのセーブには触れない。

ローカル実装のみ。commit・push・Renderデプロイは実行していない。
