# RPG 外周マップと2D/3Dの整合性強化（2026-10-09）

GitHub main の `1d816c36`（前回の地形拡張）を取り込んで実装。
既存192×88タイル、NPC・試験官・魔王・町運営の進行データは維持する。

## 前回のマップ関連の懸念と対応

| 懸念 | 今回の実装 |
| --- | --- |
| 3D外周から2Dに戻ると元の場所へ戻される | 外周の位置・高さを `position3D` に保存したまま `surface2D` で2D探索。地下は安全な地表、水中は水面へ投影。再開時にも保存される。 |
| 外周が2Dマップに存在しない | 同じseed・地形・河川・道路・樹木・施設・ブロック編集を2D表示。旧マップの東西南北に出入口を用意。コンパスと外周全体マップも表示する。 |
| バイオーム・旧マップとの境界が急に変わる | 気候と標高で色を補間し、旧6バイオームの境界から24mかけて外周の色へ移行する。山の遠景を傾斜面で描画する。近景は掘れる1mブロック。 |
| 外周の設置物が全部同じ立方体になる | 既存のBlender製形状・78素材のテクスチャ・回転を共用。半ブロック、階段、窓、照明、設備、ドアも地下を含めて表示。 |
| 穴・坑道の壁や床の表示が実際のブロックと違う | 編集セルと隣接セルの実データから露出面を生成。植物を地面が失われた場所に表示しない。遠景は実際に近景がロードされるまで残し、ロード後は該当面を隠す。 |
| 1回の編集で全チャンクが消える | 編集位置・隣接位置のチャンクだけ再生成し、完成まで旧メッシュを残す。遠景の全再生成も廃止。低品質は最大25、通常は49チャンク。 |
| 橋が水底まで埋まった堤防になる | 水底と橋の床板の間を空気・水にし、水面も橋の下に表示。潜って通れる。 |
| 水流と息継ぎが演出のみ | ワールドの権威側で水流と20秒の息継ぎを更新。水上で回復し、息切れ時は橋の床板を避けて安全な水面へ戻す。停まっていても更新。 |
| 新施設には調べる行動がない | 5施設の探索チェック、初回の魔晶石、全施設達成時の鋼材報酬を追加。近くで調べる／Eで操作。重複受領不可、保存とオンライン同期対象。 |
| 外周で元の町のNPC・資源を操作してしまう | 遠隔の本編シーン起動を拒否し、旧資源のクイックボタンを外周では表示しない。外周で採集画面を開くとクラフトから開始する。 |
| 外周ではドアによる自宅登録や設備が使えない | 囲い判定をワールド全域に広げ、登録・室内判定・家具設置・ゲームへの距離を実座標で判定。作業台・かまど・共有チェストの検索も修正。自宅のペット操作も通す。 |
| 外周の他プレイヤー位置が旧座標で判定される | 2Dの表示・名前・描画順、3Dの表示と近接判定を実座標に統一する。 |
| 2Dの木や花がクリップ／変な位置に表示される | 地面を描いた後に外周の樹木を描画。座標変換解除後に重複していた花・花壇描画を削除する。 |

## 保存・通信

- 保存形式はversion 1のまま。追加項目はoptionalで既存セーブを読む。
- 旧タイルのx/yは外周にいる間も最後の有効な旧マップ座標として保持し、配列添字へ外周座標を流し込まない。
- 水中の時計 `waterAt` は再開時に休止期間だけずらす。アプリを閉じている間に呼吸は減らない。
- 移動・施設報酬・水中処理・部屋は既存のWorld/Action経路を使う。参加者から報酬や部屋を直接確定しない。
