# RPGの農園・牧場・ペット

マップ下の「農園」ボタンから開く。家の中では同名のタブ、暮らし画面でも農園タブから使える。冒険の開始後から利用でき、クリア後の都市運営と共存する。

## 栽培

- 春・夏・秋・冬に各8種類、計32種類。初回は今の季節の種を各3袋、農園コイン100、飼料12、堆肥3を受け取る。
- 木材4・石材2で7×7タイルの農園を設置。道・水・建物・NPC・他の農園・都市設備と重ならない場所だけ選べる。
- 遠くに設置した農園には「農園へ向かう」で自動歩行できる。12区画で開始。農園Lv.2で18区画、Lv.4で24区画。作物は1～3日分の水やりで育つ。1日=3分。
- 水やりは毎日1回、まとめて水やり／収穫も可能。雨は自然に水を与える。季節外の作物は枯れず休眠する。
- イチゴ・トマト・キュウリ・ブドウ・リンゴ・雪ベリー・茶葉は再収穫可能。
- 作物の系統を変える輪作で初期品質+10、堆肥で+15。成長ごとに+5、乾燥で-5。品質80以上は星付き食材となり収穫+1・売価2倍。
- 自動水やり、四季の温室、大きな牧舎はコインと採取素材で導入。薬草1個から堆肥3個を作れる。

## 家畜・ペット

- ニワトリ・ウシ・ヒツジ・ヤギ・アヒル・アルパカ・ブタ・ミツバチの8種類。卵・ミルク・羊毛・ヤギのチーズ・アヒルの卵・アルパカの毛糸・トリュフ・ハチミツを生産。
- 4匹まで、牧舎の拡張後は12匹まで。名前は16文字まで、後から変更可能。
- 給餌・ブラシ・掃除はそれぞれ毎日1回。給餌と健康条件を満たすと種類ごとの1～3日周期で生産。絆80以上で生産+1。最大5個を貯められ、受け取り後に図鑑へ記録。
- 健康と絆から品質を計算する。世話を忘れても死亡しない。
- ペット16種類、6匹まで。犬4種類・猫4種類・ウサギ・ハムスター・ハリネズミ・キツネ・インコ・シマエナガ・カワウソ・ちびドラゴン。ドラゴンは農園Lv.5から。
- 毎日の給餌・なでる・遊ぶ・しつけ、連れ歩き20歩で絆が育つ。散歩報酬は1日1回。しつけはおつかいのコイン報酬を増やす。
- 絆20・満腹40以上で3分のおつかいへ。種／薬草／コインを種類に応じて持ち帰る。おつかい中は他の世話を受けない。
- ペットはマップと家の中に描画。動きはRPGの動きを減らす設定に従う。

## 料理・図鑑・保存

- 新しい農園料理48種類を従来24種類に追加。食材庫の食材を選ぶと組み合わせを含むレシピを検索できる。通常品質を優先して使い、不足分だけ星付き食材を消費する。
- 家の作業台・ストーブ・暖炉で従来の3段階タイミング調理を使う。材料不足・料理の持ち物上限・他の行動中などはサーバー側でも拒否する。素材は開始時に一度だけ消費。
- 料理は食べるほか、暮らしの料理タブで住人や参加者にごちそうし、好みの発見や友好度の向上に利用できる。
- 作物と生産品40種類の累計／最高品質、農園10目標と報酬、農園レベル・設備・ペットの記録を保存する。
- 世界の相対時計と季節を利用し、アプリを閉じている間は成長・空腹・おつかいが止まる。既存の保存データは農園を初めて開くと初期化される。
- 所有者の農園にだけ操作を適用。オンラインでは世界状態に含めて全員へ配信し、途中参加は完全な農園・家畜・ペット状態を受け取る。Peerプロトコル18。

## 画像

ImageGenで作物32・家畜8・生産品8・ペット16・料理48の計112点を生成。生成時に余白を増やし、実際の独立した輪郭に沿ってスプライトを機械的に切り出し、透明の余白付きWebPで配置した。単純な等分割による足・葉・皿の切れや隣の絵の混入を避ける。生成元と座標は `public/sprites/rpg/farm/generation.json` に記録。各画像は独立ファイルなのでUI・Canvasで同じ素材を使う。

## 検証

- `node scripts/test-rpg-farm.mjs`：栽培・品質・設備・動物・ペット・食材消費・調理・保存・不正入力／重複操作。
- `node scripts/test-rpg-farm-browser.mjs`：実際の操作、6種類の画面サイズ、6タブ、料理、画像読み込み、英語／ひらがな。
- `pnpm run server:build && node scripts/test-rpg-farm-server.mjs`：実サーバー、複数参加者、所有権、途中参加。
