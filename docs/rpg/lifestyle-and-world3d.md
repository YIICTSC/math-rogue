# RPG: 交流・都市・農園の拡充と一人称3Dマップ

## 遊び方

- 暮らし → 料理 → 料理の贈り物: 既存の全72料理を住民や近くの参加者に贈れる。包みを6種から選び、80文字までのメッセージを添えられる。1人1日8件。参加者は受け取り／返却を選択する。10分のワールド内活動時間で期限切れになり、料理は送り主の在庫へ戻る。
- 贈り物は大成功品質を保持し、好み・誕生日・性格に応じた会話とニュース／思い出を残す。相手ごとの友好ボーナスは1日1回。保存しても、預かり中の料理・返却済み状態・日別上限を維持する。
- 農園 → ペット: 18種。レトリバーと灰トラ猫を追加。16種類の芸は絆としつけで解放される。満腹を2使い、8秒間隔で披露。初披露の経験値と絆ボーナスは各芸1日1回。
- 農園 → 家畜: 毎日のなでる行動を追加。健康80・絆50以上、迎えて2日以上、飼料8と購入価格の半額があれば同種の子どもを迎えられる。親ごと7日間隔。既存の家畜上限を適用し、生まれた子どもは生産進捗ゼロから始まる。名前は既存の改名機能で変更可能。
- 4姿勢（挨拶／ごろん／お昼寝／ジャンプ）の生成イラストをレトリバー・灰トラ猫・牛・鶏に導入。他の動物も固有の既存イラストを使って揺れ・呼吸・ジャンプの演出を行う。動きを減らす設定を尊重する。
- 都市 → 住民と地区: 6地区方針、6交流プロジェクト、6種から回転する市民要望と状況に応じた助言。自分の建物の方針変更は市の資金30。完成プロジェクトは幸福度・汚染に反映され、地産地消マルシェは農園の出荷価格を20%上げる。要望達成報酬の再取得を防止する。

## 3Dマップ

マップ右上の `2D / 3D`、またはRPG設定 → マップの表示で切り替える。初期値2D。全体マップは2Dで確認でき、閉じると選択した表示へ戻る。位置・経路・採取・イベント・マルチプレイ判定は従来のサーバー側マップを共有する。

- Three.js WebGLによる一人称表示。草原／森／湿原／砂丘／雪原／遺跡の地色と樹木・岩・柱、川、建物、農園、作物、家畜、同行ペット、他プレイヤー、作成住民を表示。
- 空のグラデーション、雲、遠景、霧、時間帯別の光、暖かな窓を追加。高画質では影を描画する。繋がる道路はコード生成し、画像の継ぎ目を作らない。
- `WASD / 矢印` は視点に合わせた移動。`Q / R`、左右旋回ボタン、横スワイプで90度旋回。`E` と既存の調べるボタンでイベントを開く。タップ移動は従来の経路探索へ渡す。十字キー／スティックの設定を共用する。
- 品質は自動／高画質／軽量。軽量は描画範囲と解像度を減らす。静的形状をインスタンス化し、同じ形状をまとめて描画する。視点移動の補間は「動きを減らす」で無効になる。
- WebGL非対応、描画エラー、コンテキスト喪失時は位置を変えず2Dへ戻り、その設定を保存する。レンダラー・GPU形状・テクスチャ・監視・入力・RAFを終了時に破棄する。
- キャラクターと作物は既存のイラストを使うビルボード。地形・樹木・建築は立体形状。別のダンジョンや別の進行状態を作る仕組みではない。

## ImageGen素材

本作業でImageGenを2回使用。背景透過の16アイコンと16動物姿勢を生成。元画像は作業環境の `generated_images` に保存。各対象の透過境界を抽出し、256pxセルに最大220pxで中央配置することで、四辺の欠けと隣セルの混入を防いだ。1024×1024 WebP化し、レトリバー・灰トラ猫の通常画像も切り出した。

- `sprites/rpg/lifestyle/icons.webp`: 4×4、贈り物・花束・弁当・ピクニック・ケーキ・手紙・収穫・おやつ・玩具・ブラシ・絆・昼寝・噴水・マルシェ・庭・祭り。
- `sprites/rpg/lifestyle/animal-poses.webp`: 4×4、行=レトリバー／灰トラ猫／牛／鶏、列=挨拶／ごろん／昼寝／ジャンプ。
- `sprites/rpg/farm/pets/retriever.webp`、`graytabby.webp`: 上記シートから切り出し。

## 検証

- `node scripts/test-rpg-lifestyle.mjs`: 贈り物の預かり・品質・承諾・返却・期限・再送防止・日別上限・NPCの記憶、16芸、家畜の子ども、地区の所有権、6プロジェクト、要望再取得防止、保存と再開、視点相対入力。
- `node scripts/test-rpg-lifestyle-browser.mjs`: 実際のWebGL、6画面サイズ、切り替え・位置維持・コンテキスト喪失・設定保存、農園料理の贈答、芸と都市の追加画面。
- `node scripts/test-rpg-world3d-browser.mjs`: 実際のRpgOnlineで旋回、キーボード・タッチ移動、スマホ縦横／デスクトップ、余計なスクロール、切り替え。
- 既存の farm / town / city モデル・farm / city / mobile ブラウザテスト、英語UI監査、Web build、server build。

`tsconfig.rpg.json` の型チェックでは、新規モジュールにエラーなし。依存先を含む全体には既存の型エラーがあるため、型チェック全体の成功とは扱わない。

## 追加改善: 横画面・暮らしの説明・音声・マップ農作業

- 採取・クラフトのエネルギーと素材欄を本文のスクロール領域に移動。横画面では見出しを縮小し、タブを横へスクロールする1段にする。暮らし・農園・都市・設定・家の各画面にも低い画面向けの余白と高さを適用する。
- 「今日」を「暮らしの状態」に改名。おなか・幸福度・居心地の改善方法、日課の意味、性格と誕生日の設定、1日3分・季節7日・閉じている間の停止を説明する。
- 農場の畑と動物に隣接すると右下に操作を表示。種を選んで植える／水やり／堆肥／収穫、家畜へのえさ／ブラシ／なでる／生産物の受け取り、ペットへのえさ／なでる／遊ぶ／しつけ／芸を実行できる。詳細ボタンから設備・出荷・料理へ進める。
- `farm/mapTargets.ts` のセル座標を表示とサーバー検証で共有。`farm-quick` は自分の畑・動物の距離1以内を検証し、既存アクションの在庫・日別制限・成長・忙しい時の制限を再利用する。通常の農園メニューは従来どおり利用できる。
- 同行していないペットも農場内に表示する。同行ペットと畑・動物の描画座標を2D／3Dの操作対象に合わせる。
- 会話音声に6つのおすすめ（やさしい／元気／落ち着いた／小さくかわいい／渋い／メカ）、6話し方、抑揚0〜100%を用意。文のまとまりを読み、疑問文・感嘆・性格に合わせた控えめな高さと速さ、25〜120msの間を付ける。過去の設定は互換。住民の性格別の初期声も変更する。
- 音声はSpeechSynthesisの日本語／英語エンジンを使用し、端末にある声を選ぶ。機種ごとの声質差は残る。実音の品質評価と、モックで確認する音声キュー・抑揚・ミュート・停止・共有は区別する。
- 音声テストは追加6プリセットの範囲と共有、マップブラウザテストは隣接農作業・動物操作・横画面のメニュー末尾への到達も検証する。

## 3D内の2D配置物（追加調整）

立体モデルがある建物・地形は維持し、NPC・会話イベント・敵・宝箱・封印・隠し入口などは2Dマップの描画を共有するカメラ向きスプライトで表示する。既存NPCは対応する立ち絵を使用。人の高さは約1.5タイル、宝箱は約0.8タイル、草花は約0.45タイル。画像の縦横比を保ち、透明余白を除いた2D描画を地面に接地させる。小さな採取物と季節の花も既存アトラスを使用。隠された地図の断片の表示条件、タップ時の元のタイル座標を維持する。
