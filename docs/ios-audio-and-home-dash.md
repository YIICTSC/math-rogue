# iOS音声・帰宅ダッシュの修正

## 合成効果音と会話音声

GPのエンジンとRPG／ことば日和の独自ボイスは、各ゲームのWeb Audioノードを維持する。共通の復帰処理でAudio Session APIが使える場合はplaybackへ指定し、最初の操作内で無音バッファとresumeを実行する。suspendedだけでなくiOSのinterrupted状態でも復帰を再試行し、次のタップ・キー操作・アプリ復帰でも回復できるようにする。終了したGPのcontextは復帰対象から外す。会話音声を端末TTSに置き換える変更はない。

## BGMの高速な画面遷移

HTMLAudioElementはplay()の完了待ち中から停止管理へ登録する。画面変更時は保留中の要素も即停止・解放し、古いplay()の成功・失敗やonendedから旧曲を再開しない。pause後の遅延resumeとアプリ復帰も再生世代を確認する。事前読み込み済み要素が再利用された場合は新しい所有世代を優先する。

## 帰宅ダッシュ

手動ダッシュは1マップにつき1回。時間・電池・ボスへの攻撃では復活せず、次のマップ（背景エリア）の境界で回復する。新規ランと練習モードの再出発も新しいエリア権利で開始する。電池はFlowエネルギーを補充する。1回のダッシュを温存してボスへ使えば撃退できる。

階段は3・5・7段へ増加。段差1つの高さを抑えつつ階段の出現比率を増やし、上段にコイン、高い階段の上にスターを配置した。床・壁・描画は同じ階段形状を参照する。

## 検証

- `node scripts/test-ios-audio-recovery.mjs`: 遅延playの停止、失敗後の旧URL再試行防止、旧onended・resume競合、中断状態、GPの実ノード、独自ボイスの実再生。
- `node scripts/test-ios-bgm.mjs`: 既存iOS BGM・アプリ復帰・SE経路の回帰。
- `node scripts/test-home-dash-browser.mjs`: エリア単位のダッシュ、電池、階段着地、マップ巡回、ボス、縦横画面、スクリーンショット。
- 会話ボイスの既存PCM・破裂音・抑揚テストも維持する。

Linux上のブラウザによる検証とiOS状態の再現であり、実機WKWebViewの音声出力・Bluetooth等の出力先変更の最終聴取は別途必要。

## 柱の継続表示と空中コース

ギミック準備で消してよい障害物は画面の外にあるものだけに限定し、乗り物の終了時も画面内の柱を残す。長い足場は中心ではなく右端が画面を出てから解放する。空中の柱は太さ56〜148、開口部の高さ153〜219で変化し、隙間の上下位置も緩やかに動く。柱間隔は移動速度と両方の柱の太さを考慮する。本体模様の繰り返しと開口部側の端部を別に描き、見た目と衝突矩形を一致させる。
