# 戦記・技ごとの専用カットイン

40人の追加技（各3技・計120点）と固有必殺（40点）をImageGenで生成。キャラクターごとに4セルの原画を作成し、独立した透過WebPへ分離する。マジック編の戦闘衣装は変身後の戦闘素材を参照し、通常の会話立ち絵だけを参照しない。

- 原画・生成指示・技名対応: `assets/lantern-war/technique-cutins-plan.json`
- 生成元と各画像のSHA-256: `assets/lantern-war/technique-cutins.json`
- 実行時画像: `public/sprites/lantern-war/cutins/<hero>-art1.webp`、`art2`、`art3`、`ultimate`
- 再パック: `node scripts/lantern-war/pack-technique-cutins.mjs`
- 画像・対応監査: `node scripts/test-lantern-war-cutins.mjs`
- 実表示確認: `node scripts/test-lantern-war-cutins-browser.mjs`

技名を個別技キットと照合して画像を選択する。旧セーブのCombatEventも技名を持っているため、新しいイベントフィールドやセーブの変換は不要。敵は従来どおり戦闘アニメーションを使う。

各セルは隣のセルを含めずに切り出し、外周に独立した透明余白を追加する。実画面ではcontainで画像全体を表示し、従来の190%拡大による武器・エフェクトの欠けを防ぐ。バナー演出や戦闘の進行時間は維持する。

## コマの分離と倍率

原画の固定等分ではなく、中央付近の透明な列と、左右それぞれの透明な行を検出して分離する。目に見える内容（alpha > 16）がない8px以上の隙間が必須。今回の40原画では最小11px。切り出し位置と検出した隙間幅を出力台帳に記録する。

原画上の絵の大小・余白量をそのまま表示倍率にしない。切り出し後の透明部分を詰め、alpha > 32 の見える輪郭の長辺を基準に約720pxへ正規化する。縦横比を維持し、全画像を816px角のキャンバスへ配置する。絵が小さく描かれた原画も同じ表示枠に合わせる。ごく薄い光の尾も削らずに保持し、全体は最大784pxに制限して全周16px以上の完全透明な余白を確保する。武器・衣装・主要エフェクトが外周24px以内に入らないことと、実ピクセルの見える長辺が704〜730pxに収まることを画像監査で検証する。倍率は台帳の `normalizationScale` に記録し、2.5倍を超える拡大はパックを失敗させ、解像度の高い原画の再生成を促す。
