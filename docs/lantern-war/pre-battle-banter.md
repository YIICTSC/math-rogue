# 継界戦記：出撃前の掛け合い

44人の全組み合わせ946組に、個別に執筆した日本語の呼びかけ・返答を用意した。計1,892台詞。自分同士と、順序だけを逆にした重複組は含めない。同じ編の相手、別の編の相手、アステルとリュラの組も原稿に含む。全文は [全組台本](banter-manuscript.md)。

## 原稿の方針

名前や職業を入れ替える共通台詞は使わない。戦記の王権・軍法・撤退・補給と、各人の元の物語や技術を、組み合わせごとに結びつけた。例えば、反逆の高校生には命令に反する理由、あかりには母の杖、しずくには観測と家系、ひよりには治癒で受ける痛み、まどかには装置の事故、みらいには舞台と隠した弱さ、ヴェスパーには指揮の責任、セーブルには撃たない選択がある。

楽しい場面は食事、部活、忘れ物、船酔い、灯台の階段、道具の用途などから作る。二人のレオンの呼び間違い、世話焼き同士の休憩確認、完璧な会長の想定外、森に返される自分の声など、相手が変わると成立しない返しを目指した。事故や戦争の被害そのものを笑いにはしない。

## ゲームでの表示

日本語・ひらがな表示では、エンドレスのミッション導入の後、戦場へ進む直前に一組を表示する。出撃編成に実際に配置され、加入済みの二人が対象。未配置・未加入の人物を、会話の都合だけで前線へ登場させない。相手が二人に満たなければ追加会話はない。

未読の組を優先し、一巡後は読んだ回数が少ない組を優先する。複数組が候補なら直前の組を避ける。同一セーブ・到達航路・編成からの選択は再現可能。会話内容は抽選・組み立てをせず、選ばれた組の固定原稿をそのまま読む。

二人の立ち絵を左右に固定し、話し手だけに指定の表情を使う。二台詞目から「戦場へ」を押した時に読了を保存する。航路のプレビュー、会話を開いただけの時、再挑戦では既読回数を増やさない。保存データには選択済みの原稿も含め、中断・再開で相手を入れ替えない。

本追加は日本語原稿の第一稿。英訳は未収録のため、英語UIでは既存のミッション導入を維持し、本稿を日本語のまま混在させない。日本語セーブを英語で再開しても、会話を未読のまま安全に戦場へ進める。新規ボイスはこの変更では生成しない。
