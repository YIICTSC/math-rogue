# 出撃前の掛け合い音声：選抜フルボイス＋人物別の短い返し

ユーザーの方針変更により、全1,892台詞を個別録音する方式を終了。原稿946組のうち95組（10.04%）をフルボイスに選定し、それ以外は話者本人の短い代表ボイスを再生する。字幕・会話内容・二人の順番・表情・既読管理はそのまま保持する。

## 選定と感情

フルボイスは片方だけでなく、必ず二人のやり取り全体を録音する。王権や過去の責任、帰還と故郷、仲間同士の信頼、人物固有の印象的な軽口から95組・190台詞を選定。全44人を4〜6組ずつ含む。例：アステルとリュラの帰還への誓い、二人のレオンの呼び分け、ヴェスパーとセーブルの命令への責任、ナギとミレアの星と灯台。選定した全原稿は [選定一覧](banter-voice-selection.md) を参照する。

代表ボイスは各人物10種類、計440本。「疑問・同意・受け止め・決意・心配・驚き・軽口・感謝・制止・しみじみ」を、人物ごとの口調・距離感で執筆する。例：湊は「どうでしょうか？」「はい、そうですね！」、大和は「どういうことだ？」「ああ、そうだな。」。深刻な傷や喪失を扱う会話に笑い声を割り当てず、拒否・制止を単純な肯定で返さない。

`src/mini-games/lantern-war/banterVoicePolicy.json` が固定の選定組・人物別短文・全組の発話意図を持つ。場面再生時にランダムな相槌を選ばない。同じ話者・原稿に対して同じ意図の返しを使い、原稿が変われば準備工程で内容の一致を再検証する。汎用の受け止めは「うん」「はい」「ああ」など、質問や自己紹介を勝手に付け足さない短い発声にする。

## 規模と音源保全

- フルボイス：95組 × 2人 = 190本
- 代表ボイス：44人 × 10種類 = 440本
- 新計画の録音数：計630本（旧1,892本から約67%削減）
- 字幕1,892台詞すべてに、本人のフル台詞または代表ボイスを割り当てる。

すでに作った録音のうち、選定組に含まれるものはhashと発音を検証して再利用する。追加検査で誤読が疑われるものは元ファイルと記録を `tmp/lantern-banter-voices/full-semantic-originals/` へ退避し、同じ承認済み参照で補修する。既存709エントリーとその音源は変更しない。選定外の旧フル録音は `tmp/lantern-banter-voices/unused-full/` へ退避し、配信しない。旧計画と記録は `full-manuscript-plan.json` / `retired-full-voices.json` に保持する。既存709再生エントリーと元音源は変更しない。

## 生成・検査

既存40人は本編の参照、航路4人は独立した承認済み参照を維持。アステル・リュラは成人v3、湊は `magic-voices/MINATO/attack-1.ogg`。参照の欠落・hash不一致で勝手に別の声を作らない。最新公式Irodori-TTSコード・モデルを確認し、現行v4.1 Small MeanFlow、モデル・codec両方CPU、bf16、2 threadsで生成する。基本4-step、疑わしい音源だけseed・steps・読みを調整。繰り返し不良になる録音は同じ公式v4.1の通常Small（RF）・40-step・text CFG 3.5へ個別に切り替える。モデルとcodecは引き続きCPU、参照音源は同一。合格済み録音は再生成せず、モデル・revision・生成条件を録音ごとに記録する。短い返しは約0.8〜3.5秒の生成枠で、台詞を言い足させない。

190本の選定フル音声と440本の代表音声をASR・波形・hashで検査。代表返しは正規化した言語部分の発音一致を必須とし、単語の読み違いや言い足しを通さない。文末助詞の伸ばし（「助かるよー」）、短い笑い・明示された感嘆詞の促音表記、単独の相槌の長音表記、同意の返しで肯定文が続く「ええ」の表記、感謝の「ありがと／ありがとう」、感嘆詞「へえ／へぇ／へー」、口語「ねえか／ねーか」の表記だけを限定的に同等扱いとする。単語内部の長音や言葉の違いは保持する。`tease` として台本に明示された短い笑いはASRの非言語部分として比較から除き、残る言葉の一致を必須とする。生成原稿の笑いは削らず、ASRで笑いの実演まで確認できたとは扱わない。長いフル台詞はCER 0.18以下と人名確認を維持。意味が変わる近似認識はmediumの別ビーム設定でも確認し、必要な語・語頭・逐語一致の個別条件を `voice-corrections.json` に保持する。数値が基準内でも指定語が欠ければ再試行へ回す。条件のhashを検査と公開時に照合し、ビルド後にも全音声を再検証する。フル台詞で逐語一致しないものは、追加の意味確認と現音源hashに結びついた承認記録も公開条件にする。音源を再生成した場合、古い意味確認は引き継がない。全文の機械的なひらがな化は避け、辞書で確認できる語と手で確認した読みだけを補正する。検査ルール更新時は旧判定を合格数へ混ぜず、保存済みASRを再評価する。生成は16本ずつ区切り、再開時は未検査の既存音源を先に確認する。要修正分は他の生成を止めない。疑わしいものはWhisper mediumで再検査する。その後も不一致が残る音源は、日本語向けKotoba Whisper v2（revision固定、CPU int8・2 threads・beam5・原稿の誘導なし）で独立検査する。正規化後の発音が完全一致し、固有名・指定語・波形・音源hashも合う場合だけ救済する。近似認識や否定語の欠落、手動で拒否した音源は救済しない。同じ音源の検査証跡を保持し、音源を変えたら古い証跡を使わない。一次判定が閾値内でも言い足しが確認されたものは保留する。「あの印」のような文脈固有の読みは辞書で一致させ、辞書更新後は保存済みASR結果を再評価する。個別の不良は永続再試行キューへ回し、ほかの制作を継続。1巡最大8本、再試行間隔は30分〜最大6時間。読みの明示修正は待機を解除。参照・音源hashの不一致は保護のため停止して調査する。手動指定した生成stepsを再試行で下げない。

全630本の合格後、`voiceManifest.json` に同一話者の音源参照を登録。選定外の1,702台詞は440本を再利用し、同じ意図をキャラ違いの音源で再生しない。元の字幕キーから音源を解決するため、再生停止・ミュート・画面遷移制御は既存機構を使う。英語画面と未収録のエンドレス導入は従来の仕様を維持する。

```sh
node scripts/lantern-war/prepare-banter-voices.mjs
node scripts/test-lantern-banter-voices.mjs --plan-only
node scripts/test-lantern-banter-routing.mjs
/workspace/Irodori-TTS/.venv/bin/python scripts/lantern-war/test_banter_retry_queue.py
/workspace/Irodori-TTS/.venv/bin/python scripts/lantern-war/test_banter_pronunciations.py
/workspace/Irodori-TTS/.venv/bin/python scripts/lantern-war/test_banter_review_rules.py
/workspace/Irodori-TTS/.venv/bin/python scripts/lantern-war/complete-banter-voices.py --publish
```

`voice-build.json` は録音実績、`voice-review.json` は現音源hashの検査、`retry-queue.json` は再試行状態、`status.json` は630本に対する進捗。全量合格前の公開は行わない。ゲーム操作・実OGG再生・元音声保全・アセット一覧・英語gate・Web/サーバービルド後にmainへpushする。長時間作業中にmainやソースが変わっていれば、安全に取り込んで再検証する。

## 既存音声による代用

音声生成を打ち切り、検査済み622録音と、同じ人物の検査済み短文を使う8件の代用で1,892台詞をカバーする。代用の一覧と理由は `assets/lantern-war/banter/fallbacks.json` を参照する。選抜フル台詞190件のうち2件は短い問いかけ、返し440件のうち6件は同じ人物の別の返しを用いる。字幕は変えない。未合格8録音は公開対象から外し、作業用退避先 `tmp/lantern-banter-voices/substituted-unapproved/` に保存する。生成・検査済み音声の参照元とハッシュは変更しない。
