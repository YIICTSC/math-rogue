# ストーリー・追加技の音声制作

2026-10-29のユーザー指示により、ストーリー音声と追加個人技120種類の音声を新しく制作する。過去に破棄した音源は復元しない。最新main `cf7e47cd` のカットイン画像と描画処理は保持し、新たな画像・Blender制作は行わない。

## 対象と声の同一性

- 章の導入・終幕、支援会話、遊撃戦、ナレーション、エンディングの各主人公の言葉を収録する。
- 40人のLv.3/6/12の技をキャラクターの性質に合わせたカタカナ名に変更。技ID、効果、消費AP、習得レベル、カットイン参照先は維持する。
- アステル・リュラは承認済み成人v3の参照音声とhashを固定する。承認済み20本も保持する。
- 高校編・マジック編は各主人公の既存ストーリー音声 `endless-true-1.ogg` を参照。ダンジョンズ2は既存のキャラクター音声、星潮の航路は元のvoice-anchorを使用。湊は `public/sfx/magic-voices/MINATO/attack-1.ogg` の戦闘ボイスを明示的に参照する。
- 参照音源が欠けている場合、勝手に声を設計し直さず準備工程で停止する。
- 技は20 steps、3〜6秒の枠で、参照人物の声を保ちつつ、明瞭かつ力強く技名を叫ぶ演技を指定する。音量だけを増幅する処理ではない。

## 再現・検証

`prepare-story-techniques.mjs` が再現可能な台本と参照音声hashを準備する。既存の `catalog.mjs` / `prepare-voices.py` も現在のポリシーではこの準備工程へ委譲する。今回の台本の全439本は既存戦闘20本、追加技120本、キャラクターストーリー299本（重複台詞は同一人物内で共用）。

モデルは公式最新版を確認したIrodori-TTS v4.1 Small。公式コードはorigin/mainとの差分0を確認。推論とcodecをCPUに固定しbf16で生成する。モデルrevision、コードrevision、seed、steps、参照hash、音声hashを `voice-build.json` に保存する。生成は中断後に再開可能。

```sh
node scripts/lantern-war/prepare-story-techniques.mjs
/workspace/Irodori-TTS/.venv/bin/python scripts/lantern-war/generate-voices.py --batch-size 2
/workspace/Irodori-TTS/.venv/bin/python scripts/lantern-war/review-voices.py
node scripts/lantern-war/verify-voices.mjs
node scripts/lantern-war/finalize-voices.mjs
```

ASRで発音が疑わしい音源を特定し、強いASRで再検査するか、個別の発音・尺・seedを修正して再生成する。未解決の検査結果や欠けた音源がある間はパッケージ化と公開を行わない。

台本・声の参照・Lv解放は `test-lantern-war-battle-voice-catalog.mjs`、技の挙動は `test-lantern-war-techniques.mjs`、音声制御は `test-lantern-war-voice-controls.mjs`。パッケージ化後に実OGGによるブラウザ再生、英語UI監査、Web・サーバービルドを実施する。

## 発音調整とメモリ制御

発音が不安定だった4技は、効果・技ID・習得レベルを維持して「バイオ・リブート」「ライフ・ガーデン」「ケミカル・フレア」「マージン・ブレード」へ調整。採用しない旧音源は配信対象から除外する。読み仮名・発声・秒数・steps・seedは個別の `voice-corrections.json` に記録し、カタログを準備し直しても上書き設定を維持する。

TTSと高精度ASRを同時にロードすると8GB環境でメモリ不足になるため、両スクリプトは同じ `cpu-audio-heavy.lock` の排他ロックを利用する。高精度ASRを待つTTSはモデルをロードしない。完成処理も生成→検査→再生成を順番に実行する。高精度ASRの `--follow` は生成待ちを占有するため使用しない。

冒頭2章の決意の台詞は選択主人公の発話へ訂正。あかりが自分の名前を呼ぶなどの不整合を解消し、アステル・リュラそれぞれの録音を用意する。旧話者の録音は、既存生成ジョブが完了してから完成処理が配信対象外へ退避する。

最終章の王冠の扱いを語る台詞も選択主人公へ統一し、序盤から結末まで主人公の意思と声を一致させる。
