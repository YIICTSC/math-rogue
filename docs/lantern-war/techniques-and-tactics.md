# 継界戦記：固有技と作戦の拡張

全40人に3技ずつ追加し、既存必殺と合わせて各4技。新しい120技はLv.3・6・12で順に習得する。既存セーブは現在の経験値から利用可否を判定し、明示的な作戦設定を保持する。未設定・おまかせ作戦は現在レベルの固有技を組み込む。

## 育成と作戦枠

| レベル | 作戦枠 |
|---|---:|
| 1–3 | 3 |
| 4–6 | 4 |
| 7–9 | 5 |
| 10–12 | 6 |
| 13–15 | 7 |
| 16以上 | 8 |

追加共通技は、守りを固めるLv.2、戦意を高めるLv.4、状態を整えるLv.5、防具を崩すLv.7、連続攻撃Lv.10、好機を仕留めるLv.14。既存の通常攻撃・通常回復・一列攻撃・固有必殺も使える。条件は16種類、対象は12種類。基本・攻勢・支援・妨害・追撃の5プリセットを備える。

## 戦闘上の扱い

攻撃・防御の強化と弱体は交戦内でのみ集計し、終了後の能力値に蓄積しない。防御強化は+8、攻撃強化は+6、弱体は-6まで。AP不足、未習得、回復・解除対象がない場合は次のルールへ進む。近接は前衛を優先し、遠距離・狙撃は後衛を狙える。槍の庇う・反撃・ガードと連動する。通常攻撃を最後に残すと、条件に合う技がない場合も行動できる。

作戦設定画面の技カードで必要レベル・AP・効果を確認できる。技カードはタップで詳細表示、未習得技は作戦の選択肢で無効化する。作戦は追加・削除・上下入れ替え・プリセット変更に対応し、既存の保存方式で保持する。新技は既存キャラの演出と攻撃・回復音声を利用する。
