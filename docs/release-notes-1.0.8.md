# 学習ローグ 1.0.8 リリースノート

更新日: 2026-10-12
対象: GitHub `main` の `c55e0022..75e528b7`（197コミット）をローカルへ反映した差分
iOS: Version `1.0.8` / Build `60`

## 変更点

- RPGワールドを大幅に拡張し、地域探索、住民との会話、採集、釣り、農業、料理、家具、ペット、街の発展を追加した。
- 3D探索、採掘、建築、家づくりと、ストーリーブック風の3Dキャラクター表示に対応した。
- オンライン協力、招待、途中参加、観戦、ランキング、専用ロビー、結果画面を改善した。
- VRを300ミッションまで拡張し、協力ルーム、再出撃、装備、高低差、サバイバルルールを追加した。
- GAKURO GP、カート、ゴルフ、リズム、釣り、家具スポーツなどの進行とミニゲームを拡張した。
- 学校ダンジョンに2D／3D表示切替、50ステージの道場、旅の村と新しい演出を追加した。
- 主人公・住民・敵の音声、BGM、効果音、イベント演出を追加・改善した。
- 縦画面・横画面のスマートフォンUI、オンライン準備画面、操作、画像表示を改善した。
- 画像・WebP資産の読み込みと初期表示を最適化し、各モードの安定性を向上した。

## 主な実装領域

- `src/rpg/`、`src/three/`、`src/mini-games/`
- `src/services/audioService.ts`、`src/services/eventService.ts`、`src/services/storageService.ts`
- `src/components/`、`src/styles.css`
- `public/` の新規3D・イベント・音声・WebP資産
