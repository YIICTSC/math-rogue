# 学習ローグ 1.0.8 リリースノート

更新日: 2026-10-16
対象: GitHub `main` の `c55e0022..75e528b7`（197コミット）をローカルへ反映した差分
iOS: Version `1.0.8` / Build `64`
Android: versionName `1.0.8` / versionCode `19`

## 変更点

- Steam版でRPG・GAKURO VR・GAKURO GP・GAKURO GOLFのXboxコントローラー操作を拡充。移動、視点、長押しアクション、走行、ショット、メニューと問題画面の操作を切り替え、切断・画面復帰時の入力残りを防止した。
- コントローラー接続時の操作ガイドと、設定項目を上下で移動・左右で調整する操作を追加した。

- RPGワールドを大幅に拡張し、地域探索、住民との会話、採集、釣り、農業、料理、家具、ペット、街の発展を追加した。
- 3D探索、採掘、建築、家づくりと、ストーリーブック風の3Dキャラクター表示に対応した。
- RPG、GAKURO VR、GAKURO GP、GAKURO GOLFの4つのオンライン対応ゲームを追加し、招待、途中参加、観戦、ランキング、専用ロビー、結果画面を改善した。
- GAKURO VRを全100ミッションに対応し、協力ルーム、再出撃、装備、高低差、サバイバルルールを追加した。
- GAKURO GP、カート、ゴルフ、リズム、釣り、家具スポーツなどの進行とミニゲームを拡張した。
- 風来の小学生シリーズに2D／3D表示切替、50ステージの道場、旅の村と新しい演出を追加した。
- 主人公・住民・敵の音声、BGM、効果音、イベント演出を追加・改善した。
- 縦画面・横画面のスマートフォンUI、オンライン準備画面、操作、画像表示を改善した。
- 画像・WebP資産の読み込みと初期表示を最適化し、各モードの安定性を向上した。

## Build 64／Android 19の追加修正

- GAKURO GPの全8コースで、建物・樹木・装飾が別区間を含む走行路に重なる配置を修正した。
- 実際の3Dモデルの大きさ・回転・高低差を考慮して配置を判定し、コースのテーマと走行レイアウトを維持した。
- 高画質・低画質およびスマートフォン縦横表示で走行路の遮蔽がないことを検証した。

## Build 63の追加修正

- GAKURO VRの足音への反応距離を2.5mから1.2mへ緩和し、立ったまま背後へ接近してホールドできるようにした。
- 回収・しゃがみ・ホールド・射撃・スイッチ・光センサー・防衛・デコイの8種類の操作ガイドに、ゲーム描画による操作例スクリーンショットと要点を追加した。
- 操作ガイドの日本語・英語、縦画面・横画面の表示を調整した。
- VRのステージ検証を全100ミッション（5章×20任務）の構成に合わせた。

## 主な実装領域
