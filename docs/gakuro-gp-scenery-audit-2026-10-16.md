# GAKURO GP 背景配置の走路干渉対策

## 原因と修正

- 背景の配置元となる道路からの横方向オフセットだけでは、別のカーブ・折り返し区間に建物が重なる場合があった。
- 全周1024区間に対し、拡大・回転後の実際の部品の境界を照合する `SceneryClearance` を追加した。
- 道路中心から左右16m（走路・基礎・路肩を含む）、路面上8mを保護する。高低差も判定し、十分に上や下へ離れた背景は残す。
- 干渉するビル、本棚、観客席、柱、ソーラーパネル、樹木、浮島などの配置だけを省く。車両、ガードレール、意図したコースゲートは対象外。
- GLBモデルは部品単位でばらばらに消さず、配置全体で判定する。浮島とその上の建物・樹木も一緒に判定する。
- クラウド・ガーデン、森の教室、海辺の学校では、車両に追従する巨大な背景丘を無効化した。雲・光の粒・既存のコース別装飾は残す。
- コース形状、車両物理、ミニマップ、レースルールは変更していない。

## 全コース検証

部品の境界と保護領域との重なりを計測。変更前は低画質、変更後は低画質・高画質それぞれで実際のGLB読み込み後に確認した。部品数であり、建物の棟数ではない。

| コース | 変更前・低画質 | 変更後・低画質 | 変更後・高画質 |
| --- | ---: | ---: | ---: |
| NEON CAMPUS | 2 | 0 | 0 |
| CLOUD GARDEN | 120 | 0 | 0 |
| SOLAR WORKS | 8 | 0 | 0 |
| LIBRARY LOOP | 18 | 0 | 0 |
| FOREST CLASSROOM | 144 | 0 | 0 |
| HARBOR SCHOOL | 134 | 0 | 0 |
| AURORA LAB | 70 | 0 | 0 |
| STADIUM SPRINT | 14 | 0 | 0 |

- 各コースでスタート、干渉箇所付近、終盤の走行視点を撮影した。
- クラウド・ガーデンと放課後スタジアムはスマホ縦・横画面でも撮影した。
- クラウド・ガーデンの風車アニメーションが残ることを確認した。
- 幅のある建物、別区間、終端接続、高低差、頭上空間を単体テストで確認した。
- 既存の全8コース・ミニマップ・走行カメラのテストと型チェックが通過した。
