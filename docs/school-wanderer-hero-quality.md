# 風来の小学生：主人公モデル品質レビュー

## 対象と調査

対象は `SchoolDungeonRPG.tsx` と `SchoolDungeonRPG2.tsx` の主人公「わんぱく小学生」。赤い鉢巻、茶髪、白シャツ、青い短パン、ランドセルは既存主人公画像とゲームデータから確認した特徴。固有の人名や追加の物語設定は作っていない。仲間は保健係あおい、体育係たける、図書係ひなたで、役割は回復・援護・道具回収。

既存のゲームは11×9タイルを表示する見下ろしターン制。シリーズ2にはカードもある。2DスプライトとCanvas描画、進行中のThree.js描画の両方がある。今回は主人公1体と代表装備2点を高品質化し、既存の敵・仲間・マップ試作は保持した。

ユーザーの参考画像は、丸い形、明快な顔、小画面での装備の存在感、滑らかな質感の指標として使用。特徴的な耳・衣装・紋章などは採用していない。髪型は追加指定に合わせ、大きな束を斜め上へ流す独自のスパイキーな茶髪に変更した。

## 再設計した仕様

- 頭身は約2.6〜2.7。頭部の頬・顎・額を独自の断面メッシュとSubdivisionで形成。身長の半分近くを頭と髪のシルエットが占める。
- 顔は黒い縦楕円の目、短い眉、小さな口、最小限の鼻。以前の虹彩・白目・大きいハイライト・頬の装飾を取り除いた。
- 前髪・側面・背面・頭頂に広い根元と尖った毛先を持つ曲線メッシュを配置。曲線のフレームを連続させ、ねじれによる凹凸を減らした。
- 小さい胴、短く太い腕・脚、丸い手と厚底の靴。制服のボタン・細かい縫い目・ポケットを削減し、鉢巻・赤いスカーフ・ランドセルを残した。
- 鉛筆ソードには六角断面、削った先端、鍔、握り、金属の口金を追加。校長の盾には厚い面取り、青い面、独自の学校バッジ、背面の握りを設けた。
- 肌・髪・衣服・革・金属はPrincipled BSDFのroughness、metallic、coat、specularを分けた。粗いマット一色から、適度な反射のある表面へ変更した。
- 独自メッシュの法線を再計算し、曲面にはSmooth Shadingと必要なSubdivision、硬い縁にはBevelとWeighted Normalを適用した。

## 改善サイクルと画像確認

初期の約3頭身試作と、その後の参考画像レビューは別ディレクトリに保存。最新の再設計については次の3サイクルを行った。

1. `compact-1`：体型と顔を全面変更。正面・45度・側面・背面を確認。腕の断面が硬く、髪の反射が強く、装備を見せる画像が不足していた。
2. `compact-2`：腕・脚の曲面と法線を修正。反射を調整し、鉛筆ソードと盾を新規造形。装備ありの画像を追加。通常の前髪はかわいさに寄っていた。
3. `compact-3`：追加の髪型指定を反映。斜め上への大きなスパイクと尖った側面・背面の束へ変更。正面・45度・側面・背面・ゲーム視点・装備あり画像を実際に確認した。

最終画像は `assets/school-wanderer/hero-quality/compact-3/`。各サイクルの元画像も保存して比較できる。

## ゲーム用出力・アニメーション

- 編集用：`assets/school-wanderer/hero-quality/hero-quality.blend`
- ゲーム用：`public/models/school-wanderer/hero-quality.glb`（668,668 bytes）
- スクリプト：`scripts/blender/build-school-hero.py`
- 正面等のPNG：`compact-3/front.png`、`angle.png`、`side.png`、`back.png`、`game.png`
- 装備ありPNG：`compact-3/equipped-angle.png`、`equipped-front.png`
- 表情PNG：`compact-3/expression-*.png`
- GLBは主人公、鉛筆ソード、校長の盾の3ルートを含む。主人公の通常表情は19,820 triangles、27 meshes。表情差分は同時に描画しない。テクスチャは使わない。
- 7表情：通常、笑顔、驚き、怒り、悲しみ、ダメージ、勝利。
- 7動作：Idle、Walk、Run、Attack、Hit、Victory、Defeat。腕・脚・頭・胴の剛体パーツアニメーションで、武器は手のsocketに追従する。布・髪の物理シミュレーションやスキニングは未導入。Runは素材として出力し、通常のターン移動はWalkを使用。

Blenderファイルでは確認用の鉛筆ソードと盾を装着している。GLBでは独立した装備ルートとして出力し、実ゲームの所持・装備状態で脱着する。静止画確認用にNLAトラックはミュートして保存しているため、Blenderで再生するときは確認したいトラックを有効にする。

再生成の例（PowerShell、Blender 4.5.11）：

```powershell
$env:SCHOOL_HERO_CYCLE='3'
& '..\tools\blender\blender-4.5.11-windows-x64\blender.exe' --background --python scripts/blender/build-school-hero.py
```

## 組み込み・検証

Three.jsは旧キットと新しい主人公GLBをロードし、主人公のみを置き換える。鉛筆ソードと校長の盾は種類IDで新モデルを選ぶ。他の装備は旧キットを保持し、胴・頭の取り付け位置を新体型に合わせた。頭巾・ヘルメット時には髪を隠し、ランドセルの交換時には元のバッグを隠す。

初期表示は2D。ゲーム画面の右下「2D / 3D」で明示的に切り替える。3Dの拡大確認は「Sts」→「装備」。ゲーム進行・能力値・所持品・当たり判定は従来のエンジンに保持する。

`node scripts/test-school-3d.mjs` でシリーズ1・2の起動、7回の装備操作、頭巾による髪の非表示、透視・未探索、単一表情、7動作の出力、Attackでの腕と武器の追従、道場移動、2D/3D切り替え、コンテキスト喪失時の復旧を確認。PC、390×844、844×390のブラウザ表示を確認した。これはWindowsのブラウザテストで、携帯実機・コンソールでの性能試験ではない。

3DモジュールのTypeScript確認と通常ビルドを実行する。Web・Androidのアセット一覧を再生成する。commit・pushは実行しない。

## 他キャラクターへの展開計画

1. あおい・たける・ひなた：役割ごとの既存スプライトを確認し、髪・服・所持品のシルエットを先に設計。主人公の顔・身長・材質基準を適用し、単なる色違いにしない。
2. 通常敵：種別ごとに体型と攻撃シルエットを設計。スライム・幽霊・植物・文房具の生き物を同じ球体から作らない。
3. ボス・先生・商人：主人公との大きさと密度を差別化。校長という既存の役割を基に、衣装設定は追加調査する。
4. その他の装備・地形：今回の厚み、色面、面取りの基準を展開し、ゲームの小表示と実機性能を優先して調整する。LODは実機計測に基づいて必要性を決める。

これらは展開計画であり、今回まとめて高品質モデルを生成済みとするものではない。
