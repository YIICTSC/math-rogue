# TypeScript型チェックの修正（2026-10-14）

## 結果

以前のソース・サーバー全体の型チェックで報告されていた467件を解消。React 19用の型定義を追加すると145件の実装・型定義の不一致が残り、それらも修正した。`src`、`server`、`vite.config.ts` を含む `pnpm run typecheck` がエラー0件で完了する。

型チェックを無効化するコメントや包括的な `any` による回避は追加していない。通常の `pnpm run build` に型チェックを追加し、エラーがあればビルドを停止する。

## 修正内容

- React・React DOMの型定義と、再実行可能な `tsconfig.typecheck.json` を追加。
- Playerの使い魔配列と数値を使う進行フラグを実装に合わせて定義。
- `NORMAL` という旧言語設定を正規の `JAPANESE` に統一。
- 魔法主人公の元データと、生成後のルール設定に必要な項目を区別。
- カードテンプレートとID付きカード、クレジットの任意項目、読み取り専用配列、町の会話配列、Reactのref初期値などの型を整合。
- イベントのカード強化18か所で未定義の `prev` を参照していた処理を、最新状態を受け取るsetter内部へ移動。
- 麻雀のCPU捨て牌変数と効果音、サバイバーの記録用スコア参照を修正。
- 協力プレイの自己プレイヤー判定・ホスト参加者検索とプレビュー状態を修正。
- ボタンクリック時にマウスイベントをプレイヤーIDやアイテムとして渡さないように修正。
- ダンジョンの消耗品分類を実際のアイテム識別子に合わせ、家具ゲームの型に既存のボウリングを補完。
- VR保存記録を検証し、旧ミッションの記録を維持しながら型付きデータを構築。
- 翻訳監査で検出した既存カード説明2件のひらがな変換漏れを補完。
