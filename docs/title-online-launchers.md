# タイトル画面のオンライン4種

学習ローグのタイトル画面にRPG・VR・GAKURO GP・ゴルフの4ボタンを常時表示する。
ロゴを3回押す解禁操作と、そのセッション内だけの解禁状態は廃止する。

タイピングモードが表示される画面では、その直下へ4ボタンを置く。
タイピングが表示されない画面では、通常のモード選択の次に並べる。
4ボタンを1列に並べ、補足説明は取り除く。GAKURO GPは2行にしてボタン内に収める。
名前の省略はタイトル画面のボタンだけに適用し、各ゲーム内の名前は変更しない。

日ごとの利用制限・課題制限・オフライン配布版の通信制限による利用可否は、既存のルールで判定する。
利用できない状況でもボタン自体は表示する。
