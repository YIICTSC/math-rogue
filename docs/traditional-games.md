# 世界の伝統ゲーム集

ミニゲーム一覧から最初から選択できる。縦横それぞれに生成した主人公たちのタイトルイラストを表示し、ひとりプレイ・部屋作成・招待参加へ進む。キャラクターと席数を選ぶ。CPU戦では空き席をすべてCPUが担当する。オンラインではホストが対戦ルールと席数を選び、6桁のコードまたは招待URLを共有する。ゲストが切断した席はCPUが引き継ぐ。手牌と山札の順番はホストの対局状態に保持し、参加者には自分の手牌と公開情報を送る。

## 収録ルール

| ゲーム | 席数 | 採用したルール |
| --- | --- | --- |
| コンペティティブ・ドミノ | 4 | ペア戦、山札なし、200点 |
| キプロス | 2〜8 | ダブル9、八方向の根元を優先、60点 |
| チキンフット | 2〜6 | ダブル9、中心に4本、以後のダブルに3本、10局の罰点 |
| メキシカントレイン | 2〜8 | ダブル12、開放列・共有列・ダブル優先、13局の罰点 |
| ファイブアップ | 2〜4 | ダブルの枝分かれと5の倍数、61点超 |
| スニッフ | 2〜4 | 最初のダブルだけ分岐、未接続の脇を計上、250点 |
| セブン・ロックス | 2〜4 | 全員7枚、最初のダブルだけ分岐、250点 |
| バーゲン | 2〜4 | 同じ端を作る2点・3点、10点または15点 |
| ファイブ・アンド・スリー | 2〜4 | 3と5の倍数、61点ちょうど |
| 42 | 4 | ペア戦、ビッドと目の切り札、7マーク |

各ドミノ卓のアプリ内ルールから、採用した基本ルールの参照ページを開ける。[GameFarm ドミノのルール](https://gamefarm.jp/rule/ruledomino.html)

- ピーパーは2〜6席で、ボム・マイン・リターンを含む基本ルールを3局の得失点で集計する。赤い1が配られなかった局は親がリードする。[世界遊戯博物館 ピーパー](https://sekaiyugi.com/2020/10/18/peeper/)
- クロキノールは2席または4席。通常の1対1は各12投、ペア戦は各6投で1局。局の勝者に2点、引き分けなら各1点を付け、4局終了時に同点なら追加局を行う。[World Crokinole Championship](https://worldcrokinole.com/thegame.html)
- ごいたは4席のペア戦。初手や全員パス後は受けを伏せる。五しは自動で公開し、向かいの味方が続行か配り直しを選択する。六し以上は手役として精算する。[能登ごいた保存会](https://goita.jp/rule/)

ごいたの盤面は自分を手前、味方を向かい、相手ペアを左右に配置する。ペア得点と役割を色分けし、手番を枠で強調する。

クロキノールは自分の円盤を後ろへ引き、指を離すと発射する。引く向きで方向、引く距離で強さを決める。キャンセルした操作は発射しない。

チュートリアルは本番と同じ操作で、決まった手牌・配置から一手ずつ試せる。各ルールの練習のあと、そのゲームのCPU戦に進める。

## 盤面と駒

ImageGenで真上から見た布・木・畳の素材と、ドミノ牌、数字牌、竹駒、赤と青の円盤を制作した。素材を個別に切り出し、WebPとして `public/sprites/traditional-games/` に収録した。目や文字、板上の得点線はゲーム内で重ねて描画する。

## 対局ボイス

トランプゲーム集と同じ高校編・マジック編の26人に、手番と伝統ゲームの開始、上がり、ピーパーのボム、ごいたの五し、クロキノールの中央穴成功を各1本収録した。結果のボイスはトランプゲーム集の音源を共用する。手番の声は自分の手番を5回迎えるごとに、前の発声から13秒以上空いたときに再生する。

Irodori-TTS公式コードの確認時のrevisionは `f01c08cd40c0afa62a862439a5de12f6dcf62054`。CPU対応の v4.1 Small と Small MF を、speech.cpp 0.11.0で使用した。推論と音声コーデックはともにCPU、2スレッドで実行する。元の音源、台詞、シード、生成秒数、モデルのrevision、変換モデルのSHA-256、出力のSHA-256は [生成記録](../assets/traditional-games/voice-build.json) に収録している。[Irodori-TTS](https://github.com/Aratako/Irodori-TTS) · [Small](https://huggingface.co/Aratako/Irodori-TTS-v4.1-Small) · [Small MF](https://huggingface.co/Aratako/Irodori-TTS-v4.1-Small-MF) · [CPUランタイム](https://github.com/nyosegawa/speech.cpp/releases/tag/v0.11.0)

参照は各本人の `attack-1.ogg` を44.1 kHzモノラルに変換した音源。一部の録音では、本人のトランプゲーム開始・勝利ボイスを連結した参照を使う。Small MFは2〜4ステップ、Smallは16〜24ステップで生成する。「ボム！」に加えて「爆弾です」、「五しです」に加えて「しが五枚です」など、役を伝える台詞も使用する。配信用音声は32 kHzモノラルMP3。効果音とBGMはトランプゲーム集のライブラリを使用している。

## 検証

`node scripts/test-traditional-games.mjs` で13ルール・44通りの席数構成のCPU対局完走、特殊ルール、手牌の非公開、手番と更新番号の検証、156音源のハッシュと再生時間上限を確認する。

`node scripts/test-flight-school-results-browser.mjs` で入力を保持したフライト終了と、結果画面からの折り返し・再挑戦・選択画面への復帰を確認する。`--webkit` でWebKitを使用できる。

`node scripts/test-traditional-pull-browser.mjs` でクロキノールの引いて離す発射、キャンセル、円盤アニメーション、手駒の配色、ごいたの対面配置を確認する。

オンライン参加はトランプゲーム集と同じプロフィール入力画面を共用する。招待URLを開くと参加画面へ直接進み、URLの貼り付けにも対応する。ホストは部屋を作ってからゲームと席数を選び、参加者は待合室で開始を待つ。
