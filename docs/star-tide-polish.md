# 星潮の航路：戦闘・探索・出会いの更新（2026-11-03）

## 戦闘

8武器それぞれの3連撃に、ため技・回避反撃・空中技を追加。通常24動作＋新規24技を使い分ける。既存のスプライトフレームを組み替え、武器の動き、円弧・軌跡・着地波紋を重ねる。

- A / B：装備した武器の3連撃。回避後0.8秒以内なら反撃に変わる。
- A / B：0.5秒長押しすると、そのボタンの装備武器で大技が一度発動。短押しは通常攻撃。C / RBは従来の押して放すショートカットとしても使用できる。スタミナ0.45消費（盾は通常の0.3も必要）。被弾・回避・防御・手帳・画面の非表示でためを解除する。
- 敵の予備動作終盤や至近の飛び道具に合わせた回避では、反撃猶予が1.4秒になる。
- 滑空中のA / Bは空中技。安全な地面では着地し、水上では滑空を維持する。
- 剣・槌・盾のため技と近接空中技は周囲にも当たる。遠隔のため技は5方向へ、盾のため技は近くの敵弾を反射する。
- 回避では効果音・アクションボイスを再生しない。大技は既存の武器効果音を使用する。

## 地図と仕掛け

常時ミニマップは24区画を実際の6列×4行の接続位置で表示。現在地、訪問、戦闘クリア、仕掛け攻略、入手した星灯の鍵を示す。押すと手帳の拡大地図を開く。海図入手前の未訪問区画は伏せ、隠し採集地は表示しない。

各章13種類の仕掛けを1回ずつ配置。残りは探索、住民、戦闘、ボスの区画とする。

## 出会い

`encounterFor`をフィールド、会話、名前、本文、音声IDの共通定義にする。区画の剰余で無関係なNPCを表示する処理を撤去。人物のフィールド表示は会話と同じ表情シートの通常表情を使用する。語りで記録を読む場所は石碑、ナギ自身の台詞は記憶の投影として配置する。既存の音声・台詞の組み合わせを維持する。

## ARPG拡張：成長と手触り

- Q / 右スティック押し込みで敵に注目して移動射撃。再入力で対象切替・解除。回避は移動入力の方向を優先する。
- Shift / LB / 防御ボタンの長押しで前方を防御。構えて0.18秒以内の命中はジャストガードになり、被害を防いで敵弾を反射し、反撃猶予と必殺ゲージを得る。通常防御はスタミナ0.25を使って被害を4分の1にする。背後は防げない。
- 命中・ジャストガード・見切りでゲージをため、V / LTで「星潮解放」。周囲への一撃、6秒間の攻撃力1.5倍・スタミナ回復増加。星の護符2個で8秒になる。
- 与ダメージ数値、会心、炎上、連鎖雷、短いヒットストップ、対応ゲームパッドの軽い振動。画面全体の点滅・強制的なカメラ揺れは使わない。
- 戦闘・仕掛け・依頼の経験値によるレベルと成長点。剣・風・心の3系統・9スキルを選び、いつでも無料で振り直す。既存セーブは過去の戦闘・依頼から経験値を補う。
- 12種類の護符を2枠に装備。3段階強化、数値効果と炎上・連鎖の強化、3系統の2個セット効果。初めの2個は自動装備。区画3・8・11・15・19・23の宝箱と任意試練で入手し、重複は星粉として強化に使う。
- 区画18の強敵討伐、区画22の三連戦。通常戦闘後の祭壇から何度でも再挑戦でき、護符・追加星粉の達成報酬は各周回に一度。撃破経験値・魔物図鑑と最速タイムを記録。退却時に装備や成長を失わない。
- 魔物24種の撃破図鑑。物語重視・航海士・英雄の3難易度を随時切替でき、敵の残り体力率を保って反映する。
- エンディング後も「冒険を続ける」で未探索や試練を攻略できる。手帳の成長→冒険記録からエンディングや周回の選択へ戻れる。
- エンディング後の「強くてニュー航海」。確認後に章攻略をリセットし、道具・護符・強化・料理・成長・図鑑を引き継ぐ。周回ごとに敵の体力と経験値が増える。序盤から滑空を使用できる。

`progression.ts`に追加セーブの検証・補完と装備効果を集約。試練中の敵配置・一時的な必殺状態は再入場で終了し、恒久的な成長・達成報酬は保存する。学習休憩の発生条件は維持する。

ImageGenで護符12種と効果8種・操作アイコン16種、Blender 4.3.2 / Cycles CPUで祭壇3種を新規制作。原画・`.blend`・生成スクリプト・ハッシュ・並び順を`assets/star-tide/arpg/`に保存。`scripts/star-tide/pack-arpg-art.mjs`で等間隔・透明余白・同じ基準サイズのWebPアトラスへ正規化する。操作アイコンを含む実行時の追加画像は約410KB。WebとAndroidのアセット一覧へ登録する。

追加検証：`test-star-tide-arpg.mjs`は装備・成長・ガード・反射・注目・必殺・炎上・連鎖・難易度・全24試練の実戦・報酬の重複防止・周回・画像の透明な外周と登録を検証する。`test-star-tide-arpg-browser.mjs`は実入力で成長・護符・戦闘・試練報酬・周回移行を行い、縦横と英語画面を保存する。


## 2026-11-03：操作をアクションアイコンへ統一

防御・注目・星潮解放を体力HUDからA/B近くへ移し、回避・滑空と一つの操作群にまとめる。独立した「ため」ボタンは撤去。ナギの武器8種・回避・防御・注目・必殺・滑空・調べる・手帳・地図の16枚をImageGenで制作し、透明な余白を付けた4×4アトラスにまとめる。元絵・並び順・ハッシュは既存の`assets/star-tide/arpg/`に保存する。

A/Bは装備中の武器アイコンを表示し、近くで話す・調べる場面ではAが手のアイコンに変わる。文字ラベルとA/Bの印を残し、長押し進行と必殺ゲージはボタンの円周に示す。キーボードの補助表示はPCに限定する。

タッチ・キーボードのZ/X・ゲームパッドのA/Bで、短押しの3連撃と0.5秒長押しの大技を使い分ける。長押し中に一度自動発動し、離した時に二重発動しない。攻撃中の短押しは次の連撃を予約できる。長押しは現在の攻撃の終了後に発動する。別の指や古いキーの解放、メニュー・被弾・回避・防御・装備変更・移動先への切替で、意図しない遅延攻撃が出ないようにする。移動パッドの指を離す処理は武器操作を中断しない。

`test-star-tide-controls.mjs`は全8武器×A/B、連撃予約、長押し・入力の所有者・キャンセルを検証する。`test-star-tide-controls-browser.mjs`は実タッチの2本指、ポインター、キーボード、ゲームパッド、会話の維持、320pxからの縦横画面、44px以上の操作範囲、ラベル、iOSの余白と英語表示を確認する。画面は`tmp/star-tide/controls/`へ保存する。
