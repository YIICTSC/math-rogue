# ひらがな読み・空島タッチ操作の精査（2026-10-14）

## 実装

- 空島の移動スティックとアクションを指IDごとに管理。ジャンプ・アタックはタッチ開始で受付。アクションの指を離しても移動を継続し、移動の指だけがスティックを解除する。
- ダッシュ・急降下は指ごとの保持状態で管理。二段ジャンプ、キャンセル、ポインター捕捉解除、ウィンドウ非アクティブ時の解除を検査。
- 翻訳は確認済みの語・活用形、文全体の訳を優先。旧辞書を順々に置換して熟語を分解する方式から、元の文に対する最長一致の一回の置換へ変更。
- 未登録の熟語内の単字を推測した読みで埋めない。残った漢字は監査で検出する。
- 「3分の1」の **ぶん**、「40分」の **ふん**、時刻の「9時」の **じ**、数量の「2人分」の **ぶん** を元の文から区別。
- 板書のひらがな表示も元の文を使い、学年別の部分変換を経由しない。「分の→ぶんの」という汎用置換を削除。実際の板書コンポーネントをレンダリングし、同じ画面内で時刻と分数が正しく読めることを検査。
- 自動生成辞書は単字変換済みの文を入力にせず、元の日本語と確認済みの語彙から生成。誤った中間文を入力した回帰テストを追加。

## 調査範囲と結果の意味

全TS/TSXを抽出し、初回48,965種類の文字列を検査候補にした。漢字そのものを問う教材を破壊しないため `src/data/subjects/` は除外した。この広い抽出には識別子、翻訳辞書のキー、他言語用データ、各ゲーム専用の翻訳経路を持つ文言も含まれる。共通 `trans` の結果に漢字が残る件数は、実画面の未翻訳件数ではない。

全量抽出の形態素解析で得た読みの差は誤りの確定ではない。候補を確認し、「手札→しゅさつ」「割る→われる」「預ける→あづける」など機械側の誤りは採用しなかった。「戦闘→バトル」「消費→つかう」など既存の子供向けの言い換えも保持した。

共有・ゲーム専用の辞書は31ファイル、22,180項目を、確認済みの誤読82系統に照合。既存の35項目を修正し、46件の文単位の訳と177語の確認済み語彙を追加した。例：長押し、分かる、数える、上がる、主人公、周回数、声質、八ツ橋、くじ引き。

監査対象のUI・カード・敵・アイテム・ランキング・動的ログは既存のひらがな監査で確認し、表示文・NPC質問セットも別の表示コピー監査で検査。任意の未知の固有名詞やユーザー入力の正しい読みを保証する仕組みではない。抽出した全文章を人手で逐語校正したという意味でもない。

## 再検査

```powershell
pnpm run audit:hiragana
pnpm run audit:hiragana:corpus
pnpm run test:sky-touch
pnpm run build
pnpm run server:build
```

- `audit:hiragana` はUI検査・辞書検査・語と長文の読みテスト・辞書生成テストをまとめて実施する。
- `audit:hiragana:corpus` は全量調査用。`tmp/hiragana-all-review.json` と `tmp/hiragana-reading-candidates.tsv` に比較結果を保存し、人の確認が必要な候補を残す。自動的に訳を書き換えない。
- タッチテストは実際のゲームシミュレーションで移動とジャンプを同時入力し、位置・高さ・二段ジャンプを確認する。
- 型チェックは既存と同じ475件のエラーが残る。変更した翻訳・空島モジュールには新規エラーなし。

検証結果：`audit:hiragana`、177語・46文と動的ログの回帰テスト、辞書生成テスト、移動中のジャンプのシミュレーション、`pnpm run build`、`pnpm run server:build` は成功。ビルドには既存の大きなチャンクの警告がある。
