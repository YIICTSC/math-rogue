## 2. 実装上の画像対応

現在の表示は1イベント1ファイルではなく、9イベントを1枚にまとめた正方形シートを使用する。

```text
public/sprites/magic/events/endless/character-sheets/MGE-001-009.webp
...
public/sprites/magic/events/endless/character-sheets/MGE-082-090.webp

public/sprites/magic/events/endless/character-sheets/MGEM-001-009.webp
...
public/sprites/magic/events/endless/character-sheets/MGEM-082-090.webp
```

セルは左上から右へ進む行優先で割り当てる。

```text
1  2  3
4  5  6
7  8  9
```

例: `MGE-010` は `MGE-010-018.webp` の左上、`MGE-018` は右下になる。`MGEM` も同じ規則を使う。

## 6. 結果文の整合性

### 6.1 現在の表示

通常選択は次の形式で表示する。

```text
イベントタイトル「選択肢」：実際に適用した効果。
```

学習判定を含む選択は次の形式になる。

```text
イベントタイトル「選択肢」：学習判定：成功／失敗。実際に適用した効果。
```

このため、どの選択肢の結果かを結果画面だけで判別できる。

### 6.2 今回確認した結果文の補正

効果処理は次の実値を表示するようにする。

| 効果 | 結果文 |
|---|---|
| HP回復 | 最大HPで切り詰めた後の実回復量を表示。満タンなら「HPはすでに最大だった」。 |
| HP減少 | HPを1未満にしない処理後の実減少量を表示。これ以上減らせない場合も明示。 |
| カード獲得 | 成功時「カードを1枚得た」。候補なしの場合も理由を表示。 |
| カード強化 | 強化できた場合と、対象カードなしの場合を分けて表示。 |
| 呪い除去 | 除去できた場合と、対象呪いなしの場合を分けて表示。 |
| ゴールド・追加ドロー・最大HP・記録値 | 実際に適用する数値と結果文の数値を一致させる。 |

現仕様では各選択肢に物語上の「その後」を表す独立した結果文章フィールドは持たず、導入本文＋選択肢＋ゲーム効果の結果を表示する構造である。今回の監査範囲では、この機械的結果文と実効果の矛盾は解消している。将来、選択後の短い物語文を追加する場合は、`resultText` のような専用フィールドを各選択肢へ追加し、効果メッセージとは分離して管理する。
