# 星潮の航路：料理と探索の更新

ミニゲーム一覧はダンジョンズ2の直後、4000問解放を維持する。

料理は12種類。ImageGen生成の4×3原画から個別WebPを作成し、全料理に専用画像を割り当てる。原画と順序・ハッシュは assets/star-tide/food-art.json に保存。

新しい料理は dishes に料理IDごとに保存し、野営地以外でも手帳から使用できる。古い meal/tonic ストックはそのまま保持する。料理時に即回復しない。個数上限は各999。体力・スタミナ回復に加え、移動＋20％、攻撃＋30％、被ダメージ半減の料理を導入。強化は120秒、最後に食べた1種類が有効。セーブと再読込に対応する。

屋外同士の有効な接続辺は壁を除き、横断位置を保って移動する。屋内の狭い入口や非接続辺の壁は維持し、壁手前の判定で勝手に隣へ移動しないよう修正。

謎解きパーツには背景色付き番号と金色の輪郭を、木や主人公の描画後に重ねる。周囲の大型装飾を透過して手掛かりを見やすくする。

追加ギミックは料理による時間制の能力強化と、草地への延焼。炎は上下左右の草地へ広がり、敵へのダメージと既存の上昇気流を活用できる。最大32個に制限し、雨で消える。燃えた草地は既存の地形変更セーブに保存する。

検証: test-star-tide-food-borders.mjs、test-star-tide-wild.mjs、test-star-tide-food-browser.mjs、通常ビルド・英語監査・サーバービルド。
